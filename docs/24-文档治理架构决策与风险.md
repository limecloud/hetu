# 文档治理、架构决策与风险

产品范围由[01](01-产品需求PRD.md)维护，阶段退出条件由[20](20-实施路线与里程碑.md)维护，外部来源与适用边界由[research](research/README.md)维护。

## 1. 文档与合同治理

每项事实只有一个维护位置，其他章节通过链接引用。产品需求使用 FR，故事使用 US，用例使用 UC，贯通旅程使用 E2E；新增范围同步对应验收，不通过复制表格制造不同结论。

正式实现阶段 `contracts/` 拥有机器 Schema、工具和正负夹具。Markdown 示例是说明或设计样例，迁入正式合同时由真实校验器验证；生成类型、帮助、文案及设计资源不可手工改生成副本。

设计文档定义稳定的需求、边界和验收合同。实现进度、测试执行结果、排查记录与会议讨论进入对应工程记录，不混入规范正文。需求变更须更新拥有该事实的文档及引用，不保留过时结论或对话过程。

## 2. ADR 摘要

| ID | 决定 | 理由与限制 |
| --- | --- | --- |
| ADR-01 | 核心无模型与生成 API | 本地工程化为主体，外部 Agent 可选 |
| ADR-02 | 共享 C++20 Core 与 C ABI | 复用规则、版本与存储，付出跨语言构建和 ABI 测试成本 |
| ADR-03 | SwiftUI/AppKit + WinUI 3 | 原生编辑和系统集成；双端 UI 分别开发验收 |
| ADR-04 | 跨平台 Swift CLI 薄入口 | 共用命令编排与 macOS 桥接，Windows runtime／TTY 为 M0 门槛 |
| ADR-05 | 源码与 IP 内容工作区分离 | 软件开源不导致作者内容自动开源 |
| ADR-06 | 文件为正文事实，数据库仅可重建索引 | Git 和可读性优先，不否认 SQLite 的价值与可靠性 |
| ADR-07 | Agent 仅草稿，设定集与定稿归作者 | 受管入口强制，不宣称能阻止同用户任意文件写入 |
| ADR-08 | stdio MCP 独立进程 | 无本机 HTTP 服务前提，生命周期由宿主管理，操作记录持久化 |
| ADR-09 | AXI 0.2.1 作为设计采用基线 | 复用任务、回执与恢复；草案非行业认证，无运行依赖 |
| ADR-10 | 小说 Markdown、剧本 Fountain、profile 导出 | 可编辑源与外部交付分开；中文互操作需验证 |
| ADR-11 | Codex 接入与多媒体插件分开 | 方法／连接不承担生成服务，商业插件独立授权和收费 |

## 3. 技术准入与变更约束

| 事项 | 准入门槛 | 约束 |
| --- | --- | --- |
| 工具链精确版本 | 双端 C++／Swift／WinUI 最小原型 | 版本和依赖必须可复现 |
| C++ MCP 库或协议适配 | 规范、维护与许可、宿主测试 | 不声称官方 C++ SDK 已可用 |
| legacy MCP 支持 | 目标 Codex／WorkBuddy 版本真实能力 | 仅声明已验收协议组合 |
| macOS sandbox | 桌面与独立 stdio 权限原型 | 不假定权限跨进程继承 |
| 编辑器与格式转换库 | 中文、大文档、跨平台、许可与回环 | 不保证任意富文本无损 |
| Intel／ARM64 扩展 | 对应 native 依赖与实机证据 | 不纳入 V1 默认支持范围 |
| Apps 直接批准 | 可验证人类交互与可信身份机制 | 只提交意图，回到原生批准 |

## 4. 风险与处理

| 风险 | 影响 | 应对与触发条件 |
| --- | --- | --- |
| 中文自由文本提取覆盖有限 | 作者期待自动理解全部 OOC | 明示候选、未知与覆盖，独立标注集评测 |
| Swift Windows 依赖／runtime 分发 | CLI 看似通用但用户不能启动 | M0 先验干净 Windows，再扩命令 |
| C++ 解析与 ABI 内存错误 | 崩溃、越界或数据损坏 | 小边界、模糊测试、sanitizer、所有权和错误检查 |
| 多文件与 Git 并发 | 丢改动或混合版本 | 进程锁、CAS、恢复日志和原 index 保护 |
| 宿主与插件规范变动 | 安装／工具／UI 不一致 | 冻结来源、制品与兼容矩阵 |
| 格式转换损失 | 对白、分页或批注丢失 | 导入预览、转换报告、独立阅读器与渲染 |
| 团队锁被误解为权限控制 | 未授权者改写内容 | 明确本地范围，V1 不声称团队 ACL |
| 素材版权／秘密外发 | 交付或供应商风险 | 权利元数据、最少外发、作者确认、凭据隔离 |
