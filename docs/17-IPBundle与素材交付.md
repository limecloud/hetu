# IP Bundle 与素材交付

Bundle 是可核验的文件包，包含固定内容、版本、诊断与来源声明。

## 1. 交付内容

```text
hetu-bundle-<bundle_id>.zip
  manifest.json
  shared/blueprint.json
  novel/                         # 选定章节的确切修订
  drama/skeletons/
  drama/scripts/                 # 默认仅批准剧本
  reading/                       # 分别合并小说／剧本的 DOCX、PDF 或 TXT 阅读稿与转换报告
  reports/                       # 一致性、影视化与改编差异
  cues/music/
  cues/visual/
  assets/                        # 明确选择且允许交付的媒体
  provenance/version-log.json
  provenance/reviews.json
  DELIVERY.md                    # 包内阅读说明，由 manifest 投影
```

Bundle 的 `DELIVERY.md` 属于用户导出产物，不是软件仓库新增的根级文档。它描述所选内容、版本、未覆盖项及权利说明，不能宣称未经验证的行业统一标准。

## 2. 导出配置

默认 profile 为 `production_delivery`：选择完整设定集、选定原著、选定骨架与已定稿剧本、相关报告、线索和版本记录。草稿、被驳回版本、内部批注、Token、系统路径、缓存、Git 对象库、恢复日志一律不默认导出。

定稿以作者独立确认的 FinalizationRecord 及固定正文修订为依据，不从 AI 参考稿通过或已采纳状态推断。默认排除完整 Prompt、未采用建书候选、外部结果 inbox、Apps／网页临时数据和配对材料；所选正文可携带必要的采纳来源摘要。审阅包允许选择作者尚未定稿的写作修订；参考稿证据不能冒充作者正文参与选集。导出不触发阅读平台发稿或自动发送。

可选 `review_delivery` 允许待审内容，但必须显著标记状态并由作者额外确认。默认导出不依赖 Git 仓库存在、远端在线或 Agent 已安装。

媒体文件权利状态为 `author_owned|licensed|reference_only|unknown`。只嵌入作者拥有或有明确授权且可再分发的文件；未知／仅参考内容导出元数据和排除原因。当前没有绕过权利限制的导出开关，不把软件校验当法律授权。

## 3. manifest 合同

| 字段 | 内容 |
| --- | --- |
| `schema_version, bundle_id, profile, created_at` | 包格式、身份和导出信息 |
| `workspace_id, title` | 内容项目身份 |
| `inputs` | 设定集、文档、骨架、报告、审核的确切版本和摘要 |
| `files` | 相对路径、字节数、SHA-256、媒体类型、来源对象及审核／权利状态 |
| `provenance` | 软件构建标识、规则版本、可选 Git commit、dirty 状态 |
| `coverage, warnings, exclusions` | 缺失、过期、未确认项与未嵌入材料 |

`files` 只列 payload，不包含 manifest 自身，避免自摘要循环。完成后另返回 ZIP 的字节数与摘要；如需外部校验文件，作为同目录 sidecar 创建，不嵌入自身引用。

## 4. 导出执行

1. 作者选择章节、骨架、剧本、报告、线索和素材，系统显示导出预览。
2. 校验定稿资格、证据新鲜度、来源存在性和媒体权利状态，说明阻断／警告／排除。
3. 冻结输入清单和摘要，取得一致性快照；长时间压缩不持续阻塞编辑写锁。
4. 从固定修订读取数据，在 `.hetu/deliveries/delivery_<UUIDv4>/artifact.tmp` 生成包；任何输入摘要不符立即停止。每次交付持有独立文件锁，压缩期间释放工作区写锁。
5. 重新读包校验路径、数量、长度及各文件摘要；发布前重新核验授权及选中定稿、素材权利未被撤回，通过独占硬链接发布到 `exports/`，同步目录后解除临时链接。
6. 返回导出结果与排除清单，不覆盖同名历史包，不自动上传或发送给他人。

源文变化后旧报告不得伪装为最新。需要的报告缺失时先执行或要求选择作者批准的带缺口交付；完整性损坏不能通过“忽略警告”导出。

冻结计划固定所有内容输入。压缩期间作者保存新写作修订时，本次导出继续使用选中的历史定稿，不静默改用最新稿；发布前定稿确认或素材权利已撤回，则停止发布并请求作者重新预览，不能使用旧许可绕过当前撤回。已发布包保持原 manifest，不随作品后续编辑改变。

导出产物与原操作回执采用可恢复的发布步骤；即使文件已发布，也能在崩溃后核对原输入、实际包摘要和原键。`.hetu/deliveries/` 保存固定意图、发布前产物摘要和回执；大文件不进入通用 JSON 事务日志。成功回执丢失时返回原产物，不以新 bundle ID 重复导出。导入和交付的时序分别见[23第29节](23-业务流程与MCP时序.md#29-小说与剧本导入时序)、[第30节](23-业务流程与MCP时序.md#30-固定版本交付与回执时序)。

Core 动作采用先 `hetu.bundles.preview`、再由作者传回完整预览及非空 `acknowledgement` 执行 `hetu.bundles.export` 的合同；原键恢复先于重新检查当前写作修订。阅读稿默认选择 DOCX 与 PDF，可显式选 TXT 或空数组。Markdown／Fountain 源交付经过非打印注释过滤；源修订摘要、导出字节摘要及过滤报告分别保留，不把过滤后的文件摘要冒充原稿摘要。

当前预算为正文选集合计 16 MiB、展开总量 4 GiB、单项 2 GiB、10,000 个 ZIP 条目、manifest 16 MiB、内存文本与转换产物合计 256 MiB。核验在解析目录前检查目录预算，并拒绝重复路径、绝对路径、跳转、反斜杠、链接、隐藏／重叠条目、未列入清单的文件及局部头与中央目录不一致；不向文件系统解压。

## 5. 素材与线索

乐律线索保存情绪、场次、节拍／风格说明及音乐文件引用；视觉线索保存人物、场景、造型、构图说明及图片引用。线索描述是作者／Agent 提供的内容，核心只组织和校验引用。

素材元数据包括 `asset_id, sha256, media_type, size_bytes, source_type, source_uri?, creator_statement?, rights_status, narrative_refs`。外部服务来源可以保留供应商任务 ID 与安全参数投影，生成来源由供应商／调用方声明，不能伪装为河图洛书验证过的事实。

大文件导入先复制到受管 staging、核对类型与摘要，再登记；不自动跟随 URL 下载，不接收可执行文件作为媒体。外部链接导出前清除凭据、私有签名查询参数和本机绝对路径。

### 5.1 素材登记与权利修订

素材通过作者入口先 `hetu.assets.inspect`、再 `hetu.assets.import`，后者绑定预览的文件字节数与 SHA-256。支持 PNG、JPEG、GIF、WebP、WAV、FLAC、MP3、Ogg 音频、M4A、MP4、MOV；依据文件签名识别类型，`validation=signature_only` 不声明完整解码或安全扫描通过。单文件上限 2 GiB，使用固定 256 KiB 缓冲流式读取和复制，超过限额明确拒绝。

媒体原字节保存在所属包 `assets/<asset_id>/source.<extension>`。元数据采用 `asset.json` 当前索引与 `revisions/<revision>.json` 不可变历史，修订通过前一条原始字节摘要连接。原文件名保留，作者选定的本机绝对路径不进入公共素材记录。未完成登记的孤立文件不出现在素材列表；登记、操作回执与审计使用共同事务公开。

来源类别为 `author_supplied|third_party|external_agent`，均为提供方声明。公开来源地址只接受不含凭据、查询参数及片段的 HTTP(S) 页面，不进行下载。权利状态与 `redistribution_allowed` 分开：只有 `author_owned|licensed` 且填写非空再分发依据才能设置允许；`reference_only|unknown` 必须为 false。修改权利使用当前修订与元数据摘要 CAS，旧修订不能绕过当前的权利撤回。

### 5.2 乐律与视觉线索

线索采用 `cues/<cue_id>/cue.json` 当前索引与不可变修订。作者填写名称、情绪／画面说明、类别，选择已保存正文中的原文选区，并关联素材的确切元数据修订与摘要。引用须满足固定正文 UTF-8 边界及引句一致，不接受虚构引文、重复素材或跨类别素材；正文变化只标记来源过期。

素材说明或权利更新不静默替换线索中的引用；界面显示过期并允许作者选择引用当前修订。线索可归档和恢复，通过新修订保留历史。Agent 可读取已登记的线索与素材，直接写入和本机路径检查仅对作者开放；Agent 提交材料仍走草稿入口。分页游标绑定工作区、身份、筛选与当前列表，列表变化后重新查询。

## 6. 接收方核验

接收方无需安装河图洛书即可解压阅读 Markdown／Fountain／JSON 和常规媒体。已有作品中的包可通过 `hetu --workspace <作品目录> bundle verify <bundle_id>` 核验，CLI 保持 Agent 身份，只读取该作品登记的受管包；不要求作者授权，也不接受任意本机路径。该检查不证明来源声明真实或材料具有版权。

剧本源格式为 Fountain，并随交付 profile 提供 DOCX／PDF 阅读稿；小说可提供 TXT／DOCX。转换版本、profile、损失报告与产物摘要进入 manifest。格式约束以[25](25-小说与剧本标准格式.md)为准，不能只给制片方一份私有 JSON 就宣称标准剧本交付。

相同输入可生成相同的 payload 摘要集合；ZIP 时间戳、导出 ID 和 manifest 创建时刻可能不同，V1 不声称整个压缩包逐字节可复现。导入 ZIP 回写工作区不属于 V1 必需能力，未来启用前必须增加解压限额、路径与覆盖保护。
