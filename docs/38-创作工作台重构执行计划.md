# 创作工作台重构执行计划

本计划用于跟进创作库、小说、剧本与视频全生命周期重构，覆盖产品文档、官网、使用指南、博客、Core、Skills、MCP、CLI、桌面呈现和真实 Codex 验收。设计依据为[37](37-创作库与小说剧本视频设计.md)，需求见[01](01-产品需求PRD.md)，验收规则见[19](19-测试策略与验收矩阵.md)。本文件拥有本轮工作包、依赖和跟进状态；[20](20-实施路线与里程碑.md)保留实现基线、差距及历史证据，避免两处维护同一进度快照。

## 1. 目标与范围

从“小说内附带短剧”改为“创作库中的小说、剧本、视频独立关联”。外部 Codex 等 Agent 通过 Skills + CLI/MCP 筹备、整理、创作、预演、生成、剪辑与回传，作者在河图阅读、观看、发现细节、提意见、比较、取舍及确认。作品内容、固定来源、历史修订与作者决定可持续接续。

本轮到可交付成片和完整工程包为止，包含音画字幕、局部返工、源工程依赖及接收方核验。不包含发布、投放、发布后运营、Windows 实施、移动端、云端协作或桌面三维／多轨制作台。官网更新包含中英文产品表达、使用文档、博客和截图，不扩大为云作品后台建设。

“创作库”是软件总入口；“书库”仅用于小说分类。独立对象不等于强制独立目录或 Git 仓库，不重建已有作品，不因导航改造搬目录、改 ID 或重算历史摘要。修复机器接口和 Skills 是交付的一部分，不能用临时脚本直写受管记录来补验收。

## 2. 跟进规则

| 状态 | 含义与更新条件 |
| --- | --- |
| 待核对 | 尚未对照本轮完整退出条件检查现有实现，不能据此推定缺失或通过 |
| 待实施 | 尚无可审查的完整实现，不推定当前代码必然缺失全部能力 |
| 进行中 | 已开始具体工作，记录涉及路径及完成范围 |
| 待验收 | 已形成同版可运行制品，列出准确机器入口和预期结果 |
| 需修复 | 实际验收失败，保存原请求、结果和复现条件；修复后重验相关步骤 |
| 已验收 | 本项退出条件全部通过，记录版本、制品摘要、调用与界面证据 |
| 阻塞 | 写明缺失入口、权限、工具或依赖，不用其他层测试代替 |

设计更新、代码完成、机器业务通过、界面通过及安装通过分别记录。未执行记 `not_run`，不能由文档、有按钮、截图或夹具推定通过；历史成功仅覆盖原版本和范围。本轮文档任务不构成付费调用、覆盖用户稿件、提交推送或部署授权。

实施时保留现有用户数据及其他改动。每个工作包先核对现有实现，只补缺口；API、Schema、错误、CLI/MCP、Skills 和页面以同一用例交付，禁止长期双写或平行工作流。

每次接续先读本表及关联证据，确定当前工作包和修改范围；结束时更新状态、实际完成范围、失败步骤与下一步，不仅在聊天中报告。待核对的工作包先建立基线，再转为进行中或待验收；不因其他工作包通过而批量关闭。

## 6. Skills、MCP 与 CLI 的交付要求

- Skills 唯一源按筹备／导入、小说、剧本、资产、预演、视频、音画剪辑、审阅返工、交付组织，复用通用定位、授权、固定修订及恢复方法。型号技巧是可核查的能力 profile，不把每个模型或场景复制为整套工作流。
- Skills 中间脚本用于格式辨识、分批、编排和验证，通过公开业务动作提交；不能直写 `.hetu`、替作者批准、静默扩范围或用固定演示文件硬编码成功。
- CLI 与 MCP 使用同一应用用例和权限，发现、准备、执行、查询、反馈及恢复均可机器调用。明确对象、完整任务引用与版本，跨对象读取另获权；稳定连接不绑定全局当前项目。
- 已知目标从精确引用恢复，无作品时从公开筹备入口开始；任务回读必要上下文、已有工作稿、候选和意见。缺能力返回准确错误并修复公共入口，不能让模型猜动作名或改用GUI补链。
- MCP Apps 在已支持宿主中局部观看、比较和写意见；保存、请求继续、消息受理与实际返稿独立取证。无Apps或无消息能力时，复制同一引用继续，数据和操作不另建。
- 视频和外部工程不塞进文本Draft；媒体文件走有界上传／inbox与固定清单，MCP返回必要元数据或受管预览。凭据不进Prompt、参数日志、作品和交付包。
- 方法及分发包从唯一源生成；仓库源、安装插件缓存和App随包内容分别核对版本摘要，不以改完源码证明当前Codex已加载新Skill。

## 7. Codex 侧实际业务验收

主样本使用作者已指定的《持械入宋》及其持久原稿，不重导、不重建以掩盖已有缺陷。使用当前对话实际阅读、规划和创作；现有导入记录、前六集及历史任务先回读，沿原引用继续。另用最小原创剧本／原创视频样本证明没有小说前置；破坏性负例放隔离测试目录。

| 顺序 | Codex实际执行 | 必须回读的证据 |
| --- | --- | --- |
| 1 | 发现随包CLI／MCP及已加载Skills，定位现有作品、项目、任务和导入记录 | 版本、路径、能力修订、准确对象；无GUI或预建任务补入口 |
| 2 | 核对原稿目录、章节范围、导入字节及阅读；逐集打开既有六集 | 原著覆盖、真实稿件、来源、缺项；导入完成不等于改编完成 |
| 3 | 组织全剧改编方案、集序和取舍；完整创作一集并固定提交 | 可读Fountain、场次、人物行动、对白、原著映射、改编例外与连续性 |
| 4 | 整理设定、人物、场景、道具及需要的图片与声音资料 | 固定事实、候选、角色单人图／多视图、场景及道具用途；实际文件与来源 |
| 5 | 固定镜头及资产，生成动态分镜；复杂空间按需白模 | 实际可播预演、时间／空间问题、工程依赖与固定版本 |
| 6 | 回读作者位置意见，沿原任务改稿或改预演并固定新版 | 意见对象、理解、工作修订、旧提交固定、差异和实际返工成果 |
| 7 | 在明确授权和额度内准备并执行代表性真实视频 | 型号模式、输入职责、费用、提供方任务及实际结果；未知沿原计划查询 |
| 8 | 组织所选片段、对白、配乐音效、字幕与剪辑，实际渲染 | 完整解码、真实音轨与字幕、源片段到成片映射、可继续编辑工程 |
| 9 | 按作者意见局部返工，保持无关成果与旧版；准备成片确认 | 固定区间、修复层次、影响范围、独立作者确认；Agent不能自批 |
| 10 | 导出文稿、成片与完整制作工程，接收方离线核验 | 文件清单、摘要、许可／排除、依赖可用、媒体可播与工程可恢复 |
| 11 | 按全剧目录继续制作与核对，逐集记录同一覆盖维度 | 每集文本、设定／资产、预演、视频、声音、返工及交付覆盖；缺项明列 |

必须覆盖两作品隔离、同根不同对象越权、源修订变化、未保存正文、CAS冲突、空作者稿有参考稿、迟到结果、撤权、断线、相同原键和未知费用。作者的采纳、定稿及成片确认用实际可信通道；隔离作者夹具只能证明合同，不代替本对话的真实创作和真实宿主决定验收。

## 8. 桌面端渲染与交互验收

Computer Use 只执行本节及安装后界面检查，业务准备由前一节的同一机器旅程产生，不另造假界面数据。CUA 不可用时保留工具错误；可使用系统辅助功能操作及真实窗口截图核对可观察的交互，逐项标明覆盖范围。缺少实际交互或渲染证据的项目仍记未验收，不能用编译或模型测试代替。

| 工作面 | 必查内容 |
| --- | --- |
| 创作库 | 混合类型筛选、最近更新、真实状态、待审和关联往返；三种类型不都画成书封；无跨作品内容闪现 |
| 小说 | 中文卷章、完整正文、定位及输入法；历史／参考稿／作者稿／定稿区分，光标、滚动、撤销与未保存缓冲保留 |
| 剧本 | 既有六集逐一打开，真实参考稿可读，场景／动作／人物／对白有层次；计划不抢阅读区，原著对照可定位 |
| 视频 | 分镜／预演／片段／成片视图可区分；实际视频、声音、字幕、连续播放、暂停、定位和版本比较；竖横画幅等比 |
