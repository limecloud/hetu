# 设定集与规则规范

唯一正典为 `shared/blueprint.json`；草稿、提取结果与外部知识都不能自动成为正典。

## 1. 设定集结构

| 字段 | 说明 | 校验 |
| --- | --- | --- |
| `schema_version, blueprint_id, revision` | 格式、稳定身份、修订 | 必填，不能由 Agent 更换身份 |
| `lock` | `locked, changed_at, actor_ref, reason` | 只允许作者确认的入口变更 |
| `characters` | 名称、别名、简介、性格描述、明确事实与有效期 | ID 唯一，别名允许歧义但必须可区分 |
| `factions` | 势力、组织、关系 | 引用存在，角色归属可随时间变化 |
| `locations` | 地点、父地点、内外景属性 | 父子无环，未知属性保留 `unknown` |
| `timeline` | 历法、事件、先后关系、时间区间 | 区分故事时间与叙述顺序 |
| `world` | 世界观说明及条目 | 文字说明不自动成为可执行规则 |
| `rules` | 可执行约束与解释文本 | 有版本、范围、严重级别、证据需求 |

角色事实采用 `fact_id, subject_ref, predicate, value, valid_from, valid_to?, source_refs`。`subject_ref` 必须是所属角色；`valid_from` 为必需的事件引用，`valid_to` 为可选截止事件，有效期采用包含起点、不包含终点的区间。身份 `identity` 为非空字符串，唯一归属 `primary_faction` 引用势力，生存状态 `life_state` 为 `alive|dead`，年龄 `age` 为非负整数；未知值以缺少已确认事实表达，不填造确定状态。

事件的 `before_refs` 表示当前事件早于所列事件，`after_refs` 表示当前事件晚于所列事件。可选 `time_anchor` 包含作者命名的 `calendar` 与整数 `tick`；同一历法可比较刻度，相同刻度表示同时，不同历法不自动换算。明确先后、刻度与事实区间联合检查循环。只有能够证明时段重叠的同谓词异值事实才阻止保存；无法比较的时间关系保留未知。

设定集与输入结构以 [Blueprint Schema](../contracts/schemas/blueprint.schema.json)、[预览 Schema](../contracts/schemas/blueprint-preview-input.schema.json) 和[保存 Schema](../contracts/schemas/blueprint-save-input.schema.json) 为准。Schema 资源通过内存注册解析，校验不发网络请求。V1 不解析任意自然语言规则为可执行代码。

## 2. 规则类型

| 类型 | 可执行输入 | 结论边界 |
| --- | --- | --- |
| `required_reference` | 节点中的人物／地点引用 | 检查实体存在，不判断场景合理性 |
| `fact_equals` | 作者确认的节点断言与时间范围 | 同一时段、同一谓词冲突才确定报错 |
| `event_precedes` | 明确事件 ID 与先后边 | 检测矛盾边或环，不把章节顺序当时间 |
| `forbidden_term` | 明确词形、范围、例外 | 标记字面命中，引用和反讽不自动定性 |
| `world_constraint` | 受限结构谓词，如某区域禁止某类能力 | 只有结构化前提完整才可判定违背 |
| `advisory` | 性格、动机、影视化等文字说明 | 供作者／Agent 参考，不能返回确定通过 |

每条规则包含 `rule_id, revision, type, scope, severity, parameters, rationale`。严重级别为 `error|warning|info`，确定性另用 certainty 表达；警告数量不能代替语义置信度。禁止规则嵌入脚本、Shell、正则灾难回溯或可执行表达式；确需匹配模式时采用有界实现与长度限制。

`scope` 包含非空 `packages`、`document_ids` 与 `entity_refs`；后两者为空时覆盖相应包的全部对象，多个非空筛选条件同时满足才适用。`exception_policy` 为 `author_review|none`。规则初始修订为 1，作者提交当前规则修订后，由内核分配下一修订。

| 规则 | parameters |
| --- | --- |
| required_reference | 非空 entity_types，取 character／location／faction |
| fact_equals | 非空 predicates，取已声明的四种事实谓词 |
| event_precedes | before_event_id、after_event_id |
| forbidden_term | 非空 terms、case_sensitive、exceptions；均为字面匹配，不执行表达式 |
| world_constraint | location_ref、forbidden_capability；仅对已确认结构前提检查 |
| advisory | 非空 text；保留为作者参考说明 |

## 3. 锁定与编辑

1. 新项目可编辑，设定集表单保存须通过结构和引用校验。
2. 作者点击锁定，预览设定集修订、影响范围与未解决引用问题，确认后保存锁状态。
3. 锁定后受管设定集写入口拒绝修改；作者须显式解锁才能继续编辑。
4. Agent 在锁定与解锁状态下均无设定集写权限，只能提交带原文证据的建议草稿。
5. 作者采纳建议时重新校验证据、去重及引用，在一次设定集事务内合并；并发变更返回冲突。
6. 设定集每次修改，包括锁状态修改，递增修订；报告按依赖重新判断是否过期。

每个修订保存独立内容与摘要记录，可按修订号只读读取。移除仅改变当前设定集合，历史修订仍保留；当前角色事实、势力关系、地点、时序或规则仍有引用时阻止移除。同一事务可先迁移引用再移除实体。归档不改变稳定 ID，已有引用仍可解析。

工作区文件被其他编辑器改写时标记 `externally_modified` 并提示作者审阅，不自动恢复或静默信任。锁是应用合同，不是防篡改加密或文件系统 ACL。

## 4. 人物与地点候选

已知名称和别名按词典匹配，匹配结果保留全部候选。未知人物可利用明确对话标签、称谓和重复专名模式发现；地点可利用场景标题、地点词与作者标注。候选均携带来源片段、识别规则与歧义说明。

作者可选择合并已有实体、新建、忽略或延期；被忽略候选按证据和规则记录，不以全局字符串黑名单抑制其他作品。重名、隐瞒身份、化名及群体称谓不能自动合并。

## 5. 例外与版本

倒叙、梦境、假身份、角色谎言等由节点视角与时间标注表达。作者可对具体 finding 接受例外，必须记录理由及输入版本；例外不会改写原规则或自动适用于未来文本。

新设定集导入先显示新增、修改、删除与引用影响；同名不是覆盖依据。格式升级、批量改名和实体删除先预演，成功后再使依赖报告过期。V1 不提供 Agent 批量改设定集入口。
