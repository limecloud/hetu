# 官网插件宣传图规范

## 目标与位置

作者浏览插件时先看懂它适合什么创作，再决定进入详情。宣传图以具体人物、物件和动作表达专业用途，例如场记核对两条镜头里的信封、音乐剧人物对唱、剧本杀玩家查验角色档案。标题和用途由网页文字承担。

插件目录卡片、详情首屏、首页插件入口和详情分享图使用同一插件的主题插画。实际工作面在详情的成果审阅部分展示；宣传插画不证明软件功能或具体操作已经实现。插件包版本、能力、安装和验收继续由原事实源维护，图片更新不要求重发专业运行包。

## 视觉规则

- 每个插件有独立主体与创作场景，避免把同一本书或同一片山水换色复用。
- 使用纸色、玉色、深绿和少量暖金；通过纸面、墨线和柔和绘画质感保持品牌关联。
- 三比二横幅在卡片尺寸下仍能辨认，主要动作留在画面中央，不依赖细小注释。
- 不生成标题、Logo、按钮、界面或假操作画面；文字、可点击区域和无障碍名称由网页提供。
- 美感、用途辨识和与相邻图片的区分度分别检查；实际点击转化需要使用数据，不能由设计评分推断。

## 来源与制品

[宣传图清单](../../assets/marketing/plugin-artwork.json)保存每图用途、模型、实际提示、原图摘要、尺寸、网页路径、衍生摘要及替代文字。私密凭据不进入清单、日志、版本库或网页。

生成原图保存在本地 `output/imagegen/plugin-marketing/`，网页只发布 `apps/website/public/plugins/illustrations/` 中的WebP。每图按480、960、1440宽度输出独立文件，文件名包含内容摘要，使用响应式选择与延迟加载；详情首屏优先加载，尺寸提前声明以避免布局跳动。清单中的摘要与实际发布字节一致。

## 验收与维护

新增或移除官网插件条目时，同步维护对应宣传图。重绘保留专业包身份和实际工作面来源，核对生成结果后更新图片摘要与清单，不覆盖已发布内容摘要文件的字节。

验收覆盖全部目录条目、中英替代文字、图片解码、主体辨识、手机及桌面布局、键盘进入详情、真实工作面的独立呈现与分享图对应。部署后逐字节核对线上图片及对应构建，记录页面缓存传播的实际结果。实施状态归[主20](../20-实施路线与里程碑.md)，图片来源归上述清单，不复制第二份插件功能清单。
