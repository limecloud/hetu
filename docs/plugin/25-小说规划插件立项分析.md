# 小说规划插件立项分析

## 1. 定位与身份

小说规划是首个独立专业插件，面向整书、卷章、详细剧情、实体关系和伏笔组织。作者表达目标、阅读与取舍，外部Agent生成和执行获权操作，插件提供专业结构与可视化，Core保证共享作品规则。

| 项目 | 定义 |
| --- | --- |
| 仓库 | wordflowlab/hetu-novel-planner |
| 插件ID | org.wordflowlab.novel-planner |
| 中文／英文名 | 小说规划／Novel Planner |
| 首版目标 | 完整专业规划与宿主接续，独立预构建JS/TS包 |
| 技术 | TypeScript、React、esbuild；宿主内部采用Cordis |

首版必须覆盖完整的专业创作旅程。工作包分步实施，专业发布范围及验收以插件仓库11为准，不能在宿主另维护一份简化清单。

## 2. 产品边界

插件拥有规划、备选、详细剧情、计划出场、关系及线索。正式正文、目录、大纲、设定、批准与定稿归宿主；功能可以整合在同一旅程中，但不能复制权威事实或扩大权限。关系图与表服务阅读，不要求作者手动连线。

正常链路为Codex→河图CLI/MCP→插件，Skills按需提供方法。GUI读取同一成果，支持阅读、比较、意见和可选编辑；无窗口机器业务独立验收。本包不内置Agent、聊天、模型循环、账号、支付或独立数据库。

## 3. 当前合同与必需接入

核对依据为packages/plugin-sdk/src/index.ts、packages/plugin-host/src/、core/src/application/extensions.rs及插件20／21。下表区分现有基础与完整首版依赖，不作为新功能运行通过的声明。

| 需求 | 当前基础／缺口 | 完成要求 |
| --- | --- | --- |
| 隔离阅读、卡片、详细剧情与关系图表 | 现有React／Chromium视图可承载 | 插件提供完整工作面与机器等价动作 |
| 专业数据、历史、CAS和原键 | 现有objects及operations入口 | 覆盖四类数据、组合快照及分步恢复 |
| 当前对话发现新增插件 | 现有plugin_access.capabilities/invoke | 重查实际包、权限和能力摘要，不创建Codex插件 |
| 原始专业输入严格重放 | Core目前记录最终save输入 | 补自定义原始输入指纹合同，不以最终成果相同冒充原请求相同 |
| 可信AI交接 | SDK context没有management_ref或发送对话句柄 | 宿主窄桥接携带固定对象、版本、范围与恢复引用，不泄露grant |
| 正式卷章与大纲接续 | 可复用现有目录及outlines用例；缺outline／volume固定来源类型 | 完整映射、差异和独立方案，必要时补来源合同 |
| 实体正式来源与正文统计 | 专业SDK尚无对应类型化桥接 | 明确获权读取、统计版本与不可用状态，不把未知显示为0 |
| 打开正式章节、返回位置 | 现行SDK无类型化导航 | 核对完整作品与文档，不能任意URL或文件路径代理 |
| 外部工作步骤与停止 | 插件不能控制任意外部Agent | 记录请求与确认，未知原键回读，不伪造取消成功 |
| 语言与外观同步 | SDK未定义配置通知 | 提供窄配置合同并验证，不能只凭系统主题CSS宣称完成 |

这些宿主依赖属于完整首版验收门槛。缺失时登记并补合同，不用Computer Use、人工填表或任意Core代理绕过。

## 4. 数据与事务

插件设计分为单一结构聚合、分节点详情、故事网络及工作记录。整书结构的移动和重排在单对象事务内完成；长篇剧情独立保存，经固定引用接入方案，读取旧方案不得自动跟随附件最新头。

详情／网络保存与方案接入分别使用固定输入和原操作键。中断保留待接入成果，正常阅读继续旧快照；不宣称Core已经支持跨对象原子事务。完整导出按固定清单分段，缺包时仍可通用读取所有对象。精确字段、预算与方法只由插件仓库03／04拥有。

source_refs目前可核验同作品work、document、blueprint、asset、cue，未定义outline／volume。物品、规则与正式属性按实际宿主类型接入，不能伪造引用。候选设定与正式设定分开，规划保存不会自动推进正式正文或大纲。

## 5. 实施与发布门槛

先跑通无窗口创建、分节点详情、固定接入、局部返工、原键恢复和完整导出，再整合完整GUI与宿主接续。纵切是开发方法，不是简化首版的发布范围。宿主Cordis专项由主38及插件26跟进，专业功能与验收由独立仓库08跟进。

发布需要机器、MCP、GUI及平台证据一致，覆盖正常、权限、冲突、unknown、待接入与退出。代码可解析、图表可渲染或设计包Schema合法都不表示可执行插件完成。按23／24准备固定制品与目录材料，经明确授权发行及申请收录，不提前标记已上架。
