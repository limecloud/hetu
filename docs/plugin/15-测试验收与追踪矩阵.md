# 测试验收与追踪矩阵

## 1. 验收口径

本章定义未来实施的验收，不记录能力已经通过。主产品验收规范见[19](../19-测试策略与验收矩阵.md)。每次结果绑定源码、制品、包摘要、协议、系统、宿主及任务引用；设计图、编译成功、能安装和真实创作完成分别取证。

业务准备通过 CLI/MCP，GUI 用于真实阅读、观看和交互验收。Computer Use 不补产品缺少的机器入口。没有执行的组合标为 not_run，外部依赖阻塞标为 blocked，不用下层测试代替完整旅程。

## 3. 分层测试

| 层次 | 主要验证 | 证据边界 |
| --- | --- | --- |
| 包与合同 | Schema、资源路径、依赖图、语义修订和许可入口 | 不代表可安装或创作有效 |
| Core | 授权、CAS、原键、事务、修订和跨作品隔离 | 不代表宿主接入已成功 |
| 插件运行 | 注册、调用、超时、崩溃、清理和升级 | 进程隔离不等于 OS 安全沙箱 |
| CLI/MCP | 实际发现、输入输出、无窗口旅程与原任务恢复 | 模拟 stdio 不代表所有真实宿主 |
| 视图 | 双视图一致、焦点、未保存保护、区域意见和降级 | 截图不替代实际动作与数据断言 |
| 媒体与工程 | 解码、时长、音轨、时间映射和工程重开 | API 成功与文件存在不足以通过 |
| 制品与安装 | 同版打包、干净环境、固定包及真实系统权限 | 开发目录可用不代表用户安装可用 |

## 4. 负例与故障注入

桌面准入额外覆盖：标准JSON-RPC 2.0握手与预算；插件页/普通网页无法调用作者preload；切换WorkRef后旧会话失效；TS注册与拖拽缩放不依赖Rust往返；Core基础CLI不启动Node，TS插件动作在无Electron窗口时仍可执行。原生历史通过不转换为Electron证据。

至少覆盖：其他作品的对象 ID；同名人物和重复局部 ID；撤权后的旧视图；自报批准；越界文件与压缩路径；恶意 HTML；超大消息；循环依赖；核心动作冲突；旧 Schema；坏摘要；工作进程崩溃；索引损坏；下载中断；代码切换失败；迁移提交后回退；原响应丢失；提供方结果未知。

每个故障检查当前内容、历史、未保存稿、原操作和外部任务是否仍可解释。恢复不能依赖手工编辑受管文件或删除历史。

## 5. 用户研究与总成本实验

### 5.1 研究对象和任务

覆盖偏重文字的作者、编剧、愿意使用专业工具的导演或视频创作者；另包含未参与内核开发的扩展开发者。先用探索性访谈确认任务，再制定样本量和统计方法，不由小样本推导整体市场规模。

配对任务包括：调整一卷冲突；核对多人物时间关系；修改一个镜头构图并保持站位；比较两版成果；换 Agent 接续；插件卸载后交付。每种任务在等输入、等完成标准下比较临时生成与复用插件路线；动态界面实验再区分“临时生成页面代码”“固定专业组件”“A2UI 组合相同组件”，避免把后两者的复用收益误算为固定页面独有。

### 5.2 记录指标

记录模型实际用量及费率来源、工具运行时间、首个可见内容时间、可操作时间、最终确认时间、作者主动操作、求助、错误与返工。工具和模型未知计费不得按零记录。将插件初次开发、安装和维护摊销单独列出。

A2UI 实验单独记录目录进入上下文的成本、实际推理输入输出、编译后传输体积、结构与数据更新量，以及函数调用是否触发推理。检查普通筛选、已注册函数和播放能否在无模型调用时完成；不能由网络请求数或 JSON 字节数推算 Token。另核对增量更新中的焦点与未保存状态、断流恢复、未知目录降级和跨会话重开。

成果质量由预先定义的完整性、正确性、可修改性、可理解性及来源检查判定；创作品味由作者评价，不混成自动评分。任务质量不相当的样本不能直接比较成本收益。

### 5.3 对假设的判定

H01至H05由01定义。实验结果报告具体任务和样本范围；若自由成果更合适，保留自由路径；若动态组件更有优势，调整工作面组合而保持作品合同。一次工具演示不能支持全体作者使用偏好。

## 6. 性能和规模实验

记录机器、系统、内存压力、包摘要和冷暖缓存；分开测量对象查询、首屏、编辑响应、渲染及长任务。拟议性能预算应在基准机器和代表作品固定后冻结，不把未经测量的数字当已达成 SLA。

规模至少覆盖最小作品、常规作品和明显超出常规的压力数据，包含长中文正文、大量引用、场面图元和实际媒体。UI 卡顿、索引重建、缓存完整性与任务取消单独测量。

首期标题投影按插件20第25节验收：中文与英文子串、类型筛选、快照分页、作品／插件／类型／当前授权隔离，缓存缺失／损坏／过期的显式回退，保存与Schema迁移后的失效，重建前后权威文件一致及不安全路径拒绝。独立CLI和真实MCP互相回读，后台read动作不得主动重建。对象数量、累计扫描字节和缓存预算需分别记录边界样本；小样本通过不外推为规模性能，JSON投影不登记为SQLite或全文检索。
