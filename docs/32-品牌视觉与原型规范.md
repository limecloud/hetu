# 品牌视觉与原型规范

河图的视觉以“作者拥有自己的故事世界”为主题。中文名称为“河图”，英文为 Hetu；中文界面使用“设定集”，英文使用 Story Bible。品牌表达为：**设定有据，创作有序。**

## 1. 品牌角色

吉祥物“小图”是一只玉青色的小龙马：暖玉白的卷轴鬃毛、短圆角、三枚横向金点、墨色眼睛与朱砂印章吊坠。卷轴连接设定与创作，印章表达作者确认；角色保持友善、安静，不使用战斗表情或复杂鳞片。

3D 表面采用柔和陶瓷与黏土质感，保留适度高光和柔影。Logo 与宣传插画共用母图，不对每个场景重新发明角色。母图见[透明 PNG](../assets/brand/mascot-master.png)，展示入口见[品牌与产品设计](../design/index.html)。

## 2. 颜色与文字

| 颜色 | 值 | 用途 |
| --- | --- | --- |
| 玉青 | `#1E6B5E` | 主操作、选中态、品牌文字 |
| 纸白 | `#F8F6EF` | 网站、展示页与图标背景 |
| 墨色 | `#20312B` | 正文与标题 |
| 浅玉 | `#E8F0E9` | 低强调选中与状态背景 |
| 朱砂 | `#CF765A` | 品牌配饰，避免替代危险状态语义 |
| 暖金 | `#AD823C` | 小面积装饰与材质，不作浅底小字 |

产品 UI 使用平台中文无衬线字体；阅读区可采用系统宋体类字体。标题、文案和操作始终使用真实文本，避免把生成图片中的文字当成唯一的可访问内容。英文版共用语义层级，按文本长度调整布局。

## 3. Logo 与跨平台图标

| 资源 | 目录／文件 | 使用规则 |
| --- | --- | --- |
| 透明吉祥物母图 | `assets/brand/mascot-master.png` | 保留 alpha，不以截图或压缩缩略图代替 |
| 应用母图 | `assets/brand/app-icon-1024.png` | 1024 方形、不透明；系统负责 iOS 等平台遮罩 |
| 深色图标 | `assets/brand/app-icon-dark-1024.png` | 深色背景使用，保持角色辨识 |
| Web | `assets/brand/icons/web/` | favicon ICO、16～512 PNG、180 touch icon、192／512 maskable |
| iOS | `assets/brand/icons/ios/` | 40～1024 像素资源，按最终平台资产目录装配 |
| Android | `assets/brand/icons/android/` | mdpi～xxxhdpi 前景、背景、legacy 与单色层分开 |
| macOS | `assets/brand/icons/macos/` | 16～1024，保留系统外观所需留白 |
| Windows | `assets/brand/icons/windows/` | 多尺寸 ICO 与 PNG，安装清单按目标缩放引用 |
| 单色辅标 | `assets/brand/river-seal.svg` | 简化河纹印章，用于单色层；不是吉祥物的矢量重绘 |

小尺寸图标使用同一角色的头部裁切，减少全身细节。Android 自适应与 Web maskable 采用更大安全留白；前景不预烘焙系统圆角。iOS 和 Android 资源属于视觉延展，不构成移动应用的功能范围或上架声明。

最小展示尺寸、透明度、内容裁切和文件摘要以[资源清单](../assets/manifest.json)为准。图标总览见[预览图](../assets/brand/icon-overview.png)。

## 4. 宣传素材

| 资源 | 目的 |
| --- | --- |
| `assets/marketing/hero-workspace.webp` | 主 Hero，留出可排版标题的区域 |
| `assets/marketing/feature-blueprint.webp` | 设定集、角色关联与作者确认 |
| `assets/marketing/feature-drama.webp` | 小说到分集大纲的结构流转 |
| `assets/marketing/feature-review.webp` | 人工审核与可追溯交付 |
| `assets/marketing/brand-merch.webp` | 手办、杯、笔记本、贴纸与徽章视觉 |
| `assets/marketing/social-og.png` | 1200 × 630 社交分享卡 |

PNG 原图与提示词保存在 `output/imagegen/`，网站使用优化后的 WebP。视觉资产来源记录 `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` 请求模型及文件摘要，不保存密钥或带凭据 URL。资产制作工具不属于河图产品的生成接口。

含文字资源按 `zh-CN` 与 `en` 分开交付，英文版使用 `-en` 文件名。英文桌面与网站界面图由对应语言的交互原型／页面导出，来源保存在 `output/design/`；英文移动端概念图保存在 `output/imagegen/prototype-mobile-en.png`。无文字插画共用原图，品牌字标保留品牌身份。英文分享卡与图标总览单独排版，语言切换不得引用另一语言的界面图。

周边图是材质与品牌应用展示，印刷出血、刀模、Pantone、3D 网格及量产打样另按制造流程提供，不能把渲染图直接称为制造源文件。

| 入口 | 内容 |

交互原型可切换章节、编辑与保存页面内修订、切换语言、展示设定锁状态、定位原文、填写返工意见、确认审核与预览交付选择。所有数据只在页面内演示，不连接 MCP、Git、文件系统或生成服务。

HTML 是评审媒介，原生 App 仍按 SwiftUI/AppKit 和 WinUI 3 实现。移动端原型不引入云端账号、实时同步或移动开发承诺。视觉图中的文字和样例不覆盖正式 API、领域不变量或权限合同。

## 6. 资产维护

修改角色身份需统一更新母图、图标、插画与界面示意，不能在单一场景产生不同脸型或配饰。裁切、优化和版式派生不得覆盖原始图；最终资源需核验透明度、实际尺寸、小尺寸辨识与浅暗背景。

官网和原型不引用在线字体或第三方 CDN。宣传文案与功能范围保持一致，不用下载按钮、商店徽章或兼容标志暗示未发布的应用或平台认证。
