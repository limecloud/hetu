# 桌面客户端与插件工作面交互设计

## 以当前作品和目标组织入口

阅读已有作品无需打开终端或建任务。AI入口支持只读查阅、临时讨论和持续修改；草稿请求先表达目标与需保留内容，Agent按需选领域动作。目录、完整成果和反馈可随时进入，不以任务列表或模型表单替代作品。

产品定位与任务分流见[01](01-产品需求PRD.md#1-产品定义)。

## 统一执行模式

本机偏好 `execution_mode` 默认 `auto`，桌面、独立 MCP、CLI 和 Skills 使用同一策略修订。auto 在明确当前工作区直接创建、编辑、整理、导入导出及执行已配置连接器同步；confirm 读取直接完成，写入前将本次固定变更集中确认。对象、来源和任务引用继续用于定位与恢复，不再把逐作品、逐任务或逐动作授权作为默认前置。Core 仍核验 Agent 身份、CAS、事务、幂等、外部副作用和原操作恢复；策略变化使旧确认计划失效。

## 无额外插件的基础工作面

基础小说、剧本与视频工作面随应用提供，不显示安装专业插件的必经步骤。视频分集先呈现实际媒体与用途，再按需查看前版、固定区间意见与交付。作者可连续播放，在任意位置保存意见并交给外部Agent；历史意见固定原版本，不静默迁移。默认内容不展示时间基准、摘要或机器字段表单，技术信息按需展开。插件增强与基础内容共享固定来源；停用后基础工作面继续可用。分层见[39](39-Electron与插件优先重构架构.md#无额外插件的基础产品)。


新工作台采用Electron和插件贡献模型，技术合同见[39](39-Electron与插件优先重构架构.md)。文件路径保留以维持引用。本章定义任务、状态和交互约束；本轮视觉与交互按作者指定的参考软件进行完整复刻，采集和验收合同见[41第2.1节](41-创作与审阅体验迭代方案.md#21-参考编辑器的完整复刻基准)。归档Mac实现保留业务行为对照，不继续冻结旧布局。小说、剧本、视频和专业工具贡献工作面，宿主负责上下文、布局、可信决定和恢复。

桌面内优先通过Codex TUI表达目标并执行，GUI在TUI验收后完善；外部 Codex MCP App 保留。作者在作品旁讨论、阅读、比较、提意见及作必要决定，也可独立手动编辑。Codex 经 Skills + CLI/MCP 完成资料填写和业务准备，界面展示真实成果和状态。小说、原创剧本和改编各自有直接机器入口，不能要求作者先填写建书或任务表单。仅改稿需要固定可改范围；读取上下文、维护参考稿、创建结构、采纳和定稿分别授权。

两端共享用户任务、Web组件和业务语义，遵循各自窗口、快捷键、输入法及辅助功能习惯。界面和内容的语言规则见[31](31-国际化与中文体验.md)。

## 工作台共同布局基准

- 窗口使用中性灰底和52px作品工具栏；侧栏默认280px，分为项目导航与当前作品两层，底部定位点和侧栏菜单切换同一状态。项目层承载作品功能与插件，当前作品层呈现封面、标题、更新时间及目录／任务／附件／查找四段图标。目录独占面板，不与插件挤在长列表中；切换层级及面板不切换正文、不丢未保存稿、各面板位置和搜索条件。目录复用当前对象与组件，通过布局插槽进入侧栏，不复制作品状态。侧栏外缘可拖动调整，当前实现范围180～390px，拖至120px以下收起；重新展开恢复本次拖动前的宽度，取消拖动恢复起始宽度。分隔边支持键盘左右键、Home／End与Enter收起。宽度属于当前视图会话，不写入作品或跨宿主全局偏好；收起与调宽不重建文稿。760px及以下侧栏按需覆盖，选中章节后收起；内容区保留返回和展开入口。文稿信息、修订比较、图片与定稿按需打开浮窗。
- 小说与剧本文稿工作面填满内容区，窗口级工作面留8px边隙及16px圆角，正文纸面本身保持无边框、无卡片、无嵌套滚动。章节／分集名称在正文起点显示一次，使用20px系统无衬线标题，工具留在轻量页头；正文沿作者独立阅读偏好显示，页脚显示真实字数。宽屏保留阅读行宽，不将正文限宽误作整个工作面限宽。

上述结构来自公开实际界面图的主体对照及本地实现，尺寸是当前共同布局选择，尚未构成同版本安装版的精确测量或1:1验收。系统标题栏、完整格式面板及其余页面继续按41采集核对。
- 项目导航固定按作品资料、创作资料、协作与审核、小说／剧本／视频、版本与交付、本机与扩展排列；选中项采用中性灰底、前景文字和字重区分，创作库的导航切换在宽窄窗口均可达。显式打开版本、交付、任务或插件可以直达对应工作面，但不改变作品默认先进入资料页的规则。
- 工具栏按当前文稿显示精确AI交接、保存状态、设置、专注、保存修订和更多操作。正文搜索、批注、历史比较、图片与定稿按任务展开，不把全部操作堆在阅读区。
- 创作库保留类型导航、搜索、列表／封面视图、打开已有作品与新建交接；封面卡宽174～192px、图面高220px，小说书封保持2:3比例，卡内文字左对齐并显示状态、章数和更新时间。作品资料、设定、关联、审核、素材、版本、交付及设置共用同一色板与布局节奏。没有真实封面时使用原生随附的默认书封，叠加书名和作者，通过可访问名称与提示标明默认占位，不写入作品、不伪装成已采用资产。
- 正文、目录与当前文稿选择在返回时保留；当前作品层默认展示卷章／分集目录，项目功能和插件位于另一层，不能挤占目录首屏。未保存稿和原操作恢复继续复用共享Core及本机恢复区。视觉还原不重新录入作者内容、不扩大授权、不把按钮或截图当完整业务验收。
- 通用作品工作面撑满剩余窗口，外留20px、内部24px，页头将标题、搜索和操作同排；页面只有一处对应当前任务的AI入口。导航条目统一14px，图标占20px。顶栏窗口缩放与文稿专注分开，`Command+,`与应用菜单打开同一个设置窗口。
- 图片页使用220px搜索、八类分类按钮及190～250px网格，缩略图高218px并保留原比例。空状态居于剩余区域；只含文字的任务页自动跳过，更多图片去重追加。详情在独立分栏弹窗中展示原图、同批缩略图、来源、历史版本和直接意见；收到新批次不切换正在审阅的旧批次，未保存意见禁止静默丢弃。
- 设置使用独立、可重复聚焦的窗口，首次打开沿当前工作台内容尺寸，最小520×460px；MCP App 内设置受宿主尺寸约束。共用52px顶栏、280px分类侧栏和64px内容页头；本轮按 Orca 设置密度采用最大720px居中内容列、宽窗至少32px左右留白，窄窗降为16px并将分类折叠，禁止横向挤压表单。分组标题置于组外，15px半粗；行标题14px、帮助12.5px，行高至少44px、上下约9px、组内左右20px、select高28px，分隔线内缩。按24px组间距组织中性成组表单，动作置于末端，长文说明自然换行。外观仍显示系统／浅色／深色的真实预览，河图品牌和Radix语义色不变。
- 设置依次展示通用、写作、模型服务、AI协作、版本与关于。AI协作本轮聚焦Codex，内分为连接与诊断、会话、GUI外观、TUI终端；外部MCP App及Skills安装复用原接入用例，其他引擎不作为本轮主设置。普通偏好即时保存并同步，失败就地保留输入；只影响未来轮次的模型／策略选择明确标注，不重启当前任务。设置关闭前保存仍在输入的署名，未知结果保留恢复入口。设置仅开放本机偏好、模型配置及所选套件等必要通道，不能调用作品或插件作者动作；渠道密钥继续进入Core私密存储，不回显、不进入作品、日志或协作提示词。Agent 修改设置仍使用同一 local_settings 用例及 auto／confirm 策略，不增加平行配置写入口。
- 更换封面使用独立分栏窗口，当前封面与候选、历史及本地导入分区；选用固定原候选引用和当前封面基线，历史恢复生成新修订。作者选择的本地图片先完整解码预览，文件变化时拒绝选用；未知操作保留原键并先回读。候选接收不等于采用。
- 作品资料和卷章结构保留次级人工编辑窗口，分别按原生560px与680px宽度组织。资料维护书名、作者、题材、状态、语言和简介；结构维护分卷、归卷和组内顺序，不更换章节身份或正文。保存固定打开时的CAS，冲突保留输入，关闭未保存稿先确认，未知沿原操作回读。
- 作品首页首屏聚焦封面、已有基本资料和简介，内容上限980px。封面168×252px，与500px资料列相隔32px；基础资料的标签和值就近排列，不显示未填写的作者和题材占位行。封面候选通过“更换封面”进入独立窗口，本地导入及历史收在封面菜单。卷章数量提供直接打开目录的入口，页面下方卷章／分集目录默认展开，点击章节进入确切正文，不能退回上次阅读的另一章；协作设置和版本信息默认收起，时间、资料修订及摘要放在版本信息内。协作设置展开后保留本作品客户端、题材套件、分类检索与外部Agent引导、安装检测及Skills列表、安装审核与接入说明。客户端与套件按精确WorkRef存入独立本机设置，不改变默认客户端或同根其他作品；文件检测、客户端登记和会话加载分别报告，未知不等于未安装。点击安装后展示当前所选客户端、套件及固定版本，作者确认后由桌面执行同一Core安装方案并回读；无需复制给Agent。选择套件本身不安装。参考稿审核页不再重复显示进入当前页面的审核提示。

## 界面风格

Electron、内嵌审核页和插件遵循仓库级 [hetu-ui-style](../.agents/skills/hetu-ui-style/SKILL.md)。界面不使用中点分隔文案，不堆重复说明、装饰眉题和技术解释；必要的授权、冲突、费用与恢复信息就地呈现。调用失败保留具体原因和恢复指引，去除Electron远程调用的技术前缀。次要操作按任务收拢，保留作者正在比较和决定的位置。

颜色统一使用共享Radix UI Colors语义变量：背景1–2、交互表面3–5、边框6–8、文字11–12，并覆盖浅暗主题。界面字号采用12、14、20、28px，正文沿作者独立阅读偏好显示，每页最多四档且不小于12px。容器边框0.5px，窗口工作面圆角16px，正文纸面无边框和圆角，控件与浮层按用途收敛；内容不堆装饰卡片或彩色左边线。默认无动画，必要时采用250ms ease-out并支持减少动态效果。检查文字基线、图标中心和嵌套圆角的光学对齐。

macOS 应用图标由品牌原图等比派生：1024px 透明画布中居中放置824px圆角底板，四周各留100px，不将底板铺满画布。各尺寸PNG与ICNS共用同一图案、比例和透明边距，保持Dock中的视觉尺寸一致。

工作台使用共享Radix Gray表面，顶栏与整合侧栏承接同一中性窗口底，正文、输入和决定弹窗保持稳定实色；品牌山水与官网渐变独立。macOS、Windows与Linux共用Web表面，不依赖桌面壁纸；原生标题栏单独验收。减少透明度或增强对比度时关闭模糊，作品、来源和作者决定语义保持。

创作库使用紧凑的纸页山水插画页头，浅暗主题分别适配，搜索与作品列表紧随其后。无作品时提供小说、剧本与视频的新建交接及打开已有作品入口，复用固定筹备请求；插画不登记为作品成果或默认封面。阅读与审核页仍以真实文稿和成果为主。

内嵌参考方案审核页跟随应用当前外观；切换浅暗或跟随系统时更新同一面板，不重建任务或丢弃未保存意见。通用图片成果标记为“图片候选”，只有明确的封面场景使用“封面候选”。

创作插件的安装操作与页标题同排；未安装时只显示简短空状态。全局工具页不重复显示顶部已有的作品名称，不保留泛化的常驻使用说明。

第三方插件以独立页面打开：收起宿主顶栏、项目导航和重复页标题，插件使用完整窗口宽度。支持整合导航的插件将左上角“返回”、插件名称、功能切换和常用操作合为一栏，宿主不再另占一行；其他插件使用宿主轻量返回栏。应用菜单和 Alt+Left 提供独立于插件内容的返回入口。退出前等待恢复稿落盘，成功后回到进入前的页面，并保留原导航展开状态；打开失败或插件热替换／停用时恢复工作台，失败原因就地显示。

## 1. 信息架构

软件从“创作库”进入，筛选为全部、小说、剧本、视频。每个对象独立创建、打开、授权和交付；小说到剧本、剧本到视频是可选来源关系，不是导航父子关系。小说分类内可使用“书库”，软件总入口不能继续以小说命名。四个工作面的ASCII布局以[37](37-创作库与小说剧本视频设计.md)为准。

混合列表显示类型、名称、更新时间和实际成果；小说封面、剧本标题页、视频海报或实际帧按各自比例呈现，不把所有项目画成书。待审聚合只读本机已登记且获权的实际事项，没有待审项时省略。搜索、新建、打开已有项目和设置持续可达；Agent可从对话直接筹备，不必先打开此页。

卡片显示更新时间，列表显示创建与更新时间，详情按需查看最近打开时间和目录。文稿详情按需显示创建、保存、格式、语言、大小、来源及定稿时间；视频显示真实接收和渲染时间。未保存修改单独提示，未知时间显示“未记录”，不把查看当成编辑。

登记移除、项目删除、工作区删除分别命名。同根多个对象时删除单项目先列所属内容和被引用影响，可恢复处理，不能移动整个根。只有明确删除工作区时，才列出全部受影响对象及目录，输入完整工作区名称后移入废纸篓；取消无副作用，失败保留输入，成功后才更新登记。作者可从废纸篓放回重新打开。现有整根删除合同不能直接套到新增独立项目入口。

进入对象后，由WorkRef、已选套件、实际贡献与权限解析工作面；默认先展示作品资料，再由作者明确进入小说正文、剧本分集或视频成果。设定、关系、画布、导演、版本和交付按需加入。贡献声明适用对象、区域和动作，新能力不修改宿主页面路由。审核和关联始终有可达入口。内容目录另按小说的卷→章、剧本的集→场、视频的集→成果展开；阅读、对照、比较或分镜、预演、片段、成片只切换当前成果模式。关闭最后一个文稿回到作品资料，导航层级以[37](37-创作库与小说剧本视频设计.md#导航层级)为准，不将这些入口平铺成一排菜单。

已有作品时，创作库首屏优先展示作品、搜索和类型筛选；Agent 接入使用紧凑入口。首次空库才展开开始创作的引导，不在每次返回时重复占据主要空间。

内容占主要宽度，一处主导航；文稿批注和详情按需浮出，不占用常驻右栏。小说以卷章和中文长文为主，剧本以分集和语义场次为主，视频以实际画面和连续观看为主。窗口收窄优先折叠次级目录；原著对照、差异和来源可切换或在宽屏并排，不强制三栏全文。当前对象、成果版本、参考／采用状态与必要保存信息持续可见，换对象清除旧临时投影。

项目导航与内容面板共用侧栏的展开收起，窄窗口按需覆盖。收起不改变已选章节、分集或未保存内容；深层定位自动展开所属卷、集并显露当前项，返回保留阅读位置。四段图标支持悬停说明、方向键循环、Home／End及可见焦点；任务可筛选已结束项，附件读取当前作品真实资料与图片，不用空壳按钮代替能力。新建章、集、场与整理目录属于当前内容的次级操作，不与全局新建项目并排，也不重复占据目录上方的多个按钮。

附件侧栏只承担列表、当前项与刷新，不在窄栏展开资料全文。点击资料在主工作面按固定修订打开，保留原文稿的挂载、未保存稿、选区与阅读位置；返回或切换侧栏面板后恢复原工作面及入口焦点。详情使用共用阅读排版；正文以一级标题开头时使用该标题，资料名仍保留于列表，避免两个略有差异的标题重复占位。原稿中可核对的固定文稿引用以折叠来源信息呈现，原始内容和引用字节不修改。读取失败在主工作面就地重试，快速切换拒绝旧回包。窄窗选择资料后收起侧栏，保证全文可读；桌面与MCP App使用同一组件。

页面操作继续分层：保留与当前对象对应的 Agent 交接入口，刷新使用紧凑图标；设定历史、锁定／解锁和手工新增放入“更多操作”。未建立自身设定时展示建立交接，不出现不可执行的操作菜单；锁定仅禁止编辑，历史与原文始终可读。

设定人物和地点以230至310px网格展示，人物预览高240px，地点预览高175px；人物只选择该实体的单人形象或正面图。其他类型采用列表。条目详情、660×650px人工编辑、530px人物事实、470px锁定与650×580px历史窗口保持独立。所有保存固定打开时的基线；同作品资料刷新不重建正在编辑的窗口。

每个页面提供当前对象的AI交接，完整说明按需展开。作者在外部客户端表达创意，Agent经机器接口准备资料和成果；界面首先供阅读、观看、比较和提出意见，第二才是手动编辑。保存、停顿、打开内容不自动触发改稿，新增成果不抢焦点、覆盖缓冲或跳走播放位置。无需节点画布、三维布景、模型参数表或多轨剪辑操作。

“AI协作”设置管理外部客户端接入与桌面所选Agent，具体任务留在对象旁。桌面提供与当前作品关联的对话和执行面板，“让AI处理”准备明确请求及上下文，不绕过作品授权、固定计划或费用确认。首页可以简短表达作者主张，不能以口号、市场数字或重复说明挤占作品。

## 2. 页面与主要动作

| 页面 | 主要内容 | 主操作及边界 |
| --- | --- | --- |
| 创作库 | 小说、剧本、视频，类型筛选、最近更新和待审 | 交给所选Agent开始或继续，打开已有项目；无作品不扫描全盘 |
| 创作筹备 | 意图、资料候选、来源及保存方案 | Agent准备完整方案，作者比较及作必要决定，无长表单前置 |
| 外部协作任务 | 请求、获权资料、工作稿、候选、公开意见及回执 | 首次复制提示词，返工沿原任务继续；接入设置只在缺失时出现 |
| 小说资料与封面 | 书名、笔名、简介、题材、状态、封面候选 | 已核验候选一键用作封面；外部图片可另行导入，外部设计见34 |
| 小说 | 卷章、正文、大纲、批注和修订 | 阅读、比较及选区反馈；人工编辑保留，目录维护由Agent准备 |
| 设定集 | 人物、势力、地点、时序和世界规则 | 作者维护、采用或锁定；锁编辑不阻止阅读 |
| 剧情节点 | 原文与结构、歧义和未确认项 | 明确校正与来源，不能把提取完成当语义正确 |
| 剧本 | 全剧、分集、场次、行动与对白、原著对照 | 直接读实际参考稿或作者稿，按位置提意见，骨架置于改编工具 |
| 视频分镜与预演 | 顺序镜头、动态分镜或按需白模、来源 | 连续观看、版本比较与位置意见；预演认可不等于成片确认 |
| 视频片段与成片 | 实际音画、字幕、当前剪辑版本和可追溯片段 | 观看、区间反馈和作者确认；参数及生成记录次级展开 |
| 资料与素材 | 人物、场景、道具、媒体、设计、来源和使用位置 | 对象页和统一库呈现同一候选，等比比较与选用，生成由外部Agent驱动 |
| 诊断与审核 | 固定证据、覆盖、候选差异与作者意见 | 查看原文／原媒体，自主发现未标记细节，采纳和文稿定稿独立 |
| 版本 | 工作树、文件差异、分支和远端状态 | Agent准备确切快照／同步提案，作者核对目标及副作用 |
| 交付 | 文稿、成片、工程及依赖、权利和排除项 | 导出固定版本，分别核验文本、媒体和源工程，不自动发布 |
| 设置 | 通用、写作、AI协作、版本与关于 | 维护本机偏好及接入；私密凭据不进入普通交接 |

分集本身是阅读入口。选择分集后直接展示剧本，可切换已提交参考稿、未提交工作稿与作者稿；作者稿为空而参考稿有内容时默认展示最新提交，不能进入空编辑器。参考稿只读，提供审核及原任务继续入口；选择作者稿才编辑。计划、属性与目录维护次级展开。

Fountain分集默认使用剧本排版：场景标题与场号、动作、人物提示、括注、对白和转场分别显示，隐藏语法标记；双人同时对白并排呈现，窄屏依次阅读。英文采用等宽字体，中文使用系统可读字体，不将英文制片页数规则套用于中文时长估计。连续阅读不伪造打印分页或时长。标题页、署名、来源和语言放在“稿件信息与来源”按需展开；分集标题在页头只出现一次，与当前分集相同的首个段落标题不再重复。目录每集只保留一个入口，当前集展开其真实稿件场次，不能重复一层同名文件。

作者稿支持剧本阅读与元素排版编辑，原始格式从更多操作的“查看原稿”按需进入，不在主工作面常驻源码标签。呈现层不改写内容或换行，无法辨识的正文按原文保留；场次定位、选择批注、恢复稿、保存、撤销及CAS继续绑定同一固定原文。参考稿不得因切换显示模式变为可编辑作者稿。桌面与MCP App共用解析、阅读组件和样式。

关联由Core按固定身份和目标文档计算，不按标题或集号猜测。`target_ref`指定接收成果的文档及基线，不赋予覆盖权限；读取上下文仍由`input_refs`决定。既有任务只有固定输入存在唯一同类型目标时可兼容关联，有歧义则不关联。提交、保存、采用及定稿分别保留修订。

### 2.1 每页的 AI 操作入口

每个页面和详情提供一个位置稳定的“让 AI 处理”入口；已有任务显示“继续处理”，成果待审时以“查看待审”承接。入口使用当前引擎或客户端名称，展开后提供具体任务建议、固定上下文和当前操作状态；桌面模式进入关联对话直接发送，外部模式打开宿主面板、准备消息或复制提示词，不要求作者填写业务字段。作者也可直接在所选Agent会话表达目标；引导不是必经操作。

| 页面或状态 | 交给 Agent 的操作 | 人主要审阅什么 |
| --- | --- | --- |
| 创作库、首次启动、无作品 | 从零筹备、创建小说／剧本／视频、定位明确已有项目 | 方向、保存位置、作品身份和访问范围 |
| 建书筹备、作品资料 | 讨论方向，填写书名、简介、题材及大纲，准备创建或资料更新 | 方案差异、保留内容及修改结果 |
| 卷章目录、正文详情 | 创建卷章、排序、起草或按范围返工 | 目录变更、参考稿、原文差异、局部采用 |
| 剧本项目、分集、场次 | 建项目、安排分集、维护 Fountain、准备改编映射 | 分集节奏、人物行动、原著差异及来源 |
| 视频、预演、片段、成片 | 组织镜头、资产、预演、固定生成与音画剪辑，沿意见局部返工 | 实际连续画面、表演、声音、字幕、版本差异和成片确认 |
| 设定集 | 整理人物、地点、时间线及规则变更提案 | 事实依据、前后差异、冲突和采用决定 |
| 资料、设计、封面、素材详情 | 检索和整理资料、准备设计、回传文件组、整理用途 | 来源、版本、等比预览、权利声明与选用 |
| 剧情、诊断 | 提取结构、运行检查、整理问题和修正建议 | 证据、覆盖、定位、语义建议与确定问题 |
| 参考稿、审核、历史 | 解释差异、按具体意见返工、准备局部采纳方案 | 对应成果、保留段落、采纳及独立定稿 |
| 版本、冲突 | 准备快照说明、比较分支、提出冲突解决及同步方案 | 固定文件集合、差异、目标远端和外发范围 |
| 导入、交付 | 识别结构、填充映射、准备选集与格式、执行获权导入或导出 | 损失、来源、定稿范围、包清单及结果 |
| 设置、接入、关于 | 检查安装与能力、准备扩展安装及本机偏好变更 | 具体变更、版本、权限；私密凭据仅在可信渠道处理 |
| 空、只读、无权、冲突、失败、未知 | 读取原因、请求具体缺项、查询原操作、准备可执行的恢复 | 能否继续、所需范围；不要求复制报错后重新填表 |

所有子页面、弹窗和侧栏继承当前页面的交接能力；上下文发生变化时重新生成。一个页面可给出少量相关操作示例，例如“把第七章移到第二卷”“保留结尾，重写争执”“按 Word 格式准备交稿”，不展示协议字段或大段教程。

交接以[30第25节](30-应用API详细设计.md#25-全软件联动与操作提案合同)的固定对象、版本、范围、任务或提案引用为准。未知结果提供原操作恢复；权限缺失提示所需对象与用途。复制成功只表示已复制，读取成功只表示已读取，页面不显示虚假的“AI 正在处理”。没有机器入口的操作显示准确缺口并进入实施清单，不能引导 Agent 用 Computer Use 完成普通业务。

### 2.2 固定管理方案的审阅

工作窗口顶部的“让 AI 处理”读取 Core 的页面交接，包含当前作品、已保存对象及固定修订。正文、人物详情、资料、分集、审核、目录、大纲和资料影响比较提供对应对象入口；无作品接入窗口可复制从零建书提示词。复制不代表已发送，未保存缓冲和私密批注不进入交接。

正文“让 Codex 处理”固定采用“选择目标 → 核对固定上下文 → 发送或放入草稿”的顺序，桌面和 MCP App 共用请求模板。独立桌面优先进入当前作品的内嵌 GUI／TUI 会话，无需复制；MCP App按宿主实际能力提供“发送给当前 Agent”和“放入对话草稿”。复制提示词保留为回退。生成和预览不启动引擎、不调用模型、不自动发送宿主消息，也不改剪贴板或正文；无需预先安装 Agent。写作、扩写润色、续写、章纲、审稿纠错和小说的剧本改编使用各自明确目标，附带当前作品、已保存文稿修订及可选的固定选区。写作意图由宿主模板处理，不能混入 Core 对象引用。未保存或正在输入时提示先保存，引用校验失败就地显示原因并可重试；关闭和切换文稿后旧回包不得重新打开提示词。发送受理、准备草稿、拒绝及结果未知分别呈现；同一预览发送后不重复发送，结果未知先核对当前对话。

作者也可直接在Codex对话中指定作品及目标，Agent经能力发现、固定页面交接、任务准备、参考稿保存与结果回读驱动河图，无需先点击GUI或复制提示词。沿既有`hetu_call_action`及CLI业务合同操作，不开放第一方App的作者会话或复用`hetu_app_request`作为通用Agent权限。

Agent 准备管理变更后，作者在交接窗口查看方案列表及前后内容，批准或拒绝本次方案，无需转抄字段。作品资料、卷章、大纲、设定、短剧项目与分集、协作任务准备复用这一机制。正文创建只建立空稿；起草、改稿及图片成果继续进入独立协作任务。批准后返回外部对话，Agent 执行相同方案并回读，界面刷新已保存投影，保持作者未保存的正文缓冲。

方案固定输入、结果身份、文件集合、摘要、作品基线和一天有效期。审阅不改正文、设定或定稿；过期、版本前进、被拒绝、摘要不符时拒绝执行。作者可以在执行前撤销批准，执行意图落盘后按原方案恢复，成功执行保留原结果。采纳、定稿、解锁、费用批准及任意网络动作不属于通用管理能力；Git 同步有独立的固定远端和提交审阅。

此入口展示当前可用动作及限制。已有作品先“授权本作品并复制”，后续稳定连接逐请求携带范围引用；撤权立即停止管理及派生任务。导入交付显示文件、格式损失、选集及固定修订，素材显示权利和再分发许可，版本显示远端、提交及冲突两侧内容。本机设置与套件选择在设置页独立审阅。完整技术参数可折叠核对，不代替业务差异。

MCP Apps 的任务面板用于比较候选和公开意见；操作面板只读固定管理／设置方案并刷新状态，不提供模型可调用的批准。作者在原生端批准后，Agent 沿原方案执行。书库自动接纳同客户端机器新建的小说与原创剧本，验证目录身份并去重，不改变最近打开时间。实测结果见[测试策略](19-测试策略与验收矩阵.md#页面交接与固定管理方案验证)。

模型授权、额度追加、余额不足及充值后的恢复均在当前所选Agent对话闭环，包括外部客户端和桌面会话；充分授权后不逐图询问，不要求作者切换入口重复审批。Agent 经 MCP／CLI 登记实际任务授权，在额度内连续提交固定计划并收集成果；宿主 form elicitation 可辅助对话中尚缺少的确认。原生任务结果页展示计划、渠道、输入、授权、提交状态和候选，供作者检查、比较与编辑。平台计划显示 Credits，自定义渠道明确说明供应商计费且金额无法核定。软件中的历史单次审阅入口不作为生成的必经步骤，关闭任务后不能继续提交。

### 2.3 资料整理与固定审阅

资料工作面按当前作品展示分类、来源、固定设定、完整文字、历史及章节使用位置。默认交接 Agent 整理，作者阅读后采用或归档；人工修改作为可选入口，保留本机恢复稿。采用与正文定稿分别决定，资料更新不替换已有使用位置。恢复入口独立于筛选和归档，重开仍能核对原操作；细则见[35资料合同](35-资料素材与短剧制作资产.md#31-资料的作品归属与审阅)。

### 2.4 素材与线索审阅

第一方贡献工作面分别分页显示当前作品素材与线索，读取固定历史、来源说明、当前与历史权利，以及正文和素材关联。刷新保留所选修订，来源推进单独提示；切换作品清除旧投影，读取失败与空结果分开。“让AI处理”交接当前素材或线索的确切身份、修订和摘要，导入及修改沿共享管理方案审阅，作者无需重复填写资料。作品与引用约束见[35第3.2节](35-资料素材与短剧制作资产.md#32-通用素材与线索的作品归属)；媒体实际播放单独验收。

素材详情按原比例预览图片，音频和视频提供标准播放、暂停、进度和音量控件，默认不自动播放；固定历史保留同一原字节及当时资料。预览加载失败与不支持的编码有明确提示和重新加载入口，不把空白播放器显示成成功。离开素材或切换作品停止旧播放与读取。该入口仅审阅，不隐式选用或定稿；传输与权限细则由[插件20第19节](plugin/20-首期可执行合同与开发入口.md#19-可信媒体预览传输)拥有。

## Codex 会话工作面与设置

本节拥有本轮会话及设置的视觉、输入和导航合同；源码依据见[研究14](research/14-编辑阅读与全局体验研究.md#12-orca-会话与设置源码研究)。Orca 是会话和设置参考，小说／剧本的阅读排版、作品资料首屏、直接章节／分集入口和 DocumentTabs 预览／常驻语义继续执行既有领域合同。终端工作区承接已安装的原生CLI；Codex另提供共享引擎的结构化GUI，两种表面独立于外部Codex Desktop。

### 会话布局与导航

- 在创作库也能开始筹备对话，不要求先建空作品；进入作品仍先显示作品资料。页面“让 Codex 处理”附加当前固定对象并聚焦会话，不替换资料或正文页面、不自动发送。
- 默认在现有主区打开完整会话工作面；作者明确选择并排后，在作品右侧提供可调宽会话区，初始宽420px、最小360px，作品主区至少600px。可用内容不足960px时改为作品／会话切换，保留双方位置，不套双重滚动或将正文压成窄条。这些尺寸为河图并排布局选择，参考客户端实测参数单独取证。
- 会话页头只保留标题、真实连接状态、新建和更多菜单；支持的GUI／TUI切换归入更多菜单；列表按当前作品及“创作库筹备”分组，可搜索、重命名、切换和移除本机记录。默认以首条用户消息命名，不为命名额外调用模型。移除记录不删除作品或引擎历史；存在运行或未知结果时先展示影响。
- 切换会话不重新发送、清空草稿或重启进程；关闭侧区只隐藏视图。停止、关闭引擎和移除会话分别命名，运行中关闭窗口须说明实际后台策略，不用隐藏界面冒充任务已停止。
- 创作库“新建小说／剧本／视频”将对应筹备请求放入创作库会话草稿并打开会话，不以复制提示词作为默认路径。筹备会话不绑定尚不存在的作品；作品创建后从真实Core回执定位并刷新创作库，进入作品时使用独立的精确作品会话。关闭或展开会话面板均不发送草稿。
- 引擎、模型和推理强度在创建面板按需选择，来自实际引擎能力，不静态编造模型列表。引擎未连接、登录失效、用量不足及协议不兼容在发生处给恢复入口，已有作品与对话可读。
- 引擎已退出时，切换GUI用于阅读本机已有对话，不启动模型或建立作品机器连接。存在运行进程、待答或未知执行时仍按单输入者边界核对；离线视图不能显示在线或自动重发。

### GUI 消息、过程与成果

采用连续、轻量的消息列与底部输入区，用户消息和助手内容依靠角色、位置及留白区分，避免大面积气泡和卡片套卡片。消息正文、工具时间线、审批、错误与成果链接在同一阅读流中；长历史使用稳定消息键与有界渲染，加载更早历史不重置阅读锚点。

工具项展示真实名称、目标、进行／完成／失败／未知状态及耗时，可展开具体输入和输出；默认折叠长日志，执行错误和待答请求不藏在折叠项里。消息复制、选区复制、代码复制、链接打开和失败详情均可用；Markdown、列表、表格、代码、长URL及中文换行不撑破消息列。不显示协议原文作为普通回复，不编造推理过程或工具活动。

每轮的“作品变更”来自 Core 真实回执，按资料、章节、参考稿及媒体成果列出可打开对象；显示可用差异、来源及未完成项。消息链接可直接打开相应章节、资料、候选或比较页，返回保留会话位置。CLI命令成功、模型说“完成”、消息显示保存均不能代替 Core 回读；采用和定稿继续绑定确切成果单独决定。

输入前可附加当前作品资料、目录、章节、固定选区、人物、设定、参考稿、反馈和已支持专业成果。以可移除的短标签展示对象、版本和覆盖，展开可核对实际外发内容；默认不附整书、私密批注、未保存稿或秘密。Agent 也可通过机器入口自行发现和读取。引用过期或未保存时提示修复，不静默换成最新版本。附件只允许已配置能力和受管来源，不以任意路径取得文件读取权。

### 输入、滚动与 TUI

Codex终端在现有主窗口内打开，默认铺满当前主工作区并最大化窗口，不创建独立终端窗口。并排查看作品是作者明确选择的布局；返回作品、收起会话和切换预览不停止PTY或另建线程。会话标签和文档预览共用中间区域，右侧目录显示当前作品的正式卷章／分集和资料，复用原应用读取与固定引用，不展示私有存储文件或中间脚本。目录可搜索、展开、定位和调宽，单击打开临时预览，双击保留标签；引用及拖入只向选定会话的输入区插入固定来源，不附加Enter。异步读取后再次核对作品、会话和输入代次，切换后拒绝迟到投递。编辑、改名和业务写入继续沿原作品页面及机器用例，不在目录持有第二套正文。

2026-11-24作者提供的2560×1285实机图确认：中心终端紧接约36px顶部标签栏向下铺满，左右栏独立折叠，不能在中心重复堆窗口顶栏、会话标题、文稿标签与终端工具栏。河图展开会话时采用一行36px会话／标签／工具区，查找和成果入口合并在此；终端无卡片外框和额外外边距。新视图左栏280px、右栏350px，保留已有作者宽度。左右栏可独立展开、折叠与调宽；“最大化终端”暂时收起两侧，“还原终端布局”恢复原选择与栏宽。系统全屏复用现有原生窗口能力；进入、退出均保留同一PTY与线程，不吞终端自己的Esc。原生窗口按钮在普通、最大化终端与全屏分别保持可见、避让和正确拖动区域。正常已连接且无提示、无查找行的1280×860以上视口，终端区域应占客户区高度至少94%，最大化时同时占满可用宽度；尺寸断言与截图分别记录。

终端回放与实时输出使用同一会话、输入代次及有序游标；回放期间到达的数据消重接续，缺段重新读取原宿主，不猜测或重启模型任务。核对完成前不接受输入，旧代次输出不进入新屏幕。固定修订预览使用有界缓存，各标签记住自己的阅读位置；关闭目录的宽窗选择与目录宽度保存在本机视图状态。目录支持组级方向键、折叠与定位当前预览；预览失败可沿原修订直接重读，目录更新后旧修订明确提示并由作者选择查看当前修订。同作品后台会话完成时按通知中的WorkRef刷新目录，其他作品通知不触发本作品读取。预览标签支持左右／首尾键、鼠标中键关闭、右键关闭其他及右侧标签；这些动作只关闭视图，不停止Codex或删除内容。目录及预览的具体几何与控件状态按同版本参考证据逐项复拍，未取得的实机证据保持未验证。

铺满终端时，窗口顶栏只保留当前作品、会话与窗口操作，文稿目录标签、保存与写作工具跟随原文稿工作面隐藏。左栏页头的应用名称与26px折叠按钮分别占位，不能继承导航行的整行按钮宽度；与原生窗口按钮保持避让。进入时左侧显示项目导航，配套内容目录放在右侧；返回同一文稿时恢复先前侧栏层级，作者仍可主动切换。窄工作面优先给终端保留600px，目录变为作者明确展开的覆盖层；恢复宽度后还原宽窗目录选择。会话菜单复用工作台的选择后关闭、点外关闭、Escape和键盘导航规则。读取、输入或窗口操作失败时，共享提示在当前可见工作面显示并可关闭，不能随隐藏的文稿页面一起消失。

GUI 的 Enter 发送、Shift+Enter 换行；提供“Enter换行、主修饰键+Enter发送”的偏好。组合输入中的 Enter／Escape 不发送或关闭，重复按键和双击发送只产生一个消息尝试。运行中追加／排队按实际能力显示，未支持或拒绝时保留草稿；未知投递显示“待核对”，不提供伪装为安全操作的一键重发。

左右栏折叠后，键盘焦点返回仍可见的对应展开入口；展开左栏后返回折叠按钮。收起右目录与目录搜索框的Escape共用该恢复行为，不将焦点留在被移除的控件上，也不把快捷键误发到Codex。

预览标签获得焦点时，Delete和平台关闭快捷键只关闭该预览，返回相邻标签或终端；不关闭主窗口、终止会话或删除作品内容。

终端内边距由xterm自身承载，尺寸适配容器不重复设置内边距；实际字符画布须完整落在可视区域内，正常、最大化、全屏、缩放和字号变化均不能裁掉最后一行或最右列。

原生终端客户端意外退出时，受管引擎和原线程继续保留；显式重连及并发启动共用一次进行中的启动。重建PTY即更新输入代次，拒绝旧页面迟到的输入、尺寸和输出，不重发模型轮次；恢复成功后清除已解决的客户端退出提示。

河图启动的Codex终端通过单次CLI配置关闭启动更新检查，避免升级菜单阻断确切线程恢复；不修改作者全局配置、不自动安装或更新Codex。认证和实际业务确认继续由原引擎处理。

受管引擎连接中断时，终端转为离线观察并关闭输入；PTY进程仍存活不能当作引擎在线。原引擎仍运行时先恢复原观察连接，原引擎已退出时，显式恢复先确认旧终端与桥退出，再重建引擎并恢复确切原线程；不并发保留两个终端执行端。

TUI中的写作请求使用“放入Codex终端”：固定当前作品与文稿修订，经bracketed paste放入原生输入框，作者核对后按Enter；宿主不附加Enter。资料、图片、插件成果、导入和版本等普通AI入口进入同一会话草稿，显式复制入口继续支持外部接续。空白、超限、控制字符、旧作品及运行中插入直接报错，保留已有内容。终端的`/new`与`/resume`仅在当前作品会话范围内切换，旧线程消息和草稿分别保存；其他作品从河图的作品及会话列表打开。回放历史不会将其中的终端查询响应重新发送到运行进程。

页面交接在固定作品引用准备完成后立即展示当前会话，再等待宿主接入或插入草稿。开始、错误与待核对状态在同一工作面可见，避免初始化期间仍停留原页面而没有可观察进度；打开面板不等于请求已插入或模型已执行。

参考稿审阅保存公开意见后，可直接放入当前作品的Codex草稿，或在该作品新会话中准备；交接固定原任务与反馈摘要，不重新建立任务。内嵌审阅宿主以`hetu/message`能力声明只支持草稿，隐藏直接发送按钮；外部宿主按实际能力保留消息、草稿或复制回退。离开作品或关闭旧审阅面板后拒绝迟到交接，不附加Enter或自动开始模型轮次。

confirm模式下的资料草稿方案在管理审阅页直接显示待保存正文、分类和来源；修改显示固定旧修订与新稿的对照。审批前不写入资料头，读取旧修订失败时显示失败，不用空白冒充原稿。完整机器输入仅在高级详情展开，不作为作者理解本次资料变更的前置条件。

默认自己发送后滚到最新；仅在原本位于底部时跟随流输出，用户向上阅读、选区或展开工具时保持锚点并显示“有新内容／回到最新”。是否发送后滚动、标记新消息和显示每轮变更摘要可独立设置。切换主题、宽度、字号、会话或加载历史后保持语义阅读位置；不能靠每次强滚到底避免历史错位。

TUI 提供真实 PTY 和终端渲染，尺寸变化传播 cols／rows，中文宽字符、组合输入、ANSI颜色、备用屏幕、原生选择器及斜杠命令保持可用。Codex 拥有 TUI 内部界面和命令语义，宿主提供页头、字体、主题、复制粘贴、查找、滚动、进程状态和成果旁览。Ctrl+C 保留终端中断语义，macOS有选区时Command+C复制，粘贴及多行内容采用终端实际 bracketed-paste能力；OSC／链接不取得文件或业务权限，剪贴板写入不得绕过宿主控制。回放旧输出明确标记离线，不能显示成仍连接。

Shift+Enter使用Codex支持的换行编码，不退化为提交；组合输入期间由终端处理原生输入法事件。macOS使用Command+F查找，其他桌面使用Ctrl+Shift+F，保留Ctrl+F的终端编辑语义。行首、行尾、按词移动和删除采用对应平台的终端键位；快捷键和菜单粘贴共享一次宿主读取及同会话核验。

终端查找的按钮、右键菜单和快捷键共用打开与关闭行为：再次查找聚焦并选中已有查询，关闭或Escape返回终端输入；Enter查找下一处、Shift+Enter查找上一处，输入法组合确认不触发查找跳转。无匹配时在查找行显示简短状态，空查询禁用前后查找。查找和定位不向Codex输入或发起模型轮次，不改变原线程和输入代次。

`terminal_focus_on_hover`默认关闭；开启后，鼠标进入当前在线且持有输入权的终端才聚焦原生输入框。查找、菜单、弹窗、其他表单及非当前表面的输入保持，不被鼠标经过终端抢走。改变此偏好即时生效，不重建会话；桌面、CLI与MCP共用同一本机设置。

GUI／TUI 切换执行[39第4.3.3节](39-Electron与插件优先重构架构.md#433-单执行者与界面切换)：优先连接同一受管App Server，在轮次边界解除旧表面控制后转移输入权；需要中断时先核验停止，再连接确切线程。独立进程回退另须核验旧引擎退出。切换失败保留原表面和草稿，不能同线程双执行；恢复不支持时明确提供新会话接续。终端输入回显不是消息受理或业务保存回执。

| TUI渲染 | GPU与连字auto，可手动开／关 | 渲染失败有可见回退，不丢PTY或重启任务 |
| TUI交互 | 输入滚到最新默认开，选中即复制／焦点随鼠标默认关 | 保留复制、粘贴、查找、链接动作及多行粘贴；不搬远程Shell管理 |
| 主题与预览 | 跟随系统／浅／暗，终端浅暗可分别选，实时样张 | 复用河图语义色，GUI跟随终端仅影响会话，不染色作品纸面 |
| 恢复默认 | 按GUI、TUI、行为分组恢复 | 不清理会话、账号、作品或授权；并发设置用同一CAS |

GUI外观、TUI外观、界面缩放、文稿排版和文稿缩放是不同设置。调整显示立即生效且不重建会话；Codex 模型与执行策略的变更仅对支持的下一轮生效，运行中保留已固定参数。所有非敏感偏好进入共享本机设置，CLI／MCP／Skills 可按同一合同读取和修改；外部 MCP App 不显示不能使用的本机PTY控制，显示当前宿主能力及其回退。

## 3. 视觉层次与插画

书库使用浅色与深色两套背景插画，未选封面的作品使用三套通用书封底图。底图不包含文字，书名与笔名使用原生字体叠排；中文与英文界面共享插画，正文标题保持原语言。默认书封按作品身份稳定分配，改书名与重启不换图；默认插画不代表作者选定封面，也不写入作品素材目录。全部位图等比缩放，封面保持 2:3，原图、生成提示词与摘要登记在 `assets/manifest.json`。

工作台使用 Radix 中性背景和玉色操作强调，浅暗主题遵循相同语义层级。正文保持独立纸面，诊断警告与风险颜色遵守语义，不使用装饰色代替状态。

| 区域 | 视觉规则 |
| --- | --- |
| 书库 | 山水横幅、2:3 封面、资料卡、状态标签；网格与列表显示同一作品事实 |
| 作品资料 | 封面与资料并列；候选卡一键用作封面并标识当前使用，点击图片可放大预览，本地导入位于封面更多菜单；简介独立成段，不将占位插画标记为作者封面 |
| 导航与卷章树 | 选中背景、文字颜色与字重指示当前位置，悬停只改变表面，不移动条目 |
| 小说正文 | 无插画覆盖正文；工作面铺满可用区域，不设纸张卡片外框，窄窗口优先正文宽度 |
| 设定、短剧、审核与素材 | 标题、操作与内容分层；空状态简述下一步，省略装饰性说明 |
| 剧情、诊断与版本 | 来源、修订与业务状态优先；装饰插画不暗示校验已通过或版本已保存 |

工具页内容固定从顶部开始排布，空状态仅占据剩余内容区，不将标题与操作组整体推到窗口中部。相同页面不重复展示同一装饰插画。工作页共享背景、面板、按钮和标题组件，颜色以 `WorkbenchPalette` 为唯一原生语义来源。

工具主题插画分别提供浅色与深色资源，随外观切换，避免浅色画布在深色面板形成亮块。插画不包含中英文文字、按钮或伪造内容；界面文案始终由本地化资源绘制。装饰不接收点击、不进入 VoiceOver，系统增强对比度或减少透明度时收敛光晕并使用实色面板。背景没有持续动画。macOS 的“显示 → 外观”提供跟随系统、浅色、深色三个选项，仅改变河图洛书的外观。

书库与作品窗口的顶部提供齿轮设置入口，macOS 应用菜单和 `Command+,` 打开同一个原生设置窗口。通用、写作、AI 协作、版本与关于集中管理偏好及接入；界面语言、外观、书库布局和正文排版同步应用到各窗口。Git 作者信息与快照表单使用同一本机偏好，不设置全局 Git 身份，不执行提交或远端同步。作品内容与本机偏好独立保存。

## 4. 正文编辑体验

小说与剧本采用选区浮动批注：选择已保存原文后，在选区旁显示“添加批注”和精确AI交接；意见在就地浮窗填写，不自动展开右栏。已有未解决批注在原文高亮并显示可点击、可键盘聚焦的浮标，点击可查看、编辑意见或标为已处理；工具入口可查看全部及历史批注。浮窗随滚动定位，窄屏限制在工作区内，支持关闭及快捷键。批注固定修订与UTF-8范围，正文变化后不把旧坐标套到新稿，历史批注保留原引用；保存继续使用CAS、固定操作键和本机原操作恢复，私密意见不自动发送给Agent。

正文格式菜单与快捷键共用命令：支持Markdown强调、标题、引用、代码及分隔；Fountain提供强调、元素转换、原稿与上下场定位。人物和场景补全仅来自当前分集，回车按人物／括注接续对白，其他元素进入下一段；Tab始终保留离开编辑器的路径。原文选区、复制所见文字、复制原稿与纯文本粘贴分别处理，异步粘贴目标变化时拒绝插入。所有格式操作在原稿同一撤销栈中形成独立事务，不自动保存。

提供中文输入法、选区、撤销／重做、搜索替换、字数与章节顺序。编辑显示名与磁盘 ID 分离，重排章节不重命名稳定对象。大文档增量布局、后台索引，避免每次键入全量重排或扫描。

查找区明确区分“当前文档”和“本作品已保存正文”，显示精确匹配／中文分词模式、命中数量、查询中、部分覆盖及无结果；未索引章节不能被算作零命中。当前文档搜索包含未保存缓冲，全书搜索结果固定命中修订，定位前核验原文；遇到新修订展示历史引用并提供重新检索入口，不覆盖当前编辑缓冲。替换及全部替换作用于当前编辑器，预览确切变更并形成一次撤销，不自动保存或定稿；跨章节先定位再编辑，见[UC-28](26-用户故事与用例.md#31-uc-28-中文全文检索与当前章替换)。

主文稿搜索在统一左侧栏展开，展示段落摘要与当前命中，正文顶部不插入查找横条。关闭搜索恢复原导航与阅读锚点，窄窗复用导航浮层；参考、历史及比较两侧保留各自局部查找。目录状态和未保存内容在切换中保持。

阅读排版由小说／剧本独立档案拥有：字体及本机字体名称、14–32px字号、1.25–2.5倍行高、段距、24–64个CJK字形的最大行宽和视觉首行缩进。新安装小说使用16px系统字体、1.5倍行高、44字形行宽和0.5em段距，不增加首行缩进；剧本使用18px英文等宽／中文黑体回退、1.65倍行高，不应用小说缩进。既有作者档案保持，恢复默认才使用当前默认值。普通段落之外的题记、诗歌、已有空格缩进及剧本元素保持原意。屏幕字号统一CSS px，交稿模板的pt独立。

正文页头以`Aa`打开文字格式面板，以画笔图标打开“阅读排版”；格式面板使用标题样式网格和行内命令组，选中状态来自当前原文语法与选区。阅读排版与设置“写作”消费同一档案，提供当前正文预览、分项恢复、纸色、字体、大小、行宽与段落样式；高级行高和段距按需展开。显示调整不修改作品、修订或撤销历史，中文输入组合期间延后排版更新。旧偏好按实际px和等效行高迁移，精确备份且可恢复，不强制套用新默认；本机偏好合同由29拥有。文稿缩放、界面大小、专注和宿主展开各自独立，完整规则见[41](41-创作与审阅体验迭代方案.md)。

浮层按层退出：Escape先由当前输入或最内层浮层处理，不同时关闭文稿详情、退出专注或关闭设置窗口。键盘关闭浮层后，焦点仍在该浮层内时返回它的入口；格式命令已把焦点交回编辑器时保留编辑选区。输入法组合中的Escape不触发界面退出，真实输入法与模拟事件分别验收。桌面与MCP App共用此规则。

编辑器的逻辑换行与原文字节分别保留。打开 CRLF、LF、CR 或混合换行文稿，以及同步固定内容，都不登记作者修改或触发自动保存；实际编辑只替换对应原文范围，范围外换行保持。撤销、重做恢复原始字节，选区按原文计算 UTF-8 范围，不把编辑器逻辑位置直接作为来源坐标。

自动保存只保证编辑缓冲可恢复；显式保存生成可引用的修订。状态区区分“编辑中”“已自动保存”“已保存修订”“保存失败”“外部修改冲突”。切换文档或关闭窗口遇到未保存内容时提供保存、保留恢复副本、取消，不静默丢弃。

关闭窗口与退出应用共用同一次恢复稿落盘。应用退出只标记退出意图，由正常窗口关闭事件检查未保存稿、等待落盘并接续退出；不在退出事件中嵌套关闭窗口。取消或落盘失败保留当前窗口，成功后必须核对进程实际退出与重开的阅读位置，不能以窗口消失代替退出完成。

诊断高亮不改变正文格式。点击问题定位对应源修订；当前正文变化后显示过期标记和重算入口。Emoji 与中文偏移使用内核 SourceRef 转换，禁止按 UTF-16 长度直接解释字节偏移。

## 5. 审核与风险呈现

正文、设定集差异、来源与确定错误优先于摘要评分。提交 Agent 的名称标为调用方声明，审核人显示本地作者身份。批注引用确切修订；要求修改产生可查询的审核结果，不显示虚假的“Agent 正在重写”。

通过前展示当前输入版本及未解决的确定错误、启发式警告和覆盖不足。不可豁免的数据损坏与引用错误阻止定稿；可接受的业务例外需作者说明理由，见[15](15-人工审核与审计.md)。

Git 提交、分支切换、合并、拉取、推送、导出含待审内容等操作分别预览确切影响。普通编辑与受限草稿提交不反复弹确认；已变化的输入使原确认失效。

## 6. 异步与故障状态

所有异步任务具备稳定布局、进度、取消与逐项结果。明确展示空内容、没有访问权限、工作区占用、离线、部分结果、失败、过期和成功，不能依靠整页重载隐藏状态。

取消抽取不会删除源文；取消导出清理自身临时包并保留诊断；Git 推送发出后取消不能保证远端未更新，显示“结果待核实”。对未知状态先查询原操作，不提供自动重试。

## 7. 原生与可访问性

- macOS 使用原生菜单、快捷键、文件选择器、窗口恢复与 VoiceOver；Windows 使用 Fluent 控件、键盘焦点、Narrator 与高对比主题。
- 编辑区支持字号调整；状态不只靠颜色表达，图标有可访问名称与 tooltip。
- 支持系统浅暗主题、缩放与减少动态效果，不将 Web 组件套壳作为核心 UI。
- 键盘可完成打开、编辑、校验、处理问题、审核与导出；焦点在异步更新后保持可预测。
- 窗口背景使用中性表面，正文、表单与诊断不使用装饰底图，不以卡片层层包裹同一信息。

目标支持 1024×768 及以上桌面可用布局，较窄窗口采用折叠导航；最终最小窗口、字号和间距须经双端原型验证后冻结，不直接照抄参考项目尺寸。

## 8. AI 协作任务与验收界面

建书默认展示想法交接、已有筹备和 Agent 已准备的方案，不以填写表单开始。未知书名可以先构思，筹备名称仅用于识别，不自动成为正式书名。候选按书名、简介、大纲等字段比较；选用结果由 Core 保存，Agent 根据确切选择准备并执行获权的创建操作，作者无需把候选转填到另一张表。

手动创建和资料编辑收在“手动填写”入口，仍支持保留输入、渐进展开、冲突比较和恢复。内容区不足900点时纵向排列并允许滚动；宽窗口可并列成果与来源。字段由 Agent 填入时显示待审差异，不抢焦点、覆盖未保存内容或自动把新建议当成作者决定。

任务准备由 Agent 优先完成，作者主要核对范围及需要作出的决定。页面显示当前筹备或作品、目标、获权资料与可理解的影响摘要；引擎／客户端、专用Skill、请求版本和完整提示词按需展开。桌面可直接在任务旁讨论和发送，外部模式按宿主能力打开面板或复制交接；后续沿已有任务继续，不为返工重新填目标或配置连接。进度仅来自实际引擎事件和Core回执。

任务详情以目标与当前成果为主，提供“参考稿”“已提交候选”“修改意见”“相关资料”分组，不在主界面展示 JSON 或协议名。参考稿页显示确切保存版本，可查看当前工作副本，标明“尚未提交”；提交后的候选单独固定，不随新保存变化。作者与 Agent 同改参考稿发生冲突时保留双方内容并比较，接收结果不抢编辑焦点。

修改意见紧邻成果，先于接入与任务详情；长任务要求、完整提示词、连接信息和结束任务操作收进按需展开的详情。无模型计划时不展示空计划区；读取失败与待恢复事务分别表达，不把并发读取中的忙碌显示成操作失败。多个只读面板加载不占用作者保存事务的界面锁，也不改变未保存正文。

结果页显示候选批次、来源、版本、核验结果及下一步；书名与简介按字段选择，大纲按结构比较，图片保持原比例并可放大。文本候选与当前写作稿并排或逐行比较，支持局部采纳；主操作为“采纳到写作稿”。需要返工时，作者选择可公开的批注与确切成果，点击“按此修改”。先保存反馈，再在支持的宿主内请求继续当前对话；无桥接或发送失败时提供“复制继续提示词”，沿原任务继续，不要求新建同义任务或重配 MCP。

作者也可以只阅读参考稿，返回原编辑器自行撰写，或关闭结果页而不采纳。对既有正文请求 AI 改稿时，任务准备页明确所选范围、修改目标与希望保留的语气、视角或表达；正文保存、输入停顿和打开章节均不自动发起改稿。外部结果到达只更新参考列表，不切走焦点或替换编辑缓冲。

编辑器同时提供“写作稿”和“定稿”查看入口，显示当前保存状态及是否存在相对定稿的新修改。来源以独立标签或详情呈现，不给整篇内容贴不可消除的 AI 标记；采纳及后续修改可从修订历史追溯。手工作者直接编辑、检查和确认定稿，不经过 AI 收件列表。

Apps 和本地网页只承载当前任务需要的审阅、选择和批注。界面持续显示所属作品或筹备，切换上下文清空旧临时数据。只有实际具备可信作者确认合同的通道才能签发确切批准；其他通道提交操作提案并定位原生审阅页。提案由 Agent 填完整，作者确认后由 Core 或持确切执行授权的 Agent 执行，不要求人重走表单。浏览器自动化点击和模型自报选择均不能冒充作者批准。

### 8.2 独立桌面对话与外部面板

两种入口的完整旅程见[27第1.1节](27-Agent与Codex插件集成设计.md#11-双入口协作)。作品阅读／观看保持主工作面，对话在相邻可折叠区域展开；窄窗口按阅读、对话和待审内容切换，保留各自位置、未发送文本和未保存稿。对话不取代成果目录、版本比较或作者决定。

| 作者动作 | 桌面表现 | 外部宿主表现 |
| --- | --- | --- |
| 让AI处理当前对象 | 进入关联任务对话，显示所选引擎、明确目标与可移除的固定上下文，作者发送 | 打开指定MCP App或准备宿主消息草稿；无能力时复制同一交接 |
| 追加要求 | 能直接注入则明确追加到运行轮次；只支持排队时显示待处理，不冒充已经生效 | 按本次宿主消息能力继续原任务 |
| 处理审批 | 在发生处展示确切命令／动作及范围，区分引擎审批与作品采纳／定稿 | 按已验收宿主合同展示；不支持时保留原提案和恢复引用 |
| 提意见及返工 | 先保存绑定成果版本的公开意见，再发送给关联会话 | MCP App保存同一意见，并在支持时请求继续 |
| 停止或关闭重开 | 区分停止请求、引擎确认和仍在执行的外部调用；重开读取同一任务与会话状态 | 关闭面板不推定外部Agent停止；重新打开回读Core |

发送中、已受理、执行中、等待审批、停止待确认、断线待核对和成果已保存分别表达。模型完成不显示“已采纳”；失败保留输入和原操作。引擎未安装、需登录、版本不支持、没有作品授权及额度不足各有对应恢复入口，不让作者重复抄写任务信息。切换作品先清理旧附加上下文和待答请求，迟到结果只归原任务。

外部MCP App与桌面共用创作库页头、类型导航、山水背景、封面卡片、搜索筛选和布局切换。页面占满宿主提供的工作区，窄屏折叠导航；不另设居中窄版或常驻生成表单。全局入口载入桌面同一创作库目录，分别标明作品是否已授权给当前客户端；未授权不表示作品不存在，目录读取错误不显示成空库。MCP App作为本机工作台入口，点击已登记作品直接进入原作品，不逐作品请求授权、不弹出Agent交接。与Electron共用工作台页面及应用用例，阅读、编辑、比较、反馈、采纳和定稿保持相同语义；必要的固定结果决定仍在原操作处确认。外部Agent的机器范围继续使用独立精确引用，不继承作者句柄。

## 9. 接入与任务状态文案

| 场景 | 展示 | 可执行的下一步 |
| --- | --- | --- |
| 尚未选择客户端 | 选择用于本次任务的客户端 | 选择或改用手工 |
| 用户完成安装但未技术检查 | 用户已确认安装，连接尚未验证 | 复制只读接入检查说明 |
| Prompt 已复制 | 提示词已复制，等待外部结果 | 到客户端粘贴、重新复制、查看输入 |
| 收到部分候选 | 已收到部分结果，并列出缺项 | 预览合法候选、复制补全说明 |
| 文件出现但回执不完整 | 已发现文件，等待完整结果 | 保留现有稿件、重新检查 |
| 目标基线已变化 | 当前稿已有修改 | 查看三方差异后重新选择 |
| 作者发布了新任务请求 | 任务资料或要求已更新 | 保留未保存意见，查看变化并重新打开当前请求；不自行替换旧引用保存 |
| 本地网页未配对 | 等待在河图洛书确认本任务访问 | 回原生端核对，不展示私密正文 |
| Apps 或浏览器不可用 | 当前客户端无该交互能力 | 回河图洛书预览，使用文本结果继续 |
| 参考稿保存成功 | 参考稿已保存，尚未提交 | 继续修改或查看已提交候选，不显示为作者正文 |
| Agent 请求更多资料 | 需要补充资料，列具体用途与范围 | 提供、缩小或拒绝；无关写作继续可用 |
| 意见保存成功 | 意见已保存 | 按此修改，或复制继续提示词 |
| 宿主接受继续消息 | 已请求继续 | 等待或回对话查看，不显示为已返工 |
| 新成果引用了反馈 | 收到修改后的参考稿 | 比较后继续提意见或采纳，不自动标验收通过 |
| 任务已关闭或访问已撤销 | 本次协作已结束 | 停止外部读写，回河图洛书查看历史；不阻止作者打开作品或继续手工编辑 |

这些状态来自本机可观察事实，不能从复制或用户点击推断外部任务正在运行。内容来源、外部交接状态、审核状态和文档定稿状态分别表达。

## 10. 已有正文的外部改稿

作者从当前章菜单或选区菜单进入“请外部 AI 改稿”。界面使用“允许改动”“仅供参考”“不在本次范围”表达权限，不要求作者理解角色、ACL 或 token。没有选区时要求明确选择“整章改稿”或“在此续写”，不能把空选区解释为整书授权；整章含章末插入点，指定位置续写只允许在该点插入。

### 10.1 权限与内容矩阵

| 对象 | 外部 Agent 在本任务可做什么 | 作者操作 |
| --- | --- | --- |
| 明确授权的正文选区／整章／插入点 | 读取固定原文，提交范围内的改动候选 | 比较、选用部分或全部改动、自行改写或放弃 |
| 添加的其他章节、设定及作品资料 | 仅供参考，不获得这些对象的修改权 | 单独编辑；需要外部改稿时另建对应任务 |
| 本章未授权修改的段落 | 原文可作为已确认的上下文；补丁必须保留这些字节 | 在范围预览中排除不想改的段落，或重新划定可改范围 |
| 未保存正文与输入法组合内容 | 不自动读取，不作为提交结果的写入目标 | 先保存修订再发起；也可取消任务准备，继续写作 |
| 定稿及历史修订 | 可把明确选择的版本作为参考，不能覆盖或移动定稿指针 | 修改写作稿，满意后另行确认新定稿 |
| 设定锁、目录结构、正式封面、版本及交付 | 无本任务写入权限；可以在意见中提出建议 | 回到对应原生界面单独处理 |
| 其他作品、其他任务、本机凭据与应用设置 | 不在本次任务的读取或写入范围 | 新任务重新选范围；凭据不外发 |

“不改这段”是本次任务范围的排除，不给文档增加永久只读状态，也不阻止作者自己改稿。文风、人设和情节走向要求可写入“需要保留”，这些语义由作者审阅及诊断辅助判断；范围外字节不变则由内核确定校验。

### 10.2 准备、交接与验收

1. **固定原文**：完成中文组合输入并保存当前修订；若保存失败、外部冲突或作者选择取消，则留在编辑器，不自动复制缓冲。选区在保存后重新核验，避免把旧坐标套到新稿。
2. **确认范围**：预览“允许改动”的高亮段落或插入点，另列“仅供参考”的章节、设定和作品资料。作者可以缩小范围、排除段落、移除上下文；上下文扩展不扩大可改范围。单任务修改一个文档，多章分别建关联任务，不默认读写整本书；同目标补资料或调整本章范围时发布原任务的新请求版本，不反复创建任务。
3. **表达要求**：输入修改目标及需要保留的语气、视角、称谓等，预览提示词、资料清单和固定回传位置，再复制到所选客户端。安装引导按需出现，不在河图洛书中启动对话或生成。
4. **继续写作**：复制后作者可正常编辑；状态只显示“等待外部结果”。收到候选仅更新任务提示，不抢焦点、不改变当前选区或撤销栈。关闭任务撤销后续访问，历史候选保留。
5. **逐处比较**：展示作者原文、AI 改稿及当前写作稿；将改动按段落分组，每处提供“采用这处”“保留原文”，支持作者继续改写。首次全部未选，不默认全采纳；被保留的原文不能被一次“采纳所选改动”带走。
6. **确认落稿**：主按钮显示“采纳所选改动”，附选中数量；未保存稿先由作者处理。只写选中的结果并形成可追溯新修订，不移动旧定稿。当前稿变化时保留用户选择，重新比较并预览；不按旧行号自动套用。放弃候选不回滚作者后来写的内容。

结果中的越界补丁、错引句或拆分中文字符应整批拒绝，并说明“改动超出本次允许范围”等原因；不裁掉越界部分后假报成功。合法的迟到候选显示“基于较早版本，仅供参考”，作者可选择重新发起或与当前稿重新比较。只读参考与正式采纳走不同动作，MCP Apps／本地网页上的勾选仅保存偏好。

“相关资料”只列本任务作者已批准的资料目录及覆盖，不默认展开全书。Agent 提出缺项时，就地展示需要的章节／资料、用途及拟外发范围；作者确认后保留 task_id 并生成新的请求版本。旧请求停止新写入，旧成果仍可查看，不把补资料解释成允许修改相应正文。

参考依据见[Agent 改稿交互研究](research/09-Agent改稿边界与交互研究.md)，具体调用与恢复见[30第17节](30-应用API详细设计.md#17-建书筹备与外部创作任务)，流程与时序见[23第34节](23-业务流程与MCP时序.md#34-已有正文的受限外部改稿)。

## 11. 引导、新建与导入的场景适配

以[36](36-创作场景与引导流程.md)为场景规则与界面流程唯一来源。书库提供写小说、写剧本、导入已有稿件、打开作品四种意图；AI 协作与设置可直接进入。新建剧本按从零或改编渐进展开原著和授权，独立编剧不需要创建空小说；已有稿件先确认用途、格式和结构，再进入对应工作台。

引导、表单、导入报告、编辑器、参考稿、资料与交付预览共用作品与来源上下文。输入丢失、先收全部字段、跳转接入后回不到原任务、未知状态重复创建、把授权缺项变成整个作品不可进入，均为体验缺陷。中文和英文、键盘、读屏、IME、窄窗口与常规大桌面分别验收。

## 12. 按任务组织的Agent First工作面

本节落实FR-41～44；领域归属见28第15节，执行与恢复见30第31节。借鉴写作产品的上下文分类、编辑辅助和能力发现，不照搬人工表单及全量生成工具栏。

| 位置 | 默认内容与主要交互 | 按需展开及状态 |
| --- | --- | --- |
| 作品资料 | 打开作品后的固定首页；已有资料及直接进入确切章节／分集／成果的入口 | 协作设置、历史及技术信息收起，不用完整插件清单顶走内容 |
| 左侧目录 | 当前作品的正式卷章或分集；单击直接打开目标，不增加“章节列表”中间页 | 搜索、结构整理及批注列表按任务切换，保持同一目录状态与返回位置 |
| 正文工作面 | 适合小说／剧本的连续阅读编辑；一个主滚动区，保留语义行宽 | 文稿缩放、专注、系统全屏与宿主显示模式分别命名；不使用内部纸面滚动条 |
| Agent工作面 | 作者按需打开当前目标、任务、真实执行状态及成果 | 不强制常驻右栏；完整阅读可收起，固定上下文可预览与移除 |
| 上下文引用 | 人物、设定、大纲、章节选区、资料、参考稿及实际支持的专业成果 | 显示来源及修订，缺失／错误／不支持／部分覆盖分开；私密信息不默认附加 |
| 选区浮条与右键 | 格式、复制、查找、批注及针对固定原文的AI处理 | 共同原文命令与目标；中文组合输入期间不重建编辑器或触发内容修改 |
| 专业能力入口 | 当前任务适用且实际可用的审校、规划、改编及制作入口 | 未安装时提供明确发现／安装路径，不在正文平铺所有包与功能 |
| 扩展及方法管理 | 完整目录、实际安装／启用／版本和方法说明 | 搜索及分类是筛选；Agent推荐显示理由和来源，自动使用不等于静默关键词触发 |
| 设置 | 主题、字体、字号、行高、段距、行宽、缩进、缩放及执行模式 | 同一偏好源；即时预览、保存失败和恢复明确，屏幕设置不改变交付版式 |

上下文选择不是复制正文到另一个编辑框。选择后使用原Owner固定引用；未保存稿先保留输入并说明保存状态。执行前后若来源或目标变化，提示保持旧输入或准备新请求；不能把已打开面板误当成当前任务仍有效。

所有异步列表和菜单区分加载、空、不可用、失败、部分结果、冲突及未知；状态反馈留在发生处。消息送达、专业检查、成果保存、采纳和定稿分别显示，不从“AI处理完成”推断全部通过。

桌面与MCP App共用目录语义、文稿命令、排版、差异和意见。窗口全屏、字体检测、剪贴板及宿主消息能力由薄适配器声明，缺能力时准确降级；同一业务不得出现一端只可阅读、另一端另存正文的分叉。具体测试见[19第18节](19-测试策略与验收矩阵.md#18-agent-first本体与能力组合验收)。


### 多引擎终端创建入口

进入终端直接显示已有PTY工作面并恢复已选择会话；没有可启动会话时在工作面内展示创建面板，不显示Codex专用空页。顶部以会话标签和新建入口为主，不常驻TUI／GUI双按钮。创建面板约512px、24px内边距，包含当前作品／创作库上下文、本机运行位置、可选名称和引擎选择；模型选择使用可搜索弹层、引擎标签和该引擎真实可用选项。Enter创建终端，Cmd／Ctrl+Enter使用支持的聊天模式；无适配的聊天模式不显示。创建后立即启动PTY，失败在原会话就地重试，不静默换引擎。Shell、Claude Code、Gemini CLI和OpenCode使用真实原生命令与PTY；Codex继续受管App Server／remote终端，模型从实际model/list读取，推理档位来自该模型返回值。其他引擎没有模型发现时使用其已配置默认值，模型与认证可在原生终端中管理。不同引擎会话独立保存，旧Codex记录不迁移成其他引擎；收起／切换不停止进程，终端退出只标退出，不伪造模型轮次或恢复线程。


### 终端业务工作面

创建会话可选择已登记的小说、剧本或视频，也可在创作库筹备新作品。切换作品先走创作库身份核验和当前作品选择，再连接该范围的会话；顶部持续显示作品名称，正式文稿与资料目录复用原Owner。创作任务按作品类型提供大纲、设定、资料、图片、媒体和交付入口，文稿请求固定具体修订；作者填写目标后准备当前引擎请求；Codex核验原生输入就绪后放入，其他原生引擎先显示待放入请求，完成登录或信任提示后由作者放入终端，不自动补Enter。原生登录、信任和模型确认继续由原生客户端处理。成果入口回读真实工具回执，再独立核验Core，不能由终端末句判断保存。
