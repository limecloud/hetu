# 宣传网站与部署

对外叙事以最终产品定位组织：外部 Agent 通过 Skills + CLI/MCP 联动全软件，负责资料填写、结构整理、创作参考及操作；河图洛书首先供作者可视化 review、审核与决定，其次供手动编辑优化。正文使用具体场景和当前对象，避免把 AI-first 缩成可选的单个生成按钮。首页、工作流程、接入说明和中英文博文保持相同分工；不将内部实现进度、工程审计或逐项待办放进宣传正文，实施及验收状态由20和19维护。发行入口仍须准确说明实际交付物，不能把源码包当成已签名安装包。

官网为 `https://hetu.limeai.run`，源码位于 `apps/website/`，与内核和桌面客户端同仓管理、独立构建和部署。网站介绍产品、提供面向作者的使用指南、展示品牌和可操作的设计原型。仓库 `docs/` 中的 PRD、架构、领域、数据、API 与研究资料属于研发文档，不参与官网构建与发布。

中文为默认入口，不根据 IP 地址强制跳转。语言切换保留指南位置，使用指南正文提供完整中英版本。用户作品正文不因界面语言切换而改写。创作动效使用预置示例；桌面预览使用隔离原创资料的真实 Electron 截图，不连接作者工作区、Git 或 MCP。

中文首页以创作库中的小说、剧本、视频及作者取舍为主叙事，“小说走向短剧”作为具体场景，不作唯一入口；英文从全球独立作者与小团队的跨媒介协作出发独立组织内容。首屏给出免费开源、安装包获取、无需安装的成果示例与界面预览、创作路径示意与带时间口径的市场信号。MCP、CLI、Skills 在首屏及其后提供可达入口，明确外部Agent负责理解、规划和生成，河图提供可查询、可操作、可恢复的创作底座，桌面工作台供作者查看、编辑、验收与定稿。

首屏采用河流、远山与书页长桥构成的原创环境背景，标题、说明和操作居中，中央雾面留白保证可读性，两岸与长桥分配在两侧及下方。背景延伸到导航后方并向正文自然淡出，超宽屏保持视觉中心与左右平衡；手机使用独立纵向构图。该意象表达从故事到剧本的连接，不复用 Lime 的月亮或布谷的鸟与竹叶。中段使用独立的连续镜头视觉示意，将内心活动变成可见动作；作者主张展示人的创作选择，三篇博客各有独立封面。首页不重复使用同一组宣传图，不以近似裁切充当新设计。插画不模拟按钮，不当作软件截图或成片能力证明；首屏优先加载，后续图片延迟加载。

“你的品味、判断与创意，始终是作品的中心”置于首页显眼区域，并配作者提出创意→工具展开候选→作者取舍定稿的关系图。小说与剧本工程化解释为系统性、可视化与创意管理，尊重小说作者和编剧各自的专业与独特表达，不宣传AI替代人类审美。客户端与演示书库保留简洁主张，长论述进入独立博客。

首页依次展示可切换的小说／剧本／视频成果、独立创作入口、外部Agent协作、作者意见与新版比较、Electron 工作台实图及工程分层；作者主张、市场证据、插件、Skills、疑问和文章保持可达。成果先于方法说明，不重复堆叠工程路径与格式图标。中国图表使用CNNIC、QuestMobile和中国作协来源；英文使用全球短剧App收入、下载及区域数据。证据由 `assets/research/story-market.json` 统一提供，图表使用线性零基线、明确单位、日期和来源。用户数、月活、下载量不混用，不把市场规模写成收益保证。详情见[市场研究](research/12-故事改编市场与创作者价值研究.md)。

成果与反馈使用预置双语原创示例，明确标注演示身份。首屏完整保留山水、长桥与留白，成果演示置于背景下方的独立正文区域，不以大卡片遮盖风景。连续六镜使用六张独立构图的插画，进入视口后约12秒推进一次后停止，字幕与镜头同步，支持逐镜切换与重播；小说可阅读段落，剧本可阅读场次，视频以可手动查看的分镜示意表达，不冒充真实生成成片。意见固定到对应示例位置，只展示变化文本；视频使用紧凑时间线标明所指镜头，不重复整组三镜插画。安装提示词折叠后恢复内容高度。比较展示旧版与新版及待审状态，不自动采用或定稿。文稿、设定、素材、修订及交付用可聚焦的纸面层次展示，保留格式指南入口。

同屏仅保留一个自动播放焦点，离屏和后台暂停，用户暂停后不自动恢复；减少动态效果时直接显示完整成果并支持手动浏览。标题、操作与首份成果由静态HTML提供；动效不阻塞阅读或导航。常规状态切换采用约250ms ease-out，禁止背景持续漂移、整页滚动隐藏或鼠标追逐。图片生成只用于故事场景插画和隔离示例的封面，不生成界面、品牌图标或流程文字；提示词、指定模型及摘要登记于素材清单，调用凭据不落盘。

自研 Agent 的取舍集中在简短说明和接入指南：通用 Agent 专注推理、上下文、工具调度与执行恢复，河图专注作品、设定、资料、版本和交付。介绍客户端生态时不推断全量兼容；插件安装、Skills 加载、MCP 连通、Apps 支持与实际任务分别核验。

官网文案从作者眼前的问题进入：人物改名后旧资料未更新、小说的内心活动难以表演、一份参考稿只有半句合适、交稿双方所说的“最新版”不同。博客用原创场景与带日期的数据展开论证，指南用真实按钮和小任务带读者完成操作。中文参考国内产品的自然表达，英文围绕独立作者及小团队的连续性、地区市场与交接独立写作。参考依据见[市场与创作者价值研究](research/12-故事改编市场与创作者价值研究.md#7-国内产品的文案参考)。

各页的信息组织与版式以[32第4.1节](32-品牌视觉与原型规范.md#41-官网逐页设计)为准。创作流程提供连续步骤与对应指南；接入页先说明三方分工和协作再进入 Skills 目录；指南采用任务分组与正文导航；博客采用主文章、独立封面、正文目录与相关阅读；FAQ 按问题分类；品牌资源按用途组织，标明演示与概念的区别。内页组成样式归 `src/styles/pages.css`，文档阅读样式归 `src/styles/docs.css`，不重复使用首页背景。文档概览采用三类创作任务入口和分组索引；顶部每个分类进入独立板块页，提供该板块的任务示例、审阅要点和指南，文章侧栏与前后篇限定在当前板块，面包屑可返回板块概览。顶部分类导航、全文搜索、文章侧栏和本页目录共享同一内容目录。搜索在浏览器内检索当前语言的标题、摘要和正文，支持键盘进入、空结果反馈与关闭后焦点恢复，不发送创作内容。文章提供复制正文、前后篇阅读和移动端目录。

创作场景按[创作场景规范](36-创作场景与引导流程.md)组织。小说、剧本、视频各自独立，固定来源按需关联；原创视频不要求空小说或空剧本。剧本、资产、预演、真实片段、剪辑音画及成片交付形成可接续过程，桌面供作者阅读观看、提意见与取舍，不承担节点画布或制作台操作。官网展示完整产品体验，内部能力覆盖与验收结果由20和19维护，不在宣传正文逐项添加进度标签。创作示意、交互演示和客户端截图按素材用途区分。

首页主 CTA 直接进入当前 Electron 工作台预览，快速起步使用真实截图、按钮名称与创作例子，说明交接目标、审阅成果、反馈与采纳。普通作者指南不展示终端命令、JSON、协议或工程流程图；Codex 入门说明复制目标、由 Agent 准备资料并通过工具保存、回读结果和作者审阅，不要求手工转填资料。源码下载保留独立的开发者入口，不称为安装包。下载交付物和客户端兼容性保持准确，设计演示不替代工程验收证据。

官网静态内容和本地编辑、审核、MCP 协作不要求登录。可选模型服务由同源 Pages Functions 提供，负责对接 Cloud 开放平台及 Console 账号、费用导航；不代理本机文件、作品保存、采纳或定稿。职责与先后见[03第8节](03-总体技术架构.md#8-桌面端与-web-服务端职责)及[20第5节](20-实施路线与里程碑.md#5-服务端演进与准入顺序)。

## 2. 技术与内容归属

Astro 输出静态 HTML，Markdown 文档通过 marked 在构建时渲染。首屏与导航不依赖客户端框架；移动菜单采用原生 details，支持键盘和 Escape 关闭。精确工具版本由工作区 `package.json` 与根 `package-lock.json` 锁定。

品牌母图归 `assets/brand/`，优化宣传图归 `assets/marketing/`，首页桌面实图预览归 `apps/website/src/components/Workbench.astro`、`scripts/workbench-preview.ts` 与 `styles/workbench-preview.css`；预置创作示例归 `CreativeResults.astro`、`RevisionExperience.astro` 与共用创作动效脚本，原生书库插画归 `assets/illustrations/library/`，设计材料归 `design/`。使用指南归 `apps/website/src/content/guides/{locale}/`，目录和页面标题归网站指南索引。`scripts/prepare-assets.mjs` 只投影公开品牌与原生插画资源，清理生成的旧工程文档副本，不读取根 `docs/`。机器来源及媒体摘要保留于 `assets/manifest.json`。

资源准备时核对发布副本与清单摘要，生成 `build/website/asset-versions.json`；静态页面与首页演示共用 `assetURL`，为图片、图标、下载和分享卡添加摘要版本参数。图片字节变化时地址随之改变，发布不依赖旧地址的 CDN 缓存过期。

题材目录复用 `integrations/catalog.json`，中文方法复用 `tools/hetu-skills/genres.json`，套件版本读取各自的 `plugin.json`，不在官网复制第二份分类或方法。目录卡片只保留题材、简介和版本，点击后以原生模态弹窗展示方法、例子、共用任务与来源分类，页面不原地展开长文。目录支持题材、平台与频道交集筛选；关闭弹窗保留筛选并恢复触发按钮焦点，支持 Esc、浏览器返回及 `#suite-{id}` 深链接。弹窗标题与关闭按钮固定，正文独立滚动，手机尺寸不越出视口。英文页面提供英文简介，并明确标注安装包中的中文方法。平台来源及核实边界以分类目录和[研究记录](research/10-GitHub写作Skills对照与方法整理.md)为准；官网不将分类节点数等同于安装包数量或平台实时全量覆盖。

插件中心与客户端 Skills 目录分开。插件身份、名称、版本、许可及权限读取 `plugins/*/plugin.json`；官网只维护精选目录、作者场景与检索分类，不复制专业动作清单。功能来源链接到各包的 `CAPABILITIES.md`。详情页提供自然语言协作请求、安装与逐作品授权说明、停用后的成果保留说明；未提供已核验分发制品时链接源码与构建指南，不显示虚假下载或在线安装。结构示意明确标注用途，不冒充运行截图。作者指南与开发者指南分别说明使用旅程和 JS/TS/React 开发合同。

官网开发者板块保留插件开发与发布指南；宿主源码构建及工具链要求由GitHub仓库README维护，官网不单独发布Mac源码版指南。作者安装路径只指向正式发布制品。

作者指南截图归 `apps/website/assets/guides/`，截图清单记录尺寸、摘要与实际制品来源；当前 Electron 预览另记录采集日期和隔离示例身份。资源准备逐图核对摘要，正文图片与原图放大链接使用同一版本地址；页面预留实际尺寸。截图只使用示例作品，并明确区分预置示例、历史 Mac 界面与当前 Electron 客户端，不生成假界面。站点不引用在线字体。

山海经纬以独立模板站 `https://shanhai.limeai.run/` 提供小说、剧本和短剧的原创范例、方法及固定下载。河图首页设置故事入口，各页页尾保留模板站链接；具体故事链接直接进入对应模板。插件中心按固定发行登记山海独立条目，展示运行包与验收来源，并链接到山海官网；外部条目的 `capabilities_path` 支持 monorepo 内的功能清单。模板目录、内容版本和专业插件由山海仓库维护，河图官网不复制模板库。模板可独立阅读和下载，使用河图时再进入桌面插件接续指南；山海与小说规划是平行插件。

## 3. 构建与发布

真实开发、构建和预览命令见[网站说明](../apps/website/README.md)。构建输出为 `apps/website/dist/`，无需原生内核、Swift、Xcode、WinUI 或数据库。

Cloudflare Pages 项目名为 `hetu-website`，配置归 `apps/website/wrangler.jsonc`；生产分支标识为 `main`。发布从本地已验证产物上传，不自动提交或推送 Git。Cloudflare 登录凭据由 Wrangler 的用户凭据存储管理，不写入仓库或网页资源。

自定义域名通过 Pages 项目绑定，并在 `limeai.run` DNS 中将 `hetu` 指向该项目的 Pages 域名。绑定后必须分别验证域名状态、DNS、TLS 和应用路径，不能以部署上传成功代替官网验收。

## 4. SEO、隐私与访问性

每页提供 title、description、canonical、语言 alternate、Open Graph 与 JSON-LD。`sitemap.xml` 包含正式页面，桌面预览作为首页内嵌组件，不生成独立页面；未知路径使用 404 页面，不回退成首页成功响应。

站点源码不收集创作示例输入，不设置分析脚本；河图控制台使用独立的必要登录 Cookie，Cloud 令牌仅在服务端加密保存。模型输入仅在作者批准的固定任务中外发；托管平台按其隐私政策处理连接与性能数据，线上可能出现同源性能回执请求。创作演示不得向性能回执或其他请求传输表单值与作品正文。响应头限制摄像头、麦克风和定位，设置 nosniff、引用策略与同源嵌入限制。应用图片、协议示例与外部链接不能包含凭据或本机路径。

页面支持 375 像素手机和桌面布局。检查键盘可达、焦点、图片替代文本、页面语言与溢出；宣传图中的文字不能替代真实标题和操作。双语资源键相同，创作示例与实际截图明确各自身份。

## 5. 发布验收与恢复
