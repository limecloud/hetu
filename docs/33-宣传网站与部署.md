# 宣传网站与部署

官网为 `https://hetu.limeai.run`，源码位于 `apps/website/`，与内核和原生客户端同仓管理、独立构建和部署。网站介绍产品、提供面向作者的使用指南、展示品牌和可操作的设计原型。仓库 `docs/` 中的 PRD、架构、领域、数据、API 与研究资料属于研发文档，不参与官网构建与发布。

## 1. 页面与语言

| 路径 | 内容 |
| --- | --- |
| `/`、`/en/` | 简体中文与英文首页 |
| `/workflow/`、`/en/workflow/` | 创作流程 |
| `/integrations/`、`/en/integrations/` | 题材 Skills 分类、方法与任务简介，以及外部助手协作与作者取舍 |
| `/faq/`、`/en/faq/` | 平台、边界、数据与许可 |
| `/brand/`、`/en/brand/` | 对应语言的品牌、界面图及桌面图标下载 |
| `/docs/`、`/en/docs/` | 中英文使用指南入口 |
| `/docs/{slug}/`、`/en/docs/{slug}/` | 源码下载与 Mac 启动、入门、Skills 选择安装、Codex 首任务、写作、设定、改编、审核、交稿、Agent 与备份指南 |
| `/#prototype`、`/en/#prototype` | 首页内嵌书库与工作台交互演示，无独立原型页面 |

中文为默认入口，不根据 IP 地址强制跳转。语言切换保留指南位置，使用指南正文提供完整中英版本。用户作品正文不因界面语言切换而改写。原型使用演示数据，不连接工作区、Git 或 MCP。

首页主 CTA 直接进入首页体验，快速起步使用真实截图、按钮名称与创作例子，说明打开作品、编辑、审核与采纳。普通作者指南不展示终端命令、JSON、协议或工程流程图；Codex 入门先说明复制提示词、读建议和手工填回资料，不把对话回答说成自动回传。源码下载保留独立的开发者入口，不称为安装包。产品范围与兼容性声明须绑定实际发布制品，网站中的设计演示不作为功能已实现的证据。

官网不参与本机 MCP、编辑或审核的运行链路，不要求作者登录后才能创作。服务端业务须有明确需求后单独立项，静态站点不作为本机工作区代理；职责与先后见[03第8节](03-总体技术架构.md#8-桌面端与-web-服务端职责)及[20第5节](20-实施路线与里程碑.md#5-服务端演进与准入顺序)。

## 2. 技术与内容归属

Astro 输出静态 HTML，Markdown 文档通过 marked 在构建时渲染。首屏与导航不依赖客户端框架；移动菜单采用原生 details，支持键盘和 Escape 关闭。精确工具版本由工作区 `package.json` 与根 `package-lock.json` 锁定。

品牌母图归 `assets/brand/`，优化宣传图归 `assets/marketing/`，首页交互演示归 `apps/website/src/components/Workbench.astro` 及其脚本和样式，原生书库插画归 `assets/illustrations/library/`，设计材料归 `design/`。使用指南归 `apps/website/src/content/guides/{locale}/`，目录和页面标题归网站指南索引。`scripts/prepare-assets.mjs` 只投影公开品牌与原生插画资源，清理生成的旧工程文档副本，不读取根 `docs/`。机器来源及媒体摘要保留于 `assets/manifest.json`。

资源准备时核对发布副本与清单摘要，生成 `build/website/asset-versions.json`；静态页面与首页演示共用 `assetURL`，为图片、图标、下载和分享卡添加摘要版本参数。图片字节变化时地址随之改变，发布不依赖旧地址的 CDN 缓存过期。

题材目录复用 `integrations/catalog.json`，中文方法复用 `tools/hetu-skills/genres.json`，套件版本读取各自的 `plugin.json`，不在官网复制第二份分类或方法。完整目录支持题材、平台与频道交集筛选，方法和来源分类路径可按需展开。英文页面提供英文简介，并明确标注安装包中的中文方法。平台来源及核实边界以分类目录和[研究记录](research/10-GitHub写作Skills对照与方法整理.md)为准；官网不将分类节点数等同于安装包数量或平台实时全量覆盖。

作者指南截图归 `apps/website/assets/guides/`，截图清单记录尺寸、摘要及首页演示或 Mac 来源。资源准备逐图核对摘要，正文图片与原图放大链接使用同一版本地址；页面预留实际尺寸。截图只使用示例作品，并明确区分首页演示和 Mac 客户端，不生成假界面。站点不引用在线字体。

## 3. 构建与发布

真实开发、构建和预览命令见[网站说明](../apps/website/README.md)。构建输出为 `apps/website/dist/`，无需原生内核、Swift、Xcode、WinUI 或数据库。

Cloudflare Pages 项目名为 `hetu-website`，配置归 `apps/website/wrangler.jsonc`；生产分支标识为 `main`。发布从本地已验证产物上传，不自动提交或推送 Git。Cloudflare 登录凭据由 Wrangler 的用户凭据存储管理，不写入仓库或网页资源。

自定义域名通过 Pages 项目绑定，并在 `limeai.run` DNS 中将 `hetu` 指向该项目的 Pages 域名。绑定后必须分别验证域名状态、DNS、TLS 和应用路径，不能以部署上传成功代替官网验收。

## 4. SEO、隐私与访问性

每页提供 title、description、canonical、语言 alternate、Open Graph 与 JSON-LD。`sitemap.xml` 包含正式页面，原型作为首页内嵌组件，不生成独立页面；未知路径使用 404 页面，不回退成首页成功响应。

站点源码不收集原型输入，不设账号、分析脚本或 Cookie；托管平台按其隐私政策处理连接与性能数据，线上可能出现同源性能回执请求。原型不得向性能回执或其他请求传输表单值与作品正文。响应头限制摄像头、麦克风和定位，设置 nosniff、引用策略与同源嵌入限制。应用图片、协议示例与外部链接不能包含凭据或本机路径。

页面支持 375 像素手机和桌面布局。检查键盘可达、焦点、图片替代文本、页面语言与溢出；宣传图中的文字不能替代真实标题和操作。双语资源键相同，设计原型明确自身演示性质。

## 5. 发布验收与恢复

构建门禁检查类型、产物本地引用、双语指南对应关系、双语键、敏感数据特征及 Pages 单文件限制，并拒绝工程文档与源文件副本。浏览器门禁检查首页体验、源码与快速起步入口、题材目录与版本、平台和频道交集、空态重置、键盘展开、双语指南正文、截图加载与放大链接、移动菜单、首页书库、编辑、审核、局部采纳、独立定稿与版本快照演示，并确认旧编号规范、研究和源文档路径返回 404。

线上验证首页、英文页、使用指南、原型、图标、站点地图、404 及缓存和安全响应头。图片按页面实际请求的版本 URL 核对字节摘要，不能只凭 HTTP 200 判断已显示新图。发布失败保留上一份有效部署；回滚选择 Pages 中上一份已验收的生产部署，再执行相同线上检查。不提交表单数据，无数据库迁移，无内容工作区同步或正文数据回滚。
