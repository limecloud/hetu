# 宣传网站与部署

官网为 `https://hetu.limeai.run`，源码位于 `apps/website/`，与内核和原生客户端同仓管理、独立构建和部署。网站介绍产品、提供面向作者的使用指南、展示品牌和可操作的设计原型。仓库 `docs/` 中的 PRD、架构、领域、数据、API 与研究资料属于研发文档，不参与官网构建与发布。

## 1. 页面与语言

| 路径 | 内容 |
| --- | --- |
| `/`、`/en/` | 简体中文与英文首页 |
| `/workflow/`、`/en/workflow/` | 创作流程 |
| `/integrations/`、`/en/integrations/` | MCP、Agent 与 AXI 职责 |
| `/faq/`、`/en/faq/` | 平台、边界、数据与许可 |
| `/brand/`、`/en/brand/` | 对应语言的品牌、界面图及桌面图标下载 |
| `/docs/`、`/en/docs/` | 中英文使用指南入口 |
| `/docs/{slug}/`、`/en/docs/{slug}/` | 入门、写作、设定、改编、审核、交稿、Agent 与备份指南 |
| `/prototype/index.html` | 品牌与设计展示 |
| `/prototype/workbench.html` | 页面内交互原型 |

中文为默认入口，不根据 IP 地址强制跳转。语言切换保留指南位置，使用指南正文提供完整中英版本。用户作品正文不因界面语言切换而改写。原型使用演示数据，不连接工作区、Git 或 MCP。

## 2. 技术与内容归属

Astro 输出静态 HTML，Markdown 文档通过 marked 在构建时渲染。首屏与导航不依赖客户端框架；移动菜单采用原生 details，支持键盘和 Escape 关闭。精确工具版本由工作区 `package.json` 与根 `package-lock.json` 锁定。

品牌母图归 `assets/brand/`，优化宣传图归 `assets/marketing/`，原型归 `design/`。使用指南归 `apps/website/src/content/guides/{locale}/`，目录和页面标题归网站指南索引。`scripts/prepare-assets.mjs` 只投影公开品牌与原型资源，清理生成的旧工程文档副本，不读取根 `docs/`。机器来源及媒体摘要保留于 `assets/manifest.json`。

Mermaid 运行文件随站点托管，来源、版本、摘要和许可证位于 `public/vendor/`。只在包含图表的文档加载，不通过第三方 CDN 传输读者请求。站点不引用在线字体。

## 3. 构建与发布

真实开发、构建和预览命令见[网站说明](../apps/website/README.md)。构建输出为 `apps/website/dist/`，无需原生内核、Swift、Xcode、WinUI 或数据库。

Cloudflare Pages 项目名为 `hetu-website`，配置归 `apps/website/wrangler.jsonc`；生产分支标识为 `main`。发布从本地已验证产物上传，不自动提交或推送 Git。Cloudflare 登录凭据由 Wrangler 的用户凭据存储管理，不写入仓库或网页资源。

自定义域名通过 Pages 项目绑定，并在 `limeai.run` DNS 中将 `hetu` 指向该项目的 Pages 域名。绑定后必须分别验证域名状态、DNS、TLS 和应用路径，不能以部署上传成功代替官网验收。

## 4. SEO、隐私与访问性

每页提供 title、description、canonical、语言 alternate、Open Graph 与 JSON-LD。`sitemap.xml` 包含正式页面，原型通过响应头标记 noindex；未知路径使用 404 页面，不回退成首页成功响应。

站点无表单、账号、分析脚本或 Cookie；托管平台按其网络运营政策处理连接信息。响应头限制摄像头、麦克风和定位，设置 nosniff、引用策略与同源嵌入限制。应用图片、协议示例与外部链接不能包含凭据或本机路径。

页面支持 375 像素手机和桌面布局。检查键盘可达、焦点、图片替代文本、页面语言与溢出；宣传图中的文字不能替代真实标题和操作。双语资源键相同，设计原型明确自身演示性质。

## 5. 发布验收与恢复

构建门禁检查类型、产物本地引用、双语键、敏感数据特征及 Pages 单文件限制，并拒绝工程文档与源文件副本。浏览器门禁检查双语指南正文、移动菜单、资源加载、使用流程图、原型编辑、审核与交付预览，并确认旧编号规范、研究和源文档路径返回 404。

线上验证首页、英文页、使用指南、原型、图标、站点地图、404 及缓存和安全响应头。发布失败保留上一份有效部署；回滚选择 Pages 中上一份已验收的生产部署，再执行相同线上检查。无表单与数据库迁移，无内容工作区同步或正文数据回滚。
