# 资料、素材与短剧制作资产

本章定义小说与短剧共用的资料管理、制作资产、生成交接和原生界面。身份与状态见[05](05-领域模型与数据合同.md)，字段见[29](29-数据字典与Schema设计.md)，动作见[30](30-应用API详细设计.md)，研究依据见[资产管理与图像模型研究](research/11-资产管理与图像模型研究.md)。

## 1. 用户与范围

中文作者是首要用户。共用导航使用“资料与素材”，短剧制作视图使用“制作资产”；不要求作者先理解文件哈希、模型协议或工程对象。界面采用 zh-CN 默认和完整 en 文案，作品内容语言独立。

| 分类 | 小说写作 | 剧本与短剧制作 |
| --- | --- | --- |
| 人物资料 | 人物小传、外貌参考、关系资料 | 人物形象、服装、妆发、声音参考 |
| 地点与场景 | 地图、建筑、环境资料 | 空间布局、布景、日夜、天气与破损版本 |
| 物品与道具 | 信物、兵器、关键物品资料 | 道具结构、尺寸、材质及持续状态 |
| 灵感与考据 | 灵感笔记、历史资料、摘录及来源 | 行业资料、生活参考、动作与表演参考 |
| 封面与插图 | 封面候选、插图、宣传图 | 海报、人物海报及宣传物料 |
| 音视频与文件 | 采访、录音、视频与附件 | 配音、配乐、音效、白模预演与外部工程 |

资料可以只有文字。没有图片、没有 Agent、没有账号和网络时，作者仍可整理资料、写作、编辑剧本、关联使用位置和交付。文件夹与标签用于组织，不承担故事身份或权限判断。

## 2. 作品与内容关系

```text
我的作品
 |
 +-- 小说作品 A（独立工作区）
 |    +-- 正文、分卷章节、大纲、设定集
 |    +-- 资料与素材
 |    +-- 短剧改编方案 A1
 |    |    +-- 固定原著来源
 |    |    +-- 分集计划 -> 分集剧本 -> 场次 -> 分镜
 |    |    +-- 本方案的造型、场景版本、道具及选用记录
 |    +-- 短剧改编方案 A2（独立身份与修订）
 |
 +-- 小说作品 B（独立工作区）
 |
 +-- 原创短剧作品 C（独立工作区，无需虚构小说来源）
      +-- 短剧项目、剧本、设定、资料与制作资产

通用素材：作者明确导入所选作品，保存独立记录和固定来源
```

源码 Monorepo、作者作品登记和作品工作区分别管理。小说工作区可包含多个改编方案，短剧项目不以同 IP、相同集号或人物同名认定归属。原创短剧工作区无需创建空小说。

改编消费固定原著修订。原著人物与短剧人物可显式对应；改编中的年龄、身份或地点调整须作为项目设定与改编说明保存，不能通过换图修改原著设定。

## 3. 唯一归属与领域关系

```text
设定集中的人物 / 地点 / 物品
              |
              | 明确关联，故事事实不复制为另一份权威
              v
资料条目（可独立保存文字、来源、标签）
              |
              +-- 设计版本（不变项、变化项、适用范围）
              |       |
              |       +-- 候选 A -> 成图、底图、透明图层、源文件
              |       +-- 候选 B -> 图片 / 音频 / 视频
              |                     |
              |                  作者选用
              |                     |
              +---------------------+
                                    v
                        章节 / 分集 / 场次 / 分镜的固定引用
```

| 对象 | 拥有内容 | 边界 |
| --- | --- | --- |
| 设定集 | 人物身份、经历、地点、规则等已确认故事事实 | 只有作者可维护；素材不反向覆盖事实 |
| 资料条目 ResourceItem | 说明、笔记、分类、标签、来源及关联 | 不把考据或外观提案自动认定为正典 |
| 设计版本 AssetDesign | 同一对象的一套造型、空间或持续状态设计 | 名称可变；日夜、天气、换装不是新故事身份 |
| 素材文件 MediaAsset | 受管原字节、摘要、类型及来源权利记录 | 缩略图可重建，原文件不可覆盖 |
| 素材候选 AssetCandidate | 某次设计提交所对应的一组固定文件与生成记录 | 接收成功不等于已选用 |
| 选用记录 AssetSelection | 作者对用途及候选的固定选择 | 与正文定稿、任务局部选择分别管理 |
| 使用记录 ResourceUsage | 所用资料或候选版本、用途和目标位置 | 不随“最新版本”静默替换 |

一份文件可被多个条目引用，但文件相同不意味着人物相同、权利相同或设计相同。作品内可按摘要去重原字节，业务身份、来源和许可记录保持独立。跨作品导入产生明确映射，交付不依赖另一作品仍在原路径。

## 4. 设计版本与场景

“地点”指故事中的空间身份，“场次”指某集的一场戏，“场景资料”保存空间与美术设计，“场景版本”表达同一空间的日夜、天气或持续变化。换机位通常属于分镜；仅在需要独立复用的视图时增加参考视图，不重建地点身份。

人物设计分别保存身份关联、基础外貌、造型与视图。换装不默认换脸，表情和瞬间姿势不强制拆成独立资产。道具的打开、破损、持有人等持续状态按剧情需求维护；普通陈设可以留在场景设计中。

设计的已知事实、作者选择和待确认提案明确区分。没有原文依据的外观可以作为设计提案，不谎称原著已经规定。未知字段允许为空，不强制真实朝代、固定画风、固定三视图或固定数量。

小说章节、剧本场次和分镜通过稳定 ID 关联资料。一个场次可拆成多个生成片段；模型时长上限只影响生成片段，不强迫改写分集与场次。片段参考角色、场景和道具的固定版本，不使用另一集的同名对象代替。

## 5. 图片生成与文件交接

外部 Agent 负责理解角色、组织提示词及推进任务，软件负责固定计划、核验结果和展示候选，不运行内置 Agent。作者可以使用 Agent 自身的图像能力，也可以选择河图的模型工具；自定义渠道的凭据保存在本机私密模型设置中，不进入作品、任务输入或 Agent 回读。单次内容外发及供应商计费须经作者批准，未知结果不自动重发。

角色、场景、道具及插图使用 `artwork` 图片任务，配套 `hetu-artwork` Skill；小说封面继续使用 `cover`。两者复用图片计划、完整解码、固定提交和预览，素材图不显示“设为封面”或书名叠字操作。角色图只是外观候选，不回写人物设定、正文或正式素材选用。Codex 通过已发现的 MCP／CLI 创建计划、查询批准、提交及收集原结果，再提交固定图片候选；软件按原比例展示并提供意见返工入口。

任务固定以下内容：作品与可选短剧项目、目标资料及设计修订、用途、中文设计要求、参考文件及用途、目标尺寸／比例、需保留与允许改变内容、候选数量、输出目录和结果合同。书名、笔名、正文引用保持作者原文；英文版任务中的界面示例与生成文字使用对应英文要求，不由界面语言擅自翻译作者内容。

参考图用途采用 `identity, appearance, style, layout, pose, palette, edit_base, mask, markup`。通用用途是交接意图，不声称模型原生支持同名参数；具体映射、图片顺序、数量、比例和编辑约束由型号档案说明。不支持的用途明确返回，不静默丢弃。

首批研究与交接覆盖 GPT Image、Gemini 图像模型、Midjourney、千问图像 Qwen-Image 和豆包生图 Seedream。万相为独立系列，不归入 Qwen 型号。Seedream 与视频模型 Seedance 分别管理，即梦产品入口与火山方舟接口分别说明。Midjourney 采用其允许的官方交互路径，不接入未经核实的第三方“官方 API”或自动化抓取。

模型档案按 `系列 + 具体型号 + 任务类型 + 通道 + 核查版本` 标识；记录任务能力、参考用途、输入数量、尺寸、输出格式、透明通道、分层、参数互斥和生命周期。模型原生能力、供应商开放能力、当前 Agent 可用工具及实测状态分别记录。官方文档支持不等于当前用户账号可用。

```text
作者选择资料与生成目标
          |
准备固定任务、参考版本和输出约定
          |
复制提示词 -> 外部 Agent / 用户选用的生成产品
                         |
                 生成、修改或下载结果
                         |
                 写入任务专属收件目录
                         |
河图核验任务、原文件、文件组与来源记录
          |
       候选比较
       /      \
    批注返工   作者选用
       |         |
   沿原任务    固定到具体用途与版本
```

收到同一提交键的重复回传在仍获权时返回原记录。已登记的迟到候选保留，来源变化标明不适用当前输入；关闭／撤权后拒绝新提交，新请求发布后旧请求停止新写入。未登记文件不自动进入候选或成为选用，作者可从仍持权的原生入口按明确导入流程处理。生成失败或结果未知由外部调用方恢复原供应商任务，河图不以新任务自动重复扣费生成。

## 6. 成组素材与可编辑成果

一个候选可包含完整成图、无字底图、透明图层、文字信息、蒙版、预览图和外部源工程。文件各自保存摘要与角色；图层另保存顺序、尺寸、位置及必要合成信息，保留提供方原始元数据。

Seedream 的图层拆分与富文本 OCR、Qwen-Image-Layered 等成果通过此合同接入。保留提供方结果不等于保证无损复原或具有 Photoshop 编辑能力；只有实际验证过的合成方式才启用本地合成预览。未知格式保留为附件，不执行脚本，不把截图称为可编辑源文件。

封面选用复用 [34](34-小说封面与Agent协作.md) 的 BookCover 记录；封面任务与通用设计任务复用素材、候选和固定引用，不另存一份当前封面。选用图层或修改书名后形成新候选，原封面及其来源保持可查。

## 7. 状态、权限与变更影响

| 维度 | 规则 |
| --- | --- |
| 资料与设计 | 草稿、已采用、已归档；只有作者可采用及恢复／归档正式资料 |
| 外部任务 | 待交接、等结果、部分返回、结果已到、需处理、已结束；不以复制事件推断生成中 |
| 候选 | 追加保存；作者可以选用、换用、撤回选用或批注返工 |
| 依赖当前性 | 与固定事实、设计或文件版本比较；过期不等于原文件损坏 |
| 文件可用性 | 存在性、摘要、可解码与预览能力分别记录 |
| 权利 | 来源、使用许可及再分发说明；选用不自动授予交付权 |

Agent 可查询获权范围内的资料、设计、候选及使用位置，分页获取必要字段，不默认读取全库或返回大文件字节。在任务授权内可新增、编辑和批量提交自己的未采用资料与设计，也可维护作者明确列为可改范围的未采用资料；其他已有内容只提出独立修订提案。只读资料固定到获权修订；可改资料一经采用或归档，任务不能继续读取作者之后的修订，只能读取原有固定参考；本任务新增且未获固定读取授权的正式资料退出任务列表。已采用资料、设定、正式封面选用、正文定稿与历史均受 Core 检查，Skills 不作为权限防线。

对同一任务的正常整理、生成候选、自检和返工不逐字段反复询问。作者决定集中在任务范围、设定变更、正式资料采用、素材选用和定稿。MCP Apps 与局部网页可以保存偏好、比较和批注；局部选择不冒充作者的最终选用能力。

稳定入口一次配置，每次调用显式 task_ref；原任务恢复先读已有资料、设计、候选和公开反馈。长资料通过目录、摘要、获权检索和固定片段按需取用，媒体只读取任务批准的受管预览／文件引用，不将全库或整组大图塞进任务 get。需要新增参考时，记录材料、用途与范围，作者批准后发布同任务的新请求和授权版本，读取扩展不等于修改扩展。

文字及设计草稿复用本章 Resource／AssetDesign 的 CAS，不用工作副本再保存第二个可写资料头；长篇参考说明、小说和 Fountain 创作稿采用通用工作副本。普通返工沿任务保存公开反馈并维护已有成果，正式文件候选不可覆盖。“按此修改”通过真实宿主能力请求继续，无能力复制精确提示词；Agent 完成声明、反馈保存与实际文件回执分别判断，合同见[30第23节](30-应用API详细设计.md#23-持续协作与任务接续合同)。

设计或参考图更新只提示实际依赖的候选与场次，不自动替换正在使用的版本。归档不损坏既有引用；移除仍在使用的资料须先处理引用。锁定限制编辑，作者仍可打开和阅读。

## 8. 原生界面与中文表达

入口为作品内“资料与素材”；短剧内“制作资产”按本项目过滤同一资料，不复制另一套库。“封面”继续位于作品资料，打开后可定位相同候选。

```text
+--------------------------------------------------------------------+
| 资料与素材                         搜索                 导入   AI 辅助 |
+---------------+---------------------------------+--------------------+
| 全部          | 名称       分类      状态        | 旧宅               |
| 人物资料      | 旧宅       地点场景  已采用      | 说明  版本  使用位置|
| 地点与场景    | 林舟赴宴装 人物造型  待选用      |                    |
| 物品与道具    | 玉佩       物品道具  已采用      | 白天 / 雨夜         |
| 灵感与考据    | 城市交通   考据资料  草稿        | 固定参考及图片预览  |
| 封面与插图    |                                 |                    |
| 音视频与文件  | 列表 / 缩略图                   | 比较版本   查看原文 |
+---------------+---------------------------------+--------------------+
```

文字资料默认紧凑列表；图片采用保持比例的缩略图，不拉伸，不为所有资料套大图片卡片。详情显示说明、版本和使用位置；来源、参数与技术 ID 放在可展开详情。AI 辅助沿用已选客户端，展开具体任务后提供“复制提示词”和“查看返回结果”。

资料编辑器通过“所属项目”区分“作品通用”与具体短剧项目；列表可按项目筛选。关联设定使用作者已保存的人物、地点、势力、事件和世界设定，不要求输入技术 ID。关联固定到选中时的设定修订，详情与历史查看显示该修订中的名称及版次；人物改名、项目切换和界面语言变化不能静默替换原关联。解除关联只修改资料的新修订，不删除设定或改写历史。

作者在章节或场次旁可查看相关资料，不必退出编辑；返回时保持光标、滚动和未保存缓冲。更换素材先显示当前与候选及受影响位置。主界面不堆提示词全文、模型参数、装饰眉题或解释性段落。颜色、字号、边框和对齐遵循[32](32-品牌视觉与原型规范.md)。

### 8.1 文字资料的版本影响核对

资料详情的“使用位置”以已登记的固定关联为范围，分别显示“资料已有新版”与“正文已有新版”；两者只说明版本变化，不推断语义错误或未登记的全书影响。支持全部／待核对筛选，归档关联不列为待核对。分页摘要只统计已载入的有效关联，存在后续页时明确显示可继续加载；读取失败不得显示为“没有变化”。

“核对变化”并列显示关联时的固定版本与本次读取的已保存版本，可分别比较资料和正文。旧原文坐标仅用于定位固定旧稿，不自动套用到新稿；未保存缓冲不进入比较，也不被刷新覆盖。资料摘要及原文引文不符时拒绝比较并保留错误。比较与关闭均不更新关联、不记录作者确认、不改变采纳或定稿；作者在正文编辑器处理修改，并按实际需要明确登记新的固定使用位置。作者步骤见[资料更新与影响核对](../apps/website/src/content/guides/zh-CN/references.md)。

## 9. 交付与验收

制作交接包包含所选资料说明、固定设计、参考图及用途、角色／场景／道具对应表、可选分镜／白模工程、模型提示词和来源清单。正式制片交付默认排除未采用候选、内部返工意见和完整生成提示词；作者可以单独选择制作交接 profile，仍逐项核验权利。

验收必须覆盖纯文字资料、手工导入、外部 Agent 候选、成组图层、多方案复用、跨作品导入、旧版本查看、CAS 冲突、迟到回传、权利撤回、断网及无 Apps 路径。具体编号与证据归[19](19-测试策略与验收矩阵.md)，界面可渲染或文档有图不代表业务已通过。
