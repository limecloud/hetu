# 故事改编市场与创作者价值研究

采集日期：2026-11-14。用于官网、博客与产品定位的证据核对，不作为产品能力或商业结果承诺。数字单一来源为 [`assets/research/story-market.json`](../../assets/research/story-market.json)；摘录及响应摘要见 [`evidence/story-market-2026-11-14.json`](evidence/story-market-2026-11-14.json)，来源登记见 [`sources.json`](sources.json)。

## 1. 需要回答的作者问题

- 我会写小说，为什么难以开始剧本与短剧制作？
- 我已有稿件，是否必须重新建小说、先整理骨架或先接 AI？
- Agent 的候选会不会直接成为正文或正式设计？
- 工程化会不会让作品公式化、让模型决定审美？
- 免费开源是否影响作品权利，外部生成是否另行收费？

产品回答以真实工作为起点：跨媒介需要把内心叙述转成可表演内容、把长篇组织成分集场次、把文字设定整理成可保持连续性的制作资料。河图连接这些材料，作者决定表达与取舍。场景与实现范围分别见[36](../36-创作场景与引导流程.md)和当前构建能力目录。

## 2. 已核实的中国市场来源

### CNNIC 第57次报告

- [发布页](https://www.cnnic.net.cn/n4/2026/0304/c88-11549.html)及[报告 PDF](https://www.cnnic.net.cn/NMediaFile/2026/0304/MAIN1772588317069TUXN3827X8.pdf)。
- 时间口径：2025年12月。
- 正文第23页表5：网络文学用户52595万人；第35页正文按四舍五入写为5.26亿，占网民46.7%。
- 正文第32页：微短剧用户6.64亿，占网民59.0%。微短剧包含于网络视频用户，不能把短视频用户整体算成短剧观众。
- 两类用户可重叠。两者数量关系不支持“短剧受众是小说十倍”，也不能通过相减推算新增可触达观众。

### QuestMobile 2026短剧行业洞察报告

- [官方报告](https://www.questmobile.com.cn/research/report/2041710682848727041/)，2026-04-08发布。
- 时间口径：2026年2月。正文列出红果免费短剧App月活3.04亿，独立短剧App整体月活3.35亿，短剧微信小程序渠道用户4.27亿。
- App与小程序存在交叉，不直接相加。月活与CNNIC调查用户数的统计方法和时间不同，不画为同口径排名。
- 采用官方可读正文；没有用维基百科、搜索摘要或转载替代最终证据。

### 中国作家协会网络文学中心《2024中国网络文学蓝皮书》

- [中国作家网全文](https://image.chinawriter.com.cn/n1/2025/0630/c404023-40511500.html)，来源为文艺报，2025-06-30发布。
- 根据全国50家重点网络文学网站数据：截至2024年底作品总量超过3300万部，2024年新增注册作者约280万人，新增签约作者35万人；年度新增微短剧改编授权超过1600部。
- 作品存量、年度新增注册作者、年度授权数量不能构成转化漏斗，也不宜推断“多少作者不会编剧”。授权不等于已拍成片，作品总量不等于完本数量。
- 报告还区分有收入作者与可职业化写作群体；注册人数、累计作者和专职从业者不能互换。用户提出的“1000多万小说从业者”未获得同口径支持，不作为事实发布。

## 3. 已核实的全球市场来源

[Sensor Tower: State of Short Drama Apps 2025](https://sensortower.com/blog/state-of-short-drama-apps-2025)，Rui Ma，2025年7月。

- 全球短剧App内购估计由2024年第一季度1.78亿美元增至2025年第一季度接近7亿美元，报告称接近4倍。
- 2025年第一季度全球下载超过3.7亿次。下载不是去重人数，不能写成观众人数。
- 同期美国占全球内购49%；拉美下载接近1亿次，东南亚接近8700万次。地区指标用于说明不同市场的形态，不据此自动推荐题材或承诺传播。
- 报告范围为App Store及Google Play，不含广告收入、第三方Android商店或官网支付。平台内购收入不能写成创作者收入。
- 这是一份明确日期的历史快照，不宣传为2026年的全球现状或预测。

## 4. 论述边界

| 说法 | 处理 |
| --- | --- |
| 短剧受众是小说十倍 | 缺少可靠依据，不采用 |
| 中国有1000多万小说职业从业者 | 未核实同口径，不采用；注册作者不等于职业从业者 |
| 小说只适合安静场景、只有小说爱好者才读 | 不做绝对判断；两种媒介都可碎片消费，注意力与阅读习惯有差异 |
| 短剧可以占据全天所有时间 | 不采用；描述更多观看场景，不承诺用户时长 |
| AI消除编剧和导演的必要性 | 不采用；专业创作者各有独特价值，工具帮助形成可讨论、可接续的材料 |
| 一键生成完整短剧、保证收益 | 不采用；河图组织创作、资料与交接，外部工具和团队负责生成、拍摄、剪辑与发行 |
| 作品工程化就是公式化写作 | 明确区分；工程化管理关系、版本与决定，不规定审美答案 |

## 5. 作者价值与工程化定位

每位小说作者和编剧都有独一无二的经历、观察、品味与表达，值得尊重。产品不提倡AI代替人的品味、判断和创意。小说与剧本工程化用于系统性、可视化和可管理的创作过程：设定可查、来源可核对、修改可比较、素材有版本、协作能接续。

确定性规则只能对有依据的约束给出结果。审美、动机、复杂人物与表达取舍由创作者判断。候选接收、参考稿审核、正文采纳、正式素材选用和作者定稿各自独立。完全手工创作是完整路径。

外部Agent负责理解、规划与生成；河图提供可查询、可操作、可恢复的创作底座；原生客户端供人查看、编辑、验收和定稿。成熟通用Agent已投入推理、上下文、工具调度与恢复，河图专注其可以使用的创作软件。MCP、CLI、Skills是一等入口，插件与Apps按宿主支持分别验证，不暗示全量兼容。

## 6. 中国与全球内容分别组织

| 内容 | 中文 | 英文 |
| --- | --- | --- |
| 主要受众 | 中国网文作者、编剧与IP工作室 | 独立作者、编剧与小型制作团队 |
| 市场证据 | CNNIC、红果与国内网文创作积累 | 全球移动短剧内购、下载与地区差异 |
| 核心问题 | 从卷章与原著到分集、场次与素材 | 跨媒介协作、连续性、版本与制作交接 |
| 示例 | 林舟、玉扣、雨夜旧宅；公版原著示例聊斋 | Mara、无线电、灯塔；特定公版原文与现代版本分开 |
| 获取路径 | 页面演示、中文作者指南与源码版说明 | 页面演示、英文作者指南与源码构建边界 |
| 方法范围 | 中文题材方法，平台分类按真实来源 | 明确当前套件为中文，不宣称全球题材覆盖 |

网站两种语言共用功能合同与证据定义，但标题、论述、市场图表、案例和文章独立写作。界面按钮及截图沿用当前真实语言，不能为本地化改造假按钮或伪造客户端结果。
