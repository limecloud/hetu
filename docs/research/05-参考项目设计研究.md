宣传网站位于 `apps/website/`，采用独立 Cloudflare Pages 项目。Gootuan 的 Workers、D1 与候补名单属于其业务；河图宣传网站没有对应业务需求，不引入数据库或表单。

Shou 的统一命令分发不代表统一 Swift CLI；河图选择一套 Swift CLI，通过共享 C ABI 调用 C++ 内核。语言与依赖的跨端部署按河图自己的发行要求验收。

河图不继承参考项目的品牌、业务源码、模型能力、私有接口、工具链通过记录或运行状态。共享 C++ 内核、无生成 API、文件权威与作者内容工作区是河图的独立设计决定。
