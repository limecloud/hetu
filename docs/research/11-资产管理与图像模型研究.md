# 资产管理与图像模型研究

核查日期：2026-11-14。证据包括固定提交的本地源码、项目所附截图和官方公开文档；本研究未运行第三方创作软件或付费生成任务，不提供模型画质排名、调用成功率或行业人数结论。来源及原字节摘要见[来源清单](sources.json)。产品采用规则见[资料与制作资产设计](../35-资料素材与短剧制作资产.md)。

## 1. 研究问题

小说作者既需要可自由书写的灵感、考据和人物资料，也需要封面与图片；短剧作者还需要复用人物造型、场景、道具、声音与分镜素材。研究重点是资料与正文的引用、基础身份与制作版本、候选与选用、文件与源工程、生成工具差异及多作品隔离。

## 3. GPT Image

依据：[生成指南](https://developers.openai.com/api/docs/guides/image-generation)、[提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)、[2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)、[2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)、[2.6 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst)。

2.5 的 Sunburst 与 Flare 有各自型号及快照，官方分别强调编辑精度和快速生图；综合指南同时描述 2.6 的新能力。参考图、蒙版、透明输出、标注辅助编辑、SVG 与动画输出等必须对应具体型号与任务，不把当前综合指南的所有参数套给旧型号。

官方明确提示文字、重复人物一致性及精确构图仍存在限制。书名与笔名须逐字核对，不能以提示词包含了原文就判定封面文字正确；参考图与实际返回文件分别保存。带透明背景的输出要检查实际 alpha 通道，不依靠扩展名判断。

## 4. Gemini 图像模型

依据：[官方图像生成与编辑指南](https://ai.google.dev/gemini-api/docs/image-generation)、[型号目录](https://ai.google.dev/gemini-api/docs/models)。当前官方图像指南列出 Nano Banana 系列不同型号，描述文本生图、多图参考、多轮编辑与分辨率差异。

指南中的 14 张参考图规则有型号与参考类别细分，不能为所有 Gemini 型号共用同一上限。人物、物品与风格参考各有含义；多轮修改需要外部调用方保留其所需的会话上下文。核心仅接收实际成果与必要来源投影，不保存推理过程或把中间思考图当成最终候选。官方说明生成图含 SynthID，导入和交付不得以去除该信息作为成功条件。

## 5. Midjourney

依据：[Image Prompts](https://docs.midjourney.com/hc/en-us/articles/32040250122381)、[Omni Reference](https://docs.midjourney.com/hc/en-us/articles/36285124473997)、[Edit Model Reference](https://docs.midjourney.com/hc/en-us/articles/48495453462797)、[Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653)、[服务条款](https://docs.midjourney.com/hc/en-us/articles/32083055291277)。Edit 与 Style 正文还通过同站公开 Help Center 文章 JSON 核实，采集表示见来源清单。

Omni Reference 文档限定 V7、单张参考；当前 Edit Model 文档适用于 V8.1／V8.2，支持最多四张参考及编辑。Style Reference 借用色彩、媒介、纹理等风格，不等于人物身份复现。Image Prompt、风格参考和编辑参考不可合并为一串没有用途的图片 URL。

服务条款限制自动工具访问。河图首批采用提示词、参考清单与作者通过官方产品操作后导入成果的路径；不把第三方中转接口称为官方 Midjourney API，也不默认使用浏览器自动化代用户生成。参考图是否上传由作者在所选产品中决定，河图不自动公开本机图片。

## 6. 千问图像 Qwen-Image

依据：[文生图 API](https://help.aliyun.com/zh/model-studio/qwen-image-api)、[图像编辑 API](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)、[官方仓库](https://github.com/QwenLM/Qwen-Image/tree/6b5e1f5cec987d404be5ac6657db3b9aacb56a89)、[Layered 模型卡](https://huggingface.co/Qwen/Qwen-Image-Layered)。

百炼的 `qwen-image-2.0`／`qwen-image-2.0-pro` 服务、开源 `Qwen-Image-2512`、`Qwen-Image-Edit-2511` 和 `Qwen-Image-Layered` 分别建档。编辑接口的图像顺序、参考数量和尺寸要求以具体服务为准；开源权重存在不代表软件内置推理或所有供应商开放相同参数。

Layered 将图像分解为多个 RGBA 图层，说明素材应支持成组文件与图层信息。不能把若干透明 PNG 直接称为可编辑 PSD，需保留实际格式和重建方式。万相属于独立模型系列，不能用 Qwen 名称概括全部阿里图像服务。

## 7. 豆包生图 Seedream

依据：[图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[Seedream 5.5](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh)、[5.0 Pro／Flash](https://docs.volcengine.com/docs/ark/seedream-5-0-pro?lang=zh)、[交互编辑](https://docs.volcengine.com/docs/ark/seedream-5-0-pro-editing-guide?lang=zh)、[4.0–5.0 提示词指南](https://docs.volcengine.com/docs/ark/seedream-4-0-5-0-prompt-guide?lang=zh)。

| 型号范围 | 本次核实的差异 | 交接设计 |
| --- | --- | --- |
| `doubao-seedream-5-5-261028` | 原生 RGBA、图层拆分、富文本 OCR、多轮编辑一致性；RGBA 参考输入范围与旧型号不同 | 成图、底图、透明图层、文字及样式信息按文件组保存 |
| `doubao-seedream-5-0-pro-260628`／`doubao-seedream-5-0-flash-260915` | 交互编辑、图层拆分；输入与透明处理约束分别核查 | 保留编辑底图、点位／框选／箭头和实际提示词 |
| 5.0 Lite、4.5／4.0 | API 定义组图输出与输入／输出总张数限制；不能推断其他型号也支持组图 | 组图、批次和多个独立候选分别记录 |

当前 API 对 5.5、5.0 Pro／Flash 的多参考与组图限制不同于上述旧型号，不能把所有 Seedream 限定成旧的 14 张参考。交互坐标指南使用单张图片归一化坐标，外部工具必须记录基准图和变换，界面框选像素不能直接充当模型坐标。

即梦是产品入口，Seedream 是图像模型系列，火山方舟是具体 API 通道；三者不共享默认权限假设。Seedance 是视频模型，图像资料不能替代视频能力档案。小说封面、人物造型、场景与道具参考均可使用适合的外部生成工具，核心不发起这些请求。

## 8. 视频制作与外部工具衔接

短剧场次与模型生成片段独立。Seedance 2.5、可灵、MiniMax、万相等视频能力按具体型号、任务、通道和生命周期维护；固定人物、造型、场景、道具与参考用途后再编制片段交接。不能从历史源码中的 15 秒常量推断最新模型限制。

参考模型资料与片段交接并不意味着提供河图内置视频生成。开放源码中的参数或网关适配先对照官方文档；外部工具返回实际型号、供应商任务与文件，来源声明和字节核验分别记录。

## 9. 采用结论与验证范围

1. 采用“资料与素材”共用入口，故事事实、设计、文件、候选、选用及使用位置各有归属。
2. 图像交接支持固定参考用途、多候选及成组成果；能力档案随具体型号而非品牌更新。
3. 默认使用中文任务说明。只有具体工具或作者要求才提供对应英文提示词，不强制所有生图 Prompt 为英文。
4. 正式选用由作者决定，Agent 可在授权范围内连续整理、提交和返工；候选接收不改变正式资料或正文。
5. 单文件结构检查、真实解码、参考身份与画面质量分别验收；研究文档不替代生成实测或版权授权。
