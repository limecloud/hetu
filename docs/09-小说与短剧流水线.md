# 小说与短剧流水线

核心做结构转换，不生成台词、镜头描述或新剧情。节点来自固定源文，作者可人工补标，外部 Agent 只能提交待审补充。

## 1. 剧情节点

节点种类为 `action, dialogue, scene, conflict_candidate, foreshadow_candidate`。共同字段为稳定 ID、类型、原文引用、人物／地点／时间引用、提取方法、确认状态及缺失前提。

原文对话可以作为只读来源证据引用，但骨架不自动把它改写成新台词。因果边只有作者标注或明确结构来源才能进入已确认图；基于模式得到的边仍为候选。

节点集合以不可变提取修订保存，作者校正产生新修订。源文变化后旧集合仍能回溯，但新骨架必须显式选择是否重提取及如何迁移人工校正。

## 2. 分集与分场

输入为节点修订、设定集修订、作者分集锚点及可选目标集长。算法优先保留作者标记，按地点、明确时间变化与场景边界分组，按稳定顺序输出。分集可以依据节点数与原文字数给出候选切点，实际时长和戏剧节奏由作者确认。

| 字段 | 语义 |
| --- | --- |
| `episode_id, episode_number` | 稳定身份与展示集号，重排不换身份 |
| `scene_id, scene_number` | 稳定场次与当前顺序 |
| `location_ref` | 已确认地点或 `null` |
| `interior_exterior` | `interior|exterior|mixed|unknown` |
| `time_of_day` | `day|night|dawn|dusk|unknown` |
| `character_refs` | 已确认出场人物，歧义单列 |
| `plot_node_refs, source_refs` | 节点和原著定位 |
| `missing_fields` | 待作者补充的结构信息 |
| `dialogue, shot_description` | 新骨架为空，留给作者或外部 Agent |

未知地点、日夜或人物必须保留未知，不能为了模板完整猜“内景／日”。预计时长标为估计，不声称达到制片方实际拍摄时长。

## 3. 编辑与草稿填充

作者可拖动场次、拆分、合并和修改结构。每次操作记录来源映射与结构修订，不直接改原著。手工与 Agent 填充的正文都进入草稿；Agent 提交必须引用 `skeleton_id`、骨架修订及设定集版本，目标结构变化时返回冲突或创建明确的分叉草稿。

重新生成骨架先预览差异，不覆盖已有剧本或已确认的人工分场。对新源文采用三方比较：旧源文／旧结构、当前作者结构、新提取候选。无法确定的映射留待作者处理。

## 4. 反向诊断与回写

差异类别为 `added, omitted, reordered, modified, unmapped, stale_source`。分别显示原著证据、骨架位置、定稿剧本修订和作者已接受的改编说明。

小说心理描写过重、缺少可见动作、动机线索不足等为影视化候选问题；不能由它们直接推出“应当删掉”或自动补情节。

“回写原著”仅指作者确认后创建原著的新修订，不能把短剧版本覆盖为新的 IP 正典。改变设定集的事实仍须经过设定集解锁与作者编辑流程。改编例外可以保存在对应剧本中，不能静默修改全 IP 规则。

## 5. 最小完整案例

输入两章已有文本，作者确认人物林舟与地点旧宅，第二场日夜未知。抽取保留动作和对话原文范围，生成一集两场；第二场显示“时间待补充”，台词和镜头栏为空。作者手工填写剧本并审核，导出包含所选原著修订、两场骨架、定稿剧本与映射报告。

验证应断言：没有新增无来源剧情、没有自动填台词、未知字段保留、章节改写使旧报告过期、重建不覆盖人工编辑、纯手工路径全程可用。
