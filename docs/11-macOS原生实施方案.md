# macOS桌面实施

## 本机使用路径

本地阅读与编辑无需Agent账号。作者选用内嵌引擎时才检查其安装及认证；只读打开作品不创建生成任务。应用更新保留作品和偏好，安装成功不代表模型创作旅程已验证。

产品定位与任务分流见[01](01-产品需求PRD.md#1-产品定义)。

macOS桌面使用Electron、TypeScript/React工作台和Rust App Server。文件名保留以维持文档引用；共享职责见[39](39-Electron与插件优先重构架构.md)，构建与签名见[21](21-构建分发与运维.md)。

## 1. 应用与机器入口

Electron主进程管理系统窗口、菜单、文件选择与受管进程，renderer经受限preload和JSON-RPC 2.0私有stdio调用Rust App Server。独立Rust CLI、MCP和插件CLI直接复用共享Core，不要求桌面窗口运行。

正式应用沿用 `run.limeai.hetu`，开发应用沿用 `run.limeai.hetu.dev`。两者分别使用自己的配置与调试目录；Bundle ID不改变作品身份、授权或持久目录。

## 2. 开发与装配

Finder双击 `dev-mac.command`，或从源码目录执行：

```bash
python3 "tools/dev-mac.py"
```

入口核验工具链、构建共享页面及Rust/TypeScript，再生成独立开发包。实际路径和源码、资源与制品摘要由本次装配清单返回。正式签名、公证、干净系统安装与升级另行验收，不由开发签名推导。

本机覆盖安装使用 `npm run package:desktop -- --local-install`，生成名称为 `Hetu.app`、标识为 `run.limeai.hetu` 的本机构建。该模式使用开发签名，清单明确记录本机安装身份，不作为官方已公证发行包。覆盖前备份现有应用，保留作者数据并核对实际应用与清单。

## 3. 系统体验与验收

窗口、菜单、键盘、输入法、焦点、撤销、辅助功能与安全文件选择按macOS分别验收。工作台沿用作者确认的Mac布局和交互，固定截图及历史证据用于对照，规则见[10](10-原生客户端与交互设计.md)与[19](19-测试策略与验收矩阵.md)。

作者作品、机器授权、设置与凭据分别遵循共享Owner和私密存储合同。停用插件、关闭窗口和重开应用不丢失持久成果或原操作恢复信息。
