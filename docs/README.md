## 使用约定

- 产品名为“河图洛书 Hetu Luoshu”，软件仓库名为 `hetu`。
- “源码Monorepo”“创作库”和“作品工作区”分别指软件工程、三类对象登记与文件事务范围；同根多个对象仍核验具体身份和权限，来源关联不自动扩权。
- V1.0 是本文档产品范围，软件发行版本、Schema 版本、ABI 版本分别管理。
- `contracts/` 拥有机器 Schema；文档拥有字段语义、约束与设计理由，修改时同步评审。
- 已采纳Electron＋TS插件宿主＋Rust Core；原生源码已退役，历史验收保留原版本证据，Electron按作者确认的Mac交互与当前风格独立验收。文件名中“原生”保留链接身份，以正文目标为准。
- 规范定义与运行证据分开；验收和兼容声明必须绑定具体版本、平台和制品。
