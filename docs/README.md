## 使用约定

- 产品名为“河图 Hetu”，软件仓库名为 `hetu`。
- “源码 Monorepo”和“IP 内容工作区”分别指软件工程与作者内容，目录不得混用。
- V1.0 是本文档产品范围，软件发行版本、Schema 版本、ABI 版本分别管理。
- `contracts/` 拥有机器 Schema；文档拥有字段语义、约束与设计理由，修改时同步评审。
- 规范定义与运行证据分开；验收和兼容声明必须绑定具体版本、平台和制品。
