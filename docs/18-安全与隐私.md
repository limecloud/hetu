# 安全与隐私

本章约束桌面、CLI、MCP 与可选插件。核心本地运行，默认无正文遥测、云备份、模型请求或后台网络探测。

## 1. 信任边界

| 输入／主体 | 信任级别 | 控制 |
| --- | --- | --- |
| 本地作者在可信 UI／交互 CLI 的操作 | 可表达本次作者意图 | 绑定工作区、对象、版本、动作与有效期 |
| 外部 Agent 与 MCP 参数 | 不可信业务输入 | 最小能力、Schema、CAS、限额、不可自批 |
| 小说、设定集文字、批注与素材 | 不可信内容 | 纯数据解析，不执行提示词、脚本或链接 |
| Git 仓库及其配置 | 可能来自他人 | 不执行 hooks、过滤器、任意 transport 或内嵌程序 |
| 可选多媒体插件 | 独立外部程序 | 显式启用、最少数据、进程与凭据边界 |
| 同用户任意文件访问程序 | 超出 API 隔离能力 | 检测外部改写，依赖操作系统权限隔离 |

本地锁和作者会话不是对具有相同 OS 权限的恶意进程的完整安全沙箱。若宿主已授予 Agent 任意 Shell 与整个工作区写权限，河图无法阻止它绕过 MCP；产品必须如实提示权限范围，不能宣称绝对防 OOC 或防篡改。

## 2. 路径与文件身份

API 使用对象 ID 或闭合相对路径映射。拒绝绝对路径、`..`、NUL、设备路径、URL 当文件、非法编码、隐藏流与越界链接。规范化后还需基于实际文件身份和受控根验证，不能只做字符串前缀比较。

macOS 验证符号链接、卷行为和打开句柄；Windows 验证 junction、reparse point、大小写与备用数据流。防止检查后被替换的竞态，写入使用原生安全打开及同卷原子替换；不读取工作区外部敏感文件后再报错。

## 3. 权限模型

能力至少分为设定集读取、所选原文读取、草稿写入、派生结构写入、报告生成、导出及作者管理。权限由服务端上下文确定，不能从请求字段或文档内容提升。

设定集编辑／解锁、审核定稿、Git 变更与内容外发需要可信作者意图。确认记录绑定本次输入摘要，一次性使用，工作区切换、撤权、过期或数据变化即失效。作者授权存储在当前用户应用数据中，不纳入 Git；业务审计可记录决定摘要，不能携带授权秘密。

## 4. 秘密与网络

Git Token 使用 Keychain／Credential Manager，SSH 私钥保留系统侧。供应商 API Key 只归独立插件管理。任何秘密不得进入 `.heturc.json`、设定集、草稿 metadata、Git URL、进程参数、普通日志、Bundle 或公开诊断。

核心联网仅在用户选择的 Git 操作和明确启用的更新检查中发生；更新检查默认不自动启用。无常驻监听端口。若未来增加 HTTP MCP，必须另立本机认证、Origin、DNS rebinding、TLS／回环边界与访问控制合同，不能复用 stdio 假设。

## 5. 内容与显示安全

Markdown 原生预览禁止脚本、自动远程图片和任意协议导航；外部链接由作者显式打开。MCP Apps 采用宿主支持的 CSP 与受管桥接，无直接本地文件和供应商访问。

正文与工具结果中的提示注入不执行；不能把“系统消息”“作者已批准”等文本解释成权限。终端输出转义控制序列，异常消息不回显完整正文、Token 或本机敏感路径。

## 6. 资源与供应链

对输入字节、文档数、规则复杂度、媒体尺寸、压缩输出、运行时长和并发分别限额。恶意长文本、递归 JSON、压缩炸弹、损坏媒体、路径逃逸与取消竞态纳入测试。插件未知任务结果不得自动重试付费生成。

依赖固定版本与摘要，记录许可与 SBOM；发布产物签名并验真。禁止从作者工作区动态加载 DLL／dylib、执行配置中的命令或隐式安装全局软件。

## 7. 隐私与保留

操作审计保存允许字段投影，支持作者预览后导出脱敏诊断。诊断包默认包含版本、错误码、资源与任务元数据，不含正文、媒体、凭据或全部路径。作者另行选择具体片段时显示外发范围。

删除项目登记不删除作品；清理缓存不删除修订、审核或操作记录。移除历史内容与审计属于显式数据保留操作，先说明引用与恢复影响并确认。安全报告不默认自动上传。
