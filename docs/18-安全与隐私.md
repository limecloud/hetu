# 安全与隐私

本章约束桌面、CLI、MCP、MCP Apps、按需本地网页与可选插件。核心本地运行，默认无正文遥测、云备份、模型请求或后台网络探测。作者复制到外部客户端的上下文受该客户端的数据政策约束，河图洛书在复制前展示资料清单与可编辑 Prompt。

## 1. 信任边界

| 输入／主体 | 信任级别 | 控制 |
| --- | --- | --- |
| 本地作者在可信 UI／交互 CLI 的操作 | 可表达本次作者意图 | 绑定工作区、对象、版本、动作与有效期 |
| 外部 Agent 与 MCP 参数 | 不可信业务输入 | 最小能力、Schema、CAS、限额、不可自批 |
| MCP App 或内置浏览器操作 | 已授权范围内的局部交互输入 | 重验任务、修订和会话；点击事件不证明是作者 |
| 小说、设定集文字、批注与素材 | 不可信内容 | 纯数据解析，不执行提示词、脚本或链接 |
| Git 仓库及其配置 | 可能来自他人 | 不执行 hooks、过滤器、任意 transport 或内嵌程序 |
| 可选多媒体插件 | 独立外部程序 | 显式启用、最少数据、进程与凭据边界 |
| 同用户任意文件访问程序 | 超出 API 隔离能力 | 检测外部改写，依赖操作系统权限隔离 |

本地锁和作者会话不是对具有相同 OS 权限的恶意进程的完整安全沙箱。若宿主已授予 Agent 任意 Shell 与整个工作区写权限，河图洛书无法阻止它绕过 MCP；产品必须如实提示权限范围，不能宣称绝对防 OOC 或防篡改。

## 2. 路径与文件身份

API 使用对象 ID 或闭合相对路径映射。拒绝绝对路径、`..`、NUL、设备路径、URL 当文件、非法编码、隐藏流与越界链接。规范化后还需基于实际文件身份和受控根验证，不能只做字符串前缀比较。

macOS 验证符号链接、卷行为和打开句柄；Windows 验证 junction、reparse point、大小写与备用数据流。防止检查后被替换的竞态，写入使用原生安全打开及同卷原子替换；不读取工作区外部敏感文件后再报错。

## 3. 权限模型

能力至少分为设定集读取、所选原文读取、草稿写入、派生结构写入、报告生成、导出及作者管理。权限由执行用例的 Core 及可信入口上下文确定，不能从请求字段或文档内容提升；本机 MCP 的权限检查不依赖云服务。

设定集编辑／解锁、参考稿审核与采纳、独立定稿、Git 变更与内容外发需要可信作者意图。确认记录绑定本次输入摘要，一次性使用，工作区切换、撤权、过期或数据变化即失效。作者授权存储在当前用户应用数据中，不纳入 Git；业务审计可记录决定摘要，不能携带授权秘密。

正文改稿还须区分 `input_refs` 的参考读取和 `edit_scope` 的可改范围。任务连接只能读取固定请求及本任务结果，不因此获得通用文档查询或写作稿保存权限；新增上下文不扩大可改范围。`revision` 任务仅接受基于固定修订的范围内补丁，整章内容提交不能绕过选区。Core 检查 UTF-8 边界、原文引句、非重叠和范围包含关系，整批拒绝越界；作者采纳及定稿各自重新核验。UI 锁、当前选区、Skill 文字或工具 annotations 均不替代此检查。

任务关闭后，既有连接的后续请求和原操作查询也须失权；已提交的候选不删除。任务 ID 与请求摘要用于身份绑定及完整性，不是作者凭据，也不赋予 OS 文件隔离；外部宿主权限的限制仍遵守第1节。

## 4. 秘密与网络

Git Token 使用 Keychain／Credential Manager，SSH 私钥保留系统侧。供应商 API Key 只归独立插件管理。任何秘密不得进入 `.heturc.json`、设定集、草稿 metadata、Git URL、进程参数、普通日志、Bundle 或公开诊断。

核心对外联网仅在用户选择的 Git 操作和明确启用的更新检查中发生；更新检查默认不自动启用。按需局部网页只提供回环 HTTP，不属于生成服务或 HTTP MCP，不默认常驻监听。若增加 HTTP MCP，其传输和授权仍须独立评审，不能复用 stdio 或网页会话假设。

## 5. 内容与显示安全

Markdown 原生预览禁止脚本、自动远程图片和任意协议导航；外部链接由作者显式打开。MCP Apps 采用宿主支持的 CSP 与受管桥接，无直接本地文件和供应商访问。

正文与工具结果中的提示注入不执行；不能把“系统消息”“作者已批准”等文本解释成权限。终端输出转义控制序列，异常消息不回显完整正文、Token 或本机敏感路径。

## 6. 资源与供应链

对输入字节、文档数、规则复杂度、媒体尺寸、压缩输出、运行时长和并发分别限额。恶意长文本、递归 JSON、压缩炸弹、损坏媒体、路径逃逸与取消竞态纳入测试。插件未知任务结果不得自动重试付费生成。

依赖固定版本与摘要，记录许可与 SBOM；发布产物签名并验真。禁止从作者工作区动态加载 DLL／dylib、执行配置中的命令或隐式安装全局软件。

## 7. 隐私与保留

操作审计保存允许字段投影，支持作者预览后导出脱敏诊断。诊断包默认包含版本、错误码、资源与任务元数据，不含正文、媒体、凭据或全部路径。作者另行选择具体片段时显示外发范围。

删除项目登记不删除作品；清理缓存不删除修订、审核或操作记录。移除历史内容与审计属于显式数据保留操作，先说明引用与恢复影响并确认。安全报告不默认自动上传。

## 8. 回环页面与浏览器配对

页面服务仅由河图洛书按需启动，绑定 `127.0.0.1` 和系统分配端口，不监听 `0.0.0.0`，不自动开启公网隧道。即使来自回环，也必须验证 Host、Origin、会话、CSRF、请求体预算及精确动作白名单，防范跨站请求及 DNS rebinding。普通页面导航与配对等待不返回正文或私密候选；只读 GET 不产生持久业务变更。

作者在可信原生界面确认配对后，为浏览器建立单筹备或单作品内的单任务短期会话。凭据经受控本机通道和浏览器会话机制交付，不能放入 URL、Prompt、命令参数、HTML 源码或日志。会话 Cookie 使用 HttpOnly 与适配实际回环协议的安全策略，关闭通配 CORS；写请求有 CSRF 校验。普通链接或 task_id 不能充当 bearer 授权。

页面仅代理当前任务查询、局部选择、意见及原保存回执查询；候选通过既有 MCP 任务工具或收件箱提交。页面不代理任意文件、路径、Shell、设定写入、正式封面选用、定稿或 Git。Node.js 不从作者配置加载可执行脚本，也不继承 NODE_OPTIONS、NODE_PATH 或 Agent 凭据；IPC 上下文由可信应用组装，Agent 不能通过 JSON 参数声明角色。

页面 CSP 使用自带脚本、样式与媒体代理白名单，不自动加载供应商或外站图片；媒体访问仍核验当前 scope。切换任务、撤权、过期和停止服务时清除会话及敏感临时数据，迟到请求不得落到新任务。外部云浏览器不可达本机时回退原生端，不扩大网络暴露范围。

## 9. 服务端部署的授权边界

服务端业务须先满足[03](03-总体技术架构.md#8-桌面端与-web-服务端职责)的立项条件。若需求涉及作品外发，须显示具体内容、修订及接收范围，取得与该次内容绑定的作者确认；不得隐式上传整库、未保存稿或本机秘密。身份、资源权限、撤权、数据保留及删除须按实际业务独立验证。

远端身份不换取本机作者身份、文件权限或回环会话。远端 MCP 如需建设，只访问明确获权的服务端对象。本机软件保持独立的权限与生命周期，公共服务不可用不阻断本机创作。
