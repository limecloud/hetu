# 测试策略与验收矩阵

以用户行为、失败及恢复验证合同；内核、跨端桥接、原生界面、协议与分发分别提供证据。

## 1. 验证层级

| 层级 | 验证目标 | 不能代替 |
| --- | --- | --- |
| 文档／Schema | 链接、ID、示例与约束一致 | 功能实现 |
| Rust 单元／夹具 | 设定集、引用、规则、状态与来源 | 原生文件系统及 UI |
| 存储／Git 集成 | 真实文件、跨进程、事务、仓库恢复 | 真实远端和用户旅程 |
| C ABI／Swift／C# | 生命周期、编码、取消与错误 | 原生编辑、签名和安装 |
| CLI／MCP 协议 | 机器输入输出、权限、断线、幂等 | 特定宿主与人类审批 |
| 真实 Agent 协作 | Codex 新会话、任务发现、按需资料、持续参考稿、反馈返工及恢复 | 其他宿主兼容、正式签名、未执行的长篇规模测试 |
| 原生 UI | 中文输入、焦点、权限及完整任务 | 其他 OS 或架构 |
| 格式互操作 | 文件有效性、第三方打开、语义回环 | 所有阅读器和制片模板 |
| 分发 | 干净系统、签名、依赖与升级 | 未测试平台支持 |

### 2.1 专项验证责任

本节规定测试应证明的合同，不记录某次构建通过了什么。自动化夹具、原生 UI、真实宿主及签名分发分别保留执行证据，不能互相替代。

| 专项 | 核心及协议断言 | 原生交互或外部验收 |
| --- | --- | --- |
| 剧情与诊断 | 中文／Emoji／CRLF 精确来源、候选隔离、事实有效期、梦境／转述／假设、覆盖与预算、处置 CAS、摘要篡改拒绝 | 作者标注、报告筛选、固定原文定位、具体处置和双语切换 |
| 分集与骨架 | 稳定 ID、空对白、未知日夜、拆合重排、跨集移动、来源不可伪造、历史与快照游标 | 分集选择、结构表单、原著对照和方案隔离 |
| Fountain 剧本 | 模板语言、结构标题、不可表达项、初稿 UTF-8 映射、正文改变后的当前性 | 建稿、手工编辑、来源定位、标准阅读器及交付渲染 |
| 参考稿审核 | 固定候选与报告、返工接替、公开／私密投影、撤回审核不改正文或定稿 | 比较候选、批注、通过／驳回／要求修改及历史查看 |
| 采纳与独立定稿 | 精确选区及 replacement、目录 CAS、来源链、定稿保持、手工稿零 Draft 定稿、旧决定不能撤新指针、原键恢复 | IME、局部采纳、一次撤销、继续编辑、独立理由和覆盖确认、重启恢复 |
| Git | 上级仓库隔离、原 index 保护、固定选集及 HEAD、批准失效、禁止 hooks、未知状态查询 | diff 评审、快照确认、分支／合并；测试远端的 SSH／HTTPS 同步 |
| MCP 与 Apps | 官方 Schema 与 SDK Client 双向验证、实际协议、工具封装、范围、分页、EOF／取消后的原键恢复、越权拒绝 | 所声明客户端版本实际安装与调用；Apps 局部选择和无 Apps 回退 |
| 资料与制作资产 | 纯文字、分层身份、CAS、授权草稿、固定使用、资料／正文分别过期、旧版摘要与 UTF-8 引文核验、归档过滤和分页、跨作品独立副本、文件组与模型能力差异 | 三栏资料、章节旁查看、固定旧版与已保存新版比较、未保存稿保护、失败可重试、制作资产选用及锁定可读 |
| 素材与封面 | 流式字节复制、类型及限额、来源声明、权利修订、历史许可不能绕过撤回、跨作品候选拒绝 | 文件面板、等比预览、选区关联、封面作者选用及书库刷新 |
| 导入与交付 | 编码和结构损失、原文件变化、目录同事务、固定计划、ZIP 路径及摘要、发布与回执恢复 | 转换预览、中文排版、第三方阅读器、独立解包及接收方核验 |

核心夹具入口见 `core/tests/`，stdio 互操作夹具见 `apps/mcp/tests/stdio.rs`，原生状态与桥接夹具见 `tests/native/`。官方协议 Schema 固定来源修订和摘要，原始许可位于 `tests/mcp/LICENSE`；测试执行绑定该版本，不根据 SDK 列名推断兼容性。各专项均包含正常、失败、并发和恢复断言，实际覆盖由对应执行记录证明。

封面专项入口为 `core/tests/covers.rs` 与原生 `CoverTests.swift`。核对手工图片检查、空白请求拒绝、固定回执及部分候选、伪摘要和损坏图拒绝、作者权限、历史链、双窗口 CAS、书库缓存重建及未知选用的原键恢复；原生文件面板与真实图片的视觉布局另行验收，状态测试不替代界面证据。

导入导出专项入口为 `core/tests/delivery.rs` 与原生 `DeliveryTests.swift`；原生构建后运行 `swift run --skip-build hetu-native-tests --delivery`。验证预览不写入、作者确认、卷章与书库投影、Word 回读、预览失效、未保存缓冲保护、正式包固定旧定稿、审阅包选集、产物核验、原键恢复和切书隔离。该状态与桥接测试不代替系统文件选择、真实页面操作、中文排版和第三方阅读器验收。

## 3. 贯通旅程

默认 AI-first 旅程的业务步骤由真实外部 Agent 经 Skill + CLI/MCP 执行，作者只审阅成果、提供意见和确认必要决定。Computer Use 用于界面、输入法、排版及可访问性验收；不承担正常业务操作。作者 C ABI 驱动可以独立验证审核合同，不能用它预建筹备、填资料和创建作品后声称机器链路从零通过。纯手工旅程验证备用能力，不能代替默认旅程。

- E2E-01 纯手工：断网 → 建项目 → 设定集 → 写小说 → 节点校正 → 骨架 → 手工剧本 → 校验及作者处置 → 对保存修订独立定稿 → 导出。
- E2E-02 Agent：作者主动选择原文范围、修改目标及风格要求并复制 Prompt → 外部客户端对话与 Skill 生成 → 提交独立参考稿 → 原生对比 → 分别验证只读后自行改写、放弃及局部采纳 → 继续编辑 → 独立检查与定稿；软件无生成请求，接收结果不改正文或抢焦点。
- E2E-03 并发恢复：两进程打开 → 同基线写入 → 第二个冲突 → 提交中断 → 重开恢复 → 旧审核不能沿用。
- E2E-04 版本协作：本地快照 → 测试远端 → 两作者改同设定集 → 冲突 → 人工解决 → 重新校验 → 单次推送。
- E2E-05 格式交付：导入中文稿 → 章节／人物人工确认 → Fountain 互换 → DOCX／PDF 制片稿 → Bundle manifest 核验。
- E2E-06 国际化：中文创作 → 切换英文界面 → 读取同一诊断 → 英文帮助与模板 → 核对原文、摘要及批准记录未变；两端分别执行。
- E2E-07 首次建书：软件选客户端 → 无书名筹备 → 对应扩展安装 → 筹备范围只读接入 → 复制 Prompt → 外部构思 → 候选按字段采纳 → 作者创建 → 关联封面任务；创建未知不重复建书。
- E2E-08 Apps：真实支持宿主加载任务 → 选择候选／批注 → 保存并回读 → 原生端显示同一结果 → 切任务不串数据 → 不支持 Apps 的客户端完成原生回退。
- E2E-09 本地浏览器：作者按需启动 → 实际内置浏览器回环可达 → 配对 → 查询和选择 → 原生验收 → 撤权并释放端口；非法 Origin、过期和云端不可达均有明确结果。
- E2E-10 编辑主权：纯手工保存与定稿 → 接收 AI 候选 → 局部采纳、撤销及手工改写 → 定稿保持旧修订 → 作者另行确认新定稿 → 默认交付仅选定稿。

- E2E-11 资料与复用：离线建立纯文字人物／场景／考据 → 关联章节及场次 → 维护两套设计与固定使用 → 更新只提示依赖 → 明确跨作品导入 → 移走原目录仍可读 → 权利撤回阻断新交付，不改历史包。
- E2E-12 图片与 Agent：真实所选客户端发现任务 → 在授权内连续维护设计候选 → 按实际工具生成或官方产品人工操作 → 成图及可用附属文件回传 → 核验与等比预览 → 作者返工及选用 → CAS／迟到／未知恢复／撤权；五类模型的资料与真实调用证据分别记录，不要求付费接口同时可用。
- E2E-13 原创短剧：不建空小说 → 原创项目与多分集 → 中文语义编辑及 Fountain 源文互读 → 场次资料、分镜、模型片段交接 → 分集重排和历史查看 → Agent 候选不能写正式稿 → 独立定稿与第三方格式验收。

- E2E-14 场景创建：分别从首屏创建原创新小说、原创剧本和小说改编项目 → 核对所需字段、可跳过项及默认页面 → 离线写作 → 重开保持作品类型，无冗余空内容。
- E2E-15 原著与权利：自己的小说／授权原著／公版版本三组来源 → 固定引用或独立快照 → 原著对照 → 分别核对改编、Agent 外发与再分发 → 缺项和撤回只影响相关对外操作 → 旧映射与历史包保持。
- E2E-16 用途导入：小说、Fountain 剧本、改编原著及文字资料四类 → 手工纠正识别与结构 → 源文件变化冲突 → 原键恢复 → 在对应工作台继续，不自动定稿或复制既有工作区。
- E2E-17 引导体验：从零、筹备、创建与导入各自执行键盘操作、IME、返回、取消、类型切换、AI 接入回返和迟到候选 → 重启恢复表单与原操作 → 核对未保存内容、焦点和重复创建。
- E2E-18 真实 Codex 小说协作：干净新会话发现实际包和稳定 MCP → 打开无书名筹备 → 与作者讨论方向并交候选 → 作者创建作品并授新范围 → 大纲和资料 → 首章参考稿连续保存 → 作者公开意见 → 原任务返工 → 固定候选及局部采纳；软件不生成，期间不逐任务重配连接。
- E2E-19 协作恢复与上下文：两部隔离作品 → 获权目录／检索／片段 → 请求补资料并由作者确认 → 旧请求写入被拒 → 保存或提交回执丢失 → 新会话按原键及反馈恢复 → 作者正文同时变化 → 三方比较 → 撤权后旧连接读写拒绝，历史可由作者查看。
- E2E-20 真实反馈交互：明确支持消息的宿主实际加载 Apps → 保存公开反馈 → 用户按此修改 → 消息响应与后续成果分别观察；另在无 Apps／无消息能力／普通网页／发送失败下复制相同反馈继续，均不伪报唤醒、不重复保存。
- E2E-21 真实原创剧本与素材：无小说及骨架创建原创任务 → 场景 Skill 组织人物、分集与 Fountain 参考稿 → 保存、反馈和返工 → 提交及作者采纳 → 关联素材设计 → 外部实际生成文件或明确能力缺项 → 核验、比较与作者选用；改编分支再单独核对固定原著和权利。

### 3.1 完整作品夹具

`tests/fixtures/book-journey/` 提供原创短篇《归宋守渡》的作品资料、两卷十章正文及五集十场 Fountain 改编稿。题材来源与原创范围记录在 `book.json`；夹具用于验证完整创作链路，不代表长篇规模性能样本。

python3 "tests/e2e/book_journey.py" run --workspace "build/book-journey/归宋守渡"
python3 "tests/e2e/book_journey.py" verify-final --workspace "build/book-journey/归宋守渡"

仅复测 Core／MCP 时，可显式指定构建产物，并在新的隔离目录初始化首章。初始化通过公开 C ABI 执行，记录为协议测试准备，不作为客户端建书、粘贴或撤销的界面证据。

### 3.2 写入期间浏览

工作区存在写入者时，作者仍能打开作品、切换章节并阅读已提交内容；正文与保存入口显示只读，其他写操作由内核拒绝。写入结束后自动恢复编辑，已有未保存缓冲不得被后台刷新覆盖。读请求在多文件事务发布期间等待完整提交，不读取一半新、一半旧的数据；异常中断的事务先恢复或明确阻断，不把不完整状态显示为成功。

内核用例为 `core/tests/workspace.rs` 的并发打开与恢复测试及 `Store` 的多文件发布、崩溃恢复测试；Mac 状态用例为 `workspaceAccessTests`。界面验收应实际持有隔离作品的写入锁，核对进入、阅读、只读提示、禁用编辑及释放后的恢复，不能只在写入完成后截图。

### 3.3 真实 Agent 协作验收

本专项以作者从软件发起、真实 Codex 执行的协作为验收对象。当前正在工作的 Codex 会话可以按公开 CLI 或实际已连接的 MCP 独立阅读资料、创作和返工；不能因另一套 CLI 未登录而否定当前会话。安装后自动发现、首次连接及新会话恢复另用新会话验证，不借缓存掩盖安装问题。测试驱动可以在隔离作品中执行明确标识的作者操作，但不能代 Agent 提交预制文本。整书夹具和协议测试继续承担其自身覆盖；只有实际执行并保存证据的范围才能标 pass。

| 检查点 | 必需证据 | 失败判断 |
| --- | --- | --- |
| 接入 | 精确客户端版本／表面、安装包及助手摘要、新会话实际工具与 Skill、任务读写回执 | 只看到文件、配置、安装成功或脚本可调用，不能判接入通过 |
| 从想法建书 | 作者意图、Agent 实际准备的资料、必要决定、创建回执与筹备转作品授权 | 测试驱动代填候选或补建书步骤、未获权接管目录、沿旧筹备权限读作品则失败；明确新建意图下的有限受管创建不要求作者重复填表 |
| 资料与首章 | 按需调用的固定引用、工作副本多次保存、正式提交摘要、原生可见结果 | 全书塞进单次工具结果、未保存声明、候选覆盖正文则失败 |
| 反馈返工 | 确切成果及公开反馈、所用继续路径、新稿反馈引用、作者对比 | 测试程序代写返工稿、保存当唤醒、没有后续成果却报完成则失败 |
| 编辑与采纳 | 作者后续修改、三方比较、仅选定范围的 AdoptionRecord、旧定稿指针 | 覆盖未保存内容、越界补丁或采纳即定稿则失败 |
| 恢复与撤权 | 中断前后原键、同 task_id、已有成果和反馈、撤权后的真实拒绝 | 换键重新生成、任务串书或旧连接仍可读则失败 |
| 原创剧本与素材 | 无原著场景、Fountain 修订、设计及实际文件／明确缺项、独立作者选择 | 强制小说／骨架、图片说明冒充成图、回传即选用则失败 |

稳定入口另验完整 TaskRef 的跨层传递：真实 stdio 返回的摘要须进入 Apps 初始化、保存参数及嵌套候选引用；模拟成功回执丢失后，通过窄操作工具恢复同一保存，不能重提或降级到未公布的 URI。协议测试覆盖真实 Core 与传输，浏览器测试覆盖桥接及界面保留意见，两者都不能替代真实 Codex 会话证据。无任务时可读取静态面板代码，但不能取得任务目录或数据；任务关闭后的静态代码可用性不作为仍有业务权限的证据。

证据仅记录必要任务输入、工具调用、结果引用、公开意见和摘要，不收集作者无关聊天、凭据或真实书稿。用原创演示材料和隔离目录，保留中文写作、英文界面、无 Apps 与无消息能力路径。图像或消息能力缺失按对应用例标 blocked／not_run 或验证明确回退，不能把回退通过写成该能力兼容通过。

Mac 本期退出条件为 E2E-18／19／21 及 E2E-20 的已声明宿主路径均有真实证据；不能用原生单测、整书断言、MCP 驱动、模拟 AppBridge 或安装包检查替代。Windows 与其他宿主分别验收，不从 Mac／Codex 结果推导支持。

### 3.4 资料版本影响核对验收

本专项归入 FR-27 与 E2E-11，合同见[35第8.1节](35-资料素材与短剧制作资产.md#81-文字资料的版本影响核对)。范围为已登记的固定使用位置；资料和正文已有新版分别标记，不把版本变化解释为语义错误，也不推断未登记的全书影响。

`tests/native/HetuNativeTests/ResourceImpactTests.swift` 通过真实 Core 验证两类版本变化、固定旧稿及已保存新版、Unicode／Emoji／CRLF 引文、错误摘要与坐标拒绝、合法空锚点、归档过滤、已载入分页摘要，以及作者缓冲和历史关联保持。比较不改变采纳或定稿的合同另以应用调用及界面操作核对。原生构建后运行 `swift run --skip-build hetu-native-tests --resource-impact`；独立 scratch 构建须使用同一 scratch 的执行文件，并记录实际加载的 Core。

同资源 App 的界面验收分别执行：

1. 打开资料详情，在“使用位置”切换全部／待核对，检查两类提示、归档排除、加载更多及读取错误；失败不显示为“没有变化”。
2. 打开“核对变化”，切换资料／正文比较，核对两列标题、版本和旧稿引文定位；新稿不得沿用旧坐标，空锚点不出现空白原文按钮。
3. 保留一份正在编辑的未保存正文，打开、刷新、关闭比较，再返回编辑器，核对内容、光标和脏状态；查看只读作品时仍可比较。
4. 分别使用中文、英文和最小支持窗口，检查阅读、分栏、滚动、键盘及关闭。比较不产生“确认完成”记录，不自动更新关联或覆盖历史。

最终装配须包含 `ResourceImpact.swift`、`ResourceImpactReviewSheet.swift`、`ResourceWorkbenchView.swift`，并核对包内 `NativeStrings.json` 与共享本地化源一致。Swift 与 Core 从同一源码输入统一构建，核验所需 ABI 符号（包括 `hetu_model_service_request`）及实际加载的包内动态库；独立 Core 的链接通过不代表共享目录或安装包已更新。源码被构建目标包含、编译通过及状态测试通过，与安装 App 的实际操作分别记录；中文行为、英文视觉及英文行为分别登记，服务超时后未完成的操作不计为通过。

## 4. 性能与规模目标

以下为性能验收目标。基准分别记录 OS、CPU、内存、磁盘、构建模式、冷／热缓存与 p50／p95；以 macOS arm64 和 Windows x64、16 GB 内存、本地 SSD 的明确机器为基线。

| 场景 | 初始目标 |
| --- | --- |
| 编辑 10 万汉字单章 | 输入到显示 p95 ≤ 100 ms；IME 不丢组合状态 |
| 1000 章、约 1000 万汉字项目 | 冷打开首屏 ≤ 5 s，全文索引异步不阻塞编辑 |
| 10 万汉字规则检查 | ≤ 5 s，结果清楚标识覆盖与预算 |
| 全书后台任务 | UI 可操作，取消请求响应 ≤ 1 s，原子提交阶段单独记录 |
| 1 GB 已选交付材料 | 流式打包，额外峰值内存目标 ≤ 256 MB，不把媒体全部读入内存 |

性能目标未达时先调查瓶颈；任何调整需记录理由与产品影响，不能在失败后静默降低门槛。

## 5. 质量样本与故障注入

核心夹具覆盖中文重名、化名、时间跨期、梦境、插叙、说谎、心理活动、群体角色、未闭合引号及无标点文本。抽取 precision／recall 使用独立作者标注集，M0 先冻结数据与评分方式，再确定数值门槛，不虚构通用 OOC 准确率。

在每个事务阶段注入崩溃、磁盘满、权限撤销、锁竞争、文件替换与进程终止；分别核对未写入、已写入、部分结果和 unknown。网络失败注入测试远端，禁止自动访问真实作者仓库。所有破坏性夹具只操作本次生成的临时项目。

## 6. 证据与发布门禁

证据记录 `requirement_ids, case_id, source_revision, build_digest, os, architecture, toolchains, fixture_digest, steps, expected, actual, status, limitations`。状态为 `pass|fail|skipped|blocked|not_run`；未跟踪工作树使用源码树摘要，不要求为测试自行提交。

V1 P0 业务及安全用例双端通过、Swift CLI 干净系统运行、基础 MCP 至少完成所声明宿主版本验收、标准交付样例第三方可读、无数据完整性关键缺陷，才可声明对应范围完成。MCP Apps、扩展架构和可选插件单独验收。

MCP Apps 资源执行 `npm run test:task-view`：用官方 SDK 桥接渲染受沙箱限制的页面，并经真实原生 stdio 获取资源、保存选择及回读持久化决定；同时覆盖中英浅暗布局、封面比例、候选文本注入、任务切换拒绝、未保存意见、旧修订和未知保存结果沿原键恢复。资源与源码摘要由构建入口核验。该自动化宿主只证明资源、桥接与本机服务的集成，不替代指定 Codex／WorkBuddy／其他客户端版本的实际加载和交互验收。

同一命令包含本地页面测试：真实任务、原生侧私有 IPC 适配、浏览器请求配对、精确 Host／Origin／CSRF、跨任务与非白名单拒绝、原键恢复、过期及父进程 EOF 后端口释放。撤权流尚未建立时停止任务，也必须清空已显示内容。`python3 "tools/build-native.py" --test` 使用装配后的 Node.js，另验证 Swift 父进程管理、原生批准、真实 Core 保存与关闭任务后撤权。浏览器自动化保存成功不替代作者定稿或实际宿主兼容证据。

完成原生构建后，`swift run --skip-build hetu-native-tests --creation-projects` 单独执行筹备状态集成用例，覆盖空书名持久化、重启恢复、受限任务候选、作者修改及来源、CAS 冲突、非空目录保护和创建回执恢复；`--local-task-view` 单独执行本地 Node 子进程、配对、WebKit 沙箱页面与任务关闭撤权用例。两项也包含在完整原生测试中，单项结果不替代完整用户界面旅程和真实外部客户端验收。

`swift run --skip-build hetu-native-tests --agent-integration` 在隔离目录验证逐作品关联、随包文件与版本、Codex 官方安装及回读、WorkBuddy 方法包安装与配置保留，不使用作者真实客户端缓存。发布前还须比较源包、Swift 资源及 App 内资源的完整文件集和每个文件摘要，并核对签名；隔离安装通过不能代表当前客户端会话已加载扩展。

## 7. 关键业务场景验收

以下场景将用户目标转为可执行断言。每项分别记录正常、失败与恢复结果；字段名和错误码由能力目录及动作合同取得，不通过 UI 文案猜测业务完成。

| 场景 ID／用例 | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01／UC-15／23 | 两部独立小说存在同名角色、章节和不同设定 | 在 A 编辑后切到 B，并用 A 的 Agent scope 请求 B | B 内容与设定不受 A 修改，跨作品访问被拒；A 缓冲与修订仍可恢复 |
| AC-02／UC-21 | 离线，无 Agent 扩展和草稿记录 | 手工建章、中文编辑、保存、检查并独立定稿 | 定稿引用确切正文修订，Draft 数量仍为零，流程无外网依赖 |
| AC-03／UC-05 | 当前正文已有定稿，收到待审参考稿 | 作者通过参考稿审核 | 仅决定和草稿状态变化，正文当前／定稿指针及章节目录不变 |
| AC-04／UC-17 | 候选包含中文、Emoji、CRLF，目标已有定稿 | 仅采纳两个不重叠且 quote 匹配的范围 | 结果字节仅含选定变更，保存 AdoptionRecord，旧定稿指针不变；越界、重叠或错 quote 整次拒绝 |
| AC-05／UC-11／17 | 作者已预览基于 R1 的采纳，另一窗口保存 R2 | 提交原预览 | 返回冲突，不覆盖 R2，不产生部分采纳记录；作者选择保持可重新比较 |
| AC-06／UC-06 | 正文及报告已冻结，之后设定或问题处置变化 | 确认旧预览的定稿 | 旧确认失效，历史报告仍可读，需重新检查；输入摘要损坏不能由例外说明放行 |
| AC-07／UC-06／21 | R1 已定稿 | 保存 R2，再独立确认 R2，最后尝试用 R1 的旧决定撤回 | 保存 R2 不改变 R1 定稿；新确认后定稿指向 R2；旧决定不能撤回新持有者 |
| AC-08／UC-11／17 | 采纳事务已提交但成功回执丢失 | 重启并以相同键和相同输入恢复，再尝试同键异输入 | 返回原修订和原采纳 ID，不新增业务记录；同键异输入明确冲突 |
| AC-09／UC-18／19 | 固定候选已通过 Apps 或配对网页展示 | 保存局部选择，再尝试调用正式采纳、设定写入、封面选用或定稿 | 选择可在原生端回读，作者动作被拒；不支持 Apps 时同一候选可回原生端处理 |
| AC-10／UC-13／25 | 原生编辑器存在组合输入、选区、撤销记录和旧定稿 | 修改阅读样式并切换中文／英文界面 | 组合输入按编辑合同处理，内容摘要和定稿不变；选区、撤销及功能入口可用 |
| AC-11／UC-26 | 素材已导入，旧权利声明允许嵌入，当前声明已撤回 | 导出引用旧素材修订的交付计划 | 当前权利策略仍生效，默认排除媒体并说明原因，不能用旧声明绕过撤回 |
| AC-12／UC-27 | 局部网页和 MCP 范围有既存操作记录 | 撤销会话／授权，再从旧客户端以已知键查询 | 失权请求被拒，作者仍能查原结果；页面停止后端口释放，正文与历史保留 |
| AC-13／UC-09 | 中文 DOCX／TXT 或 Fountain 稿件已生成导入预览 | 作者校正结构后，源文件或卷章目录在确认前发生变化 | 原确认失效，正文与目录均不部分写入；重新预览后记录来源及损失，导入不设置定稿 |
