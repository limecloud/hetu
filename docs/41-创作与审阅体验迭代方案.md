# 创作与审阅体验迭代方案

## 迭代的价值门槛

每项交互调整都应减少重复解释、寻找版本、误改或无效确认。只读和直接讨论是有效旅程；完整阅读、差异、反馈与接续优先于新增生成器和专业面板。未验证体验仍按具体版本取证。

产品定位与任务分流见[01](01-产品需求PRD.md#1-产品定义)。

日期：2026-11-20。本文对应 `0.14.0` 版本。数值为原型建议，功能为拟议交付范围，均不冒充已实现、已验收或已发布能力。实施工作包和状态由[38](38-创作工作台重构执行计划.md)维护。

本轮已按作者“完整对齐实现，特别是细节”的要求进入开发。先在本地形成同版体验、验证并由作者试用，发布独立进行。设计依据为[编辑体验研究](research/14-编辑阅读与全局体验研究.md)、[产品需求](01-产品需求PRD.md)、[作品工作台](37-创作库与小说剧本视频设计.md)及[界面风格](../.agents/skills/hetu-ui-style/SKILL.md)。作者要求匿名的参考产品及调研工具名称不进入产品文档、源码、注释或随包内容；原始调研过程留在不随包的本地资料。

## 1. 这一版要带来的变化

作者打开作品后，能够直接、舒适地阅读真实成果，在原文附近提出准确意见，理解版本差异，并顺畅地进入修改或继续交给 Agent。换主题、调文字、切换入口、接收返稿和关闭重开都不破坏这条连续体验。

产品判断标准是好的默认值、清楚的层级和可靠的细节。第一次打开不需要先设置；经常使用时操作可预测；复杂任务有足够能力，日常阅读保持安静。主题、字体和编辑命令共同服务这条旅程，避免把下一版做成设置项集合。

正文外部写作工具生成可预览、可交接的具体任务提示词，由作者交给外部 Agent 执行。MCP App按宿主能力提供发送到当前Agent对话及准备对话草稿，复制始终保留；作者也可直接在Codex对话驱动公开机器入口，无需点击工具。工具菜单按标题与用途分行，预览内保留固定作品、文稿修订及选区；“复制提示词”只复制，取消不发送、不修改正文。发送受理、草稿、拒绝和结果未知分别表达，不自动重发。无已安装 Agent 也能生成，未保存稿先保存。宿主任务意图与 Core 对象引用分层，两个工作台复用同一模板及引用核验。

### 1.0 领域优先的固定入口顺序

参考软件只提供通用交互原则，不能决定河图洛书的领域入口。作者从创作库打开任何作品后，固定进入“作品资料”；小说、剧本和视频先展示各自的资料、结构、协作与状态，再由作者明确进入正文、分集或成果。统一顺序如下：

```text
创作库 → 作品资料 → 资料／结构／协作设置 → 小说正文或剧本分集 → 阅读／编辑／批注 → 返回作品资料
```

“打开作品”只负责建立作品上下文，不隐式打开第一章、第一集或最近正文。目录、正文、任务、资料、版本和 Agent 协作分别属于固定工作面；正文内关闭最后一个文稿回到作品资料，切换作品也回到新作品资料。外部 Agent 请求 `profile` 时进入作品资料，请求 `manuscript` 时才进入正文。该顺序由宿主和 MCP App 共用，后续适配器不得自行改写默认入口。

入口顺序以以下页面合同实现，桌面和 MCP App 使用相同的阶段与返回语义：

| 阶段 | 首选工作面 | 进入方式 | 离开方式 |
| --- | --- | --- | --- |
| 1 | 创作库 | 启动、返回或关闭作品 | 选择一部作品 |
| 2 | 作品资料 | 选择作品、切换作品、完成文稿标签关闭 | 选择资料、结构、协作或正文入口 |
| 3 | 资料／结构／协作 | 从作品资料侧栏展开对应分组 | 选择小说正文、剧本分集或视频成果 |
| 4 | 小说正文／剧本分集／视频成果 | 通过作品导航或资料页的明确入口 | 打开文稿、成果或返回作品资料 |
| 5 | 阅读／编辑／批注 | 通过目录、固定成果或关联链接 | 关闭最后一个文稿回到作品资料，或返回上一级固定成果 |

侧栏顺序固定为“作品资料 → 创作资料 → 协作与审核 → 正文／分集／成果 → 版本与交付 → 本机与扩展”。显式的版本、交付、任务和插件入口可以直接打开对应工作面，但不改变默认入口；所有异步读取期间禁止重复切换，避免旧回包覆盖当前阶段。

## 2. 产品原则与取舍

1. **作品先出现。** 已有内容优先打开；标题只出现一次；参考稿、写作稿、定稿清楚区分；空白作者稿不盖住已有参考稿。
2. **显示调整不动作品。** 字体、字号、纸色、缩放和软换行不改原文、修订、来源或导出模板。
3. **同一内容有同一套排版。** 同类型阅读、编辑、比较和预览共用档案；小说与剧本保留各自规则，媒体按原比例呈现。
4. **常用操作靠近内容。** 阅读控制、意见、查找和比较在当前工作面完成；高级细节按需展开。
5. **默认安静，能力完整。** 常驻工具只表达当前任务；不常驻格式大工具栏、右侧批注表和模型参数。
6. **稳定胜过装饰。** 输入、选择、定位、保存和恢复的确定性属于体验本身；背景渐变不进入正文，不添加无目的动画。
7. **入口共用，宿主适配。** Electron 和 MCP App 共享组件与命令；文件选择、窗口和快捷键由宿主适配，行为差异可解释。
8. **作者保留判断。** 看见候选不等于采用；批注不自动外发；保存、采纳、定稿和费用决定各有确切对象。

保留 CodeMirror 6 及现有原文字节映射。外部研究没有证明必须换成富文本内核；本版先把共同排版、命令与审阅做好。新建第二套编辑器或桌面／App 专属 CSS 会继续制造分叉，不采用该路线。

### 2.1 参考编辑器的完整复刻基准

侧栏按实机分为项目与当前作品两层；底部两枚定位点显示层级，顶部菜单可切换层级和专注。当前作品头部使用封面缩略图、标题和真实更新时间，下方四段图标依次为目录、任务、附件、查找。分段使用中性底、浅色选中块、分隔与悬停说明，正文与侧栏分别滚动。层级切换不改变正在阅读或编辑的稿件；切换面板保留输入、搜索、折叠及滚动。任务承接本作品已有创作任务，附件承接本作品资料和固定图片成果，不能用审核按钮替代任务面板。查找提供范围、条件、上下命中与可编辑稿的固定替换预览。桌面与MCP App共用侧栏组件、读写用例及状态归属；未测的原生手势不得记作已还原。2026-11-21窗口补核已观察到外缘拖动、最窄限位、拖窄收起及再展开恢复宽度；截图约为180～390px，精确收起阈值未测得。实现尺寸与键盘补充行为归10；双击外缘、横向滚动及定位点点击未观察到可靠切层效果，不据此新增手势或宣称等价。

作者要求复刻已安装的参考软件本身。窗口结构、视觉风格、排版与操作均以同版本实机证据为准，覆盖创作库、作品工作面、编辑器、设置和浮层。下文既有尺寸、渐变、字体与布局示意属于待对照方案；与实机不符时修订对应规范和共享实现，不能以旧Mac布局或局部功能通过代替还原。河图的作品类型、来源、固定修订和作者决定继续由现有业务内核负责。

已读取的官方说明和界面图用于发现观察项目。2026-11-21经作者明确授权，已在安装版隔离文档观察创作库、中文粘贴、格式与页面样式面板、键盘选区浮条、快速操作及浅暗主题，并恢复原来的跟随系统外观。原始截图由窗口观察会话保留；专用采集器编译超时的回执单独保留，不冒充成功证据。实机观察与河图逐项验收分别记录，不能据观察完成宣称还原完成。证据边界见[研究第9节](research/14-编辑阅读与全局体验研究.md#9-参考编辑器的具体参考与复刻边界)。

本轮共享实现按实机修正以下交互：格式面板按标题和内容分组，行内操作使用连续按钮组；显示排版采用页面缩略预览、纸色样片与字体样张，精确值保持可编辑；选区浮条优先出现在文字上方，空间不足时翻转，下方仍保留固定修订批注与AI交接。未保存选区只开放文字编辑，不把它登记为已保存修订的意见。格式按钮、选区浮条与键盘共用同一命令和撤销历史；Markdown提供删除线、无序／有序／任务列表，阅读与编辑共用语法配置。普通编辑直接呈现已识别的文字格式、列表、引用、代码块和分隔线，光标和选区跳过隐藏标记；原稿入口保留完整语法与字节。代码块中的标记仍是代码，HTML始终按原文显示。显示调整不修改正文。

创作库将当前分类、数量、新建和筛选收为同一页头；设置采用左侧分类、右侧内容与外观缩略图，独立设置首次沿当前工作台内容尺寸打开，嵌入式设置填满宿主。2026-11-21作者追加要求完整对齐设置排版；已在参考实机核对外观、语言与高级设置的浅暗页面。对照目标为稳定的页头、居中内容列、柔和底色的成组表单、内缩分隔线、紧凑行标题与说明、末端开关和一致的组间留白。设置改为共用顶栏、分组分类、内容页头和居中内容列；成组表单按行呈现标题、值及必要说明，末端开关和内缩分隔分别核对，不能将旧设置截图记作本次通过。两端共用组件，MCP App设置受当前宿主视口限制。浅色正文使用白色、深色正文使用中性灰，窗口与正文层次分别由共享语义颜色拥有。

macOS将原生关闭、最小化和全屏按钮整合进52px顶栏，保留系统窗口行为。顶栏空白可拖动，菜单、按钮、选择器及浮层保持交互；界面缩放时按物理窗口按钮尺寸避让，全屏时释放按钮占位。设置窗口沿用同一宿主适配；插件工作面保留原生按钮所在的拖动区，专业内容从下方开始，避免遮挡第三方工具栏。MCP App不渲染原生按钮占位，由宿主管理窗口；Windows与Linux保留系统标题栏。创作库导航在宽窗和窄窗均可再次展开。原生窗口须实际观察，不能以网页截图替代。

Markdown普通编辑在空段输入`/`可选择真实支持的标题、正文、引用、列表和分隔线；选用后替换本次命令文本并登记独立撤销。原稿模式及Fountain不混用该菜单，后者沿用剧本元素补全。

普通Markdown编辑在没有选中文字时切换加粗、斜体、删除线或行内代码，只改变光标的后续输入格式，不先写入空标记、不制造修改状态。开始输入后将实际文字与格式作为原文事务保存；格式切换、组合格式、边界空白、原有格式内插字、组合输入和单次撤销分别核验。行内代码与其他文字格式互斥，以实际Markdown语义为准。移动光标重新继承当前位置格式，原稿模式继续允许直接编辑源标记。列表回车续项，任务列表的新项未勾选，有序列表保持编号；空项回车退出，项目开头退格逐级取消结构，代码区不触发列表操作。

格式字的最后一个字删除后清除其空定界符，后续输入保留当前光标样式；换段和多行纯文本粘贴按实际段落编码，不把新段或列表包进上一段的格式标记。相邻格式的编码须经同一呈现解析器核对文字和样式，范围外原稿不参与重排。取消任务项时一并移除列表与复选框，不留下失去语义的`[ ]`；组合输入期间显示输入状态并暂停保存，提交后格式和文字作为一次撤销。

快速编辑时，过期的显示状态回传不能覆盖较新的输入，也不能清空刚保留的光标格式。分组内的鼠标、Home／End和全选限定当前可编辑内文，保存、搜索与批注仍使用完整原稿坐标。打开批注并定位其原文属于一次操作，程序产生的同范围选区不能用浮条替换正在查看的批注；作者另选正文时再切换。

实机格式面板还包含片段颜色与字体、段落对齐及块分组，均纳入完整复刻范围。实现前须在文稿格式合同中明确可交换的持久表示、源坐标、撤销、导入导出和机器读取；两端与固定修订共同消费，不能只在DOM或本机偏好中保存样式。当前Markdown已有语义的实现不代表这些能力已完成。

片段与块样式按[25文稿样式交换](25-小说与剧本标准格式.md#文稿样式交换)实施。默认字体／颜色入口就近恢复默认，选区混合值不伪装为统一值；无选区时保留后续输入意图。颜色采用32px圆形样片，同时提供名称和选中状态，自定义颜色有确切值；字体以四种实际样张显示。对齐作用于实际选择的段落，页面／卡片分组可以进入、返回及恢复位置，焦点／面板保留内文编辑。分组取消只移除结构，不能删除内部文字。

隔离文档实机补核：页面分组以首段作为标题，其余段落形成淡色预览；进入后在连续工作面显示内文，返回恢复父级位置。卡片沿用相同内文和进入行为，以有边界的预览区展示；参考另有卡片配置窗口，样式配置须独立验收，不能由卡片入口存在推定已完成。河图分组是当前正文中的受限容器，阅读和编辑均按原始范围投影，进入不复制或截断正文。搜索、固定批注与阅读锚点定位到分组内部时先展开确切来源范围，格式、保存和撤销仍作用于完整原稿。

卡片配置进一步按实机覆盖五种布局、内文预览和无／纯色／渐变／图片背景。弹窗左侧呈现当前真实卡片，右侧调整预览和背景；左右切换与定位圆点指向同一布局。关闭、Escape或取消不改正文，套用固定当前文稿和卡片范围，后台变化时拒绝覆盖；整次套用独立撤销，清除分组不丢内部文字。自定义图片只由作者明确选择并以内嵌字节进入同一修订，两端均不读取原始文件路径或自动联系外部图片服务。宽窗双栏，窄窗在同一弹窗内重排，键盘焦点和原文选区分别恢复。参考中的订阅购买流程不属于河图编辑体验。

目录的“复制文稿”复制当前已保存的固定修订，在同一作品内创建独立章节或分集，并放在原文稿之后。新对象保留完整原文字节及固定来源，使用新身份和独立修订，不继承批注、定稿、任务或权限。小说沿原卷，剧本保留分集计划；当前正文或目录并发变化时拒绝覆盖。auto直接执行，confirm确认固定副本后执行；结果未知沿原操作恢复，不能再次创建副本。未保存稿先保存，复制不把编辑缓冲当作已保存来源。

2026-11-22隔离窗口补采确认：参考块菜单的“排序”为A→Z／Z→A，单块选中时禁用；“移至”提供每日笔记、新建文档及选择文档。它们与段落上移／下移分别验收。首组5块样本确认空块在升序选区开头，中文按“粗体测试、灯塔、海面”排列，原样式、范围外列表／卡片及一次撤销保持，来源见[保存专项](research/evidence/save-order-and-copy-2026-11-22.json)。后续10块及12块独立样本确认数字不是自然排序，大小写折叠后升序等价项保持原次序；中文语言环境下éclair在Eclair之前，ss与ß等价。降序将完整升序结果反转，等价项也反转，一次撤销恢复升序，见[字母排序专项](research/evidence/block-sort-2026-11-22.json)。该证据只覆盖已采样语言及字符，不证明跨文稿移动已经实现。

菜单支持右键、键盘菜单键和Shift+F10。层级菜单提供方向键、Home／End、Enter、Escape和可见焦点，禁用项不可执行；鼠标悬停与键盘选中使用同一状态。菜单宽度随真实文案与快捷键计算，基础宽度140px；约22px行高保持紧凑，无图标或勾选项时不预留空图标列。浮层按工作面边缘翻转并限制高度，浅暗和窄窗均可达；点击外部、切换对象、滚动及窗口失焦关闭。打开菜单不修改正文、不丢原选区，关闭返回原入口；选择命令后由命令决定焦点，不抢回已经打开的弹窗。

共享菜单只负责呈现和交互。文稿命令复用同一原文事务与撤销，资料和作品命令复用应用用例，CLI／MCP继续沿同一领域Owner；不通过查找并点击另一个按钮执行业务。异步剪切或粘贴固定原对象、原版本与选区，回包过期时保留新编辑。采纳、定稿、费用及删除继续核对确切结果，右键入口不扩大权限。

段落上移／下移在当前页面范围内交换本次段落或多段选区与相邻内容，顶部和底部没有相邻内容时禁用对应方向。代码围栏、列表项、卡片及块样式容器作为完整范围移动；进入内页后不跨越内页边界。移动保留原文与混合换行，整次交换可以一次撤销和重做，光标与选区跟随所移动的原文。

字母排序提供“排序 A→Z”和“排序 Z→A”，只对当前选区的完整块排序；空选区或仅一个块时禁用。块内的文字、原格式、围栏及列表续行保持完整，页面／卡片按标题比较且整体移动；进入内页后只排序当前内文，不包含内页标题及外层标记。可见文字作为比较依据，采用当前界面语言的字母比较，数字不作自然排序；大小写折叠后的等价项在升序保持原相对次序，重音按语言比较，降序反转完整升序结果。排序后选中本次完整块范围并保持选择方向，外围原文不变，一次撤销／重做恢复确切字节。不把正文改写成去格式的字符串，也不按隐藏标记排序。换行按原范围的分隔槽保留，不把CRLF统一成LF。

跨文稿“移至”采用紧凑搜索目标面板，取消及Escape不改正文，当前作品内的正式文稿可作为目标。移至已有文稿时，完整块从来源移除并追加至目标尾部；两篇文稿、确切字节范围及原操作必须由共享Core一次事务核验和写入，不能用界面顺序保存两篇代替。来源与目标均须为当前修订且属于同一作品，格式相同；参考稿、归档目标、同一文稿或旧引用拒绝执行。未保存内容先保存并固定来源，等待选择期间的正文变化不能静默重新取范围。换行分隔由Core确定，块内原字节、顺序和其他内容保持，旧批注及任务保留原引用，不把坐标迁移到目标。

跨文稿撤销使用原移动回执内的双端前后修订，在两端都未被后续改写时原子恢复，并创建新修订保留历史；冲突时保留当前两端内容和原操作，不对另一端执行部分回退。auto直接执行，confirm集中确认本次双端固定变更；未知结果沿原键查询。新建目标须将新文稿及目录插入纳入同一事务，不先创建空文稿再移动。2026-11-22隔离观察与Core、CLI、稳定MCP及桌面回读已确认目标搜索、来源移除、目标尾部追加、移动顺序和跨文稿撤销；正文回读完成后立即解除编辑锁，journal／ack仍沿原键确认。每日笔记属于独立产品能力，不能用空入口冒充已实现。

创作库对象的删除入口使用“移入废纸篓”语义，实际保存为对应作品的归档版本；列表、卡片和右键菜单显示恢复入口，归档筛选保留已归档对象。小说写回 `metadata.status`，剧本和视频写回自身 `archived` 字段，均沿作品当前修订与原子操作键。正文、任务、批注、固定来源、同根其他对象和工作区目录保持，恢复只允许沿最新修订继续。物理目录删除、登记移除和工作区删除按独立危险操作处理，不由普通作品菜单代替。

## 3. 完整用户旅程

### 3.1 从收到稿件到继续创作

作者从创作库打开作品，回到上次章节或分集。已有待审内容时可直接进入最新提交的固定参考稿，阅读页标明稿件身份和状态；收到新稿不抢走正在编辑的窗口。

阅读中打开画笔图标的“阅读排版”调整纸色、字体与大小，真实正文即时预览，当前段落留在原位置。`Aa`用于文字格式，按当前稿件开放真实可用的样式和命令。选择一段话后出现“批注”“让 AI 处理”；保存意见后明确是否公开，只有作者选择继续才交接原任务。

返稿到达后，作者在同一位置打开比较，查看修改及上下文，也可随时回到完整文章。局部采用前预览确切结果；作者稿有未保存修改时先保护双方内容。采用后仍是写作稿，定稿另作明确决定。离开再回来保持对象、稿件类型和阅读位置。

### 3.2 亲自修改的完整闭环

作者进入写作稿编辑，输入、选择、剪切、粘贴、格式与替换都进入同一原文事务和撤销历史。显示设置不登记为文字修改。查找不切换到编辑，替换只在可编辑稿件中出现。

状态始终区分编辑中、本机恢复副本已保存、正式修订已保存、保存失败及外部版本变化。保存固定本次内容，后续输入仍可继续；保存状态的切换不得短暂锁定编辑器或丢失快捷键和文字。离开时可以保存、保留恢复副本或取消；崩溃恢复能看见确切稿件及差异，不静默覆盖较新的正式稿。

### 3.3 编剧的同版旅程

编剧从分集进入场次，直接看到场景、行动、人物、括注、对白和转场。切入编辑后可以选择当前元素类型、使用人物／场景补全及上下场导航。原著或前稿按需对照，不混成可编辑的第二份剧本。

调整阅读字号只影响屏幕呈现。进入交付预览才选择既有交稿 profile 并检查真实分页；不将连续阅读长度换算为页数或中文短剧时长。

## 4. 全局视觉与主题系统

### 4.1 两层外观

| 层 | 推荐设计 | 作用范围 |
| --- | --- | --- |
| 应用外观 | 跟随环境／浅色／深色 | 导航、工具、菜单、设置、对话框、状态和插件公共表面 |
| 文稿纸色 | 跟随应用／清纸／暖纸／夜墨 | 正文、选区、光标、搜索命中、意见及文稿比较区域 |

“跟随环境”在桌面读取系统，在 MCP App 优先读取当前宿主提供的外观；宿主不提供时使用系统。用户明确选择浅／深后优先于环境。有效外观由一个共享解析器产生，不让宿主和用户属性分别在 CSS 中争夺覆盖。

纸色默认跟随应用：浅色采用清纸，深色采用夜墨。暖纸提供低饱和纸色；夜墨保持中性暗面和清晰文字，不将整页染绿，也不用纯黑纯白制造强烈反差。所有方案使用共享 Radix 色板及语义变量，具体配色在原型中计算对比度后冻结。

主题不附带字体、字号、行宽或格式变更。恢复纸色默认只恢复纸色；恢复小说排版只影响小说档案。设置中不用“重置全部”误清 Agent 连接、密钥或作者资料。

### 4.2 全状态颜色与材质

统一背景、表面、正文、次要文字、边界、悬停、按下、选中、焦点、禁用、警告和错误；文稿另有光标、原生选区、搜索当前／其他命中、公开／私密意见、插入／删除及历史状态。意见、命中和差异同时出现时有优先级，不能盖住文本或只靠颜色区分。

工作台采用中性灰窗口底、整合侧栏和连续正文工作面；官网品牌渐变与插画独立。窗口级工作面留小幅边隙，正文纸面本身不形成内部卡片或第二条滚动。浮层不透出后方正文；减少透明度、增强对比度和减少动态效果各有明确降级。图片、封面、视频和导出文件不因主题切换被滤镜或反色。

UI 控件采用12／14／20px层级；章节／分集标题按10文档使用正文字号的1.5倍且至少24px，系统无衬线半粗，与正文保持独立间距。原文首行章名复用同一层级，阅读和编辑一致，原文字节不变。其余语义标题按内容层级显示，图标采用现有成熟图标及可访问名称；边界使用0.5px，默认无动画。文稿字号属于作者排版偏好，不能反向改变目录和按钮字体。字号放大后控件随内容重排，禁止以固定高度裁切。

共享色板也要验证实际组合。研究中主要操作背景与白字的不透明配色计算约为3.15:1，因此普通大小按钮属于全局对比度整改范围；实施时在唯一共享变量处调整并验证普通、悬停、按下和禁用状态，不在各页面各补一种颜色。

## 5. 字体、字号与排版模型

### 5.1 字体职责

| 内容 | 默认方向 | 选择方式与边界 |
| --- | --- | --- |
| 应用界面 | 系统无衬线 | 跟随平台，保持目录、状态和控件的识别度 |
| 中文小说 | 系统无衬线，提供阅读宋体 | 精选宋体、清晰黑体、系统字体，并提供本机可用字体的高级选择 |
| 中文剧本 | 清晰黑体 | 行动／人物／对白由布局表达，不给每种元素随意换字体 |
| 英文剧本 | 专业等宽字体 | 优先评估 Courier Prime，中文用明确的 CJK 回退；屏幕配置不等于交稿模板 |
| 原稿与技术详情 | 等宽字体 | 仅用于用户主动打开的原稿和技术内容 |

字体列表显示真实字体名称、中文／英文样句与可用状态；选择后在当前正文中预览。相同本机的桌面和 MCP App 应解析为同一字体；缺字时按统一回退链显示，不能显示成空方块或误称字体已加载。不同系统不承诺系统字体像素完全相同。

推荐评估 Noto Serif SC、Noto Sans SC 及 Courier Prime 作为离线精选字体，OFL 正文已读取。是否随包采用由字形、许可、体积、加载及双入口原型共同决定；系统字体功能不依赖在线下载。不得将商业系统字体从本机拷入发行包。

字体资源不能内联撑大所有 MCP 工作台 HTML。若随包字体被采用，由静态资产白名单、固定摘要和有界读取按需传输；前端缓存与资产版本绑定，首屏不等待全部字体，字体就绪后恢复原文锚点。CSP 只开放必需字体来源，不通过任意文件路径或网络 URL 装载字体。

### 5.2 两套基础排版档案

以下是新安装的原型推荐值，需通过真实中文字形与连续阅读验证后冻结；既有作者偏好按第13节迁移。

| 参数 | 小说 | 剧本 |
| --- | --- | --- |
| 基础字号 | 16px | 中文 18px；英文屏幕稿 18px |
| 行高 | 1.5 倍 | 中文 1.65 倍；英文另按屏幕稿实测 |
| 最大行宽 | 默认44个CJK字形；窄／标准／宽档为30／44／56，精确值可调 | 场景、行动及转场共用工作面；人物和对白使用相对布局，独立限宽 |
| 段落 | 默认舒展式、不缩进；书籍式可选 | 无小说首行缩进；元素之间有固定相对间距 |
| 段距 | 舒展式0.5em；书籍式不额外拉大段距 | 场景、行动、人物与对白的间距成组调整 |
| 对齐 | 左对齐，使用中文换行禁则 | 按元素对齐；窄屏同时对白有明确顺序 |
| 字距 | 默认正常，不逐字插空格 | 默认正常，英文等宽字形不被强行拉伸 |

屏幕统一以 CSS px 标示字号，行高用倍数，段距／缩进用相对单位；导出模板可使用 pt 和纸张单位。现有文档的 pt 与实际 Web px 漂移须在实施前同步修正，禁止通过直接改成 pt 把作者现有文字放大。

字号原型范围为 14–32px，行高高级范围为 1.25–2.5 倍，缩进为 0／2 字。高级自定义值必须校验；不得用界面范围的变化静默夹断历史设置。字体、缩放、窄屏和实际字形共同决定最终行宽，不将固定像素宽度伪装成精确汉字数。

首行缩进只做视觉呈现；已有全角空格、制表符或缩进语法不再重复缩进。空行、诗歌、题记、短信、代码样式和 Fountain 不套普通叙述段规则。原始硬换行与段落语义分开处理，不因换排版补空格、删空行或改源格式。

### 5.3 入口与预览

正文页头的画笔“阅读排版”面板提供纸色、字体、文字大小、行宽和段落样式；行高、精确段距与回退详情进入“更多排版”。设置中的“写作”管理同一档案，并提供小说／剧本预览；两处共用状态和组件。

显示修改立即预览并写入非敏感偏好，提供就近“恢复默认”。输入数值未完成或非法时保留已生效的排版并就地提示；拖动滑块合并写入，不为每个像素生成一份方案。保存失败保留本次预览与恢复入口，不谎报已同步。

切换排版保留文稿对象、修订、选区、撤销栈与语义阅读锚点。IME 组合期间暂缓度量更新，结束后一次应用，不重建编辑器或强制结束组合。

## 6. 缩放、专注与全屏

| 操作 | 推荐语义 | 状态归属 |
| --- | --- | --- |
| 文稿缩放 | 以基础字号乘当前比例，默认 100%；预设 80／90／100／110／125／150／175／200% | 当前窗口或 App 视图会话，不驱动另一端突然放大 |
| 界面大小 | 放大导航、控件、菜单及状态；保持相同信息层级 | 当前桌面窗口；MCP 宿主自身缩放由宿主控制 |
| 专注阅读 | 收起项目导航和内容目录，保留退出、稿件身份和必要状态 | 当前视图，可一键恢复原导航状态 |
| 段落聚焦 | 输入时淡化非当前段，仍可读；默认关闭 | 写作偏好；阅读和比较不自动开启 |
| 打字机滚动 | 仅实际输入时维持当前行约在可视区 45% 处；默认关闭 | 写作偏好，拖选／搜索／意见定位时暂停 |
| 系统全屏 | Electron 的操作系统窗口全屏 | 当前桌面窗口 |
| 宿主展开 | 请求 MCP 宿主实际支持的更大显示模式 | 当前 App；宿主不支持时有普通可读布局 |

`100%` 表示当前档案基础字号，例如 20px×125%=25px。字号与缩放均有准确标签；“恢复缩放”不重置作者字体或行高。文稿放大通过重新布局实现，不用 CSS transform 缩放整块编辑器。

正文工作面始终铺满可用宽高，文字保持可读行宽；单稿只有一条主要纵向滚动。专注不自动隐藏待保存／冲突等必要信息，也不自动切换系统全屏。MCP App 不承诺突破宿主外框或强行占据整个显示器。

快捷键经平台冲突核对后绑定命令。MCP不劫持宿主／浏览器的全局缩放和保留按键；文字缩放可从“阅读排版”操作，专注可从菜单操作，不能只有快捷键。退出先关闭最上层临时浮层，再退出专注，不以Escape丢弃编辑。

### 6.1 阅读位置必须使用原文锚点

每个位置包含 WorkRef、文档身份、稿件类型、修订、原文位置和屏幕内偏移；滚动像素可作同布局的快速恢复辅助。换字体、字号、行宽、主题和模式后重新度量，以锚点恢复，不能只把旧 `scrollTop` 应用到重排后的页面。

锚点过期时保留历史引用并说明当前版本变化，按可验证上下文定位；无法核实时显示历史原文，不靠同名标题或近似文字静默定位。切到别部作品时清除上一部临时选区、搜索和意见浮窗，返回可恢复各自位置。

## 7. 专业文字操作

### 7.1 所有文字工作面共同能力

| 能力 | 本版行为 |
| --- | --- |
| 输入 | 真实中文拼音／双拼输入法、候选选择、换段、Emoji、组合字符、死键和长文本粘贴可用 |
| 选择 | 鼠标及键盘选择、跨段拖选、全选、逐词／逐段移动；按 Unicode 边界处理，不截断 Emoji |
| 剪贴板 | 剪切、复制、粘贴；“粘贴为纯文本”可达；从网页／Word 粘贴按原文格式支持范围处理，不夹带脚本或不可见 HTML |
| 格式 | 当前格式支持的强调、标题、引用和分隔可操作；命令写入最小源文变更，保留选区并可一次撤销 |
| 标点 | 成对引号／括号和常用中文符号可显式插入；智能配对与自动替换可关闭，不默认改写已有正文 |
| 撤销重做 | 输入、粘贴、格式转换和替换在同一历史中；显示偏好、跳转、搜索与外部只读刷新不污染历史 |
| 保存恢复 | 恢复副本与可引用修订分别显示；外部更新保护缓冲，重开可核对恢复内容 |
| 统计 | 当前稿件及选区的中文字符／西文词语口径清楚；参考稿统计不混入作者稿，异步更新不阻塞输入 |

小说保留纯文本与已支持的 Markdown 语义。普通阅读隐藏可确定的格式标记；编辑提供有限的内容格式命令，原稿从更多菜单查看。TXT 不能表达的操作不显示成已生效；未知 Markdown 结构可安全查看原文，不静默丢弃。

不把作者正文自动清洗成“标准格式”。繁简、标点、空格、换行和风格保留作者原意；整段排版整理属于显式、可预览、可撤销的内容操作。片段格式和块结构保留专业作品语义，阅读、编辑、比较与交付按同一固定原文呈现。

阅读和普通Markdown编辑默认复制可见文字；需要Markdown／Fountain标记时使用明确的“复制原稿”或进入原稿模式。剧本编辑按当前源格式复制。剪贴板呈现和SourceRef定位分别核验，不把隐藏语法或呈现空白误算成正文范围。

### 7.2 选区与上下文工具

稳定选区后才显示紧凑工具，默认两个动作“批注”“让 AI 处理”；复制等标准动作在原生／上下文菜单。格式命令集中在编辑菜单或按当前元素展开，避免选每段文字都遮住下一行。

工具不抢走原文选区；跨行、靠边、滚动和较大文字时重新定位，优先放在选区上方，空间不足再翻转。键盘能够打开同一命令，焦点关闭后回到原文位置。只读参考稿可选择、复制、搜索、反馈，不能显示会改写固定候选的命令。

未保存作者稿上的意见需要准确语义：可以先保留本机意见草稿；提交为正式原文意见前保存或选择已有固定修订，不把浮动缓冲位置伪装成正式 SourceRef。让 AI 处理也先固定所需输入，不能悄悄外发未保存正文或私密批注。

## 8. 查找与替换

`查找` 在阅读、作者稿、参考稿、历史及比较两侧均可用，不自动切入编辑。默认查询当前可见稿件，显示当前／总命中、上一处、下一处及环回提示；关闭搜索返回原来的阅读锚点。

主文稿查找复用左侧栏，显示命中所在段落的摘要、当前命中和定位入口；正文不增加搜索横条，也不因查询数量改变顶部位置。目录与搜索复用同一侧栏宽度，关闭搜索恢复原导航和阅读位置。窄窗以同一侧栏浮出，选择命中后可收起侧栏继续阅读；历史和比较两侧继续使用局部查找，避免互相夺取主导航。

| 范围 | 查询内容 | 修改能力 |
| --- | --- | --- |
| 当前稿件 | 当前缓冲或正在阅读的确切固定稿件 | 仅可编辑写作稿允许替换 |
| 当前选区 | 发起查找时固定的选择范围；范围失效提示重新选择 | 可编辑稿内精确替换 |
| 本作品 | 本作品已保存正文，逐结果标明章节／分集及修订、覆盖与索引状态 | 本版跨文档只定位，不提供隐式整书替换 |

普通字面匹配为默认；大小写、适用的西文整词与正则放入高级选项。中文精确匹配、分词检索和西文整词分别命名，不能把 `\b` 当作中文词边界。非法或耗时模式可取消并给出原因，不能卡住输入线程。

替换先展示原文和结果；全部替换显示准确数量与范围，形成一次撤销，不自动保存、采纳或定稿。查找字段支持 IME，不在组合中抢跳；无结果、查询中、部分覆盖、过期和错误分别显示。参考稿无命中不等于整部作品无命中。

## 9. 小说与剧本的差异化工作面

### 9.1 小说

保留整合侧栏中的卷章目录、阅读／编辑与就地意见。章节名称在正文起点显示一次；页头保留稿件身份、编辑／比较、`Aa`、画笔阅读排版和更多。项目级Agent入口不重复出现在每段上方。默认无右侧栏，人物资料、相关依据和全部意见按需打开，关闭后回到原段。

正文按中文叙述、对话、空行、题记、诗歌及场景分隔正确呈现。目录只负责结构；章标题和稿件原文中重复的结构标题按可确认语义避免重复显示，源文件仍完整。不能根据同名文字删掉正文内容。

### 9.2 剧本

| 元素或操作 | 完整行为 |
| --- | --- |
| 场景与场号 | 语义标题、稳定场次跳转，显示序号与稳定对象身份分离 |
| 行动 | 正常宽度，保留有意换行、停顿及空白 |
| 人物、括注、对白 | 对齐成组；不能只把人物文字加粗后仍按小说段落排列 |
| 转场、居中、强调 | 对应 Fountain 语义，不把 `_` 当作任意格式 |
| 同时对白 | 宽屏并排、窄屏明确依次呈现，阅读顺序和原文映射保持 |
| 元素编辑 | 当前位置显示类型；可显式转换，转换形成原文事务；回车按元素规则进入合理下一元素 |
| 补全 | 当前剧本人物和场景的本地确定性建议，可忽略；不调用模型猜人物或补剧情 |
| 键盘 | 元素转换、上下场定位可达；不以捕获 Tab 造成键盘陷阱，提供退出编辑器路径 |
| 原稿 | Fountain 标记可按需查看，隐藏标记与原稿选择均映射同一原文字节 |
| 对照与交付 | 固定原著、前稿与参考稿分别查看；打印分页只在交付预览发生 |

小说字体、缩进和段落样式不串入剧本。中文与英文剧本按语言配置排版，不将西文全大写、Courier 页数和“一页一分钟”机械套到中文短剧。内容不能识别时保留原文并提供原稿入口。

## 10. 意见、比较与作者决定

### 10.1 就地意见

正文标记表达“这里有意见”，边缘浮标靠近文字栏，避免跑到宽屏最右侧。相邻意见聚合显示数量，点击或键盘激活后展开，不遮盖正在核对的句子。选择其他段落时可开始新意见，不能只允许 Agent 标记的位置反馈。

浮窗展示引用、意见、公开／私密、修改和处理状态；长意见可在当前区域展开。全部意见按未处理／已处理／历史查看；旧版意见仍有原引用，正文前进后不套用旧坐标。公开反馈保存与“按此修改”分两步显示，消息受理与收到返稿分开。

### 10.2 比较

比较默认展示与当前任务相关的改动，提供完整上下文和“全部正文”。宽屏并列，窄屏采用同页逐段比较；用户可切换前后版。两侧共用排版档案，插入与删除以颜色加标记表达，不能只靠红绿。

按段落／场次和原文来源对齐，换字体或两侧行数不同仍比较对应内容；同步滚动可临时解除。历史版本只读，原著对照不暗示允许改写原著。局部采用必须能预览最终作者稿并保护未保存修改，内容变动使原预览失效。

### 10.3 明确决定

“保存意见”“要求返工”“采纳到写作稿”“确认定稿”“选用素材”各自沿原 Core 用例处理。普通阅读和排版调整不弹重复授权，已安装的本机 MCP App 打开已登记作品不逐作品接入；普通 Agent 的精确范围保持独立。

必要决定就在确切成果或差异旁完成。批准后沿原操作回读；结果未知显示恢复状态，不能变成再次采纳或再次付费。定稿仅引用已保存确切修订，修改产生新写作稿，旧定稿保持。

## 11. 全局页面与状态覆盖

本版不是只给正文换皮。以下每类页面均纳入浅暗、字号、键盘、宽窄、异步状态和双入口巡检；动态页面清单由实际能力地图、贡献注册和安装插件枚举生成，不能仅检查几页演示。

| 页面族 | 本版统一的体验 | 必须保留的专业差异 |
| --- | --- | --- |
| 创作库与首次进入 | 搜索、筛选、打开与最近位置；已有作品优先；一次稳定接入 | 小说封面、剧本标题和视频画面各自呈现 |
| 作品概览与资料 | 单一标题、真实资料、渐进展开、精确 AI 交接 | 作品类型、来源、权利及独立身份 |
| 小说正文与大纲 | 共同排版、搜索、位置保持和文字命令 | 卷章结构及小说段落 |
| 分集、场次与原著对照 | 共同工具、批注和版本操作 | Fountain 元素及固定改编来源 |
| 视频、音频与图片审阅 | 同一状态、浮层、焦点、版本意见语言 | 等比、适应／实际尺寸、播放与区间定位；媒体缩放独立于文字 |
| 设定集与嵌套详情 | 表单、长文和比较统一；错误就地呈现 | 设定归属、锁定、来源和作者采用 |
| 资料、素材与封面 | 真实内容先出现，来源和历史按需 | 候选、正式选用及权利分别显示 |
| 协作任务与返稿 | 成果和意见优先；发送、受理、运行、保存分开 | 原 task_ref、固定输入与客户端身份 |
| 审核、诊断与历史 | 可直接定位原文，差异与意见清晰 | 规则覆盖、历史引用与独立决定 |
| 版本与冲突 | 统一对比和恢复，不让技术记录挤占正文 | 固定提交、双方修改、同步目标与未知操作 |
| 导入与交付 | 统一预览、进度、损失与结果 | 固定原字节、来源、profile、权利及文件包 |
| 专业插件工作面 | 宿主主题、公共控件与长文档案；失效有基础降级 | 插件自己拥有的结构、专业图形与业务能力 |
| 设置、接入及关于 | 同一偏好、预览和安装反馈 | 秘密渠道、实际安装与当前会话能力分开 |
| 菜单、浮窗、对话框与提示 | 相同层级、颜色、键盘、焦点返回和错误表达 | 明确危险操作和必要决定 |

每个异步工作面覆盖加载、空内容、无权、只读、部分结果、失败、冲突、待核实及成功的适用状态。组件测试覆盖全部状态，业务旅程验证实际发生的状态；不在无意义的页面制造空状态来凑数量。

## 12. 桌面与 MCP App 的一致性

### 12.1 共用与适配

| 层 | 共同内容 | 适配内容 |
| --- | --- | --- |
| 作品与任务 | 同一 Core、WorkRef、稿件、意见、历史、作者决定和原操作 | 通信生命周期 |
| 工作台 | 同一 React 页面、排版、命令、主题变量和无障碍语义 | 容器尺寸和可用宿主能力 |
| 偏好 | 本机非敏感外观和两类排版档案 | 跟随环境的有效值 |
| 临时状态 | 相同的状态结构和锚点规则 | 各窗口的滚动、选区、缩放和浮层互不抢占 |
| 文件与窗口 | 相同用途和结果提示 | 原生文件选择、剪贴板、系统全屏、宿主展开与保留快捷键 |

同机偏好提交成功后，桌面、设置窗口和 App 消费同一修订；旧事件不能覆盖新修订。失去焦点后回到页面、重新连接和重开都回读最新状态，未保存文稿不被偏好刷新覆盖。失败显示未同步的实际状态；不要求重启软件才能看到普通偏好变化。

MCP 未提供某个原生能力时，使用同一宿主桥接完成等价操作，或给出准确可用入口；不能把浏览器不支持的按钮留成无响应。共享页面完整不等于每个宿主都支持系统全屏、任意字体枚举或相同快捷键，支持清单需逐宿主取证。

### 12.2 资源与插件

保留 HTML 内容摘要 URI、随包 manifest 和旧资源提示。App 新打开必须消费当前资源；安装包、返回 HTML、样式和插件资产来自同一构建。不能用更新桌面资源代表旧 App 面板已经刷新。

插件继续经共同 SDK 消费有效主题和语言，新增排版能力以可选、向后兼容合同提供；宿主不跨隔离边界强行向第三方 DOM 注入样式。第一方文稿插件采用共享档案，旧插件缺新偏好时基础读写和成果回读保持可用，并记录实际适配范围。

### 12.3 本轮Codex会话与设置参考

河图内优先交付并默认使用Codex TUI，随后完善GUI，外部Codex Desktop MCP App继续支持。GUI协议客户端与TUI remote客户端优先共用受管App Server，在轮次边界交接唯一输入权；不复制任务、不接管外部私有聊天。其他引擎后续适配，不增加本轮依赖。

Orca的会话消息、工具过程、输入、滚动、字体、宽度和设置分组是本轮复刻范围。参数及交互只有一个Owner，见[10](10-原生客户端与交互设计.md#codex-会话工作面与设置)；源码事实、版本、路径及采纳取舍见[研究14](research/14-编辑阅读与全局体验研究.md#12-orca-会话与设置源码研究)。不以源码研究代替同版运行截图，不复制多工作树、远程管理、多账号托管或Full Access默认。

通用设置采用10中的Orca密度基准，替代本方案第2.1节先前设置尺寸的推断；小说／剧本正文排版、作品资料首屏、直接章节／分集入口和文稿标签语义保持本方案的领域合同。外部参考更新不能自动重排这些交互。GUI与TUI显示偏好独立于文稿档案，修改外观不重建引擎或改变作品字节。

本轮完整范围还包括无作品筹备、上下文附加、真实工具过程、Core成果导航、反馈返工、unknown恢复、输入法、单输入者及同版打包；实现顺序归[38](38-创作工作台重构执行计划.md#codex-guitui-本轮交付顺序)，门禁归[19第17.1节](19-测试策略与验收矩阵.md#171-codex-guitui-与设置门禁)。文档、模拟协议、真实引擎、打包安装和作者试用分别举证。

## 13. 分层、数据与兼容迁移

本版的复用单位是实际相同的责任：排版计算、有效外观、文字命令、搜索状态、来源锚点、意见及比较组件。既有应用用例继续拥有权限、事务和作者决定；不建设新的通用框架或第二套作品存储。

| 责任 | 现有落点与拟议调整 |
| --- | --- |
| 语义颜色与材质 | `assets/styles/radix-workbench.css`；唯一色板及共同变量 |
| 共享外观与排版计算 | `packages/workbench-ui`；拆出小型纯计算及 React 控制组件，阅读／编辑／比较消费同一结果 |
| 文稿事务与命令 | 现有 renderer 编辑器与原文字节映射；按职责拆分，不把全部命令继续堆进页面组件 |
| 意见、来源与比较 | 复用现有锚点和 Core 投影；排版坐标可重算，固定来源不变 |
| 非敏感偏好 | `core/src/local_settings.rs` 和相应 Schema；单一 Owner、修订、CAS、原键恢复 |
| 桌面／App 桥接 | 现有 DesktopBridge 及 AppBridge；承接环境、资产、偏好通知和必要原生操作 |
| 插件 | 现有 SDK／贡献机制；专业模型归插件，共同表现归共享层 |
| 机器入口 | 现有 local_settings 固定方案及精确作品用例；按需扩展 Schema、CLI/MCP 和 Skills，不增加平行写入口 |

偏好拟分为全局 appearance、文稿纸色、novel／screenplay 两类排版档案及可选写作行为。界面大小与文稿缩放保存在本机视图状态，不写入作品，也不作为生成上下文。具体字段由29／contracts拥有，本文不建立另一份可执行 Schema。

### 13.1 迁移规则

1. 迁移前读取当前修订，保留可恢复原设置，事务性写入一次新版本；中断后按原操作恢复，不双写两套设置。
2. `songti`、`pingfang`、`system` 映射到对应字体选择，既有字号继续按实际 px 解释，不按旧文档的 pt 重新换算。
3. 旧额外行距转换为等效行高：`1.35 + line_spacing / font_size`。先保持实际显示，再由作者主动选择新预设；不得为凑整数而默改行距。
4. 剧本当前有独立 CSS 规则，迁移以其实际表现为基线建立剧本档案，不将小说缩进和字体整份复制过去。
5. 新安装采用经验证的新默认值；已有作者不被强制重置。恢复默认作用范围明确，不清理作品、连接、密钥及历史。
6. 旧版本遇到新偏好字段的行为、发行回退和一次性设置备份在隔离环境验收；不要求降级软件反向改写新数据。
7. 作品内容、正式修订、定稿、公开反馈、来源及授权均不因偏好迁移前进。只读真实作品的摘要前后保持一致。

普通 GUI 排版调整沿可信本机设置用例即时生效；Agent 请求修改偏好继续走固定 local_settings 方案与现有授权。文稿读取、候选维护、采纳和定稿保持精确身份，不让“统一设置”扩大 Agent 权限。

### 14.1 重点风险与处理顺序

| 风险 | 发现问题的阶段 | 处理原则 |
| --- | --- | --- |
| 原文、Markdown和Fountain的可见选择不一致 | A／C | 先固定显示与源文映射，再加格式命令；未知结构保留原稿，不把复制成功当锚点正确 |
| 大文档与外层滚动影响编辑虚拟化 | C | 用十万字剖析；可调整唯一滚动Owner，但最终仍是一个完整正文滚动区，不能重新出现双滚动 |
| 旧偏好迁移改变作者习惯 | B | 按实际px与等效行高保留，精确备份和原键恢复；新默认只作用于新安装或主动恢复 |
| 字体包体、加载与App预算冲突 | A／B | 先验证字形和资源传输；精选字体按需、离线可用，不将全量字体塞入每份HTML |
| 主题切换导致两端或插件冲突 | B／E | 一个有效解析器、修订有序事件与共享语义值；旧SDK降级可读，不能静默宣布全部适配 |
| 比较、意见和输入争夺焦点 | C／D | 保留原文选区与语义锚点；用户输入、拖选和IME优先于自动滚动及后台刷新 |
| 把计划或官网图当成运行验收 | A／F | 明确原型、官方资料、源码、安装版和作者认可；参考编辑器本机待验证项继续保留 |

如底层验证推翻某个数值或具体实现，更新该Owner设计和对应验收后再继续；不通过缩小搜索范围、隐藏错误或取消未保存保护来换取表面顺滑。

### 15.3 证据与作者试用

自动化检查负责状态、尺寸、原文字节、修订、命令和跨入口回读；真实窗口负责整体排版、输入法、字体与辅助功能。截图记录实际版本、视口与内容夹具，关键值从渲染结果读取。恢复、键盘和写入结果必须以行为验证，不以静态截图代替。

减少透明度与增强对比度属于共享工作台的全局状态：菜单、通知、阅读排版、选区浮条和文字操作面板必须关闭背景模糊并保持实色表面。该降级已在源码专项和0.13.10安装包旅程中验证；真实macOS辅助功能偏好、VoiceOver和系统输入法仍按平台门槛单独取证。

作者试用围绕八个任务：直接读一章、调整到舒适排版、定位一处文字、在任意位置写意见、接续同一任务、比较并局部采用、亲自修改后恢复、切换桌面与 App。记录完成结果、阻碍和返工，不用主观“满分”代替验收。

真实作品先只读核对；写入使用隔离资料。新原型、源码实现、随包验证、安装版和作者认可分别登记。只要仍有丢稿、误采用、无法读稿、两端事实不一致或关键操作不可达，本版本不进入统一发行。

## 16. Agent First的系统性能力组合

本节延续既定主题、字体、排版、缩放、输入和审阅基线；新增的上下文与专业能力入口必须融入同一工作面，不另起一套AI编辑器。作品打开仍进入资料页，目录项直接进入确切内容，资料、结构、协作和正文均可直接选择，表中阶段不是强制逐步向导。

| 系统 | 本轮要求 | 保持的边界 |
| --- | --- | --- |
| 作品与导航 | 作品资料首屏、直接章／集入口、同目录状态、可恢复返回 | 不以参考产品的文档树改变小说／剧本／视频领域顺序 |
| 编辑与阅读 | 当前排版档案、单主滚动、专业文稿元素、原文事务和撤销 | 不因增加AI浮条更换原文格式或削弱中文输入 |
| 上下文 | 类型化来源、固定修订、覆盖、原文附近的引用与反馈 | 原Owner唯一；未保存稿、私密信息及新版本分别处理 |
| 专业能力 | 当前任务可用的方法与插件就近发现，完整目录在管理页 | 不把技能卡片、营销名称或专业画布变成必经步骤 |
| 执行 | auto默认直达，confirm集中固定计划，结果与恢复持续可见 | 操作、成果、检查和作者认可分别表达 |
| 双入口 | 同一数据、设置、命令、比较和意见，宿主能力薄适配 | 不将MCP App做成只读摘要或另一份作品数据库 |

专业能力包括现有安装包实际提供的规划、审校、图鉴、文风和制作增强。未发布的专业功能不因进入研究列表而成为本轮必须新增的插件；优先复用已有包及Skills方法。内容生成方法不逐项扩充核心动作，本体准入归28，数据复用归29，图示归23／39，产品及验收编号归01／26／19。

实施按[38的Agent First能力组合工作包](38-创作工作台重构执行计划.md#agent-first能力组合工作包)逐项完成。文档校验、机器业务、共享工作台、真实引擎／宿主及作者试用分别取证；局部通过不关闭完整工作包。
