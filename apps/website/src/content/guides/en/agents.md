# Work with external agents

Hetu Luoshu is an agent-friendly local creative workspace. External agents understand your goal, organize material, create and operate through MCP, CLI and Skills. The native app puts review first: compare results, give feedback and decide what to adopt or finalize. Direct editing is available whenever you want it.

For a first try, read [Plan a book with Codex](codex-first-task.md). You can also create books, write and maintain story facts entirely on your own.

## Why focus on the foundation

General agents require sustained work on reasoning, context management, tool orchestration and execution recovery. Codex, Claude Code and WorkBuddy focus on those capabilities. Hetu Luoshu focuses on works, story facts, resources, permissions and versions, giving them reliable software to use.

Cursor, Grok Build, DeepSeek Harness and Doubao are also developing their own Agent and extension ecosystems. Skills, MCP, CLI, MCP Apps and plugins provide methods, actions, interaction and distribution. Support depends on the exact client version and surface; one supported capability does not imply all the others.

## MCP: connect books and tasks

<span id="mcp"></span>

External agents use MCP to discover capabilities, create authorized projects, organize chapters and references, submit candidates, prepare delivery and retrieve feedback. Your chosen client manages the connection, so the native window need not stay open. Configure the stable connection once; each explicit work and task identifies its authorized material. Novels, related scripts and videos keep separate access scopes, even in the same folder. A connection does not grant library-wide access, and reauthorization does not revive revoked tasks.

Choose MCP on the library home to read the guide and configure your client. Hosts that support MCP Apps can also show comparison and annotation panels. Other hosts continue with tool results and the native app.

## CLI: discover and call creative tools

<span id="cli"></span>

The CLI is an independent entry point for agents and automation. Query the current work’s actual capabilities, then call scoped actions. After an interruption or unknown result, query the original operation to avoid repeating the work.

CLI and MCP share the same core, permissions and revision rules. Commands and source build steps are in [Mac source build for developers](download-and-install.md). Authors can continue using the native app.

## Skills: methods for the genre and task

<span id="skills"></span>

Skills run in your chosen external Agent and provide methods for planning, outlines, drafting, revision, covers and adaptation. They do not replace live tool capabilities or expand task authorization. Select the suite for your book in [Choose and install Skills](skills.md).

Plugins distribute methods and connection definitions together. Installation, session loading, MCP connectivity and task success are verified separately. Unverified client capabilities stay unverified.

## 1. Choose your usual assistant

In the Mac app, open Settings → AI Collaboration to choose the default client for new books. For an existing book, choose its client in book details.

For example, you can use Codex for a military novel and WorkBuddy for an urban story. Changing the default leaves existing book choices intact.

## 2. Define the goal and scope

Before handing something over, decide what you need:

- For titles, describe the genre, readers, protagonist and intended mood.
- For an outline, explain the main goal, conflict and any ending or turning point already decided.
- For revision, provide the passage and explain what to preserve and what to change.
- For a cover, provide the title, pen name, genre, main imagery and anything to avoid.

For example: “Revise this argument. Keep both characters' positions, make the dialogue more tense, do not add anyone new, and do not reveal the killer yet.”

A task may include authorized resource organization, candidate submission, checks and revisions. Authors confirm story changes, official resource adoption, asset selection and finalization, without making a new choice at every routine step.

## 3. Read the brief before sending it

Use the current page's contextual handoff to review the goal and material, then paste the prompt into your external Agent conversation. You can also give the goal directly to an already connected Agent and let it prepare the task.

Share only what this task needs. When using the native copy-and-paste path, send the prompt in your chosen external client. Manage accounts, sign-in and service costs there.

The Agent saves proposals, drafts and operation results through tools, then reads back their status. Review them in Hetu Luoshu without copying the same details into a form. A chat reply alone is not a saved result.

## 4. Match the methods to the book

Use “Install Skills Suite” to choose methods for military, apocalypse, romance or another genre. Shared writing methods are already included. Install the suite this book needs.

If unsure, copy a selection request to your Agent, read its reasons and decide. Follow [Choose and install Skills](skills.md) for the steps.

## 5. Keep the decisions in your hands

Check suggestions against your characters, timeline, world rules and original intention. Fluent prose can still introduce facts you have not decided to use.

If a reference draft is already visible in Hetu Luoshu's review workspace, review it first and choose which parts to adopt. Approval does not change the manuscript automatically. After adoption, finalization is still a separate choice.

If you have continued writing since receiving a suggestion, compare it with the current text before using it. Keep the original and ask for another direction whenever a proposal does not fit.

For another revision, select the result in the original task, save specific feedback and copy the continuation prompt. Compatible candidate panels may request continuation after your explicit action. Saved feedback, message acceptance and a returned draft are separate states; inspect the actual next result before treating the work as complete.

Continue with [Checks and draft review](review.md). Developers can find advanced setup and source instructions in [Mac source build for developers](download-and-install.md).


## Optional text and image models

Open **Settings → Model services** in Hetu to connect your account. Check that the website and Hetu display the same verification code before confirming. Return to Hetu and select your text and image defaults. The website links to account and billing management.

Ask your Agent to use Hetu model services. It prepares a plan and explains the outgoing content, purpose and spending limit in your current conversation. After your explicit approval, tools record that scope and work can continue within it. Decide again when the limit is reached or the scope changes, without returning to the app to approve every image. Results remain reference candidates for your review.

If credits run out, follow the top-up guidance in the current conversation and check the amount before paying. If a request times out, ask the Agent to recover the original plan. Local writing works without a connection. Video and sound use your selected external tools; see [From preview to finished video](video.md).

For generation plans and accounts, read [Model services and costs](model-services.md). For access boundaries, see [Privacy and permissions](privacy-and-permissions.md). Use [Troubleshooting and recovery](troubleshooting.md) to inspect the original task when something goes wrong.
