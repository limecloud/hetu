# Import an existing manuscript

You can continue with a manuscript you have already written. Keep the original, ask your Agent to prepare the structure and import proposal, then check it before bringing the text into Hetu.

The purpose of importing is to preserve existing work. Polishing prose, renaming chapters and revising the story can be separate tasks afterward.

## Prepare a reliable original

Keep an independent copy of the source files and attachments. Identify the work and version you want to import, including whether it contains extra chapters, author notes, backups or alternate versions.

Specify which files are in scope. Permission to manage a work is not permission to read your entire computer. Select the files yourself or provide them through an authorized host.

You can begin with:

> This is my existing novel manuscript. First identify its encoding, volume and chapter structure, and file order. Show me an import preview. Preserve the prose and chapter names without polishing or deduplicating by title. If the result is unclear, check the original batch.

## Check the contents and representative passages

Ask the Agent to list volumes, chapters, ordering and uncertain boundaries. Numbering that restarts in each volume must be interpreted in context.

| What to check | Why it matters |
| --- | --- |
| Volume and chapter order | Filename sorting may differ from story order |
| Repeated titles or restarted numbering | Two first chapters can belong to different volumes |
| Opening, volume boundaries and ending | These reveal missing text and incorrect splits |
| Quotation marks, spacing and special characters | Confirm that encoding and paragraphs survived |
| Notes and extra chapters | Decide whether to include, separate or exclude them |

A matching word count is not enough. Have the Agent flag uncertain divisions so you can compare them against the original.

## Keep a record of format conversion

Different formats preserve different information. Check prose, headings, footnotes, comments and layout separately. If conversion is needed, retain the source and ask what information it loses.

If the structure cannot be identified reliably, stop at the preview. An import receipt should not conceal garbled text or missing chapters. See [Formats and delivery](formats-and-delivery.md).

## Read the imported novel

After importing, have the Agent read back the work, chapter list and import result. In Hetu, open the beginning, volume transitions, repeated chapter names and final chapter to confirm the full text is there.

Keep the source, import records and new work in durable locations. Continue writing in the imported work rather than importing the same manuscript repeatedly. For an existing Hetu folder, open the work directly.

## Resume the original batch after an interruption

If the connection times out or the conversation changes, have the Agent recover the original import task and batch. Establish whether it never ran, completed or has an unknown result.

If the source file has changed, compare it before preparing another proposal. Do not submit another batch to probe the old result or have the assistant edit Hetu's internal records directly.

If something is wrong, preserve both the original and current result. Record the missing location and error. See [Troubleshooting and recovery](troubleshooting.md).

After verification, continue with [Chapters and writing](writing.md), or organize the existing story through [Plan an outline and chapters](outlining.md).
