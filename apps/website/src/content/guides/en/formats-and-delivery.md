# Formats and delivery

Agree on templates, scope and revisions with the recipient. File formats, industry conventions and production templates need separate checks.

## Ask your Agent to prepare the exact handoff

Try: “Prepare an episode-one review bundle with the script, current preview and selected character references. Exclude the full source novel, private comments and failed generations. Show me the scope before packaging.” Your Agent fixes versions and attachments for review without asking you to rebuild the file list.

A review bundle and a formal delivery have different purposes. Novel finalization, script finalization, preview approval and final-cut confirmation are separate decisions.

## Choose materials and formats

| Purpose | Format | Current scope |
| --- | --- | --- |
| Editable novel | Markdown | Local text editing and revisions |
| Independent screenplay | Fountain | Original or adapted scripts with independent text and revisions |
| Collaboration and reading | DOCX, PDF, TXT | Inspect conversion and the recipient’s template |
| Video and editing project | Selected video, subtitles, audio, assets and editable external project | Full playback, sound, text and source dependencies |

Let your Agent prepare an import, export or delivery proposal, then inspect its scope and preview before execution. Manual import and export remain available. The homepage demo does not download submission files.

## Before a handoff

- Scope: agreed chapters, episodes and media; exclude private comments.
- Version: fixed finals with matching evidence, reports and mappings.
- Layout: inspect fonts, punctuation, wrapping, pagination and scene headings in an independent reader.
- Rights: check media origins, permissions and attribution.

The local media workspace provides import, checksums and rights records. File signature recognition proves neither copyright nor complete media decoding. Unknown rights are not permission.

For video, play the complete file in an independent player and open the editing project in the recipient’s environment. Check source clips, audio, subtitles, fonts and relative paths. Successful packaging does not replace these checks, rights clearance or recipient acceptance. Continue with [Versions and backups](data-and-backup.md).
