# Does this task need Hetu

Quick questions, titles, sample dialogue and ordinary file edits can stay with your current Agent and original file. You do not need to create a work to justify using software.

## Reading can be a complete task

“Who knows the secret in chapter three?” Find the relevant fixed passages, canon and decisions. Answer with references and reading coverage, then stop if no change is needed.

## Save when you want to continue

Repeated explanations, missing chosen drafts and accidentally lost lines make continuation harder. Begin with the relevant passage and add structure as needed rather than importing everything or completing a story bible first.

## Try a bounded revision

> Move their conflict earlier in chapter two. Keep the reconciliation in chapter three and yesterday’s chosen line. Return a reference draft without replacing my manuscript.

Find the necessary versions, fix changes and protected content, read the result and compare differences. Sources can be verified; motivation and dramatic effect need discussion. Complete automatic impact detection is not promised.

## Write directly or delegate

The Agent is the main operator; you are the person the product serves. Delegate continuous work in scope. A decision already expressed needs no duplicate click. Auto does not adopt or finalize every generated result.
