# Choose and install Skills

Think of Skills as writing method packs for your external assistant. A military suite helps with organizations, operations and battlefield conditions. An apocalypse suite focuses on resources, group relationships and disaster rules. Choose methods that fit the story you want to tell.

## 1. Find the installer

With the Mac app open, you can install from three places:

- To prepare your assistant: open Settings → AI Collaboration.
- While planning a new book: open “New Book” and choose “Explore with an external AI.”
- For an existing book or its cover: open book details and find AI Collaboration or the cover entry.

Choose “Install Skills Suite.” The window lets you choose a client and a genre suite. The client is your usual external Agent, such as Codex or WorkBuddy.

## 2. Choose one suite for your story

1. Expand “Find by category or ask an external Agent.”
2. Select a target platform and reader channel, or leave these open while deciding.
3. Search for a genre such as apocalypse, infinite worlds or urban fiction. Read the suite descriptions.
4. Choose the suite closest to your book's main focus.

For example, an apocalypse story for female readers about community rebuilding, without romance, can start with “Hetu Luoshu Apocalypse and survival.” Keep “no romance” as a further creative requirement; each tag does not need another installation.

Each suite already includes shared methods for planning a book, profiles, outlines, covers, drafting, revision and drama. Install only the selected genre suite.

To compare options, browse the [genre and Skills catalog](/en/integrations/#skills-catalog).

## 3. Ask your Agent if you are unsure

1. Describe your readers, the protagonist's goal, the central conflict and what you want to avoid.
2. Choose “Copy selection request for an external Agent” and paste it into Codex, Claude Code or your usual Agent. You can ask it to clarify a few things first.
3. Copy its complete recommendations back into the recommendation field and choose “Read Agent recommendations.”
4. Read the reasons, choose “Choose this suite,” then confirm installation in the installer.

For example: “I want to write for female readers, without making romance the main plot. I enjoy community building and ordinary people growing through hardship. I could use a historical or apocalypse setting. Help me compare those directions first.”

Copy only the importable result from your assistant, without its surrounding explanation. If the app cannot read it, ask: “Hetu Luoshu could not read this advice. Please follow the original instructions and return only the importable result.” Then copy it again.

The external Agent analyzes your request only after you send it there. Search inside Hetu Luoshu simply helps you find catalog entries.

## 4. Return to your assistant after installation

For Codex, choose “Install in Codex.” For WorkBuddy, check the destination and choose “Install Suite Files.” For other clients, follow the installation instructions shown in the window.

After success, return to the external client. Open a new conversation or refresh as that client directs, then confirm that the selected Hetu Luoshu genre methods are available. If installation reports a conflict, read the message first; existing files are preserved.

If the installer cannot find your client, prepare the client you normally use first. You can also exchange ideas manually using [Plan a book with Codex](codex-first-task.md) and finish installing the suite later.

## 5. Understand version notices

“Local Package Version” is the version already installed. “Bundled Suite Version” is the one provided by this app. If they differ, open the installer to check updates.

“Installed” means the method pack is in place. Check in your Agent that the current conversation can use it. Books can use different clients and suites. Changing the default client in Settings affects new books only.
