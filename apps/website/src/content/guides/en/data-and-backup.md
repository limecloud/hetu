# Your work, versions and backups

## Start with what you need

Work revisions, independent backups and engine chat history serve different purposes. Retrieve selected manuscripts and assets without requiring the full chat or a running plugin.

The creative library registers novels, scripts and videos. Their content and permissions remain separate even when they share a workspace directory. The software’s open-source license does not automatically apply to your writing.

## Website preview

The [desktop preview](/en/#prototype) displays real Electron screenshots with isolated example projects. Creative animations use prepared examples. The website does not open local projects, save manuscripts, adopt text, finalize revisions or create Git snapshots.

## Local saving and versions

The local client saves text revisions and protects recovery buffers. In a novel or script, use the manuscript versions page to review a milestone:

1. Ask your Agent to prepare a version of the saved manuscript, such as “Keep the current first-volume revision as a milestone.”
2. Open its snapshot and review the complete changes and commit identity before approving.
3. Copy the continuation request back to the original Agent conversation. The Agent executes the commit; approval alone does not save a version. Refresh to read the result.

Each novel or script has its own manuscript history. Read an earlier version without replacing your current text, then ask the Agent to prepare a reference draft from that exact version if you want to continue it.

Manuscript versions cover saved text and document metadata. Back up images, videos and production projects separately. These versions do not use the software repository or push automatically.

If a real result is unknown, retain the original task and inspect its receipt before retrying.

## Independent backups

Text and Git on the same disk cannot protect against device loss. Arrange a trusted backup location or another device, and verify that images, audio and video are complete.

Before choosing a remote such as GitHub or Gitee, check visibility, rights and scope, then authorize synchronization. Local snapshot implementation does not prove full remote collaboration is verified.

## Storage and cleanup

Open Settings → Storage to review local application data. Click “Clean up all” and confirm once to clean every currently eligible item. To choose individual items, open a category, filter by name or date, sort by size, and select items. Review the cleanup list before confirming; cancelling keeps the files. “Let AI organize” gives your Agent the current storage inspection entry.

Cleanup covers rebuildable interface caches and removed sessions without drafts or pending recovery. Removed session records cannot be restored after cleanup. Manuscripts, versions, assets, unsaved text, permissions and plugins remain protected. External work folders are excluded from this total. Results distinguish deleted, already absent and retained items; file sizes may differ from disk space actually reclaimed.

## When something goes wrong

Preserve files, unsaved text, the latest valid version and sanitized evidence before inspecting recovery or conflicts. Never overwrite your only copy. After a demo refresh there is no disk history to recover.
