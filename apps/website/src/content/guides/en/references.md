# Review a changed reference without losing the earlier decision

A character's jacket is part of your continuity notes. During a script revision, you move a tear from the right sleeve to the left. The reference takes seconds to edit; the earlier scene where someone bandages that arm deserves another look.

In the Mac app, a reference can be linked to the passage that uses it. That link records both versions, so a later revision gives you something concrete to compare.

## Let your Agent organize references and their uses

Try: “Organize the characters, locations and props this episode actually needs. Reuse existing versions first. Link the jacket to the bandaging scene and record the tear’s position. Prepare missing images as candidates without adopting them.” Return to inspect the content, sources and uses, then edit directly when needed.

Use a single-character portrait on a character card. Inspect costumes, side and back views, expressions and related illustrations separately in the detail view. Location images belong to locations; story illustrations point to the relevant text. The shared image library shows the same results. Prepare extra views when useful without asking you to label every image manually.

Receiving an image does not select it for use. A design change first identifies affected scenes and shots, preserving earlier assets. Give feedback on a region or the whole image and continue the original task with its fixed version.

## Link a reference manually when you choose

1. Open the project, choose **References and assets**, then **Written references**.
2. Select **New reference**. Save the jacket's details, including the position of the tear.
3. In its detail view, choose **Link to text** and select a chapter or screenplay document.
4. Select the relevant text, describe the purpose, such as “Wardrobe continuity in the bandaging scene,” and save.

The link retains the reference version and manuscript revision you selected. A research note, location description or prop reference works the same way. You can also keep a note without linking it to text.

## Find out which side changed

The **Used in** section distinguishes two kinds of change:

| Notice | What to inspect |
| --- | --- |
| Reference has a newer version | Whether the earlier reference still fits the scene |
| Manuscript has a newer revision | Whether the recorded passage still represents the current draft |
| Both notices | What changed on each side before making a new decision |

Use **Needs review** to focus on links with version changes. Counts cover the loaded links; if more pages are available, load them before treating the list as complete.

A new version might contain a spelling correction or a significant continuity change. The notice does not establish a story error. It covers recorded links, not every possible implication across the manuscript.

## Compare the versions that were actually saved

Select **Compare versions**. The left pane shows the version used in the link; the right shows the saved version read for this comparison. Switch between **Reference versions** and **Manuscript revisions**.

The recorded passage is located within the earlier manuscript. Its old position is not applied to the current revision: paragraphs may have moved. Unsaved editor changes stay outside the comparison.

If the new reference says “left sleeve” and the earlier scene says “right,” decide which direction serves the story. You might revise the action, keep the earlier design, or ask your external Agent for alternatives. Closing the comparison leaves text, links and finalization decisions unchanged.

Make and save manuscript edits in the editor. To record a new use, explicitly link the chosen reference version to the relevant passage. The earlier record remains available to explain the previous decision.

## Carry the decision into the next draft

For an independent author working with a script editor or production collaborator, a jacket can be a memory in prose and a visible reveal on screen. Separate purpose notes make those uses understandable without requiring everyone to reconstruct an old conversation.
