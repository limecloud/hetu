# 常见问题与恢复

遇到问题，先留下当前稿件和原任务，再核对实际状态。连接成功、意见已保存、生成完成和成果已采用，是不同的结果。

恢复时从原作品、原任务或原计划接续。新建一份相同任务通常不能解释旧结果，还可能带来重复内容或费用。

## 找不到 Agent 或 Skills

先核对河图为这部作品选择的客户端，以及该客户端当前会话实际加载的连接与套件。文件已经安装，不代表正在进行的会话已经加载。

如果软件显示已安装、助手却找不到方法，检查具体 Agent、套件版本和宿主的重新加载方式。不要反复全量安装所有题材。

见[选择与安装 Skills](skills.md)、[使用外部 Agent](agents.md)。

## 助手回答了，但河图里没有新稿

普通对话回答不等于已经保存到作品。让 Agent 核对成果是否通过工具交回、属于哪个对象和任务，再回读确认。

若你看的是空作者稿，先找已有的参考稿。参考稿与作者稿分开；不要为了看到内容，就把候选自动当成已采纳正文。

意见“已收到”也不意味着返工完成。查看原任务有没有新成果和实际错误，见[提出意见与局部返工](feedback.md)。

## 提示版本冲突

先保留未保存文字，再刷新比较当前修订。另一个窗口或 Agent 可能已经更新了同一对象。

不要用旧页面直接覆盖新稿，也不要删除记录来消除提示。让 Agent 基于当前保存版本重新准备差异，核对允许修改的范围后继续。

参考旧原文的意见仍属于旧版；重新选中当前文字，不把旧坐标直接套用。

## 生成超时，是否需要再点一次

先查询原计划和提供方任务。结果未知不等于失败，外部服务可能仍在处理。

| 看到的状态 | 接下来做什么 |
| --- | --- |
| 等待或处理中 | 沿原计划查询进度 |
| 已完成但本地未显示 | 核对回传、文件与原任务结果 |
| 明确失败 | 保留错误，判断原因和是否需要新方案 |
| 额度不足 | 核对账户与预算，处理后继续查原计划 |
| 结果未知 | 保留原引用，避免另起任务重复付费 |

详见[模型服务与费用](model-services.md)。本地取消跟踪不证明外部退款或终止。

## 图片或视频打不开

先核对原文件是否存在、是否完整，来源链接是否过期。下载成功不能证明媒体可正常解码；请 Agent 检查真实文件，再回到河图观看。

保留当前选用版本和坏文件证据，不先覆盖唯一副本。视频还要实际听声音，抽帧正常不能代替完整播放。

## 连接过期或作品无权访问

核对当前账号、作品和任务范围。重新连接后，不让旧任务自动获得新权限。关联作品也要分别授权，详见[隐私与授权范围](privacy-and-permissions.md)。

模型服务需要重新登录时，从河图发起连接，核对网页验证码和账户，再返回查询原计划。

## 安装问题和问题反馈

核对系统、处理器、应用版本和正式发布附件，不通过关闭系统保护解决安装提示。见[下载与安装](install.md)。

需要提交 [GitHub Issue](https://github.com/limecloud/hetu/issues) 时，提供版本、操作步骤、预期与实际结果，以及脱敏错误。截图先检查有没有私人正文、密钥、账户或个人路径。

恢复后实际打开相关章节或媒体，再确认内容齐全。长期保留独立备份，见[作品、版本与备份](data-and-backup.md)。
