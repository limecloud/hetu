# 隐私与授权范围

## 从当前需要开始

允许操作、任务需要操作与结果值得保存分别判断。auto支持明确范围内连续执行，不代表自动保存全部对话、认可所有结果或扩大外发费用。

你的作品默认保存在自己选择的本机目录。河图开源，不意味着你的小说、剧本、图片或视频也会公开。

使用 Agent 或外部生成服务时，分别看清允许处理哪些作品、哪些材料，以及能执行什么操作。

## 先分清内容在哪里

| 场景 | 内容的去向 |
| --- | --- |
| 在 Mac 阅读、编辑、保存 | 本机作品目录与应用需要的本机状态 |
| 首页工作台演示 | 当前页面中的示例，刷新后重置 |
| 交给外部 Agent | 按当前宿主授权与实际提供的材料处理 |
| 通过模型服务生成 | 将已批准的固定输入发送给对应服务 |
| 备份、同步或交付 | 进入你确认的目标位置与接收范围 |

外部客户端和服务各有自己的隐私与使用条款。决定发送前，核对当前计划真正需要的材料，避免为改一段对白外发整部小说。

## 连接助手不等于开放整个创作库

稳定连接让 Agent 找到机器入口；每次任务还需要具体作品与操作范围。关联小说、剧本和视频，也不会自动共享授权。

可以说：“只读取第一集与这份人物资料，准备对白参考，不修改原著，不查看其他作品。”让 Agent 先说明它实际获得什么，再进行任务。

撤销权限后，旧任务不能通过重新连接自动恢复。需要继续时，重新核对准确范围与有效任务。你的历史作品记录仍按作者自身权限查看。

## 读取参考与修改正文分开

允许参考一章原文，不等于允许直接替换整章。说明可改选区、仅供参考的段落和需要保留的内容。

Agent 可以准备候选和操作方案，你核对结果、决定采纳与定稿。正式设定、封面选用和成片确认，各自有对应的决定，不由一句泛化的“全部同意”代替。

通过其他文件工具直接访问目录时，也要留意宿主权限。软件内的设定锁不能代替操作系统的文件保护。

## 本机文件按这次需要提供

导入原稿或素材时，明确选择文件，或通过宿主授权让 Agent 读取并提交内容。授予作品管理权限，不意味着允许应用代读任意本机路径。

敏感资料可以先做脱敏副本。导入前核对真正需要的版本，保留原件，见[导入已有小说](import-manuscript.md)。

## 权利与外发不是一回事

拥有改编许可，仍需核对能否把原著发送给外部服务，以及能否把原文、参考图和源素材随工程交付。

公版故事也可能使用受保护的现代译文、插画或校注。分别保留来源与权利说明；软件记录你的声明，不认证版权。

## 密钥、反馈与远端副本

自定义模型密钥存本机私密存储，不进入作品和 Agent 回读。提交问题时只提供应用版本、错误提示与脱敏步骤，不附账户凭据和私密正文。

远端同步前确认目标和可见性。删除一个登记、删除作品文件与删除整个工作区，影响不同；有关联作品时先看影响范围。

备份与恢复见[作品、版本与备份](data-and-backup.md)，外发与费用见[模型服务与费用](model-services.md)。
