# 导入已有小说

已经写了十万字，可以从这份稿子继续。先保留原稿，让 Agent 整理结构和导入方案，核对后再把内容带入河图。

导入的目标是把已有文字安稳留下。润色、改章名和整理情节可以在导入完成后单独进行。

## 先准备一份可靠原稿

保留原始文件及附件的独立副本。确认要导入哪部作品、哪一版，是否包含番外、作者的话、重复备份或不同版本的同一章。

告诉 Agent 哪些文件属于这次范围。作品授权不等于整台电脑的文件读取权；文件由你明确选择或通过宿主授权提供。

可以这样开始：

> 这是我已有的小说稿件。先辨认编码、卷章目录和文件顺序，给我看导入预览。保留原文与原章名，不润色，不按同名章节去重。导入结果不清楚时先查原批次。

## 先看目录，再看代表性正文

请 Agent 列出识别到的卷、章、顺序及有疑问的位置。中文数字、阿拉伯数字、分卷后重置的章号都需要结合原稿判断。

| 预览中要看什么 | 为什么值得核对 |
| --- | --- |
| 卷与章节顺序 | 文件名排序未必就是故事顺序 |
| 同名或重置章号 | 两个“第一章”可能分别属于不同卷 |
| 开头、卷界与结尾 | 容易发现缺段、错分章和漏掉的尾声 |
| 引号、空行与特殊字符 | 确认编码和段落没有损失 |
| 附言与番外 | 由你决定作为正文、附录或排除材料 |

不要只看总字数。请 Agent 把无法确定的分界单独列出来，比较原稿后再决定。

## 格式复杂时保留转换说明

不同文件格式能保留的信息不同。正文、标题、脚注、批注和排版样式应分别核对。若需要先转换格式，保留转换前原件，并让 Agent 说明损失了什么。

无法可靠识别时，先停在预览。不要用“导入成功”掩盖乱码、缺章或正文被当成标题的问题。格式与交付见[文件格式与交稿](formats-and-delivery.md)。

## 导入后在小说里实际读一遍

完成后，让 Agent 回读作品、卷章和导入结果。回到河图，检查第一章、跨卷位置、同名章和末章，确认能读到完整原文。

原稿、导入来源和新作品都保留在持久位置。之后继续写新章节，不需要反复导入同一份稿子；已经是河图作品的目录，使用打开作品继续。

## 中断后接着查原批次

连接超时、窗口关闭或对话切换时，先让 Agent 找回原导入任务和批次，确认是未执行、已完成还是结果未知。

如果原文件已经变化，先核对差异，再准备新方案。不要以新的批次重复导入来试探状态，也不要让助手直接改写河图内部记录。

若发现问题，保留原文件和当前结果，记录缺失位置与错误提示。具体恢复方法见[常见问题与恢复](troubleshooting.md)。

导入确认后，继续[章节与写作](writing.md)，或让 Agent 按原稿整理[大纲与卷章规划](outlining.md)。
