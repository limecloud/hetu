# 认识创作库

创作库是你进入作品的地方。小说、剧本和视频各自独立，可以从任意一种开始；需要改编或制作时，再把相关作品连起来。

一本小说可以有多份改编剧本，一部剧本也可以关联不同的视频方案。它们保留各自的内容、修订和作者决定，关联帮助你找到来源。

## 从手里的材料开始

| 你现在有什么 | 从哪里开始 | 回来主要看什么 |
| --- | --- | --- |
| 故事念头、小说旧稿 | 小说 | 大纲、卷章与完整正文 |
| 人物冲突、原创剧本、获权原著 | 剧本 | 分集、场次、行动与对白 |
| 创意、分镜、已有视频片段 | 视频 | 预演、实际片段、音画与成片 |

可以向 Agent 说：“我只想写一部原创短剧，先整理人物和第一集，不创建小说。”已有片段时，也能直接继续视频，不必补建空的上游作品。

初次使用，先看[快速入门](getting-started.md)。不确定起点时，读[选择你的创作路径](creative-paths.md)。

## 作品与保存位置分别看

作品是你正在创作的对象；保存位置是本机承载文件的目录。一个目录可以包含有关联的作品，它们也可以分别保存。同一个文件夹不意味着所有内容共享权限或设定。

让 Agent 准备创建时，说明类型、名称和希望的保存位置，审阅后再执行。作品已经存在，就打开原对象继续。不要为了重新连接助手，把同一部作品再建一遍。

升级应用或切换导航不需要重建作品。保留原有目录和备份，见[作品、版本与备份](data-and-backup.md)。

## 关联保留的是哪一版来源

假设小说第十二章改成了第一集剧本。让 Agent 保留这次使用的原文章节与版本；以后小说改动，剧本仍能说明自己依据哪一稿。

> 把这章试成第一集。保留原著版本和人物关系，新增对白标明是改编表达。不要改小说正文，先交完整剧本让我读。

关联不会自动把小说修改传播给剧本，也不会把改编中新增的人物背景写回原著。需要更新时，先比较来源变化，再决定哪些内容跟着调整。

进一步的资料变化核对见[资料更新与影响核对](references.md)。

## 回到对应的工作面审阅

小说先连贯读章，剧本先读完整行动与对白，视频先连续观看并听声音。计划和摘要可以帮助定位，不能代替成果本身。

收到候选后，核对所属作品和版本，再提意见。参考稿通过审核、采用到正文、确认定稿，属于不同决定。视频中的预演认可、片段选用与成片确认同样分开。

你也可以亲自编辑。Agent 协作不会要求每个创作动作都先经过生成任务。

## 跨作品协作时说明范围

让 Agent 处理小说，不代表它同时获得关联剧本与视频的权限。需要对照哪些对象，就分别说明允许读取的材料和可以修改的内容。

“参考小说人物关系，调整剧本第一集”与“同时重写小说这一章”是不同范围。把话说清，能保留各自已确认的内容，也更容易比较返工结果。
