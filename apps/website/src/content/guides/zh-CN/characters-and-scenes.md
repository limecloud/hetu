# 人物、场景与道具

素材要回答具体的创作问题：这个人是谁，这场戏在哪里发生，哪件物品需要前后保持一致。先整理已经确定的事实，再准备需要的文字与图片。

人物、服装、场景和道具分别保留用途与来源，能减少返工时“到底要沿用哪一张”的困惑。

## 让 Agent 从实际场次整理需求

> 为第一集修表铺的戏整理人物、服装、场景和道具。先找已有版本，缺少的单独列出。父亲的旧外套保持左袖破损，钟的位置沿用原稿；先不付费生成，也不自动选用新图。

回来先看范围：是否多造了不需要的角色，是否把普通描述误当成必须制作的道具，已有素材能否复用。

同名不代表同一个人物，标题相近也不能证明素材来自同一场景。让 Agent 用作品中明确的对象与版本关联材料。

## 区分人物身份、服装与情节插图

人物卡片先用单人形象或正面图，便于辨认。服装造型说明这一场穿什么，情节插图说明发生了什么；它们可以关联同一人物，但承担不同用途。

| 素材 | 核对重点 |
| --- | --- |
| 人物形象 | 面部、年龄感、发型和辨认特征 |
| 服装造型 | 单品、颜色、材质与穿着状态 |
| 场景 | 空间关系、入口、光源和关键陈设 |
| 道具 | 形状、尺度、损坏状态与实际用途 |
| 情节插图 | 人物关系、动作与所指的章节或场次 |

需要侧面、背面、三视图或表情时，先说明要解决的问题。多视图应保持同一人物和服装，不把一张多人插图当成身份参考。

## 先复用，再补缺口

确认同一集前后沿用哪些版本。已经选定的外套不应因为新候选更好看，就被 Agent 静默替换。

需要新造型时，让它说明新旧差异，以及哪些镜头需要重看。下雨后衣服湿了可以是剧情状态变化，不必为每个镜头重新创造人物身份。

图片的准备、候选和意见见[图片与插图](illustrations.md)。

## 回到实际成果里判断

资料写对了，还要看剧本动作、图片和视频是否真正遵循。比如左袖破损：文字里是否写成右手包扎，图片中是否被镜像，视频切镜后是否消失。

按人物出场或场次检查，也可以在任何位置暂停、放大并提意见。不要只看 Agent 选出的摘要和几张好看的样图。

## 资料变更后保留旧依据

如果决定把修表铺从临街改成院内，先核对入口、窗户、人物进场和声音来源。让 Agent 列出已关联的使用位置，分别判断需要调整什么。

新资料不会自动证明旧画面仍然适用。原有图片、旧剧本与意见保留对应版本，具体见[资料更新与影响核对](references.md)。

准备交付时，再核对原图、来源和允许转交的范围，见[文件格式与交稿](formats-and-delivery.md)。
