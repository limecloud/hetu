# 选择与安装Skills

同样是末世故事，可以写一路突围，也可以写一个小区怎样重新分配最后一箱药。题材接近，真正要推敲的问题却不完全相同。

Skills给外部Agent准备一套创作方法：军事故事要注意组织与行动条件，末世故事要想清资源、群体和规则。你仍然决定故事怎么讲，方法帮助它少遗漏该问的问题。

## 1. 在你正在做的事旁边，找到安装入口

Mac版有三个入口：

- 先准备助手：进入“设置 → AI协作”。
- 正在构思：在“新建作品”里选择“借助外部AI构思”。
- 已经开始写：进入“作品资料”，找到AI协作或封面入口。

点击“安装Skills套件”，先选自己使用的Codex、WorkBuddy等客户端，再选题材。这里装的是方法，不是另一个聊天软件。

## 2. 用这本书的核心问题，选最接近的一套

1. 展开“按分类查找或由外部Agent引导”。
2. 已有投稿目标，就用平台、男频或女频缩小范围；还没决定，可以先不筛。
3. 搜索“末世”“无限流”“都市”等词，读套件说明。
4. 选择最贴近主要内容的一套，再补充自己的要求。

![Mac版题材选择近景，客户端为Codex，套件为河图洛书末世灾变，可按平台与频道筛选](/images/guides/mac-skills-zh-CN.webp)

*Mac开发版实图。上方选客户端与套件，下方按平台、频道进一步查找。*

比如：“女主带领小区重建，重点是经营和公共规则，不设感情主线。”可以先选“河图洛书 末世灾变”，再把这段要求告诉Agent。“无感情线”不需要单独装一套，“经营”也不意味着再叠一套。

每套已包含共同的建书、大纲、封面、起草、改稿、短剧与资料整理方法。例如，把零散的人物笔记和场景考据整理成可查的草稿，再由你确认正式采用。先装最需要的一套，避免把所有题材都塞给当前任务。可以先浏览[题材与Skills目录](/integrations/#skills-catalog)。

## 3. 分不清方向时，让Agent先帮你比较

不必先学会一长串标签。把犹豫写出来就行：

> 我喜欢小人物经营和建造，不想以恋爱为主。背景可以是古代，也可以是末世。请先问我几个关键问题，再比较哪种方向更适合这个故事。

在选型区域点击“复制外部Agent选型请求”，交给自己的Agent。读完理由，再把它返回的可导入结果粘回建议区域，点“读取Agent建议”，确认后“选用此套件”。

只复制可导入结果，别把前后解释一起带上。如果提示格式不符，可以请它“按刚才的格式，只返回可导入结果”，再复制一次。

目录搜索负责查找；理解你的想法和比较方向，由你选择的外部Agent完成。

## 4. 装好了，回到助手里确认一次

Codex使用“安装到Codex”；WorkBuddy核对位置后使用“安装套件文件”。其他客户端按窗口说明操作。

安装成功后，回到外部客户端，新开对话或按它的要求刷新，确认当前会话能使用刚选的方法。遇到文件冲突时，先读提示，原有内容会保留。

如果客户端还没准备好，先在自己常用的助手里整理故事想法。完成接入后，按[用Codex构思一本新书](codex-first-task.md)继续，让它保存方案，不必重新录入资料。

## 5. 别把“文件已放好”当成“这次任务已经完成”

“本机包版本”是已装版本，“随附套件版本”是当前软件提供的版本；不同可以检查更新。会话是否加载，还需要在外部Agent里确认。

一本军事小说与一本都市小说，可以选不同客户端和套件。设置里更改默认客户端，只影响之后的新作品。

现在可以带着自己的点子，继续[用Codex构思一本新书](codex-first-task.md)。

## 与河图创作插件有什么区别？

本篇的Skills套件安装在外部Agent客户端，提供创作方法与连接。关系图、时间线等[河图创作插件](plugins.md)安装在河图，提供专业视图与数据操作。两类扩展分别管理，不将题材套件数量计作河图插件数量。
