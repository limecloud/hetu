# 选择与安装 Skills

Skills 可以理解为给外部写作助手准备的“创作方法包”。例如，军事套件帮助核对组织、行动和战场条件；末世套件关注生存资源、群体关系和灾变规则。你选哪种故事，就给自己的 Agent 装对应的方法。

## 1. 找到安装入口

已经打开 Mac 版时，以下三个地方都能安装：

- 想先准备好助手：打开“设置 → AI 协作”。
- 正在想一本新书：打开“新建作品”，选择“借助外部 AI 构思”。
- 已经有作品，想补方法或做封面：打开“作品资料”，找到 AI 协作或封面入口。

点击“安装 Skills 套件”，会看到客户端和题材套件的选择项。客户端就是你平时使用的 Codex、WorkBuddy 等外部 Agent。

## 2. 按自己的故事选一套

1. 展开“按分类查找或由外部 Agent 引导”。
2. 选择目标平台和男频、女频；还没决定时可以先不筛选。
3. 搜索“末世”“无限流”“都市”等关键词，阅读套件说明。
4. 选最接近这本书主要内容的一套。

![Mac 版题材选择近景，客户端为 Codex，套件为河图洛书末世灾变，可按平台与频道筛选](/images/guides/mac-skills-zh-CN.webp)

*Mac 开发版实图，截取题材选择区域。上方选客户端和套件，下方用平台与频道缩小范围。*

例如：“女频末世，女主带领社区重建，没有感情主线”，可以先选“河图洛书 末世灾变”。“无感情线”是你继续补充的创作要求，不需要为每个标签再装一套。

每套已经包含建书、资料、大纲、封面、起草、改稿和短剧所需的共同方法。只装选中的题材套件即可。

还拿不准时，可以先浏览[题材与 Skills 目录](/integrations/#skills-catalog)。

## 3. 不知道选哪套，让自己的 Agent 帮你

1. 在选型区域写清楚：准备写给谁看、主角想做什么、故事最重要的冲突，以及不想写的内容。
2. 点击“复制外部 Agent 选型请求”，粘贴到自己的 Codex、Claude Code 或其他 Agent 对话中。也可以请它先问你几个问题。
3. 把它返回的完整建议复制回来，粘到建议区域，点击“读取 Agent 建议”。
4. 阅读推荐理由，点击“选用此套件”，再打开安装窗口确认安装。

只复制助手给出的可导入结果，不要连同前后的解释一起粘贴。如果提示格式不符，可以告诉助手：“河图洛书没有读懂这份建议，请按刚才的要求，只返回可导入的结果。”再复制一次即可。

例如，你可以写：“我想写女频，但不想以恋爱为主。喜欢经营、建造和小人物成长，背景可以是古代，也可以是末世。请先帮我比较方向。”

只有你把请求交给外部 Agent，它才会帮你分析。河图洛书里的搜索只是帮你查目录。

## 4. 安装后，回到自己的助手

选择 Codex 时，点击“安装到 Codex”；选择 WorkBuddy 时，核对安装位置，再点击“安装套件文件”。其他客户端按窗口中的安装说明操作。

看到安装成功后，回到外部客户端，新开一个对话或按它的提示刷新，再确认能使用刚选的河图洛书题材方法。安装遇到冲突时，先阅读提示，原有文件会保留。

如果窗口提示找不到客户端，先把平时使用的客户端准备好。也可以先按[用 Codex 构思一本新书](codex-first-task.md)手工交换想法，之后再完成套件安装。

## 5. 看懂版本提示

“本机包版本”是你已经装的版本，“随附套件版本”是当前河图洛书提供的版本。两者不同时，可以打开安装窗口检查更新。

“已安装”说明方法包已放好；是否在当前对话中可用，还要回到自己的 Agent 确认。每本书可以选不同的客户端与题材套件；在设置里改默认客户端，只影响之后的新作品。

准备好后，继续[用 Codex 构思一本新书](codex-first-task.md)。开发者的高级接入说明见[Mac 源码版（开发者）](download-and-install.md)。
