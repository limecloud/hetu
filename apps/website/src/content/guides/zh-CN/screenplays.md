# 剧本与分集审阅

## 从当前需要开始

从当前人物、场次或已有分集开始，缺少小说与完整全剧计划不阻断试戏。明确要保留并继续时保存参考稿；有意改编差异保留自身依据。

原创剧本可以从一场冲突开始。改编剧本则带上你有权使用的原著。剧本在创作库中独立保存，有自己的分集、正文、修订与决定。

## 向 Agent 说出这场戏要发生什么

可以这样说：

> 帮我开发一个原创短剧：修表师回乡找父亲，旧钟里却传出明天的求救声。先讨论全剧方向，再写第一集完整剧本。重点是父女关系，不先创建小说，也先不生成视频。

让 Agent 整理人物目标、冲突、分集安排与待决定的问题。你讨论并选择方向，Agent 保存方案；无需把对话重新填进表格。分集数可以随着故事推敲，不按视频模型的单次时长切剧情。

已有剧本就让 Agent 沿原项目继续。需要把小说改编成剧本，先固定获权原著和对应版本，具体见[从小说到短剧](adaptation.md)。

## 回来读一集完整的戏

审阅时先连贯读完，再看细节。分集计划告诉你“这一集准备讲什么”；可读剧本还需要场景、行动、人物与对白。不要把几行梗概当成已经写完的一集。

先核对这几件事：人物进场时想得到什么，什么阻挡了他，离场时局面有没有变化。改编时再看原著对照：哪些来自原文，哪些是压缩、重排或新增。

参考稿和作者稿分别保留。作者稿还空着时，也应先阅读已有参考稿，再决定采用哪些内容；需要自己改字时，继续使用正文编辑。

## 指着具体位置说，继续改同一集

例如：

> 第一集里，父亲的秘密揭得太早。保留钟声和女儿停下来的动作，删掉解释来历的对白。只改这一场，其他场次保持，先给我看差异。

在河图选中位置提意见，或把当前稿件和意见交回原 Agent 对话。保留所指版本和原任务，让 Agent 读完意见再返工；保存意见与收到新稿是两件事。

新版回来后对照旧稿，也可以沿人物出场或本次改动核对，最后回到完整剧本读一遍。旧版意见仍对应旧版，不直接套到新稿。

## 采用、定稿与制作分别决定

你可以只采用一句对白或一场戏，继续修改，再确认剧本定稿。下一步做预演或选用人物图，是各自独立的选择，不会自动把剧本定稿，也不回写原著。
