# 用 Codex 构思一本新书

这次先做一件小事：让 Codex 帮你想书名和简介，再由你填回河图洛书。全程用复制和粘贴，不需要输入命令。

开始前，准备好已经能正常对话的外部 Codex，并打开河图洛书 Mac 版。Codex 是你另外使用的助手，河图洛书不会替你发送消息。

## 1. 在河图洛书写下想法

1. 在书库点击“新建作品”，书名先留空也可以。
2. 在“创作想法与要求”中写下自己的故事点子。
3. 点击“保存筹备”，留住这次想法。

![Mac 版新建作品，书名留空，在创作想法与要求中填写故事点子](/images/guides/mac-new-book-zh-CN.webp)

*Mac 开发版实图。先写想法即可，右下角“保存筹备”能留住这次计划。*

可以先用这个例子：

> 我想写一部末世生存长篇。成年女主带领社区重建，重点写物资分配、信任和公共规则，不设感情主线。请给我两个书名、一段简介，以及开篇最吸引人的冲突。先不要写正文。

## 2. 准备要交给 Codex 的说明

选中自己写在“创作想法与要求”里的文字，复制下来。也可以直接复制上面的例子，再改成自己的故事。

这次练习先用普通对话，不需要保存或配置外部任务。已经安装了题材套件的作者，可以请 Codex 使用本书对应的方法；需要安装时再看[Skills 指南](skills.md)。

## 3. 粘贴到自己的 Codex 对话

切到已经准备好的 Codex，新开一个对话，粘贴刚才复制的内容，再补充这句话：

> 这次我们用人工交接。请直接在对话里给我书名、简介和开篇冲突，分开写清楚。只根据我提供的想法讨论，不读取本机文件、不修改软件里的资料；我会自己读完并填回河图洛书。

读完建议，可以继续追问。例如：“第二个方向更接近，但我不想让主角有特殊能力，请重新想一个开篇冲突。”

这一步的成果显示在 Codex 对话里，不会自动回到河图洛书。

## 4. 挑选、修改，再填回资料

1. 选一个自己喜欢的书名，复制到河图洛书的书名栏。
2. 把简介复制到简介栏，改掉不符合自己想法的地方。
3. 想保留的故事方向，可以写进大纲；还没想清楚的设定继续留在筹备里。
4. 暂时不建书就点击“保存筹备”。确认准备好了，再点击“创建小说”，选择作品文件夹。

看到新作品工作台，就完成了这次练习。书名和方向由你决定，Codex 的建议只是供你选择。

## 接下来

继续看[章节与写作](writing.md)，开始写第一章。想让助手更贴合题材，可以再按[选择与安装 Skills](skills.md)安装对应的方法包。

需要自动交接等高级能力的开发者，请从[Mac 源码版（开发者）](download-and-install.md)进入源码说明。本篇采用的是人工复制和填写。
