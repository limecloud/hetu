# 使用创作插件

群像故事写到一半，想看清谁在隐瞒谁；倒叙越写越多，想核对事情真正发生的顺序。这时，可以为作品加一张人物关系图，或一条故事时间线。

从[插件中心](/plugins/)按实际问题选择工具。插件扩展河图工作台；[Skills 与客户端接入包](skills.md)为你使用的外部 Agent 提供方法与连接。两者分别安装。

## 1. 先说明你想看清什么

不必先学画布操作。向已接入的 Agent 说明：

> 帮我整理这部作品的主要人物关系。先读我允许的资料，不能确定的关系问我。请用人物关系图保存并回读，不改正文，也不替我采纳或定稿。

也可以说：

> 把这三章里发生的事件排成时间线。区分明确时间和推测时间，先让我检查，不改变原文的叙述顺序。

Agent 先核对当前安装版有什么能力，以及本次连接对应哪部作品。目录介绍不能代替实际能力发现。

长篇筹备可以选择[小说规划](/plugins/novel-planner/)：

> 先读这部小说已有的规划，把各卷的目标、主题、冲突、转折和详细剧情整理好。保留我已经决定的内容，保存后回读，不改正文、不采纳或定稿。

需要检查人物走位和机位时，可以选择[导演布景台](/plugins/director-stage/)：

> 请把候车亭对白布置成白模场景，先看清两个人隔着桌子的相对位置，再比较远景和近景。输出预演，保持旧版，把切近景的时间延后半秒。白模只用来检查空间与节奏，不代表成片认可。

## 2. 安装所选的河图插件

在创作库的“创作插件”管理包；也可以让 Agent 按你的明确选择，通过河图机器入口核对包、安装并回读结果，不要求打开桌面窗口执行。

安装前看清插件来源、版本与功能。包需要包含已经构建的界面、清单和必要运行文件，源码文件夹不等于分发包。插件详情提供源码和构建指南，供开发者核对；普通作者可把所选来源交给 Agent 准备。

小说规划的详情页提供开发预览发行包及已验证平台。把该页交给 Agent，让它下载固定运行包、核对摘要、解压并通过河图安装；不需要自行构建源码。安装后重新发现，确认实际版本与能力。

官网目录用于选择与了解工具，不会自动读取本机安装状态、下载执行代码或替你授予权限。

## 3. 明确这次处理的作品

可信插件安装并启用后即可使用宿主公开核心能力，无需再逐个申请插件作品授权。向 Agent 明确本次作品与处理目标；外部 Agent 的作品连接仍需单独授权。

插件复用河图的作品数据与业务规则。正文采纳、定稿及费用仍由你决定；升级时核对来源和变化，旧包连接不能继续调用新包。

不确定时，可以先说：“列出这次要读什么、写什么，等我确认范围后继续。”

## 4. 回来审阅，指出具体问题

关系图先检查人物是否遗漏、连线方向和说明是否准确；时间线先检查事件时间、顺序和描述。不能从图画得整齐就推断故事没有矛盾。

小说规划沿卷列表阅读卷信息、本卷规划和详细剧情，再检查人物、地点及伏笔关联。工作记录显示实际步骤和状态；提出停止请求后，仍须等待外部 Agent 确认。

例如：“林乔还不知道周远的身份，把这条关系改成她目前能知道的内容。”Agent 沿这部作品的已保存版本继续，你可以比较结果，也可以亲自编辑。

保存后让 Agent 回读确认。遇到超时或结果未知，查询原操作，不另建一张图来掩盖问题。

导演布景台在同一场景中联动平面调度、三维取景和镜头台词表。只改第三镜的站位，不需要重布整个场景；台词估时、白模遮挡和对话轴线检查帮助发现需要继续核对的问题。指出人物、机位或具体帧，Agent 按固定场景返工；手工拖动和精确编辑可选。预演不含真实演员与最终材质，不能证明模型会严格复现。

## 5. 安装了新插件，如何让 Agent 用上？

在当前已连接的对话中说：“重新发现河图已安装的插件，核对本作品获权能力，再继续刚才的任务。”

河图插件通过已有的 CLI／MCP 连接发现，不需要给 Codex 安装同名插件。发现结果反映当前安装与连接；软件不会把新工具自动塞进模型的上下文。客户端自身 Skills 或接入包更新，则按该客户端要求刷新或新开会话。

## 6. 停用与卸载，作品怎么处理？

不再使用时可以停用或卸载，插件调用随之停止。已保存的专业成果保留，可通过通用读取与导出取回；专业编辑需要启用相应插件。卸载不是删除作品。

遇到版本、权限或结果不明，按[常见问题与恢复](troubleshooting.md)保留原引用继续。想自己制作工具，转到[插件开发指南](plugin-development.md)。

## 从规划走到下一稿

[文风工坊](/plugins/prose-studio/)记录你的偏好和依据，比较不同写法；[小说审校](/plugins/novel-review/)记录六类检查的实际覆盖与问题；[小说图鉴](/plugins/novel-atlas/)把人物、关系、地点和事件放在同源视图中阅读。按需要选择，三者不要求互相安装。

你可以说：

> 先读旧稿和已有规划，说明实际读了哪些内容。比较下一章的两种方向及代价，保留我的文风偏好。准备候选后，按具体问题给出意见并返工；读取新候选，再复核旧问题。最后把人物与事件更新到图鉴，不修改正式设定，不替我采纳正文。

小说规划还可阅读剧情方向比较、故事时间与叙事顺序、人物在具体事件时知道什么。未知时间保持未知，规划方向不表示情节已经发生。图鉴提供离线HTML，默认不携带整章正文，可在没有脚本和网络的环境阅读。

## 研究、人物与分析如何接起来

[创作研究台](/plugins/story-research/)整理问题、原文观察、支持与反证；[人物工坊](/plugins/character-lab/)比较动机假设、访谈、对白试演与弧光；[故事分析](/plugins/story-analysis/)记录已读范围、场景、叙事信号与问题依据。按需要单独安装，也可以围绕同一小说接续。

> 先研究林溪为什么留在旧站，区分原文、推断与反证。把有依据的结论交给人物工坊，比较两种动机与对白；再分析它们对下一章的影响。读取已有整书、卷章规划后准备候选，按意见返工，再回读新稿复核。保留每次交接的固定依据，不修改正式设定，不替我采纳或定稿。

查看研究时先看来源；查看人物时区分事实与假设；查看分析时先看阅读覆盖。模拟读者不是真实读者反馈，姓名提及不等于实际出场，提交新稿也不表示问题已解决。

## 同一部作品的更多形态

角色卡和世界书、分支故事、系列番外、译稿、朗读与书稿交付，都可以围绕已有作品继续。按当前目标安装所需插件，不必一次配置全部工具。

| 想做什么 | 选择什么 | 回来审阅什么 |
| --- | --- | --- |
| 带进已有角色卡与世界书 | [世界书互通](/plugins/lorebook-bridge/) | 角色、条目、映射与转换说明 |
| 比较不同选择与结局 | [互动叙事](/plugins/interactive-fiction/) | 路线试玩、变量与固定版本存档 |
| 组织续作与番外 | [系列组织](/plugins/series-organizer/) | 阅读顺序、角色出演与目标作品 |
| 制作并返工译稿 | [译稿工坊](/plugins/story-translation/) | 源译对照、术语、未译范围与意见 |
| 听出对白与行文问题 | [朗读审阅](/plugins/readthrough/) | 实际声音、原文映射与区间意见 |
| 整理可阅读的书稿 | [书稿交付](/plugins/book-export/) | 目录、脚注、插图与实际交付文件 |

例如，你可以向Agent说明：

> 先读这部小说和已有成果，把选定情节组织成两条可试玩的路线。把其中一条准备成英文译稿，逐段核对并记录意见；朗读只使用我明确提供或同意生成的声音。最后把选定的固定候选整理成书稿，检查完整文件，不替我采纳正文或定稿。

每次交接保留具体版本。上游有新稿，旧译稿、旧声音映射和旧交付仍有各自依据；需要更新时，先看影响再继续。

## 长篇接续与专业复核

- [小说规划](/plugins/novel-planner/)：先复盘旧稿，核对事件偏序、人物知情和修改影响，再准备卷章与候选。
- [文风工坊](/plugins/prose-studio/)：按本次人物、章节和场景选偏好；冲突先决定，明确修改再作为样本。
- [小说审校](/plugins/novel-review/)：选择固定范围与作者词表，检查重复及有据状态；新稿逐项复核，不自动认定问题解决。
- [小说图鉴](/plugins/novel-atlas/)：查看同源地图、行程、成长与关系阶段、器物流转和真实阅读覆盖，也可导出离线图鉴。

对话示例：“复盘前两卷，准备第三卷开篇。林溪的恐惧用动作表达；按意见返工后核对她何时知道暗号，再更新图鉴。未读和不确定的地方请保留。”

## 从原著到更多表达

先选当前问题，再选择专业工具。改编目标与原著分别保存；试读意见保留原话；漫画和有声剧使用实际图像与录音。

- [改编工程](/plugins/adaptation-studio/)：沿映射阅读原著与目标，核对为什么删、并、拆或新增，再让 Agent 调整具体单元。
- [试读工作台](/plugins/reader-review/)：先读原话和覆盖，再看处理理由；旧反馈属于旧稿，新稿要重新核对。
- [漫画创作](/plugins/comic-studio/)：实际阅读完整页面，检查格序、气泡和图像，再指出需要修改的具体一格。
- [有声剧制作](/plugins/audio-drama/)：听完整对白与混音，按时间区间提意见；时间线变化时先核对旧意见对应的位置。

例如：“先梳理这三章如何合成第一集，保留寄信人的悬念。把固定片段给试读者，按返回意见准备第二稿，再把这一场做成两页漫画和一段多人对白。声音与图片先使用我提供的素材，费用另行确认。”


## 世界、悬念与视听表达

- [世界构建](/plugins/world-studio/)：明确虚构历法、制度前提和资源单位，先看修改影响，再准备情节。
- [悬疑推演](/plugins/mystery-lab/)：分开作者真相与读者已知，按揭示阶段核对线索与假说。
- [美术设定台](/plugins/art-direction/)：阅读实际参考图、比较造型和色板，按具体图像区域提意见。
- [字幕工坊](/plugins/subtitle-studio/)：播放固定媒体，核对双语、时间与阅读负担，保留原件后交付字幕。

例如：“先核对封港三日的口粮和日期，再看看第二章的读者是否有足够线索。保留寄信人的真相，准备下一章；人物与服装先使用已提供的实际参考图。对白字幕要听完整段落核对，偏移后重新检查旧意见。”

小说、剧本和视频分别保存。已有参考、字幕或意见绑定原修订，上游修改不会自动替换它们；生成费用、正文采纳与最终认可各自决定。
