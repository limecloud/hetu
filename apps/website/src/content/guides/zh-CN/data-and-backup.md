# 作品、版本与备份

作者书库登记多部作品，每部作品的正文、设定与素材保存在独立工作区。软件源码的开源许可不会自动覆盖你的作品。

## 页面演示

[首页工作台](/#prototype)只保留当前页面的演示状态。“保存正文”、采纳、定稿和快照均不读写磁盘，刷新即重置。切换作品或任务会保留页面内的编辑内容，切换界面语言不会翻译正文。

## 本机保存与版本

本机客户端保存正文修订并保护恢复缓冲。Git 版本管理采用准备快照、核对固定文件与差异、作者批准后提交的步骤，不复用软件源码仓库，也不自动推送。

官网“版本管理”可以演示准备和确认，但不会执行 Git。真实操作结果未知时保留原任务并核查回执，不重复提交碰运气。

## 独立备份

同一块硬盘上的正文与 Git 都不能独自承担设备故障恢复。另行安排可信设备或备份位置，核对图片、音频和视频是否完整。

选择 GitHub 或 Gitee 等远端前，确认仓库可见性、素材权利及同步范围，再明确授权。当前本机快照实现不等于完整远端协作能力已验收。

## 遇到异常

先保留原文件、未保存内容、最近有效版本与脱敏证据，再核查冲突和恢复状态。不要覆盖唯一副本。演示刷新后没有磁盘历史可恢复。
