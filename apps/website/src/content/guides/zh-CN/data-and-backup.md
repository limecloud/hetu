# 作品、版本与备份

页面演示、真实作品、版本快照与独立备份分别解决不同问题。先弄清楚内容保存在哪里，再开始长期写作。

## 原型不保存真实作品

官网原型只使用浏览器当前页面中的演示数据，不读取磁盘、连接云盘或创建 Git 仓库。“保存修订”只是页面内状态，刷新或关闭后重置。

需要保留体验文字时，自行复制到本地编辑器保存。不要把唯一一份作品放在网页演示中。

## 软件与作品分开

河图的软件源码采用开源许可证，不表示你的小说、设定或素材自动开源。作品应存放在你单独管理的创作目录中；向 Agent 提供内容或同步远端前，先确认范围与隐私。

## 快照不能替代独立备份

版本记录帮助比较和回看修改；独立备份帮助应对设备故障和误删。Git 本地仓库与正文位于同一块硬盘时，不能独自承担灾难恢复。

为作品安排另一设备或可信备份位置。大图片、音频和视频需单独核对是否随备份完整保存。选择 GitHub 或 Gitee 时，确认仓库可见性，再执行你明确授权的同步。

## 交付前保留一份固定副本

记录交付版本、选择范围、日期与接收方要求，保留最终文件和来源清单。修改后重新生成材料，避免把不同批次的正文、剧本与报告混在一起。

## 遇到问题时

原型文字消失通常是页面已刷新；原型没有磁盘历史可恢复。真实作品异常时，先保留现有文件与备份，再核对最近一次有效副本，避免用新内容覆盖唯一证据。
