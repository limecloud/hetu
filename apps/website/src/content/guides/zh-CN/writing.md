# 章节与写作

“小说”区域把章节、正文和设定提示放在一起，方便你在写作时核对上下文。

## 找到章节

在左侧选择“小说”，再点击章节标题。当前章节会高亮，中间显示标题与正文。原型切换章节时会保留当前页面中的编辑内容。

在手机窄屏下，只显示当前章节入口，主要用于阅读和体验；完整章节切换适合桌面宽屏。

## 编辑与保存

1. 在正文区域直接输入或修改文本。
2. 点击顶部“保存修订”，观察修订号与提示。
3. 切到另一章再返回，确认页面中的内容。

演示保存不会写入磁盘，也不会形成 Git 提交。需要保留体验中的文字时，请自行复制到你信任的本地编辑器并保存。

中文演示按汉字计数；英文演示按英文词计数。计数用于写作参考，不等同于投稿平台的计费字数。

## 一边写，一边看来源

第一章右侧的“时间线待确认”是提示。点击“定位原文”，正文会选中“旧玉扣”。如果你已经删除这段文字，先回到原文核对，不要仅凭旧提示修改故事事实。

设定锁定状态出现在检查器中。写作不需要先解锁设定；只有准备调整共同事实时，才由作者重新审阅设定。

## 切换界面语言

顶部 EN／中文切换界面文字，正文保持原样。英文入口使用独立英文演示作品；切换按钮不会翻译你的章节。
