# 章节与写作

有时候，最好用的创作工具，就是能让你赶紧写下下一句。可以自己写，也可以让外部 Agent 准备参考稿，回来连贯阅读，再决定怎样继续。

## 让 Agent 接着已有小说工作

例如：“沿这本书继续第十二章，保留人物此刻还不知道真相的限制。先给完整参考稿，不替换正文。”Agent 读取获权的章节与设定、保存成果，你核对人物与伏笔，指出“这里删掉解释，只保留动作”，沿原任务返工。

外部原稿先让 Agent 核对编码、卷章顺序、重复章名与正文范围，再固定导入。导入一整本书与完成全书改编分别验收。已有河图作品直接打开，不因改版重新导入或搬目录。

小说保留自己的设定、封面与卷章；关联剧本或视频是独立作品。小说修订后先列出相关影响，不自动改写剧本或重做画面。

## 找到这本书，继续上次的地方

从[首页书库](/#prototype)打开一部作品，再进入“小说正文”。书库支持按书名或作者搜索，也可以按创作状态筛选。

想改书名、简介或封面，去“作品资料”；想写下一章，回到“小说正文”，点击已有章节或“新建章节”。手机上同样可以切换章节。演示展示分卷导航，桌面客户端另有目录管理与修订检查。

每本书独立保存资料与卷章。写两本不同题材的小说，不用先把它们放进同一个世界观。

## 给作品换封面

在 Mac 客户端打开“作品资料”，在候选卡片上点击“用作封面”即可更换，书库同步更新，当前使用的候选会单独标明。想先放大看，点击图片；想浏览其他候选，点击当前封面下的“更换封面”。

已有自己制作的封面，在封面的更多菜单选择“从本地导入”，选择 PNG、JPEG 或 WebP。检查预览，按需要叠加书名和笔名，再点击“用作封面”。取消预览会保留原封面；确认后，作品资料与书库同步更新，旧封面仍可在“封面历史”查看。Agent 已回传的候选无需重新导入。

需要设计新封面时，用“让 AI 绘图”把目标交给自己的 Agent，收到候选后再回来选择。手动换封面不需要配置 AI。

## 先写一句，再看保存发生了什么

试着在演示正文末尾加一句：“门里的人没有回答，灯却灭了。”

1. 编辑后，留意“未保存”提示。
2. 点击“保存正文”。
3. 切换到另一章，再切回来，看看刚才那句还在不在。

演示会在当前页面保留修改，切换作品或任务也保留缓冲；刷新页面会重置。练习可以放心试，自己的唯一稿件请保存在本机客户端。

本机把正文修订写入作品目录，并处理中文输入、修订冲突与恢复缓冲。保存正文不会自动执行Git提交；需要留下作品快照时，另到版本管理确认。

演示按非空白字符计数，方便观察写作量，不等同于投稿平台的计费字数。

## 今天定稿了，明天仍可以改主意

觉得这一版可以留下，就先保存，再点击“作者定稿”，核对章节与版本，在确认窗口完成定稿。

之后你仍可以继续写。界面会说明“旧定稿仍保留”：那一版不会跟着新文字悄悄改变。新的写作稿需要另行保存与确认。

这很适合“这一版先发给编辑，但我还想再改改结尾”的情况。交哪一版，要由你明确选择。

## 换界面语言，作品仍是你写下的样子

工具栏可以切换中英文界面和浅暗主题。按钮会换语言，你写下的正文、人物名和书名不会被自动翻译。英文首页用另一套英文示例初始化，也不改写你的输入。

想让故事前后更有依据，继续看[维护设定集](story-bible.md)；收到参考稿后，只采用喜欢的部分，见[检查与草稿审核](review.md)。

需要先讨论后续故事，见[大纲与卷章规划](outlining.md)；意见要落到具体位置时，见[提出意见与局部返工](feedback.md)。
