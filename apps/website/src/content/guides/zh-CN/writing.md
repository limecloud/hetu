# 章节与写作

## 从当前需要开始

可以亲自写，也可以明确委托Agent连续推进。说明哪里要改变、哪里必须保留；需要持久返工时固定原稿和必要依据，不先填写所有设定。

有时候，最好用的创作工具，就是能让你赶紧写下下一句。可以自己写，也可以让外部 Agent 准备参考稿，回来连贯阅读，再决定怎样继续。

## 让 Agent 接着已有小说工作

例如：“沿这本书继续第十二章，保留人物此刻还不知道真相的限制。先给完整参考稿，不替换正文。”Agent 读取获权的章节与设定、保存成果，你核对人物与伏笔，指出“这里删掉解释，只保留动作”，沿原任务返工。

外部原稿先让 Agent 核对编码、卷章顺序、重复章名与正文范围，再固定导入。导入一整本书与完成全书改编分别验收。已有河图作品直接打开，不因改版重新导入或搬目录。

小说保留自己的设定、封面与卷章；关联剧本或视频是独立作品。小说修订后先列出相关影响，不自动改写剧本或重做画面。

## 找到这本书，继续上次的地方

在本机“创作库”打开小说，从卷章目录进入文稿。创作库可按作品名称与状态查找；[桌面界面预览](/#prototype)展示当前界面，官网不编辑作品。

想改书名、简介或封面，去“作品资料”；继续写作时选择对应章节。每本书独立保存资料与卷章，不用先放进同一个世界观。

## 给作品换封面

在“作品资料”打开“更换封面”，比较候选并预览。已有图片时，选择“本地导入”中的“选择图片”，核对预览和书名叠加，再确认用作封面。取消会保留原封面，旧封面仍可在“历史”查看。

需要新设计时，用“让 AI 准备封面”向所选 Agent 说明目标，收到候选后再回来选择。手动导入图片不需要配置 AI。

## 编辑与保存修订

在文稿中直接修改，完成后点击“保存修订”。本机把修订写入作品目录，并处理中文输入、版本冲突与恢复缓冲。结果不明时沿原操作恢复，不重新发起另一份保存。

保存正文不会自动执行 Git 提交；需要保留阶段版本时，另到“文稿版本”准备并审阅。字数仅作为写作辅助，不等同于投稿平台的计费口径。

## 今天定稿了，明天仍可以改主意

觉得这一版可以留下，就先保存，核对章节与版本，再完成定稿确认。

之后你仍可以继续写。界面会说明“旧定稿仍保留”：那一版不会跟着新文字悄悄改变。新的写作稿需要另行保存与确认。

这很适合“这一版先发给编辑，但我还想再改改结尾”的情况。交哪一版，要由你明确选择。

## 换界面语言，作品仍是你写下的样子

界面语言与外观设置只影响软件呈现。正文、人物名和书名不会被自动翻译，网站切换语言也不改变本机作品。

想让故事前后更有依据，继续看[维护设定集](story-bible.md)；收到参考稿后，只采用喜欢的部分，见[检查与草稿审核](review.md)。

需要先讨论后续故事，见[大纲与卷章规划](outlining.md)；意见要落到具体位置时，见[提出意见与局部返工](feedback.md)。
