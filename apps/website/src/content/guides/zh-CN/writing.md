# 章节与写作

每部作品有独立的资料、封面和卷章。先从书库进入作品，再打开“小说正文”。

## 作品与卷章

[首页工作台](/#prototype)可搜索、筛选和切换多部演示作品。在“作品资料”中修改书名、作者、简介与创作状态，也可以选择随客户端提供的演示封面。

“小说正文”的章节列表在手机上同样可操作。点击标题切换章节，或用“新建章节”建立空白正文。演示展示分卷导航；原生客户端还提供目录管理与修订检查。

## 编辑与保存

修改正文后显示“未保存”，点击“保存正文”保存页面内修订。切换章节、任务或作品不会丢弃演示缓冲；刷新会重置全部状态。

本机客户端把正文保存到作品工作区，处理中文输入、修订冲突和恢复缓冲。正文保存与 Git 快照分开，不因保存自动提交 Git。

演示按非空白字符计数，供写作参考，不等同于投稿平台计费字数。

## 定稿与继续编辑

“作者定稿”只对已保存修订生效。核对当前章节与修订，在确认窗口勾选证据确认后定稿。

之后继续编辑会显示“旧定稿仍保留”。新写作稿需要保存并重新确认，不会自动改写旧定稿。

## 语言与主题

原型工具栏可切换中文／英文界面与浅／暗主题，正文、书名和其他作者输入保持原样。英文首页用独立英文演示数据初始化，不自动翻译作品。
