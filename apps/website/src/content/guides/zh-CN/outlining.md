# 大纲与卷章规划

## 从当前需要开始

大纲服务当前卡点。只需下一场戏，就不用补全整部作品；先试写再整理结构也成立。探索方向与已经确定的情节分开保存。

大纲帮助你讨论故事将怎样发展，也给下一次创作留下能接续的依据。它可以从一个问题开始，不必第一天就填满所有卷章。

让 Agent 比较方向、整理候选，你决定哪一条值得继续。大纲里的设想与正文已经确认的事实分开保留。

## 先说想写什么，也说不想写什么

人物、处境、关系和你在意的感受，通常比一长串类型标签更有用。

> 我想写修表师回乡找父亲的故事。旧钟能传来明天的声音，但不能随意改写过去。重点放在父女关系和小镇生活，不要变成拯救世界。先讨论两种故事方向，各说明开场、主要冲突和结尾的代价。

已有片段可以作为固定参考；拿不准的地方写成待决定问题，不让 Agent 把猜测当成既定设定。

新书的名称和资料筹备见[用 Codex 构思一本新书](codex-first-task.md)。

## 先比较方向，再展开结构

看方案时，先判断人物是否有值得追问的处境，主要冲突能否持续，结局是否回应开场的问题。

可以保留一个方向的核心关系，放弃它的悬疑解释。请 Agent 记录你的取舍，再展开所选方向，避免每轮都从完全不同的故事重新开始。

“第二版更好”可以继续说具体：“保留小镇互助，结尾不要靠新人物解释秘密，让女儿自己作决定。”

## 从总纲走到下一章

| 层次 | 主要回答什么 | 审阅时看什么 |
| --- | --- | --- |
| 故事方向 | 为什么值得讲 | 人物欲望、阻力和代价 |
| 总纲 | 故事从哪里走到哪里 | 因果、关系变化与结局 |
| 卷纲 | 这一阶段解决什么 | 阶段目标和结束时的变化 |
| 章纲 | 下一章具体发生什么 | 行动、信息、转折与接续 |

章节规划应服务故事。不必每章相同字数，也不必为了凑齐结构提前透露秘密。

先让 Agent 把下一章整理到可讨论的程度：人物此刻知道什么、想得到什么、采取什么行动、结束时有什么不同。再看完整参考稿，见[章节与写作](writing.md)。

## 保留弹性，也保留已经说定的事

大纲可以修改，已经写出的章节也可能改变。请 Agent 标明本次改动影响哪些后续安排，保留原方案以便比较。

例如决定父亲没有离开小镇，需要重新看寻找路线、目击者和原有误导。让 Agent 先列出相关内容，不直接重写所有章节。

正式设定由你确认，见[维护设定集](story-bible.md)。不同作品即使使用同一角色原型，也不自动共用全部设定。

## 卡住时缩小问题

如果“整本故事怎么写”太难判断，可以改问：“这一章结束时，女儿应该更信任父亲，还是更怀疑他？各试一个走向。”

回来比较后果，挑一个继续；也可以都不采用。你要保留的是能帮助继续写作的决定，而不是一份看起来很完整、实际不愿意照着写的大纲。

需要返工时，固定原方案和意见，见[提出意见与局部返工](feedback.md)。
