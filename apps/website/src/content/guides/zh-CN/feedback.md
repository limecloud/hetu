# 提出意见与局部返工

## 从当前需要开始

指出具体改动和需保留内容。公开意见绑定所读版本，换会话后沿原稿与意见继续，不把每次反馈变成新的无关任务。

“这句不像她会说的”和“这段停得太短”都是有价值的判断。把意见指向确切成果和位置，让 Agent 知道保留什么、调整什么，再沿同一个任务继续。

你可以在任何位置提意见，不必只从助手标出的疑点里选择。

## 先看完整成果，再选要改的地方

小说先读连贯章节，剧本先看行动与对白，视频先带声音连续观看。摘要和标记帮助定位，判断仍要回到上下文。

确认你看的版本。新版已经到达时，旧意见仍属于旧稿；先比较，避免让助手对着错误位置修改。

## 一条意见说清四件事

可以用“位置、问题、保留、改动范围”组织判断：

> 第一集门口这场，女儿直接解释旧钟的能力，悬念消失得太早。保留她伸手又收回的动作，只重写解释能力的两句对白，不改其他场次。

不必使用专业术语。你也可以说“我不知道怎么改，但这里不该这么快和好”，请 Agent 先提出两种方案供比较。

| 成果 | 位置怎么说明 | 怎样核对新版 |
| --- | --- | --- |
| 文字 | 章节、场次、选中文字 | 看差异，再读前后段落 |
| 图片 | 对应图片与局部区域 | 放大局部，再看人物与整体 |
| 视频 | 当前版本的时间区间 | 连续播放前后片段并听声音 |

## 保存意见，再接续原任务

Mac 任务中选择这次要反馈的成果，填写并保存修改意见。复制继续提示词回到原 Agent 对话，让它先读意见和固定版本，再返工。

支持继续消息的宿主按实际能力处理请求；没有这条能力时，复制提示词同样可以继续。无需为同一轮返工重新建作品、重复导入或重新配置连接。

保存意见、助手收到请求和新成果返回，是三种状态。没有看到新稿时，先查原任务的实际结果，不把“收到”当成“改完”。

## 新版回来，比较是否回应了意见

先看指定问题是否解决，再检查保留内容有没有被动过。只要求两句对白，就不应顺带改变人物身世或重写结尾。

有多份候选时分别比较，可以只采用一部分，也可以全部保留为参考。不要为了让任务显示完成，接受不合适的版本。

想亲自调整时，回到作者稿继续写。参考稿的审核、正文采纳与定稿分别处理，见[检查与草稿审核](review.md)。

## 视频返工保留前后衔接

例如：“第八秒开始的停顿多留半拍，先听见屋内脚步，再切门口。其他片段保持。”让 Agent 固定区间并说明会影响的声音、字幕与后续时间位置。

新版不只看改动的一帧，还要核对切入切出、对白、字幕与整段节奏。片段长度变化后，旧版时间坐标仍指向旧版。

剧情原因回到剧本，身份问题回到素材，节奏和混音回到剪辑。预演和实际成片各自验收，见[从预演到成片](video.md)。

结果未知时先查询原操作；已付费生成不换任务碰运气。恢复说明见[常见问题与恢复](troubleshooting.md)。
