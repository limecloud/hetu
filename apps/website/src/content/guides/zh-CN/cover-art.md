# 设计与选用封面

封面可以从一句明确的感觉开始。让外部 Agent 整理方向并准备候选，在河图放大比较，选择最像这本书的一张。

生成、收到图片与选用为当前封面是不同步骤。收到候选不会自动替换已有封面。

## 先说故事气质和用途

> 为这本小镇悬疑小说准备封面方向。女儿站在夜里的修表铺门口，透出一点暖光；重点是等待和疑问，不要恐怖怪物。先给两种构图建议，人物不要太大，书名留出清晰位置。生成前说明工具与费用。

告诉 Agent 书名、笔名、题材与使用场景。可以带上获准使用的简介和人物资料，不必把整部小说都交给图片服务。

如果还没决定书名，先比较无文字底图。标题发生变化后，旧图中的文字不会自己更新。

## 生成前核对材料与本次预算

Agent 应说明会交给哪个工具、发送哪些文字或参考图、准备多少候选，以及费用上限。你在当前对话中确认明确范围，再继续执行。

使用河图可选模型服务时，核对当前模型实际支持什么。文字与图片分别选择，外部工具的可用能力也以当前状态为准。见[模型服务与费用](model-services.md)。

结果未知时查询原请求，不换任务重复付费。没有可用图片工具时，先保存设计方案和具体缺口。

## 在河图比较候选

打开作品资料中的封面区域，放大看原图。先看整体气质，再看人物、细节和文字。

- 缩成书库里的大小，书名是否仍然可读？
- 人物是否对应这本书，而不是另一张泛用海报？
- 手、钟表、门框等细节有没有明显问题？
- 图中文字有无错字，是否需要换成无字底图再排版？

可以说：“保留第二张的光线，门口人物缩小，去掉图中错误文字，别改变修表铺的空间。”让 Agent 沿原任务保留参考继续返工。

## 选用当前封面

确定后，在对应候选使用“用作封面”或当前版本提供的选用入口。回到作品资料和创作库核对实际显示。

新候选不等于新的正式封面。选用会保留版本，封面历史可以查看旧图与当时排版。需要恢复旧设计时，选择那份历史建立当前版本，不覆盖历史记录。

两个窗口同时修改封面时，先刷新并比较已经选用的结果，不能让旧界面覆盖另一处的新决定。

## 筹备图片与本地图片

建书筹备阶段已有的封面，可以在作品中核对来源并转入。转入保留原请求与图片，不再生成一次；是否正式选用再由你决定。

本地已有图片时，使用封面管理的本地导入入口，先检查原图和裁切。不要为了导入一张现有图片发起新的付费任务。

最后核对图片权利和交付范围。能够预览一张图，不等于能够公开使用或把原图转交别人。

相关操作见[图片与插图](illustrations.md)、[提出意见与局部返工](feedback.md)。
