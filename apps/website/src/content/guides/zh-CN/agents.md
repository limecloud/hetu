# 使用外部 Agent

手工建书和创作不需要 Agent。需要辅助时，再选择外部客户端和授权范围。

## 当前本机接入

在 Mac 客户端的“设置 → AI 协作”、新建作品窗口，或“作品资料”中的封面旁，都可以打开同一个 Skills 安装窗口。选择 Codex 或 WorkBuddy，再选择“河图洛书·通用”或“河图洛书·军事”套件。每个题材套件都包含接入、建书、资料、大纲、封面、起草、改稿与短剧方法。

Codex 安装使用本机官方 CLI 登记并启用完整插件，完成后核对版本与包内容。WorkBuddy 安装将完整方法包放入其个人 Skills 目录，军事方法使用独立名称。安装遇到已有不同内容时会提示冲突，保留原文件。两个套件都不内置模型或生成服务。

作品资料中的客户端关联按作品保存；设置中的默认客户端只用于之后创建的作品。安装状态、Skills 版本、插件启用配置、会话加载和 MCP 连接分别展示。找到文件或完成安装不等于当前会话已加载，也不等于作品已授权；安装后按宿主要求开启新会话并核对连接。

源码包含独立 stdio MCP Server，启动时绑定作者选定的单部作品工作区。宿主在本机启动它，不通过官网连接作品；构建与启动命令见 GitHub 仓库。

当前工具可读取设定、提交参考稿、整理剧情与短剧骨架、执行诊断，以及处理作者在本机批准的固定 Git 快照。最新列表见[Agent 接入](/integrations/)，不把安装插件等同于授权整盘或 Git 全权限。

## 交接任务

接入设计采用选择客户端、安装扩展、复制 Prompt 和回传候选的路径。专用 Skills、Apps 和按需本地页面分别按实际宿主验收，不展示内置聊天或虚构生成进度。

可复制这样的任务说明到自己选择的客户端：

> 阅读选定的第一章和已确认设定，为客栈片段提交一份参考稿。保留角色与时间关系，新增细节单独说明，不修改设定、不覆盖正文、不代我定稿。

模型和生成服务由外部客户端提供。官网原型不调用模型，也不复制私人资料或密钥。

## 收到结果与恢复

核对输入修订、候选内容和来源；通过审核后仍由作者选择采纳范围，并独立决定定稿。

未收到写操作回执时先查原操作，不假定失败后重复提交。停止局部交互不自动删除作品、撤销已完成的作者决定或清除历史。

继续阅读[检查与草稿审核](review.md)。
