# 使用外部Agent

## 从当前需要开始

外部对话和可选内嵌终端都可操作同一作品。先判断目标需要哪些能力；查阅只读，临时构思可直接回答，保存后以实际回读判断完成。

你有一个喜欢的开场，却还拿不准怎么展开；写完一场争执，又觉得人物把话说得太满。这时，可以让平时顺手的Agent给几个方案，再由你挑、改、或者全部放弃。

外部Agent负责理解目标、整理资料、创作与操作。河图负责保存作品、来源和版本，供你审阅、比较与定稿，需要时亲自编辑。**品味与判断始终在你这里。**

首次接入，可以在[创作工程工作流](/workflow/#connect)选择 Codex、Claude Code、Cursor 或 WorkBuddy，复制对应的安装提示词，交给所选 Agent 核对当前版本能力并引导安装，分别验证安装、会话加载与连接。该页也能完整查看小说、剧本和短视频从创作到返工、交付的过程。

## 第一次，先做一个能判断好坏的小任务

例如，把一段争执交给Agent，说明：

> 保留两个人物的立场，不增加人物，不提前揭开秘密。请试两版对白：一版针锋相对，一版表面客气。先作为参考，不替换我的原稿。

看完后，你就能具体地说“第二版更接近，但最后一句太解释了”。这比一开始就要求“写完一本好小说”，更容易找到自己的判断。

只想试一次书名与简介，可以跟着[用Codex构思一本新书](codex-first-task.md)，让助手准备资料，你来审阅。

## 选自己的助手，让每本书有合适的方法

Mac“设置 → AI协作”可以选择新作品默认客户端。已有作品在“作品资料”里单独选择。一本用Codex，另一本用WorkBuddy，也可以分别保存；改默认值不会改掉旧作品。

需要题材方法时，点击“安装Skills套件”。例如末世故事关注资源与公共规则，军事故事需要核对组织和行动条件。按这本书选一套，见[选择与安装Skills](skills.md)。

## 把话说清，也把要交出的材料看一遍

当前页面提供与作品、章节或资料对应的AI操作提示。看清目标、原文与资料范围，把提示词交给自己的Agent；也可以直接在已接入的对话中说出目标，让它准备任务。

复制提示词时，由你回到外部助手发送。Agent通过工具保存方案、参考稿和操作结果，再回读确认；你在河图中审阅，不需要重复填写同样的资料。普通对话回答仍不能当成已经写入作品的回执。

外部账号、登录与费用由所选客户端处理。一次任务可以包含整理、候选、自检和返工，正常步骤不必反复选择；设定变更、正式资料采用、素材选用与定稿仍由作者确认。

## 三个一等入口，各自帮什么忙？

### MCP：让Agent找到这次的作品与任务

<span id="mcp"></span>

Agent在许可范围内建书、整理卷章和资料、交回候选、准备交付，再读取你的意见。你不用每次从一堆文件里重新拼上下文，也不必让它逐个寻找界面按钮。

在“设置 → AI协作”的“安装到 Codex Desktop”中，分别点击“安装 MCP App”和“安装 Skills 套件”。确认当前安装目标后，河图完成安装，再按提示刷新或重启Codex。Skills只安装当前选择的题材套件；安装登记和当前会话加载分别核对。

连接由外部客户端管理，不要求河图窗口常开。支持MCP Apps的宿主可以在对话内打开与桌面相同的工作台。点击本机登记作品直接阅读、编辑，查看资料与任务、预览图片和音视频、比较候选并保存意见，无需逐作品接入授权。需要返工时，使用“让AI处理”交回当前固定稿件；消息草稿、消息受理与实际返稿分别显示。采纳、定稿与费用继续核对确切结果。其他宿主继续用工具结果与河图工作台。

Agent的稳定机器连接配置一次，后续用具体对象和任务定位这次获准处理的材料。Agent不能因连接可用而读取整个创作库，小说与关联剧本、视频也分别核验范围；同一个目录或来源链接不自动共享访问权。撤权后的旧任务不能因重新授权而自动恢复。

### CLI：操作中断，也能接着找回结果

<span id="cli"></span>

Agent先查当前作品真正支持什么，再执行受限操作。如果中途结果不明，沿原操作查询，避免又创建一份任务或候选。

长任务可以保留进度、已交回的稿件、未读材料和下一步。你可以直接说：“继续上次的任务，先读已有稿件和意见，从没完成的地方接着做。”换会话后沿同一任务继续，旧稿仍可比较；进度说明不代表你已采用或定稿。

这条入口与MCP使用同一内核、权限和版本。普通作者继续使用创作工作台即可；高级接入说明见 [GitHub 仓库](https://github.com/limecloud/hetu#配置与接入)。

### Skills：让方法贴近你正在写的故事

<span id="skills"></span>

Skills提供题材方法与任务步骤，例如怎么整理大纲、交回改稿参考、准备封面或改编材料。它给Agent方法，不扩大对作品的权限。

客户端接入包把方法与连接组合分发，与安装在河图里的创作插件分开。装好文件、当前会话加载、连接可用、实际任务完成，是几件不同的事；软件按真实状态显示，尚未验证的部分不算成功。

## 为什么河图不再做一个通用Agent？

通用Agent要长期打磨推理、上下文、工具调度、权限和恢复。Codex、Claude Code、WorkBuddy等产品已经在专注这些能力。我们更想把作品组织、来源、版本和作者决定做好，让你能带着熟悉的工具继续创作。

Cursor、Grok Build、DeepSeek Harness、豆包等产品也在发展各自的生态。具体能用哪些扩展，要按客户端版本核对，不能因为支持一种入口就推断全量兼容。

## 参考稿回来了，你仍可以说“不”

先看人物、时间和设定，再看句子是否流畅。Agent新增的情节，不会因为写得自然就自动成为事实。

在审核工作台里，先读、再比较。只喜欢一小段，就采用一小段；还不满意，就保留原稿。正文采纳与定稿分别确认，见[检查与草稿审核](review.md)。

需要返工时，在原任务选择具体成果、保存修改意见，再复制继续提示词交给助手。支持继续消息的候选面板会按宿主能力处理明确请求；保存了意见、消息被受理、返回了新稿，分别看实际状态。没有新成果时，不把“已收到”当成“已完成”。


## 可选文字与图片模型

在河图“设置 → 模型服务”连接账号。网页确认前，核对河图和网站显示的验证码相同；完成后返回河图，分别选择文字与图片默认模型。账号与费用可从网站的“账号与费用”进入。

让 Agent 使用河图模型服务时，它先准备计划，在当前对话中说明将外发的内容、用途和费用上限。你明确批准范围后，由工具登记授权，在范围内继续执行；到达上限或改变范围时再决定，无需逐张回客户端重复批准。结果作为参考候选交回，由你决定采用。

余额不足时在当前对话查看充值提示，支付前自行核对金额。等待超时请让 Agent 查询原计划，避免重复生成。未连接不影响本地写作。视频与声音由所选外部工具制作，见[从预演到成片](video.md)。

具体生成准备与账户说明见[模型服务与费用](model-services.md)，操作边界见[隐私与授权范围](privacy-and-permissions.md)。遇到问题时，沿[常见问题与恢复](troubleshooting.md)核对原任务。

## 创作插件如何协作？

河图的关系图、时间线等工具安装在河图，不为每个工具额外安装Codex插件。Agent经原有机器连接重新发现当前已装、启用且获权的能力，按确切作品调用并回读。安装与作品授权分开，正文采纳与定稿另行决定。见[使用创作插件](plugins.md)。
