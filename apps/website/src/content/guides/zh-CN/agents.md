# 使用外部 Agent

你可以完全手工创作。需要辅助时，再选择 Codex、WorkBuddy 等外部 Agent，并决定它能看到哪些材料、完成什么任务。

## 河图和 Agent 各做什么

河图组织设定、正文、审核和交付。外部 Agent 负责你请求的草稿或改写；模型与服务由你选择。Agent 提交的内容仍然是草稿，最终是否采用由作者决定。

当前网页原型不包含 MCP 连接，不会调用模型或生成服务；这里介绍协作方法，不提供尚未发布的安装命令或连接配置。

## 先限定任务和范围

可以把任务写成：

> 阅读我选定的第一章与已确认人物设定，为客栈段落提交一份改编草稿。保留现有角色与时间关系；新增细节单独列为建议，不修改设定，不代我定稿。

给出要处理的章节、允许变化的范围、交稿格式以及需要说明的疑问。避免直接授予整盘读写权限，或把私人资料和密钥混进创作材料。

## 收到草稿后核对

先确认来源与输入版本，再查看新增或遗漏情节、人物行为和设定关系。要求修改时，给出具体批注，而不是只让 Agent“再优化一下”。

设定锁定和人工审核不能替代操作系统权限。拥有相同文件访问权限的其他程序仍可能直接修改文件，因此只授予任务所需的访问范围。

## 连接异常时先查状态

未收到成功回执时，不要假定提交失败后立即重复操作。先检查工作区是否已经收到草稿或快照，确认原操作状态再决定下一步，避免重复草稿或版本。
