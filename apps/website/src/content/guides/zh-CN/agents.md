# 使用外部 Agent

Codex、Claude Code、WorkBuddy 等外部 Agent 是你另外使用的创作助手。河图洛书负责放好作品、资料和正文；助手帮你讨论方向、想方案、写参考稿，最后用不用由你决定。

第一次尝试，直接看[用 Codex 构思一本新书](codex-first-task.md)。不使用助手也可以自己建书、写作和整理设定。

## 1. 选自己平时使用的助手

在 Mac 的“设置 → AI 协作”中，选择新作品默认使用的客户端。已经建好的书，在“作品资料”里单独选择。

比如一本军事小说用 Codex，另一本都市小说用 WorkBuddy，可以分别设置。更改默认值，不会改掉已有作品的选择。

## 2. 一次说清楚一件事

准备交给助手之前，先想清楚这次需要什么：

- 想书名：说清题材、读者、主角和故事气质。
- 想大纲：说清主角目标、核心冲突，以及已经确定的结局或转折。
- 改片段：提供要改的原文，指出保留什么、重点改什么。
- 做封面：说清书名、笔名、题材、主要意象和不想出现的元素。

例如：“请帮我修改这段争执，保留两个人物的立场，让对白更有张力，不增加新人物，也不要提前揭开凶手身份。”

## 3. 先看说明，再交给助手

在支持的任务入口，点击“预览提示词与资料”，读一遍准备交出的内容。确认后保存任务，再点击“复制任务提示词”，粘到自己的外部 Agent 对话中。

只交出这次需要的资料。河图洛书不会替你发送消息，也不会在软件里替你和模型聊天。账号、登录与服务费用在你选择的外部客户端中处理。

手工交接时，让助手直接在对话中返回建议；你读完后再复制需要的内容回到河图洛书。对话里的回答不会自动进入作品。

## 4. 让方法贴合这本书

在“安装 Skills 套件”中，为军事、末世、言情等故事选择对应方法。每套已经包含共同的创作方法，只装这本书需要的一套。

不知道选哪套时，可以复制选型请求给自己的 Agent，读它的推荐理由后再决定。详细操作见[选择与安装 Skills](skills.md)。

## 5. 把决定留给自己

收到建议后，先核对人物、时间、设定和自己的原意。不要因为助手写得流畅，就把它新增的情节当成已经确定的事实。

如果参考稿已经显示在河图洛书的审核工作台里，先审核，再选要采纳的部分。审核通过不会自动改正文；采纳后还要由你另外确认定稿。

想改已经继续写过的章节，先比较当前正文，再决定是否用旧建议。暂时不满意时，可以保留原稿，让助手再给一个方向。

继续阅读[检查与草稿审核](review.md)。开发者的高级接入与源码说明见[Mac 源码版（开发者）](download-and-install.md)。
