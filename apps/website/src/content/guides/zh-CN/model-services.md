# 模型服务与费用

## 从当前需要开始

外部Agent已有合适工具时可以直接使用它们。河图模型服务按实际任务需要选用；登录不等于生成，保存不等于认可，费用沿已批准范围执行。

河图可以为外部 Agent 提供可选的文字与图片模型能力。Agent 准备固定计划，你在对话中了解外发材料、用途和本次预算，获准后执行，结果回到作品里供审阅。

本地阅读、编辑和保存不以连接模型服务为前提。外部 Agent 客户端的账号与费用，也需要与具体生成服务分开看。

## 选择文字与图片的使用方式

| 方式 | 在哪里配置 | 账号与费用 |
| --- | --- | --- |
| 河图可选模型服务 | “设置 → 模型服务”连接账号 | 复用 Lime Cloud 账号与额度 |
| 自己的兼容渠道 | 本机模型设置中的地址、密钥与模型 | 按该服务提供方的账户与计费 |
| Agent 的其他工具 | 所选 Agent 及工具的实际配置 | 按对应工具的能力与费用 |

文字和图片分别核对可用模型。河图的文字与图片目录不代表支持视频；视频、声音和剪辑由 Agent 使用可用的外部工具处理，见[从预演到成片](video.md)。

## 连接账号时核对当前请求

在河图“设置 → 模型服务”发起连接。网页确认前，核对网站与客户端显示的验证码相同，再完成连接并返回河图。

随后分别选择文字与图片默认模型。网站的“账号与费用”进入对应账户入口；付款和订阅变更前，在托管页面核对实际商品、金额与支付方式。

跳转回来不等于支付成功。刷新账户状态，按实际余额或额度继续；Agent 不代替你执行支付。

## 生成前看清固定计划

让 Agent 用普通语言说明这次要做什么：

> 先用第一章和已经确认的人物资料准备两版对白。告诉我会发给哪个模型、发送哪些内容和费用上限。先不发送整书，也不生成图片。

核对输入材料、模型、用途、候选数量与预算。图片还要看参考职责和画幅；涉及外部素材时，确认允许交给该服务处理。

只想讨论方案时，直接说明“先规划，不执行付费生成”。计划准备完成与已经调用模型分开判断。

## 在获准范围内继续

明确批准范围与费用后，Agent 通过工具登记授权，在范围内继续，不要求你逐张回客户端重复批准。

增加候选、换模型、外发新材料或达到上限时，先说明变化再由你决定。安装了一个 Skill 或连接了账户，并不等于允许无限调用。

候选回到作品后，仍由你决定采用与定稿。调用完成不等于创作通过。

## 余额不足与结果未知

余额不足时，先看当前对话的额度或充值提示，核对账户与金额。充值完成后查原计划状态，不重新创建相同任务。

等待超时也先查询原计划和提供方任务。有些服务仍在处理，另起一单可能重复付费。取消本地跟踪不代表外部任务已取消或已经退款。

## 自定义渠道的密钥

密钥只进入本机私密存储，不写进小说、剧本、素材说明或给 Agent 的回读。不要把密钥放进提示词、截图或问题反馈。

自定义渠道由本机执行，按该渠道的账号与条款使用，不消耗 Lime Cloud 平台额度。详情和恢复见[隐私与授权范围](privacy-and-permissions.md)、[常见问题与恢复](troubleshooting.md)。
