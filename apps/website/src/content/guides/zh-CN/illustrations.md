# 图片与插图

## 从当前需要开始

只有需要比较、使用或交付的图片才整理为作品素材。先讨论方向也可以，不因一次构思生成整套图组。

人物形象、服装参考、场景图和情节插图服务不同的任务。先说清用途，让 Agent 固定对象与参考，再回到河图比较实际图片。

你可以只准备一张重要人物图，也可以为某场戏整理一组素材，不需要先做完整美术资料库。

## 从一个具体用途开始

> 为修表师准备一张单人正面形象，沿用当前人物资料和已选服装。另准备一张她站在店门外的情节插图，关联第一章的门口段落。两张分开记录用途，先给方案，生成前核对费用。

人物图回答“她是谁”，插图回答“这一刻发生什么”。人物图组只对应一个人物，多人画面作为情节插图保留，不拿来替代单人身份图。

封面有自己的选用与历史，见[设计与选用封面](cover-art.md)。

## 固定参考与必须保持的地方

让 Agent 列出本次使用的人物、服装、场景和道具版本。对照参考图时，说明每张图的职责：哪张固定面部，哪张说明服装，哪张帮助构图。

参考资料之间有冲突，先由你决定。不要让模型自行混合两套年龄、两件外套，或把参考画面的临时道具变成正式设定。

需要侧面、背面或表情组时，按用途补足，保留同一人物和服装的一致性。具体整理见[人物、场景与道具](characters-and-scenes.md)。

## 在对应对象和统一图库查看

人物相关图片在人物处查看，场景图归对应地点；剧情插图保留所指章节、场次或文字位置。统一图库帮助你找到同一份成果，不需要另存一组同名副本。

预览保持原比例，可以放大核对。竖图和横图各有构图，缩略图裁切不应成为判断实际原图的唯一依据。

看到候选时先确认它属于哪次任务、哪一版参考。候选已收到，仍不表示已经被选用。

## 把修改意见落到具体位置

| 看见的问题 | 可以怎样表达 |
| --- | --- |
| 人物变了 | “沿用已选正面图的脸型和发型，不换人物。” |
| 服装不一致 | “只改左袖破损位置，外套颜色与材质保持。” |
| 空间关系不对 | “门在人物身后，钟仍在右侧墙上，保持原构图。” |
| 插图提前泄露情节 | “拿掉背后出现的父亲，保留门缝的光。” |

意见指向当前图片或具体区域。新版回来后重新比较，旧版框选的位置只属于旧图，不直接挪到新图。

局部修改仍要看整体：一只手修好后，人物身份、比例与原有动作有没有改变？

## 选用与交付前再核对

保留旧候选、来源和意见。选用新素材前看清影响范围，不自动替换已在其他场次使用的版本。

要交给协作者时，核对原件、用途、授权和必要参考是否齐全。只有预览图或过期下载链接，不能代替完整素材交付。
