# 检查与草稿审核

## 从当前需要开始

日常读取和参考稿保存无需逐步审核。涉及采用自己的正文或确定版本时，看清具体变化再决定；已经在对话作出的确切选择不必回软件重复确认。

Agent把一段争执写得很顺，你却觉得人物说得太直白；一整段都不想用，偏偏最后半句很合意。这样的犹豫很正常。参考稿值得看，不意味着它已经是你的正文。

在河图里，审核参考稿、采纳到写作稿、确认定稿，是三次不同的决定。你可以走到任何一步，也可以停下来自己重写。

## 先分清，这次想作什么决定

| 你的判断 | 可以怎么做 |
| --- | --- |
| 方向对，但人物太直白 | 指明保留和修改的地方，沿原任务返工 |
| 只有半句合意 | 只采用那半句，其他文字自己写 |
| 自己已经改了原稿 | 先比较当前稿，重新核对替换范围 |
| 想先交给编辑，还想继续写 | 独立定稿留住这一版，之后继续编辑新稿 |

## 先问：这份建议，依据的是哪一版？

在当前作品的参考稿审核中，先读候选的固定来源与原文，再对照当前写作稿。你可能已经改过人物身份，旧建议需要按它实际依据的版本重新判断。

[桌面界面预览](/#prototype)展示当前 Electron 审核页，使用原创示例资料。官网的意见比较使用预置变化，不分析或保存你的作品。

时间线提示有时只是信息不够，不等于故事已经写错。人物在说谎、回忆可能有偏差，都需要创作者判断语境。

展开“交付与检查”，可以分别查看已提交候选、专业检查与正文采纳。需要时选择一份专业报告，核对它检查的是哪一版候选、还有哪些未检查或不确定项。切换历史批次时，交付声明也跟随原批次；报告写着通过，仍需结合原文判断。

## 不满意，就把意见说到具体的地方

较长的参考稿先显示标题，点击“读取参考稿”后按页阅读。翻页会保留已选方案和未保存意见；读取中断时可从原页重试。选中文字提出意见时，位置始终指向这一版原稿。

尚未提交的稿件在“工作稿”中查看。选择工作稿并读取，可以切换已保存的历史修订，对整份稿件或选中文字提意见。新版不会替换旧版意见的原文；工作稿提交为候选后，再比较和采用。

在“参考稿审核”里选择要讨论的候选，填写具体意见，再点击“按此修改”。只想记录偏好时，使用“保存选择与意见”。例如：

> 保留他试探对方的目的。不要直接承认认识来信，把解释改成一个停顿和一句反问。

针对一句话提意见时，选择候选或来源原文中的文字，点击“对此处提意见”，填写要求后保存位置意见。原句和版本随意见保留，翻页或出现新版后仍能核对。来源上的意见用于说明如何使用依据，不会修改来源原文。

图片也可以指明部位：打开固定图片，点击“标记区域”并框出需要调整的部分，再保存具体意见。任务面板中先点击“对此区域提意见”。区域随原图版本保留，新图片不会继承旧标记；移除区域后可改为整图意见。保存结果待确认时，查询原保存，不必再提交一次。

展开“全部意见”可以回看早先的要求，并按“待返稿”“已有返稿”或“已记录偏好”筛选。图片详情只显示当前固定图片的意见，可点击“查看原位置”核对标记。已有返稿表示收到了引用该意见的成果，仍需你判断是否符合要求。

图片意见提示已有更新时，点击“重新读取当前批次”。当前填写的意见和标记会保留，读取成功后再保存。重开图片也可以从历史意见继续：选择所需意见，放入当前草稿，或复制继续提示词；这一步不会自动发送。

保存后使用当前任务的接续入口，回到所选 Agent 对话。原任务、成果与意见一同保留，不必为了返工重新发起任务。

意见保存成功，不等于 Agent 已经开始修改。刷新查看实际回传的参考稿，再核对它是否回应了意见。可继续修改的工作稿与固定提交的候选分别保存。

## 只喜欢一段，就只采用一段

1. 先保存第一章的修改。
2. 在参考稿中选择需要采用的片段，准备采纳。
3. 对照当前片段与参考片段，确认替换范围。
4. 确认采纳，再回到正文通读一次。

只替换明确选择的范围。当前稿或选区发生变化时，重新核对；不要把旧版位置直接套到新稿。

采纳之后，你得到的仍是可以继续编辑的写作稿。词句不顺手，可以接着改；后悔了，也有版本可查。

## 定稿，留给你真正愿意确认的那一版

回到正文，核对已保存修订、设定与来源，再确认定稿。手工写出的章节同样可以定稿，不必先找一份AI参考稿走审核。

以后继续修改，旧定稿保留。新正文不会自动继承旧版的审核与定稿决定。

想进一步理解这种分工，可以读[AI可以多给一稿，但不能替你说那句话](/blog/authors-at-the-center/)。准备交稿时，再看[文件格式与交稿](formats-and-delivery.md)。
