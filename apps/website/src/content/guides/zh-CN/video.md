# 从预演到成片

## 从当前需要开始

先确定当前需要验证的节奏、动作或声音，用足以回答问题的材料继续。已有片段可直接使用，不要求每镜先做白模或生成全部素材。

可以从一个创意、一份剧本、已有分镜或现成片段开始视频。视频独立保存，需要时再关联剧本或小说，不必补建空的上游作品。

## 先说目标和已有材料

向外部 Agent 说明你要看什么，例如：

> 我已有门口对峙的三个片段。先帮我核对人物造型与动作衔接，做一个带临时声音的剪辑预演。先听见屋内脚步，再切到门口。先不付费生成新片段。

Agent 整理可用材料、来源、缺项和制作方案，使用你选择的工具处理分镜、预演、视频、声音与剪辑，回传成果和可继续编辑的工程。你回来观看，不必先学三维布景、节点或多轨剪辑。

## 先选能回答问题的预演

| 想判断什么 | 先看什么 |
| --- | --- |
| 人物动机、因果与对白 | 完整剧本与必要的原著对照 |
| 揭示时机、切镜、停顿与声音进入 | 动态分镜或带临时声音的剪辑 |
| 走位、视线、遮挡与复杂运镜 | 按需制作的白模预演 |
| 身份、表演、口型与最终质感 | 有代表性的真实生成片段 |

普通对白不必每镜先做白模。白模中的代理颜色和几何帮助看懂空间，不是最终人物与场景要求；预演顺利也不能保证模型严格复现。

## 真实生成前，明确内容与费用范围

让 Agent 说明本次使用的模型、模式、人物和场景参考、画幅、时长、声音以及费用上限。原著改编权、材料交给外部服务的权限和素材随包交付的权限分别核对。

在当前 Agent 对话中批准明确范围后，范围内可以继续；超出再决定。结果未知时沿原任务查询，保留已经付费的记录，不直接换一个新任务重复生成。

河图的可选文字与图片模型服务使用 Lime Cloud 账号和额度；视频与声音使用 Agent 选择的外部工具，不能据此认为同一模型目录支持视频。

## 连续观看，再指出要改哪里

先看完整预演或剪辑，保留前后文与声音。也可以随时暂停，沿人物出场、本次改动或具体疑点核对，不只看 Agent 挑出的几帧。

意见可以很具体：“这里先听见脚步再切门口”“这句字幕晚了”“衣服沿用上一场”。让 Agent 固定所指版本和区间，再修改对应工程。新版回来时比较前后结果，旧意见仍属于旧版。

剧情问题回到剧本，空间问题先修预演，造型问题核对素材，字幕和混音先改对应音轨。局部返工保留其余有效片段、旧版和费用记录。

## 成片与工程都要实际检查

确认成片前看完整画面，听对白、配乐与音效，核对字幕、时长和连续性。文件可下载或几张抽帧不能代替看片；完整播放也不能代替你的创作判断。

预演认可、素材选用、片段选用、成片确认和工程交付分别决定。交付所选视频、字幕、音轨与可编辑工程，检查源素材、字体等依赖和相对路径，在接收方环境实际打开。不要只交一个缺素材的工程文件。

具体交付范围见[文件格式与交稿](formats-and-delivery.md)。发布、投放与发布后的运营另行安排，不由成片确认自动执行。
