# 快速入门

## 从当前需要开始

先判断这次是否需要保存。临时想法可以在Agent中直接讨论；只查已有内容就只读。需要跨会话接续、比较或交付时，再选择作品和必要材料。

从小说、剧本或视频开始。向你熟悉的外部 Agent 说出目标，让它准备方案与成果；回来阅读或观看，提意见，再沿原任务继续。

## 先向 Agent 说什么

- **小说：**“接着写修表师回乡这一章。保留父亲失踪的悬念，先给参考稿，不替换我的正文。”回来读完整章节、比较改动，见[章节与写作](writing.md)。
- **剧本：**“开发一个原创短剧，女主从旧钟里听见明天的求救声。先给第一集完整剧本，不创建小说。”回来读行动与对白，见[剧本与分集审阅](screenplays.md)。
- **视频：**“用已有门口对峙片段做带临时声音的预演，先听脚步再切镜，先不付费生成。”回来连续观看与提区间意见，见[从预演到成片](video.md)。

Agent 整理资料和保存方案，你确认必要范围与创作取舍，无需重复填表。已有作品沿原对象继续；新作品各自独立，不必先创建空小说。

意见可以是“这里只改最后一句”或“这一段多停一下”。保留所指版本与任务，新版回来再比较。采纳文字、认可预演与确认成片分别决定。

## 先看看工作台

[查看桌面界面预览](/#prototype)，可切换创作库、文稿、剧本与参考稿审核，并放大查看。以下图片取自当前 Electron 客户端，使用原创示例资料。

## 1. 从创作库进入作品

安装并打开河图后，在“创作库”查看小说、剧本与视频。让已接入的 Agent 创建作品，或用“打开作品”进入已有项目。三类作品各自独立，不必先创建小说。

![当前 Electron 创作库，按类型查看独立作品](/images/guides/electron-library.webp)

## 2. 阅读完整文稿，再决定怎么改

进入小说后，从卷章目录打开文稿，连贯阅读。想亲自调整时直接编辑，点击“保存修订”。需要 Agent 继续时，使用“让 AI 处理”交接当前对象和目标。

![当前 Electron 小说工作台，目录与文稿并列显示](/images/guides/electron-novel.webp)

例如：“只改最后一段。保留船夫认出了来人的暗示，不解释那把黑伞属于谁。”意见沿固定版本继续，不把新版自动覆盖到正文。

## 3. 比较参考稿，把意见留在成果旁

打开“参考稿审核”，读完整候选，比较不同写法。选择需要讨论的方案，写下具体意见，再点击“保存选择与意见”，让 Agent 沿原任务返工。

![当前 Electron 参考稿审核，比较两个候选并填写意见](/images/guides/electron-review.webp)

收到候选、选择参考、采纳文字与定稿是不同决定。先审阅确切变化，再决定留下哪些内容。

## 4. 剧本按场次阅读，视频回来连续观看

进入剧本后，用分集目录阅读场次、行动与对白。向 Agent 提意见时指出分集与具体场景，不必先转成小说。

![当前 Electron 剧本工作台，按分集阅读行动与对白](/images/guides/electron-script.webp)

视频项目围绕分镜、预演、片段与成片推进。说出“铃声先响，停一秒再回头”，回来观看对应版本，确认节奏后再继续。具体见[从预演到成片](video.md)。

书名、简介和大纲可以边讨论边推敲，由 Agent 整理并保存；不必第一天就填完表单。新建作品可从[用 Codex 构思一本新书](codex-first-task.md)开始。

## 带着自己的问题，继续下一步

- 已有小说、原创剧本、授权改编或旧稿：先看[选择你的创作路径](creative-paths.md)。
- 人物与伏笔越写越多：看[维护设定集](story-bible.md)。
- 想把一段文字试成一场戏：看[从小说到短剧](adaptation.md)。
- 想直接写剧本或做视频：看[剧本与分集审阅](screenplays.md)和[从预演到成片](video.md)。
- 已经在用外部助手：看[选择与安装Skills](skills.md)。

自己的作品使用桌面客户端，见[下载与安装](install.md)。
