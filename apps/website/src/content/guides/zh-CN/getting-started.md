# 快速入门

从书库开始，进入一部作品的写作台。官网演示与本机客户端分别使用自己的数据。

## 在首页体验

进入[首页工作台](/#prototype)。原型就嵌在首页，所有操作都在当前页面内完成。点击《雾川纪》的封面进入作品，使用“返回书库”切换作品。

1. 在书库搜索书名、按状态筛选，或切换封面与列表布局。
2. 点击“新建作品”，填写资料；没有书名也可以保存筹备。
3. 打开《雾川纪》，编辑第一章并点击“保存正文”。切换章节再返回，修改仍在当前页面中。
4. 在“审核工作台”填写返工意见，或核对证据后“通过审核”。这不会覆盖正文或创建定稿。
5. 点击“局部采纳到写作稿”，核对预览并确认；再到正文使用“作者定稿”独立确认当前修订。

```mermaid
flowchart LR
    A[书库与作品] --> B[正文与设定]
    B --> C[核对参考稿]
    C --> D[采纳到写作稿]
    D --> E[作者独立定稿]
```

## 演示与本机软件

演示只保留当前页面内状态，刷新或关闭后重置，不读写文件、不调用模型、不连接 MCP 或 Git。不要将唯一作品放进演示。

当前 macOS 源码提供本机书库、卷章、编辑、设定、剧情、短剧、审核与版本等实现。可按 GitHub 仓库说明构建开发包；正式分发签名、公证和 Windows 独立验收分别管理。
