# 快速入门

用演示作品《雾川纪》，认识河图的五个主要区域。你不需要安装模型，也不需要接入 Agent。

## 打开工作台

进入[交互原型](/prototype/workbench.html)。左侧依次是小说、设定集、短剧、草稿审核与交付；中间是当前任务；顶部可以切换语言、保存演示修订。

原型中的“保存”只保存到当前页面，刷新或关闭后会重置。体验时使用演示文本，不要把它当作真实作品的保存工具。

## 完成一次写作与审核

1. 在“小说”中打开第一章，修改一句演示正文，点击“保存修订”。顶部修订号会更新。
2. 打开“设定集”，查看角色和地点。点击“解锁设定”再锁定，观察状态变化。
3. 打开“短剧”，查看分集大纲，点击“查看原著映射”回到对应正文。
4. 打开“草稿审核”，写下批注后点击“要求修改”。审阅时间线提示并勾选确认，再点击“通过定稿”。
5. 在确认窗口点击“确认通过”。进入“交付”，选择材料并预览交付清单。

```mermaid
flowchart LR
    A[阅读与写作] --> B[核对设定]
    B --> C[查看改编]
    C --> D[审核草稿]
    D --> E[预览交付]
```

## 记住三个区别

- **设定与候选**：只有作者确认的内容才能成为共同设定，推测要保留为待确认事项。
- **草稿与定稿**：保存正文不等于通过审核；“定稿”表达作者对某个具体版本的决定。
- **检查与判断**：提示帮助你找到证据，人物动机与文学表达由作者判断。
