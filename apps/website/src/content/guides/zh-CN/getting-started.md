# 快速入门

先用首页里的演示作品试一遍：打开书、写几句话、看看参考稿，再决定是否采纳。不需要安装软件，也不用准备 Codex。

## 1. 从书库打开一本书

点击[体验首页工作台](/#prototype)，在书库找到《雾川纪》，点击封面。

你会进入这本书的工作台，左侧可以切换章节、设定集和审核工作台。想换一本书时，点击“返回书库”。

![首页演示书库，点击作品封面进入工作台](/images/guides/quickstart-library-zh-CN.webp)

*首页演示截图。这里使用示例作品，不会读取你的本地小说。*

## 2. 写几句话，再保存

1. 点击左侧的章节，进入正文。
2. 在正文末尾追加一句，例如“他站在门前，迟迟没有敲门。”先保留演示原文，下一步还会用它比较参考稿。
3. 点击右上角“保存正文”。
4. 切到别的章节，再切回来，刚才的修改还在。

![首页演示写作台，左侧选章节，中间编辑正文，右上角保存](/images/guides/quickstart-writing-zh-CN.webp)

*首页演示截图。“保存正文”保留这次页面内修改；刷新页面会重置。*

## 3. 看参考稿，自己决定用不用

1. 点击左侧“审核工作台”，读一遍“建议替换片段”。
2. 在“审核批注”中试写一句修改意见，点击“要求修改”，看看状态变化。演示只记录意见，不会替你发送消息或生成新稿。
3. 觉得合适，就核对原文并勾选确认，再点击“通过审核”。这时正文还没有改变。
4. 点击“局部采纳到写作稿”，比较修改前后，确认后才把所选片段放进正文。

![首页演示审核工作台，比较参考片段并选择采纳](/images/guides/quickstart-review-zh-CN.webp)

*首页演示截图。审核通过、采纳到正文、作者定稿，是三个由你分别决定的步骤。*

需要保留为定稿时，回到正文点击“作者定稿”，核对内容后确认。以后继续修改，旧定稿仍会保留。

## 4. 在 Mac 版开始自己的书

已经打开 Mac 版时，可以按下面的步骤开始：

![Mac 版书库，右上角可以新建作品或加入已有作品](/images/guides/mac-library-zh-CN.webp)

*Mac 开发版实图，使用演示作品。点击图片可放大查看右上角“新建作品”。*

1. 在书库点击“新建作品”。
2. 填笔名、题材和简介。书名没想好也没关系，先在“创作想法与要求”里记下点子，再点击“保存筹备”。
3. 想好书名后，点击“创建小说”，选择自己保存作品的文件夹。
4. 打开章节开始写作，点击“保存修订”保存正文。

例如，你可以先写：“末世生存，女主带领社区重建，重点写物资分配与人与人的信任。”需要一起想书名和简介时，再看[用 Codex 构思一本新书](codex-first-task.md)。

Mac 版保存的是你的真实作品。首页演示仅供试用，刷新后重置，请不要把唯一的创作内容留在演示中。
