# Change a line. Know what to hear next.

Lin hides a key in the letter. The story can continue as prose, or pause for a song.

Lyrics bring more than a next line: what the verse develops, why the chorus returns, which word is difficult to sing and which version an old recording actually performs.

## Read the song, then revise a line

[Lyric Studio](/en/plugins/lyric-studio/) keeps sections, lines and performance order in one project. A repeated chorus refers to the same section while each appearance has its own identity. Use another section when the second chorus needs different words.

Tell your Agent about the character, scene and images to retain. It reads fixed sources and existing lyrics, then prepares alternatives with reasons. Return to read the whole song before choosing a line change.

## Counts, pronunciation and performance differ

A character count is not a syllable count or a guarantee that words fit a melody. Software checks explicit length limits and compares declared pronunciation and rhyme labels. Missing information stays unknown.

Add an actual recording to inspect real duration and waveform, then play and locate timed lines. Preserve original LRC and its timing convention. Repeated choruses align separately; timings are not invented from word counts. Format checks, listening coverage and artistic quality remain distinct.

## Keep the old recording meaningful

Using an alternative creates a new professional revision. Old recordings, original LRC and feedback remain. Changed lyrics flag old marks for review; saving new words does not automatically resolve feedback.

Deliver the complete review book and current valid LRC, then continue fixed lyrics and actual audio in [Audio Drama](/en/plugins/audio-drama/) or [Video Studio](/en/plugins/video-studio/). External tools create the performance. Hetu retains the project so the next iteration knows which line to continue.


## Use only what this work needs

Develop only what needs testing now. Sources, scripts and assets retain their revisions. Trying one scene needs no whole-book conversion; existing clips need not be generated again. State what changes and what remains before continuing.
