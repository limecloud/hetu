# From a key to a production sheet

A script says: “Lin hands the key to the station keeper.” Production still needs to know who receives it, whether they hold an umbrella, where the same key appears and which preparation remains unfinished.

[Production Planner](/en/plugins/production-planner/) keeps these questions in a reusable project. Tell your Agent the goal. It reads fixed sources and organizes scenes and requirements. Return to compare the plan with the script and identify omissions.

## Fixed rules and creative understanding

Scenes, cast, costumes, props, sound and tasks have explicit relationships. Software checks dependencies, batch capacity and declared estimates. Unknown values remain unknown; one key in two scenes does not mean buying two keys.

During acceptance, the first preparation omitted the station keeper and umbrella. The Agent reread the source, added both to the second scene and adjusted an overloaded batch. Prior revisions and original operation results remained available; video time and cost remained unknown.

## Continue after the handoff

Pass fixed preparation references to [Art Direction](/en/plugins/art-direction/), [Director Stage](/en/plugins/director-stage/) and [Video Studio](/en/plugins/video-studio/). Each package owns its professional results. Install what the work needs.

Append revised scripts, preview affected scenes and tasks, then reread. Byte changes identify material to revisit; they do not establish complete semantic impact. Export the complete offline package and continue the same project next time.

Preparation status, asset selection, cost authorization and final-film approval remain separate author decisions.


## Use only what this work needs

Develop only what needs testing now. Sources, scripts and assets retain their revisions. Trying one scene needs no whole-book conversion; existing clips need not be generated again. State what changes and what remains before continuing.
