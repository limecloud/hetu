# 河图洛书视频制作与审片接续

先读[任务合同](../../references/task-contract.md)，结合[本包题材方法](../../references/genre.md)中适用的故事约定。视频制作不默认新建小说或剧本。

基础分集、固定媒体、区间意见和文件交付使用随包宿主动作，无需额外河图插件；具体见[操作导航](../../references/workflows/video-operations.md#无额外插件的成果与意见)。专业制作方法仍按实际插件和外部工具发现。

读取当前公开 CLI/MCP 的实际能力和精确 WorkRef；已有项目及任务沿原引用恢复。无项目时使用已发现的独立筹备与视频创建入口，保存原键、管理引用及返回身份。构思和参数由你从对话整理，不让作者重新填表，也不让作者操作画布或三维工具。作者仅希望看方案时，不顺带调用付费模型。

## 选择流程

| 本次状态或目标 | 方法与起点 |
| --- | --- |
| 从构思、已有剧本或素材开始 | [全季推进](../../references/workflows/video-planning.md)区分输入状态；没有戏剧内容才转剧本Skill，不强制新建上游 |
| 已有制作工程、片段或未完成分集 | 先盘点实际版本、来源、费用回执及观看覆盖，再推进缺项；不能从文件名推断已选或已交付 |
| 分镜、资产、预演与代表性制作 | [制作工作法](../../references/workflows/video.md)选择能解决当前问题的材料，不给每镜强加白模或生成 |
| 根据意见局部返工 | 固定旧媒体、时间基准和意见，回到剧本／资产／预演／生成／剪辑的实际责任层，保留有效成果 |
| 查项目、维护分集或准备工程交付 | [操作导航](../../references/workflows/video-operations.md)区分宿主、专业插件及外部工具的真实动作和恢复 |

按视频制作工作法判断本轮缺的是戏剧内容、资产、时序／空间预演、真实生成、音画剪辑还是局部返工，只补影响当前交付的部分。需要 Seedance 2.5 时再读[模型方法](../../references/models/seedance-2-5.md)；其他模型按当前可用工具的确切型号和模式适配。

全季、分集与镜头计划分别保留预期；实际素材、播放区间、成片和交付分别回读事实。`video_episode_id`与剧本分集、镜头、提供方任务及媒体ID不能互换，估计时长不冒充实际流时长。专业插件数据不等于宿主正文或作者决定，不自造分镜、生成、剪辑与确认API。

河图接收可阅读、可播放的成果及固定来源，外部工具负责制作。已发布的动作不足以保存分镜、媒体、工程或意见时，报告缺失的准确环节，不直写受管文件、不拿参考图假装视频、不借 Computer Use 补业务接口。

在获权范围内连续工作，保留可接续工程和恢复记录。生成状态未知先查原计划与提供方任务；不能换键重付。采用、预演认可、成片确认及文稿定稿分别保留作者决定，不自批。

交付前通过公开入口回读项目、实际媒体及固定版本，完整解码并观看本轮声画；将技术核验与实际观看范围分别记录。软件端应能在对应分集连贯观看、比较和给出区间意见，统一资产库指向同一成果。最终保留必要的可编辑工程、依赖、来源、费用和作者意见，不扩大到发布或投放。
