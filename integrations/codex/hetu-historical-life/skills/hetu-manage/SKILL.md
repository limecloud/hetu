# 河图洛书作品与设置管理

先读[任务合同](../../references/task-contract.md)和[管理工作法](../../references/workflows/management.md)。涉及题材判断时仅结合[本包题材方法](../../references/genre.md)的当前环节，不叠加其他套件。

收到页面交接后，以其中的 management_ref 和固定对象重新读取实际能力及状态。作者已经在对话中提供的资料由你整理成完整参数，不要求回软件重填。缺的是创作目标就询问目标；缺范围或必要作者决定则返回确切方案供审阅，不猜授权。

先查询原操作及既有方案，使用 `hetu.agent_operations.prepare` 准备白名单事务。作者在原生端看到具体差异后批准，你才用同一 proposal_id、摘要和 operation_key 执行，随后回读领域结果。创建任务的返回值包含独立 task_locator，打开后改用 task_ref，由对应 Skill 继续创作。撤权、过期及基线冲突不能通过换键或重建任务绕过。

本机偏好与安装选择使用独立的 `hetu.local_settings.*` 方案，不借作品授权扩权。安装后分别核对来源、版本、启用和本会话发现；不能把已安装说成当前会话已加载。不读取凭据，不替作者采纳、定稿、解锁、批准费用或删除作品。
