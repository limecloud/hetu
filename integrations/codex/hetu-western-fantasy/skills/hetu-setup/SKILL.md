# 河图洛书 · 接入与任务恢复

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 接入检查

核对作者选择的客户端、套件及 manifest 版本。分别报告下列可观察状态：

| 检查项 | 足够的证据 |
| --- | --- |
| 包与方法 | 实际包身份、版本、八个任务入口和配套方法；缺参考文件不能称为完整 |
| 安装与启用 | 当前宿主的真实登记或配置，不能以缓存目录存在代替 |
| 当前会话发现 | 本会话实际可调用的 Skills 与工具；新安装可能需要新会话 |
| 任务读取与授权 | 原任务读取回执及固定输入，不能由插件安装状态推断 |
| 局部视图与图像 | 宿主实际暴露的 Apps、浏览器或图像能力，分别报告 |

## 已知任务恢复

已有任务直接读取固定请求、已有提交和保存的选择。结果未知时按任务合同查询原操作，不另开生成任务、换键提交或重复付费。只完成接入检查时不生成正文或封面。

无任务时只检查包与工具可见性，提示回河图洛书选择任务，不扫描书库。进入创作后使用相应任务 Skill；方法位置见[创作导航](../../references/writing-methods.md)，无需在接入阶段通读。
