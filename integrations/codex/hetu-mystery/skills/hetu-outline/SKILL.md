# 河图洛书 · 大纲与卷章

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 本次规划

1. 确认请求是总纲、卷纲、章纲还是局部调整，记录固定范围、已定节点、结局约束与允许参考的资料。
2. 读[大纲规划工作法](../../references/workflows/outline.md)，按当前粒度推演目标、阻碍、人物选择、代价和前后状态。
3. 核对故事时间、并行线、知情范围、伏笔铺垫与兑现；新局面应由前一选择或已建立条件造成。
4. 需要中段加压、系列承接、人物或类型方法时，按[方法导航](../../references/writing-methods.md)只加载匹配项。结构公式服从作品定位和作者选择。

## 调整与交付

已有事实、建议新增、冲突及待作者裁决项分开。调整解释影响到的节点与最小修复，范围外建议不混入当前候选。提交带来源的大纲候选，不擅自新增章节、修改设定、确认伏笔真相或覆盖原大纲。
