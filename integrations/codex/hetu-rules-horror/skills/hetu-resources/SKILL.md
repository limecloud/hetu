# 河图洛书资料整理

先按[统一执行模式](../../references/execution-modes.md)读取实际设置：默认auto直接处理当前工作区，confirm先读后集中确认本次写入。本规则优先于下文旧授权流程，任务引用继续用于定位、来源和恢复。

先读[任务合同](../../references/task-contract.md)，确认固定任务的 `resource_scope`；需要题材约束时只读[本包题材方法](../../references/genre.md)的相关部分。

用实际发现的 `hetu_list_resources` 和 `hetu_read_resource` 获取获权资料。固定参考与可改草稿分别处理；读取权限不代表可以修改。对既有资料保留来源、作者已确认的内容及不确定性，不把推测写成作品事实。

已有作品从精确管理引用读取当前 `work_ref`，列表明确提供该引用；准备 `resource_organize` 的固定任务方案，经作者决定后执行并打开返回的 task_locator。每次任务调用携带打开后完整 task_ref。任务会自动绑定新资料的作品归属；不按同目录、标题或旧 project_id 推断，不能迁移已有资料或读取未归属历史资料。

- `allow_create` 为真时，用 `hetu_create_resource` 新增资料草稿。
- 用 `hetu_update_resource` 连续维护本任务创建或明确获权的草稿；每次带最近回执的 `revision` 和 `sha256`，冲突后重新比较。
- 人物、地点、道具是资料分类；关联设定只引用已有实体的固定修订，不创建第二套正式设定。外部事实注明可核对的来源；虚构设计明确其候选性质。

有归属资料的实体关联使用同作品的 `work_ref,blueprint_id,blueprint_revision,blueprint_sha256,kind,entity_id`。从真实设定回执固定这些字段，不用相同修订号或同名人物代替身份。使用位置固定同作品正文版本，来源变化后保留旧引用并说明影响。

按本次整理目的选择有用的分类、名称和标签，不默认给每份资料填满模板。人物应便于写作时查身份、关系与表现；场景应便于查空间、出入口、时间与可见特征；考据应区分原始资料、摘录和作者自己的解释。

写入后回读真实记录，报告资料名称、修订与待作者决定的事项。未知结果沿原操作键和原输入恢复，不新建同义资料。没有可用的获权 MCP 或 CLI 时说明缺少的入口，不直接改 `resources/` 文件，不声称已保存。

资料任务直接维护未采用记录，不要求再交一份文字稿。采用、归档、正式设定、作者正文、素材选用和定稿由作者处理。
