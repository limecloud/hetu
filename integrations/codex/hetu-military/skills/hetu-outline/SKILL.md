# 河图洛书·军事 · 大纲与卷章

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

按任务指定粒度组织目标、人物选择、因果转折及伏笔回收，引用允许读取的设定与已定情节。把已有事实、建议新增与冲突点分开。调整时解释影响到的节点，提交大纲候选；不擅自新增章节、修改设定或覆盖原大纲。

同时读取 [军事题材方法](../../references/military.md)。检查行动时间线、信息传递、角色职责、后勤约束与损失后果；战斗段落必须推进人物或故事，不用连续胜利替代因果。
