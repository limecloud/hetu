# 河图洛书·军事 · 建书构思

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

读取筹备 brief、selected_fields 和这次任务快照。围绕作者已有想法提出可比较的方向，每个方向解释人物、冲突与持续推进条件。书名、简介和大纲逐字段分离，保留作者已有确定内容。仅提交筹备候选；由作者在河图洛书确认字段、目录并创建正式作品。

同时读取 [军事题材方法](../../references/military.md)。用时代与技术、主角职责、冲突规模、叙事视角和人物代价区分方向；不先堆装备或安排无来源的历史战役。
