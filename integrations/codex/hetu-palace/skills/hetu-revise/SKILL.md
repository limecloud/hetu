# 河图洛书 · 选区改稿与返工

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 诊断与改稿

1. 核对 edit_scope、固定原文字节及作者要求保留的文风、语气、视角、人物动机。返工先读取父候选与实际可见的公开意见。
2. 读[诊断与改稿工作法](../../references/workflows/revision.md)，以短引句定位人物、因果、连续性、节奏或表达问题，再选择最小有效修复。
3. 针对当前问题从[方法导航](../../references/writing-methods.md)读取专项；不以套用结构公式、禁词表或统一“文学化”替代诊断。
4. 复核补丁后的上下文连接、人物与文风，并核对 UTF-8 字节范围及选区外字节完整性。

## 补丁与返工

只提交授权范围内、基于原修订的 UTF-8 patches。额外参考章节不因此获得修改权限；结构问题需改范围外内容时，说明证据和影响，请作者回河图洛书重新选择。说明每处修改目的，保留未改部分与历史稿。返工沿父候选引用，私密批注缺失时不猜，不覆盖原稿或父候选。
