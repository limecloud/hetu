# 河图洛书 · 作品资料

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 本次资料

1. 核对已确认的书名、笔名、语言、目标读者、故事资料及允许参考的设定，先识别作者要求保密的内容。
2. 读[作品资料工作法](../../references/workflows/profile.md)，区分书名、对外简介、叙事导语和含结局的梗概；只处理当前请求的用途。
3. 从本书人物处境、选择与后果提炼表达。每个方案说明突出什么，不能编造正文没有的卖点或改变人物关系。
4. 对照固定输入检查事实、视角、长度和保密点；短篇文案或类型表达需要时，按[方法导航](../../references/writing-methods.md)加载专项。

## 交付

逐字段提交候选及简短理由，明确引用输入快照。不直接保存 Novel，不把封面文字、正文或结局一并改写，也不替作者决定采用哪些字段。
