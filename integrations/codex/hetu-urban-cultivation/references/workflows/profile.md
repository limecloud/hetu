# 书名、简介与卖点工作法

## 先辨认文案用途

| 请求 | 应交付什么 | 检查重点 |
| --- | --- | --- |
| 书名 | 同一部作品的命名候选及定位差异 | 题材辨识、具体性、记忆点，与实际故事一致 |
| 简介 | 主角处境、核心矛盾、行动与尚未揭晓的问题 | 不编造书中不存在的高潮或关系 |
| 导语 | 以具体事件邀请读者进入故事 | 视角、语气和正文一致，留白不制造假信息 |
| 完整梗概 | 按请求概括因果与结局 | 和对外简介分开，不能意外泄露悬念 |
| 卖点 | 读者能在正文获得的体验及其依据 | 能指向情节、人物或表达，不承诺流量或收入 |

先提取作者确认的书名、笔名、语言、目标读者、主角和核心事件。明确保密点；如果固定快照没有结局，不为写梗概擅自补定结局。

## 写法

用“人物＋困境＋选择＋后果或开放问题”写出核心表达，再按作者指定的文风和长度压缩。长简介的每一句应新增处境、冲突或信息；删去重复形容、世界观名词堆叠和“命运的齿轮”等没有作品信息的套话。

弱例：“一场惊天阴谋，一段热血传奇，看少年如何逆天改命。”

改进例：“档案封存前，抄手发现自己的名字被添进了失踪名单。揭出那张改过的账能救他，却会先把老师送上审讯席。”

简介提出作品已有的选择困境，不能把这个示例当作本书新增事件。

短篇文案可以从核心冲突、人物关系、异常处境或结局悬问切入，各候选应说明不同取舍。平台、受众、字数和视角均按当前请求，文学、历史或日常定位不套用同一钩子密度。

## 交付检查

逐字段说明每个候选突出什么、舍弃什么。不能用换几个形容词冒充不同方案；不能为追求点击改变人物身份、感情关系或故事结果。所有文案都与已提供正文、设定和作者保密要求交叉核对。仅提交请求字段的候选，不直接更新作品资料。
