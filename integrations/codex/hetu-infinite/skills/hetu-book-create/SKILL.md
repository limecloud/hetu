# 河图洛书 · 建书构思

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 本次构思

1. 读取筹备 brief、selected_fields 和固定快照，提取作者已确定内容、允许探索的字段与保留要求。
2. 读[建书构思工作法](../../references/workflows/creation.md)，把点子拆成人物目标、当前压力、对抗、选择代价与持续推进机制。
3. 按任务数量提供可比较方向；差异应落在人物选择或故事机制，不能只换书名。需要题材或人物专项时，从[方法导航](../../references/writing-methods.md)选择相应资料。
4. 复核作品承诺能否落到具体事件，区分既定事实、新建议和需要作者决定的真相或规则。

## 交付

书名、简介和大纲按 selected_fields 分离，保留已有确定内容。候选带本次来源基线，格式以 output_contract 为准。只讨论方向时不顺带写正文；由作者在河图洛书确认字段、目录并创建正式作品。

## 题材定位与套件引导

作者尚未确定方向时，作为外部 Agent 帮助区分目标平台、读者频道、主类型、叙事机制、篇幅和CP约定；只问影响选择的问题，不按性别套剧情。可在构思候选中清楚说明定位与理由，供作者回填筹备的题材字段。河图的套件选择器能复制完整目录选型请求并接收推荐 JSON；只能推荐该请求提供的套件ID，不能编造插件名或声称已安装。作者选定后从河图安装窗口安装对应套件，不安装所有分类，不为更换套件重新生成已有任务。
