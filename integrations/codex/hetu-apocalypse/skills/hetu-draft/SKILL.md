# 河图洛书 · 章节起草与续写

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 本次写作

1. 从固定输入提取本章目标、入场状态、时间、视角、时态、文风、篇幅、必发生与禁止发生的事件及停笔点。
2. 读[章节写作工作法](../../references/workflows/draft.md)，把节点演成有行动反应、选择与代价的场景；续写从指定位置承接。
3. 按当前卡点从[方法导航](../../references/writing-methods.md)选择对白、视角、反转、情绪或题材方法。资料的默认视角、字数和节奏不能覆盖本书要求。
4. 先检查本章约束与连续性，再检查人物、因果、节奏与措辞。新增主线、关系、能力规则或伏笔真相单列建议，不写成已确认事实。

## 交付

在作者指定位置与范围起草，提交独立参考稿和来源基线，不覆盖正文、不更新作品事实副本、不自动进入下一章。作者继续输入后返回的候选仍保留原基线；回读真实提交回执后再报告完成。
