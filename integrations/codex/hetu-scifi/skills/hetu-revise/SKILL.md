# 河图洛书 · 选区改稿与返工

## 本次是否需要保存

先找原稿、公开意见及明确保留要求，沿原任务和工作副本继续。只提供修改建议可以回答；实际返工固定必要修订，冲突列明，不静默扩大范围或改变已确定设定。

统一判断见[任务合同](../../references/task-contract.md#参与程度与停止条件)。


先按[统一执行模式](../../references/execution-modes.md)读取实际设置：默认auto直接处理当前工作区，confirm先读后集中确认本次写入。本规则优先于下文旧授权流程，任务引用继续用于定位、来源和恢复。

先读本包的 [任务合同](../../references/task-contract.md)，按固定任务和实际宿主能力继续。 已有任务先恢复阶段、固定成果及公开意见；返工沿原任务，完成后回读实际成果。长任务按[接续方法](../../references/task-contract.md#发现继续与恢复)记录未完成范围。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

## 诊断与改稿

1. 核对 edit_scope、固定原文字节及作者要求保留的文风、语气、视角、人物动机。返工先读取父候选与实际可见的公开意见；位置意见按固定成果或context来源的UTF-8范围核对原句，不转读最新稿，也不把来源意见当成资料修改权。
2. 读[诊断与改稿工作法](../../references/workflows/revision.md)，以短引句定位人物、因果、连续性、节奏或表达问题，再选择最小有效修复。
3. 针对当前问题从[方法导航](../../references/writing-methods.md)读取专项；不以套用结构公式、禁词表或统一“文学化”替代诊断。
4. 复核补丁后的上下文连接、人物与文风，并核对 UTF-8 字节范围及选区外字节完整性。

## 补丁与返工

只提交授权范围内、基于原修订的 UTF-8 patches。额外参考章节不因此获得修改权限；结构问题需改范围外内容时，准备包含证据、影响及确切范围的变更请求，作者确认后发布新请求修订，不要求重填任务资料。说明每处修改目的，保留未改部分与历史稿。返工沿父候选引用，私密批注缺失时不猜，不覆盖原稿或父候选。
