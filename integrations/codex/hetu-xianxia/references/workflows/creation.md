# 建书构思工作法

## 将点子变成方向

从任务快照提取作者已经确定的内容、希望探索的字段和禁止改变的要素。空白字段是可讨论空间，不表示可以另选题材、主角或阅读人群。信息不足以区分方向时，只问会改变本轮候选的关键问题；其他细节以建议或待定项保留。

对每个候选方向回答：

1. 谁在什么处境中，最迫切想得到或避免什么？
2. 为什么现在必须行动？外部阻力与人物自身的矛盾是什么？
3. 他能采取什么选择，各自失去什么？换一个人是否还会作出相同选择？
4. 首个情节单元如何改变局面，为什么还能继续产生故事？
5. 作品承诺哪种阅读体验，结局方向如何回应这个承诺？

需要人物细化时读[人物方法](../craft/characters.md)；核心问题不明确时读[结构与回收](../craft/structure.md)；长篇持续性不足时读[卷结构](../craft/structure.md)，只取适用的故事单元与期待链。

## 可比较的方向卡

候选数量服从任务。每个方向使用相同维度：一句话故事、主人公欲望与矛盾、首轮冲突、长期推进机制、情绪或悬念、与其他方向的具体差异、需要作者决定的新增设定。只请求书名时不顺带交整套人物与大纲；完整方向卡用于当前任务确实允许的构思内容。

弱例：“一个普通人在乱世成长，经历许多困难，最终成功。”

改进例：“负责保存地方档案的年轻抄手发现，登记为失踪的人仍在领取口粮。他要在档案移交前找出是谁改了账，而唯一能证明自己的副本会牵连庇护过他的老师。”

改进之处是目标、时限、对抗与个人代价可以生成事件；具体姓名、时代和真相仍由当前作品决定。

## 交付检查

- 核心卖点能落到人物行动，不能只有题材标签和宏大背景。
- 不同方向在人物选择、冲突机制或情绪兑现上存在差异，不能只换名称。
- 续作、穿越或系统等装置确实改变人物选择，并有作者可评估的限制。
- 书名、简介、大纲按 selected_fields 分开提交；已确认字段保留原值。
- 尚未决定的真相、结局或世界规则明确标为候选，不假装已确立。

提交筹备候选与本次来源基线。创建正式作品、选择目录和确认采用字段由作者在河图洛书完成。
