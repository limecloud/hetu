# 河图洛书作品与设置管理

先读[任务合同](../../references/task-contract.md)和[管理工作法](../../references/workflows/management.md)。涉及题材判断时仅结合[本包题材方法](../../references/genre.md)的当前环节，不叠加其他套件。

收到页面交接后，以其中的 management_ref 和固定对象重新读取实际能力及状态。作者已经在对话中提供的资料由你整理成完整参数，不要求回软件重填。缺的是创作目标就询问目标；缺范围或必要作者决定则返回确切方案供审阅，不猜授权。

当前对象使用完整 WorkRef 定位。设定、任务和稿件查询携带该引用，同根的小说、剧本和视频不共用设定或授权；旧项目缺自身设定时按管理工作法准备建立方案，不把原著内容直接复制过去。

整理已有作品前，按实际能力分页读取本作品正文目录和协作任务；目标明确时按目标文档查找，沿返回的 task_locator 打开已有任务。目录、历史和任务摘要的读取不授予正文直改或任务执行权；具体步骤见管理工作法，不因一次列表缺项重建。

关联作品先读取关系和确切历史，再准备更新依据、解除或恢复方案。两端作品身份不替换，旧任务和交付保持原引用；作品资料版本不是正文或媒体快照。仅持有来源权限不能替使用它的作品更改关联，读取另一端另行获权。

两端已分别获权时，按稳定入口的实际 Schema 用 related_management_ref 读取本次关联的另一端资料；不合并权限、不回写授权、不扩大为整根访问。未提供另一端授权时保持关系可见，不能猜测其当前状态。

先查询原操作及既有方案，使用 `hetu.agent_operations.prepare` 准备白名单事务。按该动作的决定合同批准后，用同一 proposal_id、摘要和 operation_key 执行，随后回读领域结果。整书原稿导入由[导入 Skill](../hetu-import/SKILL.md)依据当前会话真实指令登记固定范围，无需桌面逐批批准；不能将这项授权用于其他动作。创建任务的返回值包含独立 task_locator，打开后改用 task_ref，由对应 Skill 继续创作。撤权、过期及基线冲突不能通过换键或重建任务绕过。

本机偏好与安装选择使用独立的 `hetu.local_settings.*` 方案，不借作品授权扩权。安装后分别核对来源、版本、启用和本会话发现；不能把已安装说成当前会话已加载。凭据不进入作品或普通回读。采纳、定稿、解锁等按作者在当前会话的真实决定登记确切方案后执行；作品删除和模型费用分别遵循各自决定合同。不能将作者决定权实现为强制回桌面点击。

文稿版本显式固定 `work_ref`，先查本作品状态，再准备所选文稿快照。在当前会话展示完整差异与提交身份，作者决定后用 `hetu.git.record_snapshot_decision` 登记，再执行；沿原 `snapshot_id` 和原执行键回读未知结果。作品历史从独立空树开始，不能借此访问旧工作区、他作品、分支合并或网络同步。恢复历史内容时准备为参考稿，不直接 checkout 覆盖当前正文。

先发现 `hetu.agent_operations.catalog`，按返回的领域Schema准备方案。展示结果／差异后，依据真实用户指令调用 `record_decision`，再执行并回读；决定登记不执行领域变更。不要凭方案标题推断用户已认可内容，不能把另一版本的决定套到当前方案。

插件安装使用 `hetu.plugins.inspect/inspect_package/apply/get_operation`，固定包摘要、依赖影响及安装状态基线。作品数据授权另用 `hetu.plugin_access.*` 固定 WorkRef、包摘要、权限和类型，不因安装获得正文或其他作品权限。模型渠道使用 `hetu.model_settings.*`；密钥只经已授权私密输入交给本机存储，不在聊天、日志或普通回读重复展示。纯模型设置不执行付费生成。
