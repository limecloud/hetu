# 小说到短剧的改编工作法

## 核对原著与骨架

只使用本任务授权的原著引用、人物与已确认骨架。先列本轮场次各自来源、必须保留的事件或人物选择、允许压缩的部分及禁止改变的结果。骨架或关键来源缺失时说明具体缺口，不新建并自行确认另一版骨架。

按下方方法处理改编取舍，场次组织可参考[场景工艺](../craft/scenes.md)；本任务的可编辑剧本采用 Fountain，不把中文制片显示格式冒充交换语法。

## 将叙述转为戏

对每场回答：谁想取得什么、谁或什么阻止他、双方实际采取哪些行动、转折由何动作或揭示造成、离场时什么改变了。

| 原著材料 | 可采用的改编方向 |
| --- | --- |
| 长篇心理解释 | 通过选择、隐瞒、行动或关系中的反应表达；旁白仅在骨架和风格允许时使用 |
| 多处重复说明同一信息 | 合并为有冲突的一次行动，不合并会改变因果的独立事件 |
| 重要真相只在叙述中出现 | 设计来源明确的可见证据或交互，新增桥接需单独说明 |
| 群像与多线 | 保留本轮骨架需要的线，维持人物知情范围和场次间承接 |
| 段落结尾的悬念 | 转成具体动作、决定或信息差，不靠演员无法表演的抽象总结 |

弱例：“他意识到队友已经不再信任他，心中十分痛苦。”

改进方向：“他伸手索要记录本；队友把本子合上，交给另一个人。”这个动作只在原著关系与骨架支持时采用，不能凭方法新增背叛事实。

## Fountain 落笔

中文场景标题与人物名使用 Fountain 的显式标记，保持空行，例如：

~~~fountain
.INT. 值班室 - 夜

周岚把沾水的记录本放到桌上。

@周岚
最后一页是谁撕的？

@陈序
你先告诉我，为什么只剩你回来了。
~~~

动作写可见可听的当前事件；人物名稳定，必要括注简短，不把角色心理分析塞进动作。场景标题、对白、动作与章节结构服从河图当前输出合同；需要格式细则时读[Fountain 参考](../formats/fountain.md)。

## 改编检查

- 每场有明确功能，重复场景的再次出现改变人物关系或意义。
- 台词能体现人物目的与策略，信息不靠双方明知故问来交代。
- 核心结果、人物选择、物品和知情范围与来源及骨架相符。
- 新增桥接、压缩合并、视角变化与原著事实分开说明；超出固定骨架的结构建议不写成已采用。
- 场次可拍摄，地点、时长和人物规模与作者提供的制作限制匹配；没有预算资料就不编造成本。

交付独立 Fountain 候选及允许格式中的场次来源说明。不修改原著、不确认骨架、不替作者定稿或导出发布。
