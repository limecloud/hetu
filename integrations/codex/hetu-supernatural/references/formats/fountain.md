# 河图短剧 Fountain 参考

## 输入和输出边界

只填充固定原著与已确认骨架允许的场次，输出合同决定交付哪些场景与候选格式。骨架生成的结构初稿和 Agent 填充的动作、对白是不同产物；不改原著、不确认新骨架、不替作者定稿。

## 中文交换稿

Fountain 使用空行区分块。中文人物名用显式人物标记 `@`，不要依赖英语大写识别。内外景已知时使用 `INT.`、`EXT.` 或 `INT./EXT.`；需要强制识别场景标题时使用 `.`。例如：

```fountain
Title: 值班室

# 第1集

INT. 值班室 - NIGHT #1-1#

周岚把沾水的记录本放到桌上。

@周岚
最后一页是谁撕的？

@陈序
先告诉我，为什么只剩你回来了。
```

示例不是本书事实。场号只承载展示编号，稳定场景ID与来源引用由当前交付合同管理，不往正文擅加机器字段。

## 未知与制作显示

未知内外景可写强制场景标题 `.地点待补充 #1-1#`，未知日夜不猜为 `DAY` 或 `NIGHT`。这说明结构资料尚不完整，不能宣称已达到接收方的完整制片稿要求。

“1-1 日 内 值班室”可以是中文制片显示格式，不能代替任务指定的 Fountain 交换语法。人物、动作、对白、括注和场景标题各自成块；动作写可见可听的事件，括注不承载大段心理解释。

## 提交前检查

核对场次顺序、地点、人物名称、日夜、知情范围和原著来源；删去无法表演的创作分析。允许的新增桥接和压缩取舍留在说明中，不伪装成原著事实。未运行解析器时只报告文本检查，不声称已完成独立阅读器回环或导出排版验证。

语法出处：[Fountain 官方说明](https://fountain.io/syntax/)。河图兼容范围与当前输出合同优先于外部工具的扩展语法。
