# 河图洛书素材图

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

先读[任务合同](../../references/task-contract.md)，打开明确的 TaskLocator 并回读完整请求。`task_kind` 须为 `artwork`，输出合同须允许 `image`；小说封面使用 `hetu-cover`，资料文字整理使用 `hetu-resources`。缺少入口时报告缺口，不把角色图冒充封面或直接写受管记录。

作者已明确指定现有作品、尚无图片任务时，发现作品范围的 `hetu_preview_image_task` / `hetu_prepare_image_task`（CLI：`hetu.image_tasks.preview_prompt` / `hetu.image_tasks.prepare`），以 `task_kind: artwork` 准备固定任务；准备使用原预览的完整输入和操作键。该入口只建立图片参考任务，不授予正文修改、素材采用或费用批准权。随后使用返回的精确 task_ref 和 task_id，在该作品的任务连接中继续。稳定连接仍按已登记授权打开，不能把作品范围入口声称为整库授权。

根据任务批准的角色、场景或道具资料组织设计。区分已有设定与新增的外观提案，不为生图擅自改人物身份、时代或关系。不默认上传整书，按需读取固定参考。明确主体、服饰、构图、风格和避免项；只有作者要求时才在图片中生成文字。

作者选择河图图片服务时，读取[模型服务合同](../../references/model-service.md)。通过实际发现的 MCP／CLI 读取模型目录、准备单次固定计划、等待作者批准、提交并收集原结果。不得自批、换键重发或扩大数量；结果未知先查原计划。凭据由本机设置管理，不向任务传入密钥。

收集成功后，以工具返回的实际文件名、摘要及 `source_format: image` 调用 `hetu.creative_tasks.submit_result` 提交固定候选。沿用原 task_ref、请求摘要和操作键，记录真实模型与计划 ID。回读候选及图片预览，检查主体、比例、可解码性和明显缺陷；报告实际保存位置。参考图不等于已采用素材、人物设定或封面。

返工沿原任务读取公开意见，保留旧候选；下一次付费生成须单独批准，不把保存意见当成已开始生图。软件用于预览、比较及作者取舍，正常业务不靠 Computer Use 操作。
