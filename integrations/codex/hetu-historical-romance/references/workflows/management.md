# 作品与本机管理工作法

以当前安装版本公布的 Schema 为准。下面是用例导航，不是可跳过发现和授权的固定调用脚本。

## 连接与原操作

稳定连接只固定客户端。新作品沿独立筹备返回的 management_ref；已有作品使用作者在当前页面明确授予的作品引用，逐次携带完整 revision。不得枚举书库、猜目录或使用其他作品引用。页面交接中的对象与固定修订是本次目标，不默认处理全书。

读取原状态、填好领域输入、准备固定方案、返回供作者核对、获批执行、读取同一方案和最终领域对象。每个动作使用原键与原输入恢复。`executing` 表示副作用仍在确认；先回读方案和原操作，不换键重复导入、交付、提交或推送。

## 按目标发现动作

| 目标 | 读取与准备 |
| --- | --- |
| 书名、简介、卷章与大纲 | 读取 novels、documents、outlines，准备资料、结构、空章节或大纲方案。空章节不能夹带正文，正文改用创作任务。 |
| 人物、地点、规则 | 读取固定设定与引用，准备 typed_changes；锁定时请作者作解锁决定，不自动解锁。 |
| 剧情和短剧 | 读取固定剧情、骨架、场次和原著映射，准备剧情校正、骨架修改、项目、分集或空剧本。台词和动作走独立参考稿。 |
| 关联作品 | list／get 读取固定关系和历史，按使用依据的目标作品准备更新、解除或恢复方案；关联不授予另一端读取权。 |
| 资料与图片 | 资料维护走获权 resource_organize 任务；关联、素材权利声明及文件导入走固定方案。先 inspect，再固定摘要；不能把参考许可猜成可再分发。 |
| 问题意见 | 读取确切报告和 finding_id，可提交 findings.suggest；建议不改变正式处置，作者在问题页面取舍。 |
| 原稿导入 | 先 preview_import，解释可观察的格式损失，准备完整导入方案。执行使用审阅时固定的原文件字节，不替换为后来变化的外部文件。 |
| 导出交付 | 读取选定修订，preview_export 或 bundles.preview，准备完整方案；正式交付只用有效定稿。作者批准后执行并回读、校验产物。 |
| 快照 | 读取 HEAD 和变更，填写身份、说明及选集，按已有 snapshot 准备、独立批准和执行合同继续。 |
| 版本线与同步 | 读取 git.references、read_version 和 merge_preview，准备分支、合并或远端方案。fetch 固定远端提交；pull 合并已拉取的确切提交；push 只推送固定提交，不强制覆盖。冲突明确选本地或对方版本。 |

版本线切换及合并组织 Git 版本记录，保留当前正文、领域修订和未保存稿。作者要恢复历史内容时先读取确切 commit_id 与有界文件，比较后通过参考稿流程交付，不把历史 checkout 直接覆盖作品。远端仅用不含凭据的 HTTPS、SSH 或明确本地路径；私密信息和凭据不进入普通回读。

文件导入使用 `inline_source: {filename, base64, sha256}`：在当前 Agent 宿主已授权的文件范围内取得字节，再提交给河图；作品授权不会让河图代读任意本机 `file_path`。先检查或预览，再把相同内容交给固定方案。单文件原字节至多 8 MiB，方案和预览另受审阅传输预算约束；超出时拆分原稿或压缩参考图，不换成路径绕过限制。作者手动选择文件仍使用原生文件选择器。

## 作品与设定归属

先用当前获权 WorkRef 读取 `hetu.blueprints.get`，不要省略对象后读到旧根设定。新剧本／视频自带空设定；旧项目返回 `initialized=false` 时，发现并准备 `hetu.blueprints.initialize` 固定方案，供作者审阅。建立自身设定不授权读取原著，也不自动复制任何事实。

设定变更的 expected 使用回读的 `blueprint_id,revision,sha256`；人物或地点 ID 和修订号不能在不同作品间替换。任务的输入设定固定 `kind=blueprint,work_ref,blueprint_id,revision,sha256`，同时明确任务 work_ref 和目标文档。角色图片的 subject_refs 固定同一作品与设定身份，不能仅凭角色姓名关联。查询文档、参考稿和任务时使用 work_ref，沿已有目标恢复旧任务，不因列表缺项重建。

读取资料中的历史设定关联时，同时使用其 `blueprint_revision` 和 `blueprint_sha256`，交给 `hetu.blueprints.get` 的 `revision,sha256` 精确解析；不能只按修订号查当前设定。已知作品归属时一并传 work_ref，摘要不匹配则停止。精确授权无法读取旧关联时说明缺少的范围，不省略 work_ref 绕过授权。人物跨修订的身份以同一设定和实体 ID 判断，不能把其他作品中的同号人物合并。

同根权限仍按授权合同解释；精确单作品授权遇到其他来源或尚未支持对象范围的资料时，说明缺少的具体范围和能力，不改用整根引用绕过。作者稿、旧候选和报告保持原设定修订，更新设定只产生新的当前性判断，不重写历史。

## 固定依据与关联历史

关联使用完整 WorkRef；`hetu.work_links.get` 携带当前作品、link_id，查看旧关系另传 revision。回读 link、sha256 和 current_link_ref，先分清正在查看的历史与当前关系。`related_status=requires_authorization` 时不能读取另一端；unavailable 表示读取失败，不能解释为没有新版或没有关联。

`hetu.work_links.update_source` 固定当前 link_ref、同一来源的所选 WorkRevisionRef 和目标当前 WorkRevisionRef，经方案审阅后才推进关系。不能替换两端作品身份；要关联另一作品须新建关系。固定的作品资料修订只覆盖名称、简介和目录记录，章节、设定、素材和媒体仍须各自固定，不能说已经固定整本原著。

`hetu.work_links.set_archived` 由使用依据的目标作品准备方案：archived=true 解除，false 恢复。两种操作均保留旧关系修订、正文、任务和交付。恢复前核对已有有效关联，不能为绕过重复限制换键重建。旧关系可按 revision 继续回读；筛选已解除关系不会替作者恢复它。

单对象授权可读取本对象的关系元数据、准备解除或恢复；更新同根另一端的来源版本仍需要相应读取范围。缺跨根必要快照或精确双端授权能力时据实说明，不提交自报来源、任意 file_path 或整根授权代替合同。

## 本机设置与套件

读取 `hetu.local_settings.get` 得到白名单偏好、套件目录和实际受管安装客户端；设置某部作品的套件时携带确切 workspace_id。准备 preferences 或 agent_suite 方案，软件显示差异后由作者批准；execute 只执行这次固定内容。其他客户端可保存明确选择，受管安装以实际能力为准。

设置方案绑定本机偏好域、客户端、原值、套件指纹与期限。冲突时保留作者新设置，恢复只接续原意图，不把第三种值覆盖成旧计划。供应商密钥和私密模型配置由本机安全设置处理，不索取、不回读、不放进提示词。
