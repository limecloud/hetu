# 河图洛书素材图

先按[统一执行模式](../../references/execution-modes.md)读取实际设置：默认auto直接处理当前工作区，confirm先读后集中确认本次写入。本规则优先于下文旧授权流程，任务引用继续用于定位、来源和恢复。

创作时结合[本包题材方法](../../references/genre.md)中对应环节的增量；只使用作者已选题材，不从其他已安装套件拼接规则。

先读[任务合同](../../references/task-contract.md)，打开明确的 TaskLocator 并回读完整请求。`task_kind` 须为 `artwork`，输出合同须允许 `image`；小说封面使用 `hetu-cover`，资料文字整理使用 `hetu-resources`。缺少入口时报告缺口，不把角色图冒充封面或直接写受管记录。

作者已明确指定现有作品、尚无图片任务时，发现作品范围的 `hetu_preview_image_task` / `hetu_prepare_image_task`（CLI：`hetu.image_tasks.preview_prompt` / `hetu.image_tasks.prepare`），以 `task_kind: artwork` 准备固定任务；准备使用原预览的完整输入和操作键。该入口只建立图片参考任务，不授予正文修改、素材采用或费用批准权。随后使用返回的精确 task_ref 和 task_id，在该作品的任务连接中继续。稳定连接仍按已登记授权打开，不能把作品范围入口声称为整库授权。

根据任务批准的角色、场景或道具资料组织设计。区分已有设定与新增的外观提案，不为生图擅自改人物身份、时代或关系。不默认上传整书，按需读取固定参考。明确主体、服饰、构图、风格和避免项；只有作者要求时才在图片中生成文字。

人物形象图只关联一个角色，不用多人情节插图充当肖像。短剧制作按需要准备同一人物、同一服装的正面、侧面、背面与完整三视图；表情、服装及细节按具体制作需要补充，不默认批量下单。填写 `image_view: portrait|front|side|back|three_view|expression|detail`；主图用单人形象或正面，角色详情分人物形象、服装造型和相关插图。多人情节画面归 `illustration`，可关联多个参与者，但不会成为角色卡片主图。

模型仅支持文字生成图片时，可在明确批准的一次请求中生成同一人物的三视图原图，视觉核对后从原图无缩放裁切出各单人视图，原图及裁切图一同提交。记录原图 SHA、裁切像素范围与各文件摘要，不把裁切称为额外生成，也不隐瞒原图的多人重复视角。人物被截断、服装明显不一致或布局不符时保留并说明问题，不提交成合格三视图；不为修复自动追加收费请求。

作者选择河图图片服务时，读取[模型服务合同](../../references/model-service.md)。通过实际发现的 MCP／CLI 读取模型目录、准备固定计划，按当前对话中的真实授权登记任务额度。充分授权且未到上限时连续生成，不逐图停下来批准，也不要求回软件审批；达到上限在当前对话请求追加确认，余额不足提示充值。作者已充值时先查原计划，按未扣费失败恢复合同接续，未知结果禁止重发。不得扩大实际授权；凭据由本机设置管理，不向任务传入密钥。

收集成功后，按用途填写 `image_category`（character、scene、prop、illustration、costume、other）。用 `subject_refs` 明确关联：设定对象为 `{kind: entity, entity_ref, blueprint_revision}`，章节或剧本为 `{kind: document, document_id, revision_id}`。关联须包含在本候选的 source_ref_indices 所指固定资料中；人物同名、标题包含名字或整份设定作为参考，都不能替代明确关联。软件据此在对应角色、地点、章节及统一图片资产库展示同一候选。道具没有独立设定身份时关联其来源章节，并归入道具分类，不伪造对象 ID。

收集成功后，以工具返回的实际文件名、摘要及 `source_format: image` 调用 `hetu.creative_tasks.submit_result` 提交固定候选。沿用原 task_ref、请求摘要和操作键，记录真实模型与计划 ID。回读候选及图片预览，检查主体、比例、可解码性和明显缺陷；报告实际保存位置。参考图不等于已采用素材、人物设定或封面。

返工沿原任务读取公开意见，保留旧候选；下一次付费生成须单独批准，不把保存意见当成已开始生图。软件用于预览、比较及作者取舍，正常业务不靠 Computer Use 操作。
