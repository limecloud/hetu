# 内嵌 Agent 接入

把原生引擎嵌入现有工作台，围绕同一作品读取、创作、审阅和接续。引擎拥有推理及工具循环，河图拥有作品事实、固定修订、作者决定和确定性执行；不另建聊天专用作品库或内部 Agent。

## 先确定本次接入范围

读取根 `AGENTS.md`，以及 [10 会话与交互合同](../../../docs/10-原生客户端与交互设计.md#codex-会话工作面与设置)、[39 会话宿主](../../../docs/39-Electron与插件优先重构架构.md#43-agent-会话宿主)中与本次相关的小节。进度归 [38](../../../docs/38-创作工作台重构执行计划.md)，验收规则归 [19](../../../docs/19-测试策略与验收矩阵.md)。相对链接以本 Skill 目录为起点，命令以仓库根目录为工作目录。

先核对当前源码、实际安装的引擎版本及其公开协议：

- **只提供原生 CLI**：复用 `ProcessSession` 接真实 PTY。没有线程、模型发现或结构化消息能力时，按实际能力显示；不解析终端文字冒充这些能力。
- **提供结构化服务**：实现当前需要的适配，保留事件、投递、停止和恢复语义。GUI 的工具过程来自协议，作品成果来自 Core 回读。
- **同一引擎的 GUI/TUI**：只有原生协议支持安全共享时，才连接同一受管服务及确切线程。否则按现有独立进程恢复合同处理，不能暗中双启动。
- **不同引擎**：独立线程、认证和历史；共用的是河图的作品与任务，不伪装会话互通。

## 实施时保留的不变量

1. 会话身份、线程身份、作品 `WorkRef`、输入代次分别核对。异步读取、插入、尺寸更新和审批答复返回时，再检查当前归属；旧页面不能向新执行端投递。输入与待答请求代次沿既有会话记录持久化，启动执行端前推进并原子保存；只在内存递增会让桌面重启后旧代次重新有效。
2. 同一线程只有一个输入者。只读观察与写入/审批分开；切换在轮次边界转移，失败保留原表面及双方草稿。取消请求发出不代表实际停止。
3. `prepared/written/accepted/rejected/unknown` 分开保存。消息写进管道不等于引擎受理；未知结果查询原尝试及确切线程，不换消息身份重发。
4. 显示、隐藏、切换预览和全屏不销毁 PTY。终端客户端退出与引擎退出分别恢复；引擎还活着先恢复原连接，重建前确认旧执行端退出并释放占用。
5. 稳定机器连接与作品范围由既有 CLI/MCP 组装。临时讨论不创建作品，只读不创建任务，需保留时才保存；`auto/confirm` 复用共享执行策略，不在适配器重做审批。作品执行策略与引擎工具审批分别沿原设置核对，不以一种状态推断另一种。
6. 原生登录、首次信任和配置尚未就绪时，保存请求草稿并给原终端就绪后放入的入口。放入使用 bracketed paste，不追加 Enter；拒绝控制字符、超限和跨作品迟到插入。
7. 会话指令、协议事件、工具成功与模型说“已保存”均不构成作品事实。真实成果经固定引用回读 Core，才能显示可打开、可比较的成果；采纳与定稿另有确切决定。

## 交互应围绕作品

在现有主区创建并打开真实 PTY；引擎/模型按能力发现，不展示单一引擎专用空页面。作品选择、任务入口、正式目录和成果审阅复用已有服务。目录只显示正式文稿与资料，不暴露沙箱、中间脚本或私有授权文件。

终端采用全高工作面，常规宽度将标题、会话标签和工具合并为一行。极窄工作面优先保证标签与操作可读，按当前布局合同分行；判断依据是会话区实际宽度。左右栏独立折叠、调宽和恢复；最大化终端与系统全屏保持独立语义和原线程。具体几何取当前10文档及同版本实测，不把一次截图尺寸当所有平台常数。

GUI 保留真实消息和工具时间线、待答及错误、可核对上下文、Core成果链接和草稿。实现有界历史、稳定消息键、向上阅读不被流式输出拉走，以及返回后的阅读位置。输入法确认不触发发送；发送与滚动按共享偏好执行。

新增来源先找原领域的目录与历史读取，复用附加／发送前核验，不在会话内复制正文或创建另一套索引。读取目录与明确附加分别处理：读取可随时关闭，附加只保存确切引用；来源更新后仍读取原修订，无法核验时保留草稿并阻止投递。具体实现与反例见[上下文与来源选择](references/integration.md#上下文与来源选择)。

## 验证与交付

按 [验证方法](references/validation.md)选择与修改有关的协议、真实引擎、业务和包体测试。夹具只证明协议处理，启动 PTY只证明进程接入；两者都不能替代真实创作及 Core 保存回读。

在38记录本次实现和剩余条件，在20链接固定证据。分别报告源码、真实模型、业务回读、视觉、安装和平台覆盖；不能以测试总数或官网部署宣布完整实现。Skill 本身不授予提交、安装、发布、外发或付费调用权限，按当前会话已有授权执行。
